• 가중치 감쇠, 드롭아웃, 조기 종료, 데이터 증강, 레이블 스무딩, 앙상블의 원리와 구현을 설명할 수 있다.
  • 역드롭아웃의 배율 $1/(1-p)$와 학습·추론 모드의 차이를 설명하고 구현할 수 있다.
  • 조기 종료의 기준(검증 손실과 검증 정확도)이 결과를 어떻게 바꾸는지 설명할 수 있다.
  • 이중 하강 현상을 고전적 편향-분산 그림과 비교해 설명할 수 있다.
  • 잡음 섞인 작은 데이터에서 규제 기법들을 같은 조건으로 비교하고 결정 경계로 해석할 수 있다.

신경망의 과적합

신경망은 파라미터가 많아 학습 데이터를 거의 무엇이든 외울 수 있다. 2017년의 한 실험(Zhang 등)은 이미지의 레이블을 무작위로 섞어도 큰 신경망이 학습 정확도 100%에 도달함을 보였다. 외울 수 있는 능력이 이만큼 크므로, 학습 데이터가 적거나 레이블에 잡음이 있으면 과적합이 쉽게 일어난다(12일차). 오늘은 신경망에서 쓰는 규제 기법을 모아 보고, 같은 조건에서 비교한다.

가중치 감쇠

매 스텝 가중치를 일정 비율 줄이는 규제를 가중치 감쇠라 한다: $\mathbf w \leftarrow (1 - \eta\lambda)\mathbf w - \eta\nabla L$. SGD에서는 12일차의 L2 규제와 같고, Adam에서는 22일차의 AdamW처럼 갱신과 분리해서 적용한다. 가중치가 작으면 입력이 조금 바뀔 때 출력도 조금만 바뀌는 매끄러운 함수가 된다. 편향과 정규화 층의 $\gamma, \beta$에는 보통 적용하지 않는다.

$\eta = 0.003$, $\lambda = 1$이면 매 스텝 $(1 - 0.003)$배다. 기울기가 0이라면 1000스텝 뒤 $0.997^{1000} \approx e^{-3} \approx 0.05$배가 된다. 손실을 줄이는 데 꼭 필요한 가중치만 기울기에 의해 유지되고, 나머지는 0으로 줄어든다.

드롭아웃

드롭아웃(Srivastava 등, 2014)은 학습 중 매 스텝 은닉 뉴런의 출력을 확률 $p$로 0으로 만든다. 어떤 뉴런도 다른 특정 뉴런이 항상 있다고 기대할 수 없으므로, 각 뉴런이 혼자서도 쓸모 있는 특징을 배우게 된다.

역드롭아웃과 모드

뉴런의 절반을 끄면 다음 층이 받는 입력의 합이 평균적으로 절반이 된다. 추론 때(모두 켬)와 크기가 달라지는 것을 막기 위해, 학습 중 살아남은 출력을 $1/(1-p)$배 한다. 이를 역드롭아웃이라 하며, 기댓값이 그대로 유지된다.

$$h_{\text{학습}} = \frac{m\odot h}{1 - p},\quad m_j \sim \mathrm{Bernoulli}(1 - p);\qquad h_{\text{추론}} = h$$

$\mathbb E[m_jh_j/(1-p)] = (1-p)h_j/(1-p) = h_j$이다. 추론 때는 아무것도 하지 않으므로 학습/추론 모드를 반드시 구분해야 한다(21일차의 train()/eval()).

은닉 뉴런이 $n$개면 꺼짐 패턴은 $2^n$가지이고, 각 패턴이 하나의 부분망이다. 드롭아웃 학습은 가중치를 공유하는 $2^n$개의 부분망을 동시에 학습하는 것이고, 추론 때 전부 켜는 것은 그 부분망들의 평균을 근사한다. 앙상블을 거의 공짜로 얻는 셈이다.

보통 $p$는 완전연결층에서 0.1~0.5다. 합성곱 층과 배치 정규화가 있는 망에서는 덜 쓰고, 트랜스포머에서는 0.1 정도를 쓴다.

조기 종료

학습을 계속하면 학습 손실은 줄지만 검증 성능은 어느 순간부터 나빠진다(20일차). 검증 성능이 일정 기간(인내 기간, patience) 개선되지 않으면 멈추고, 가장 좋았던 시점의 가중치로 되돌리는 것을 조기 종료라 한다. 학습 길이 자체를 하이퍼파라미터로 보고 검증 세트로 고르는 셈이다.

레이블에 잡음이 있으면 검증 손실은 모델이 잡음 표본에 확신을 갖기 시작하는 이른 시점에 바닥을 찍을 수 있다. 이때 검증 손실로 멈추면 아직 덜 학습된 모델을 쓰게 된다. 최종 목표가 정확도라면 검증 정확도를 기준으로 하는 편이 나을 수 있다. 미니 프로젝트에서 두 기준을 비교한다.

데이터 증강

정답을 바꾸지 않는 변환으로 학습 데이터를 다양하게 만드는 것을 데이터 증강이라 한다. "이 정도 변화에는 답이 같아야 한다"는 사전 지식을 모델에 넣는 방법이다.

사진좌우 뒤집기, 무작위 자르기, 밝기·색 변화, 약한 회전숫자 6을 뒤집으면 9가 된다. 글자에는 뒤집기를 쓰지 않는다.

음성속도·높낮이 변화, 배경 잡음

증강은 매 에폭 새로 무작위로 적용한다. 같은 이미지라도 에폭마다 조금씩 다른 버전을 보므로, 사실상 데이터가 늘어난다. 34일차의 전이학습과 함께 이미지 분류에서 가장 효과가 큰 규제다. 증강은 학습 세트에만 쓰고 검증·테스트에는 쓰지 않는다.

레이블 스무딩

원-핫 정답 $(0, \dots, 1, \dots, 0)$으로 교차 엔트로피를 최소화하면 모델은 정답 로짓을 끝없이 키워 확률 1에 다가가려 한다. 지나친 확신은 일반화를 해친다. 레이블 스무딩은 정답을 조금 부드럽게 만든다.

$$y_k^{\text{LS}} = (1 - \epsilon)\,y_k + \frac{\epsilon}{K}$$

$\epsilon = 0.1$, $K = 10$이면 정답 클래스 0.91, 나머지 각 0.01이다. 그래디언트는 여전히 $\mathbf p - \mathbf y^{\text{LS}}$이므로 구현은 한 줄이다. 이미지 분류와 기계 번역에서 흔히 쓴다.

앙상블

여러 모델의 예측을 평균(분류는 확률 평균이나 투표)하는 것을 앙상블이라 한다. 모델마다 실수가 다르면 평균에서 서로 상쇄되어 분산이 줄어든다(12일차의 편향-분산). 같은 구조를 시드만 바꿔 여러 번 학습해도 효과가 있다. 대회에서 거의 항상 쓰는 방법이지만, 추론 비용이 모델 수만큼 늘어나 실서비스에서는 부담이 된다. 한 번의 학습 중 여러 시점의 가중치를 모아 쓰는 스냅숏 앙상블이나, 54일차의 지식 증류(큰 앙상블을 작은 모델 하나로 압축)가 대안이다.

이중 하강

12일차의 U자 그림에 따르면 모델을 계속 키우면 결국 과적합으로 검증 오차가 커진다. 그런데 현대 신경망에서는 모델을 학습 데이터를 정확히 외울 수 있는 크기(보간 임계점)보다 훨씬 크게 키우면 검증 오차가 다시 내려가는 현상이 관찰된다. 이를 이중 하강이라 한다(Belkin 등 2019, Nakkiran 등 2020).

직관적 설명은 이렇다. 겨우 외울 수 있는 크기에서는 데이터를 맞추는 해가 사실상 하나뿐이라 들쭉날쭉한 함수가 된다. 훨씬 큰 모델에서는 데이터를 맞추는 해가 무수히 많고, 경사하강법이 그중 매끄러운 해를 고르는 경향이 있다. 거대 신경망이 데이터보다 파라미터가 많아도 잘 일반화하는 이유의 일부로 연구되고 있다. 실무적 교훈은 "과적합이 보이면 모델을 줄이는 대신 규제를 강화하거나 데이터를 늘리는 것이 나을 때가 많다"는 것이다.

코드 실습: 드롭아웃 층과 레이블 스무딩

역드롭아웃 층을 구현하고, 학습 모드 출력의 평균이 입력과 같은지(기댓값 보존), 추론 모드가 아무것도 하지 않는지 확인한다.

import numpy as np
import math
import matplotlib.pyplot as plt
class Dropout:
    def __init__(self, p, seed=0):
        self.p, self.training, self.rng = p, True, np.random.default_rng(seed)
    def forward(self, X):
        if not self.training or self.p == 0:
            return X                                               # 추론: 그대로
        # 살아남으면 1/(1−p)
        self.mask = (self.rng.random(X.shape) >= self.p) / (1 - self.p)
        return X * self.mask
    def backward(self, G):
        # 같은 마스크로 기울기를 막고 키움
        return G * self.mask
drop = Dropout(0.5)
H = np.ones((10000, 8)) * 3.0
out = drop.forward(H)
print("학습 모드: 0인 비율 %.3f, 평균 %.3f (입력 3.0)" % ((out == 0).mean(),
                                                          out.mean()))
drop.training = False
print("추론 모드: 입력과 같은가?", np.array_equal(drop.forward(H), H))

레이블 스무딩 교차 엔트로피를 만들고, 같은 로짓에 대해 일반 교차 엔트로피와 비교한다. 정답 로짓을 계속 키우면 두 손실이 어떻게 달라지는지 본다.

def smooth_ce(Z, y, eps=0.1):
    K = Z.shape[1]
    Zs = Z - Z.max(1, keepdims=True)
    logP = Zs - np.log(np.exp(Zs).sum(1, keepdims=True))
    # (1−ε)·원-핫 + ε/K
    Y = np.full_like(Z, eps / K); Y[np.arange(len(y)), y] += 1 - eps
    loss = -(Y * logP).sum(1).mean()
    grad = (np.exp(logP) - Y) / len(y)
    return loss, grad
# 정답 로짓 − 나머지 로짓
margins = np.linspace(0, 15, 61)
ce0 = [smooth_ce(np.array([[m, 0, 0, 0, 0, 0, 0, 0, 0, 0.]]), np.array([0]),
                 eps=0.0)[0] for m in margins]
ce1 = [smooth_ce(np.array([[m, 0, 0, 0, 0, 0, 0, 0, 0, 0.]]), np.array([0]),
                 eps=0.1)[0] for m in margins]
plt.figure(figsize=(5.6, 3.2))
plt.plot(margins, ce0, label="일반 CE")
plt.plot(margins, ce1, label="레이블 스무딩 ε = 0.1")
plt.xlabel("정답 로짓의 우위")
plt.ylabel("손실")
plt.legend()
plt.grid(alpha=.3)
plt.show()
best_margin = margins[int(np.argmin(ce1))]
print("일반 CE 최소 위치: 우위 → ∞,  스무딩 CE 최소 위치: 우위 %.1f" % best_margin)

일반 교차 엔트로피는 정답 로짓의 우위가 커질수록 계속 줄어 끝없이 확신을 키우게 한다. 레이블 스무딩 손실은 유한한 우위(약 4.5)에서 최소가 되어, 그 이상 확신하면 오히려 손해다.

정리

  • 가중치 감쇠: 매 스텝 $(1 - \eta\lambda)$배. Adam에서는 분리형(AdamW).
  • 드롭아웃: 학습 중 확률 $p$로 끄고 $1/(1-p)$배(역드롭아웃), 추론 때는 그대로. 부분망 앙상블.
  • 조기 종료: 검증 기준의 최고 시점 가중치. 잡음 레이블에서는 기준 선택이 중요.
  • 데이터 증강: 정답을 보존하는 무작위 변환. 학습 세트에만, 에폭마다 새로.
  • 레이블 스무딩은 과신을, 앙상블은 분산을 줄인다. 거대 모델에서는 이중 하강이 관찰된다.

확인 문제

연습 문제

  1. 드롭아웃을 역드롭아웃이 아닌 방식(학습 때 배율 없음)으로 구현하면 추론 때 무엇을 해야 하는가?
    풀이

    학습 때 출력의 기댓값이 $(1-p)h$이므로 추론 때 모든 출력에 $(1-p)$를 곱해야 한다. 원래 논문의 방식이다. 역드롭아웃은 이 곱셈을 학습 쪽으로 옮겨 추론 코드를 단순하게 만든다.

  2. $\epsilon$으로 스무딩한 레이블에서 교차 엔트로피가 최소가 되는 예측 분포는 무엇인가? 그때의 손실은 0인가?
    풀이

    교차 엔트로피 $H(\mathbf y^{\text{LS}}, \mathbf p)$는 $\mathbf p = \mathbf y^{\text{LS}}$에서 최소이고 그 값은 엔트로피 $H(\mathbf y^{\text{LS}}) > 0$이다(6일차). 정답 0.91, 나머지 0.01인 분포를 내도록 학습되므로 로짓 우위는 $\ln(0.91/0.01) \approx 4.5$에서 멈춘다. 코드 실습에서 찾은 최소 위치와 같다.

  3. 학습 1000스텝, 학습률 0.003, 가중치 감쇠 $\lambda$에서 기울기가 0인 가중치가 처음의 10%로 줄어들려면 $\lambda$는 얼마여야 하는가?
    풀이

    $(1 - 0.003\lambda)^{1000} \approx e^{-3\lambda} = 0.1$에서 $\lambda = \ln10/3 \approx 0.77$.

미니 프로젝트: 규제 기법 비교

레이블의 10%가 뒤집힌 "두 개의 달" 데이터 100개로, 과적합하기 쉬운 큰 MLP(2 → 128 → 128 → 1)를 학습시킨다. 같은 구조와 옵티마이저(Adam, 1000에폭)에서 규제 기법만 바꿔 학습·테스트 정확도와 결정 경계를 비교한다. 테스트 데이터 2000개는 잡음 없이 만든다. 학습을 14번 하므로 수십 초 걸린다.

  1. 데이터와 모델. 학습 100개(잡음 레이블 10%), 검증 200개(같은 잡음), 테스트 2000개(잡음 없음)를 만든다. 순전파·역전파·Adam 갱신을 하나의 학습 함수에 담고, 규제 옵션을 인자로 받는다. 
    def moons(n, seed, noise=0.25, flip=0.1):
    r = np.random.default_rng(seed); c = np.arange(n) % 2; t = r.random(n) * np.pi
    X = np.where(c[:, None] == 0, np.c_[np.cos(t), np.sin(t)],
                 np.c_[1 - np.cos(t), 0.5 - np.sin(t)])
    X = (X - [0.5, 0.25]) * 2 + r.normal(0, noise, (n, 2)); yv = c.copy()
    if flip:
        f = r.random(n) < flip; yv[f] = 1 - yv[f]                  # 레이블 잡음
    return X, yv
Xtr, ytr = moons(100, 2)
Xva, yva = moons(200, 7)
Xte, yte = moons(2000, 99, flip=0.0)
def logits(Ws, bs, X):
    Z = X
    for l in range(3):
        Z = Z @ Ws[l] + bs[l]
        if l < 2: Z = np.maximum(0, Z)
    return Z[:, 0]
def bce(Ws, bs, X, yv):
    z = logits(Ws, bs, X)
    return np.mean(np.logaddexp(0, z) - yv * z)
def acc(Ws, bs, X, yv): return ((logits(Ws, bs, X) > 0) == yv).mean()
def train(drop=0.0, wd=0.0, noise=0.0, early=None, seed=1, epochs=1000, lr=3e-3):
    r = np.random.default_rng(seed); sizes = [2, 128, 128, 1]
    Ws = [r.normal(0, math.sqrt(2 / a), (a, b)) for a, b in zip(sizes[:-1],
                                                                sizes[1:])]
    bs = [np.zeros(b) for b in sizes[1:]]
    m = [np.zeros_like(x) for x in Ws + bs]; v = [np.zeros_like(x) for x in Ws + bs]
    best = (np.inf, None, 0)
    for t in range(1, epochs + 1):
        # 입력 잡음 증강
        A = Xtr + (r.normal(0, noise, Xtr.shape) if noise else 0)
        As, masks = [A], []
        for l in range(3):
            Z = As[-1] @ Ws[l] + bs[l]
            if l < 2:
                # ReLU 마스크
                mk = (Z > 0).astype(float)
                # 역드롭아웃
                if drop: mk = mk * (r.random(Z.shape) >= drop) / (1 - drop)
                masks.append(mk); Z = Z * mk
            As.append(Z)
        p = 1 / (1 + np.exp(-As[-1][:, 0]))
        G = ((p - ytr) / len(ytr))[:, None]
        grads = [None] * 6
        for l in range(2, -1, -1):
            grads[l] = As[l].T @ G; grads[3 + l] = G.sum(0)
            if l > 0: G = (G @ Ws[l].T) * masks[l - 1]
        for k, (pp, g) in enumerate(zip(Ws + bs, grads)):
            m[k] = 0.9 * m[k] + 0.1 * g; v[k] = 0.999 * v[k] + 0.001 * g * g
            step = (m[k] / (1 - 0.9 ** t)) / (np.sqrt(v[k] / (1 - 0.999 ** t)) + 1e-8)
            # 분리형 감쇠 (가중치만)
            pp -= lr * (step + (wd * pp if k < 3 else 0))
        if early:
            score = bce(Ws, bs, Xva, yva) if early == "손실" else -acc(Ws, bs, Xva,
                                                                       yva)
            if score < best[0]: best = (score, [x.copy() for x in Ws + bs], t)
    if early: Ws, bs = best[1][:3], best[1][3:]
    return Ws, bs, best[2]
print("준비 완료")

참고 답안과 해설
  • 2단계: 기준 모델은 학습 정확도 1.0으로 잡음 레이블까지 모두 외우며, 잡음 점 주위를 감싸는 섬 같은 경계를 만든다(테스트 약 93%). 드롭아웃(약 96%)과 입력 잡음 증강(약 96%)이 경계를 가장 매끄럽게 만들고 테스트 정확도를 가장 크게 올린다. 학습 정확도는 0.95~0.97로 떨어지는데, 잡음 레이블을 외우지 않았다는 뜻이므로 좋은 신호다. 가중치 감쇠 1.0도 효과가 있다(약 95%). 감쇠를 0.01 정도로 약하게 하면 효과가 거의 없다.
  • 조기 종료는 기준에 따라 결과가 크게 다르다. 검증 정확도 기준은 약 120에폭의 가중치를 골라 약 96.5%를 얻는다. 검증 손실 기준은 수십 에폭 만에 멈춘다. 잡음 레이블 때문에 검증 손실이 일찍 바닥을 찍기 때문이며, 그 모델은 덜 학습되어 약 91%다.
  • 3단계: 앙상블은 개별 모델 평균보다 조금 낫지만(약 +0.3%p), 각 모델이 모두 같은 방식으로 잡음을 외우므로 효과가 제한적이다. 서로 다른 규제나 구조를 섞으면 효과가 커진다.
  • 테스트 BCE를 보면 차이가 더 분명하다. 기준 모델은 잡음 점 근처에서 틀린 쪽으로 확신해 BCE가 크다. 규제는 정확도보다 확률의 품질(보정)을 더 크게 개선하는 경우가 많다.
