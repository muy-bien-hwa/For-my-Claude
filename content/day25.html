• 배치 정규화의 학습 모드와 추론 모드 계산을 쓰고 그 차이를 설명할 수 있다.
  • 배치 정규화의 역전파 공식을 유도하고 구현해 기울기 검증을 통과시킬 수 있다.
  • 배치 정규화, 층 정규화, 그룹 정규화, RMSNorm이 어느 축으로 정규화하는지 구별할 수 있다.
  • 정규화 층이 깊은 망의 학습을 가능하게 하고 큰 학습률을 허용함을 실험으로 확인할 수 있다.

왜 층 사이를 정규화하는가

9일차에서 입력 특징을 표준화하면 손실 지형이 둥글어져 학습이 빨라졌다. 은닉층의 입력은 앞 층의 출력이라 학습하는 동안 분포가 계속 바뀐다. 24일차에서 본 대로 초기화가 조금만 어긋나도 층을 지날수록 값이 사라지거나 폭발한다. 그렇다면 층마다 활성값을 다시 표준화하면 어떨까? 이것이 정규화 층의 아이디어다.

원래 논문(Ioffe & Szegedy, 2015)은 "앞 층이 바뀌어 다음 층 입력의 분포가 흔들리는 현상"을 줄인다고 설명했다. 이후 연구는 정규화 층이 손실 지형을 매끄럽게 만들어 더 큰 학습률을 안정적으로 쓰게 해 준다는 설명이 더 정확하다고 본다. 이유가 무엇이든 효과는 분명하다. 깊은 망이 초기화에 덜 민감해지고, 더 큰 학습률로 더 빨리 학습된다.

배치 정규화

배치 정규화(BatchNorm)는 미니배치 안에서 특징(열)마다 평균과 분산을 구해 표준화한 뒤, 학습 가능한 배율 $\gamma$와 이동 $\beta$를 적용한다. 입력 $X$가 $(N, d)$일 때 특징 $j$마다

$$\mu_j = \frac1N\sum_i X_{ij},\qquad \sigma_j^2 = \frac1N\sum_i(X_{ij} - \mu_j)^2,\qquad \hat X_{ij} = \frac{X_{ij} - \mu_j}{\sqrt{\sigma_j^2 + \epsilon}},\qquad Y_{ij} = \gamma_j\hat X_{ij} + \beta_j$$

$\epsilon$(예: $10^{-5}$)은 분산이 0일 때 나누기를 막는다. $\gamma$와 $\beta$가 없다면 모든 특징이 강제로 평균 0, 분산 1이 되어 표현력이 제한된다. $\gamma = \sigma$, $\beta = \mu$로 학습되면 정규화를 완전히 되돌릴 수도 있으므로, 정규화는 "기본값"을 정할 뿐 표현력을 빼앗지 않는다.

값 $(2, 4, 6, 8)$. $\mu = 5$, $\sigma^2 = (9 + 1 + 1 + 9)/4 = 5$, $\sigma \approx 2.236$. $\hat x = (-1.342, -0.447, 0.447, 1.342)$. $\gamma = 2$, $\beta = 1$이면 $y = (-1.683, 0.106, 1.894, 3.683)$. 9일차의 표준화와 같은 계산을 층 안에서, 배치마다 하는 것이다.

학습 모드와 추론 모드

추론할 때는 표본이 하나만 들어올 수도 있고, 같은 입력의 예측이 함께 들어온 다른 표본에 따라 달라져서도 안 된다. 그래서 배치 정규화는 학습 중에 배치 통계의 지수 이동 평균(22일차)을 따로 기록해 두었다가 추론에서는 그 값을 쓴다.

$$\mu_{\text{run}} \leftarrow (1 - m)\,\mu_{\text{run}} + m\,\mu_B,\qquad \sigma^2_{\text{run}} \leftarrow (1 - m)\,\sigma^2_{\text{run}} + m\,\sigma_B^2 \qquad (m = 0.1)$$
  • 평가할 때 추론 모드로 바꾸지 않는다. PyTorch에서는 model.eval()을 빠뜨리면 평가 결과가 배치 구성에 따라 흔들린다. 다시 학습할 때는 model.train().
  • 배치가 너무 작다(2~8). 배치 통계가 불안정해 학습이 나빠진다. 그룹 정규화나 층 정규화를 쓴다.
  • 학습 데이터와 분포가 다른 데이터로 추론하면 저장된 통계가 맞지 않는다.

배치 정규화의 역전파

$\gamma$, $\beta$의 기울기는 선형층과 같은 방식이다. $G = \partial L/\partial Y$일 때 $\partial L/\partial\gamma_j = \sum_i G_{ij}\hat X_{ij}$, $\partial L/\partial\beta_j = \sum_i G_{ij}$. 까다로운 것은 입력의 기울기다. $\mu$와 $\sigma$가 배치의 모든 표본으로 계산되므로, 표본 하나를 바꾸면 모든 표본의 출력이 바뀐다(18일차의 분기 규칙). 이를 정리하면 특징마다 다음 식이 된다($g_i = \gamma G_i$로 둔다).

$$\frac{\partial L}{\partial X_i} = \frac{1}{N\sqrt{\sigma^2 + \epsilon}}\left(N g_i - \sum_k g_k - \hat X_i\sum_k g_k\hat X_k\right)$$

세 항의 의미: 첫째는 자기 자신을 통한 직접 경로, 둘째는 평균 $\mu$를 통한 경로(모든 표본의 기울기 합을 뺀다), 셋째는 분산 $\sigma^2$을 통한 경로다. 결과적으로 입력 기울기는 표본 방향으로 평균이 0이고 $\hat X$와 직교한다. 정규화가 "평균 이동"과 "크기 변화"를 지워 버리므로, 그 방향으로는 기울기가 흐르지 않는 것이다. 미니 프로젝트에서 구현하고 수치 미분으로 검증한다.

층 정규화와 정규화 축

배치 정규화는 배치 축으로 평균을 낸다. 그래서 배치 크기에 의존하고, 문장 길이가 제각각인 시퀀스 모델에서는 쓰기 어렵다. 층 정규화(LayerNorm, Ba 등, 2016)는 표본 하나 안에서 모든 특징의 평균과 분산으로 정규화한다. 배치 크기와 무관하고, 학습과 추론의 계산이 같다. 트랜스포머와 RNN의 표준이다.

방법평균을 내는 축주된 쓰임
배치 정규화배치 (+ 공간)CNN (배치가 충분히 클 때)
층 정규화특징 (+ 공간)트랜스포머, RNN
그룹 정규화특징 묶음 (+ 공간)배치가 작은 CNN (검출, 분할)
RMSNorm특징 (평균 빼기 없음)최신 대형 언어 모델

그룹 정규화와 RMSNorm

그룹 정규화(Wu & He, 2018)는 채널을 몇 개의 묶음으로 나눠 묶음마다 층 정규화를 한다. 묶음이 1개면 층 정규화, 묶음 수가 채널 수와 같으면 채널마다 따로 정규화하는 인스턴스 정규화가 된다. 고해상도 이미지라 배치를 2~4장밖에 못 넣는 객체 검출에서 배치 정규화 대신 쓴다.

RMSNorm(Zhang & Sennrich, 2019)은 층 정규화에서 평균을 빼는 단계를 생략하고 제곱평균제곱근으로만 나눈다.

$$\mathrm{RMSNorm}(\mathbf x) = \frac{\mathbf x}{\sqrt{\frac1d\sum_j x_j^2 + \epsilon}}\odot\mathbf g$$

계산이 조금 싸고 성능은 비슷해 LLaMA 같은 최신 언어 모델이 쓴다.

정규화 층을 어디에 둘까

  • CNN과 MLP의 고전적 배치: 선형(합성곱) → 배치 정규화 → ReLU. 정규화가 평균을 빼므로 바로 앞 선형층의 편향 $\mathbf b$는 쓸모가 없어 보통 뺀다(bias=False).
  • 트랜스포머: 각 하위 층 앞에 층 정규화를 두는 Pre-LN 구조가 현재 표준이다(44일차).
  • 정규화 층의 $\gamma$, $\beta$에는 보통 가중치 감쇠를 적용하지 않는다.

코드 실습: 정규화 층의 순전파

배치 정규화와 층 정규화의 순전파를 구현하고, 정규화 후 어느 축으로 평균 0, 분산 1이 되는지 확인한다.

import numpy as np
import math
import matplotlib.pyplot as plt
rng = np.random.default_rng(0)
# 특징마다 다른 규모
X = rng.normal(size=(8,
                     5)) * np.array([1, 10, 0.1, 5, 2]) + np.array([0, 50, -3, 7, 1])
def batchnorm_forward(X, gamma, beta, eps=1e-5):
    # 특징(열)마다, 배치 방향으로
    mu, var = X.mean(axis=0), X.var(axis=0)
    return gamma * (X - mu) / np.sqrt(var + eps) + beta
def layernorm_forward(X, gamma, beta, eps=1e-5):
    # 표본(행)마다
    mu = X.mean(axis=1, keepdims=True); var = X.var(axis=1, keepdims=True)
    return gamma * (X - mu) / np.sqrt(var + eps) + beta
def rmsnorm_forward(X, g, eps=1e-5):
    return X / np.sqrt((X ** 2).mean(axis=1, keepdims=True) + eps) * g
ones, zeros = np.ones(5), np.zeros(5)
Yb = batchnorm_forward(X, ones, zeros)
Yl = layernorm_forward(X, ones, zeros)
Yr = rmsnorm_forward(X, ones)
print("배치 정규화: 열 평균", Yb.mean(0).round(6), " 열 표준편차", Yb.std(0).round(3))
print("층 정규화:   행 평균", Yl.mean(1).round(6)[:4], " 행 표준편차",
      Yl.std(1).round(3)[:4])
print("RMSNorm:     행 제곱평균", (Yr ** 2).mean(1).round(3)[:4], " 행 평균(0 아님)",
      Yr.mean(1).round(3)[:4])
print("예제 (2, 4, 6, 8), γ=2, β=1:",
      batchnorm_forward(np.array([[2.], [4.], [6.], [8.]]), 2, 1).ravel().round(3))

배치 정규화는 같은 입력도 함께 들어온 배치에 따라 다른 출력을 낸다. 확인해 본다.

x0 = X[:1]                                                  # 첫 표본
other1, other2 = X[1:4], rng.normal(size=(3, 5)) * 30
out_a = batchnorm_forward(np.vstack([x0, other1]), ones, zeros)[0]
out_b = batchnorm_forward(np.vstack([x0, other2]), ones, zeros)[0]
print("같은 표본, 다른 배치에서의 배치 정규화 출력:\n", out_a.round(3), "\n",
      out_b.round(3))
print("층 정규화는 배치와 무관:",
      np.allclose(layernorm_forward(x0, ones, zeros),
                  layernorm_forward(X, ones, zeros)[:1]))

정리

  • 배치 정규화: 특징마다 배치 평균·분산으로 표준화 후 $\gamma\hat x + \beta$. 학습은 배치 통계, 추론은 이동 평균 통계.
  • 역전파: 평균과 분산을 통한 경로까지 포함한 세 항. 입력 기울기는 배치 방향 평균 0.
  • 층 정규화는 표본 안의 특징으로 정규화(배치 무관, 트랜스포머 표준). 그룹 정규화는 특징 묶음, RMSNorm은 평균 빼기 생략.
  • 효과: 깊은 망을 초기화에 덜 민감하게 하고 큰 학습률을 허용한다.
  • 주의: 평가 때 model.eval(), 작은 배치에는 배치 정규화를 피한다.

확인 문제

연습 문제

  1. 배치 $(1, 2, 3)$에 대한 배치 정규화($\gamma = 1, \beta = 0$, $\epsilon = 0$) 출력을 구하라. 같은 표본 1이 배치 $(1, 10, 20)$에 들어가면 출력은?
    풀이

    $(1, 2, 3)$: $\mu = 2$, $\sigma = \sqrt{2/3} = 0.816$, 출력 $(-1.225, 0, 1.225)$. $(1, 10, 20)$: $\mu = 10.33$, $\sigma = 7.76$, 표본 1의 출력 $-1.203$. 같은 값이 배치에 따라 다른 출력을 낸다.

  2. 배치 정규화 입력 기울기 공식에서 $\sum_i\partial L/\partial X_i = 0$임을 보여라.
    풀이

    $\sum_i(Ng_i - \sum_kg_k - \hat X_i\sum_kg_k\hat X_k) = N\sum g - N\sum g - (\sum_i\hat X_i)(\sum_kg_k\hat X_k) = 0$. 마지막은 $\sum_i\hat X_i = 0$(표준화했으므로)이기 때문이다.

  3. 입력 차원 512인 층 정규화와 RMSNorm의 학습 파라미터 수는 각각 몇 개인가?
    풀이

    층 정규화는 $\gamma$, $\beta$ 각 512개로 1024개. RMSNorm은 $\mathbf g$ 512개(이동 없음).

미니 프로젝트: 배치 정규화 구현과 검증

배치 정규화 층을 21일차 프레임워크 형식(forward, backward, params, 학습/추론 모드)으로 구현하고 수치 미분으로 검증한다. 이어서 24일차에 학습되지 않던 10층 시그모이드 MLP와 느리던 ReLU MLP에 넣어, 정규화 층이 학습을 가능하게 하고 큰 학습률을 허용하는지 확인한다. 학습을 8번 하므로 수십 초 걸린다.

  1. BatchNorm 층. 학습 모드에서는 배치 통계를 쓰고 이동 평균을 갱신한다. 추론 모드에서는 이동 평균을 쓴다. 
    class BatchNorm:
    def __init__(self, d, momentum=0.1, eps=1e-5):
        self.gamma, self.beta = np.ones(d), np.zeros(d)
        self.dgamma, self.dbeta = np.zeros(d), np.zeros(d)
        self.run_mean, self.run_var = np.zeros(d), np.ones(d)
        self.m, self.eps, self.training = momentum, eps, True
    def forward(self, X):
        if self.training:
            mu, var = X.mean(0), X.var(0)
            # TODO 확인: 이동 평균
            self.run_mean = (1 - self.m) * self.run_mean + self.m * mu
            self.run_var = (1 - self.m) * self.run_var + self.m * var
        else:
            mu, var = self.run_mean, self.run_var
        self.std = np.sqrt(var + self.eps); self.xhat = (X - mu) / self.std
        return self.gamma * self.xhat + self.beta
    def backward(self, G):
        self.dgamma[...] = (G * self.xhat).sum(0); self.dbeta[...] = G.sum(0)
        g = G * self.gamma; N = len(G)
        # TODO 확인: 입력에 대한 기울기(세 항)
        dX = N * g - g.sum(0) - self.xhat * (g * self.xhat).sum(0)
        return dX / (N * self.std)
    def params(self): return [(self.gamma, self.dgamma), (self.beta, self.dbeta)]
print("BatchNorm 준비 완료")

    return out

class Linear:
    def __init__(self, a, b, r):
        self.W = r.normal(0, math.sqrt(1 / a), (a, b)); self.b = np.zeros(b)
        self.dW, self.db = np.zeros_like(self.W), np.zeros(b); self.training = True
    def forward(self, X):
        self.X = X; return X @ self.W + self.b
    def backward(self, G):
        self.dW[...] = self.X.T @ G; self.db[...] = G.sum(0); return G @ self.W.T
    def params(self): return [(self.W, self.dW), (self.b, self.db)]

    def __init__(self, kind): self.kind, self.training = kind, True

        return self.o

        return G * (self.o * (1 - self.o) if self.kind == "sigmoid" else (self.o > 0))
    def params(self): return []

    r = np.random.default_rng(seed); layers, a = [], 64
    for _ in range(depth):
        layers.append(Linear(a, width, r))
        if use_bn: layers.append(BatchNorm(width))
        layers.append(Act(act)); a = width
    layers.append(Linear(a, 10, r)); return layers
def run(act, use_bn, lr, epochs=10, seed=1):
    layers = build(act, use_bn, seed=seed)
    r = np.random.default_rng(seed)
    curve = []
    for ep in range(epochs):
        for l in layers: l.training = True
        order = r.permutation(len(tr)); tot = 0.0
        for s in range(0, len(order), 32):
            i = tr[order[s:s + 32]]; Z = Xd[i]
            for l in layers: Z = l.forward(Z)
            Zm = Z - Z.max(1, keepdims=True)
            P = np.exp(Zm) / np.exp(Zm).sum(1, keepdims=True)
            tot += -np.log(P[np.arange(len(i)), yd[i]] + 1e-12).sum()
            G = P.copy(); G[np.arange(len(i)), yd[i]] -= 1; G /= len(i)
            for l in reversed(layers): G = l.backward(G)
            for l in layers:
                for p, g in l.params(): p -= lr * g
        curve.append(tot / len(tr))
    for l in layers: l.training = False                       # 추론 모드로 평가
    Z = Xd[te]
    for l in layers: Z = l.forward(Z)
    return np.array(curve), (Z.argmax(1) == yd[te]).mean()
print("준비 완료")
  4. 비교. 시그모이드와 ReLU 각각에 대해 배치 정규화 유무, 학습률 0.1과 0.5로 10에폭 학습한다. 
    with np.errstate(all="ignore"):
    for act in ["sigmoid", "relu"]:
        for use_bn in [False, True]:
            for lr in [0.1, 0.5]:
                curve, acc = run(act, use_bn, lr)
                print(f"{act:7s} {'BN 있음' if use_bn else 'BN 없음'}  lr {lr}: 손실 "
                      f"{curve[0]:.3f} → {curve[-1]:.3f},  테스트 정확도 {acc:.3f}")
참고 답안과 해설
  • 2단계: 세 기울기 모두 상대 오차 $10^{-10}$ 수준이고, 입력 기울기의 열 합은 0이다.
  • 4단계: 배치 정규화가 없는 10층 시그모이드 망은 두 학습률 모두에서 손실이 $\ln10$ 근처에 머물러 정확도 10%다. 배치 정규화를 넣으면 같은 망이 학습률 0.1에서 96.7%, 0.5에서 92.6%까지 학습된다. ReLU 망도 배치 정규화가 없으면 Xavier 초기화 탓에 느리고(학습률 0.1에서 65.7%), 학습률 0.5에서는 학습이 거의 되지 않는다(17.3%). 배치 정규화가 있으면 두 학습률 모두에서 98% 이상이다.
  • 정규화 층은 초기화와 활성화 함수의 나쁜 조합을 상당 부분 구제하고, 더 큰 학습률을 허용한다. 이것이 2015년 이후 깊은 CNN의 거의 모든 층에 배치 정규화가 들어간 이유다. 33일차의 잔차 연결과 함께 쓰면 100층이 넘는 망도 학습된다.
  • 주의: 평가 전에 모든 층을 추론 모드로 바꿨다. 학습 모드로 평가하면 테스트 배치의 통계를 쓰게 되어 결과가 달라진다.
