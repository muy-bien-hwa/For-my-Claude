• 선형회귀로 분류 문제를 풀 때의 문제점을 설명할 수 있다.
  • 시그모이드, 오즈, 로짓의 관계를 이용해 로지스틱 회귀의 출력과 가중치를 해석할 수 있다.
  • 결정 경계가 $\mathbf w\cdot\mathbf x + b = 0$인 초평면임을 설명하고 그릴 수 있다.
  • 이진 교차 엔트로피를 베르누이 최대우도에서 유도하고, MSE보다 나은 이유를 그래디언트로 설명할 수 있다.
  • 그래디언트 $\mathbf X^\top(\mathbf p - \mathbf y)/N$을 유도하고 수치적으로 안정한 형태로 구현할 수 있다.

분류를 회귀로 풀면 생기는 문제

이진 분류는 정답이 0 또는 1인 문제다. 유방 종양이 양성(0)인가 악성(1)인가, 메일이 정상(0)인가 스팸(1)인가. 0과 1을 숫자로 보고 8일차의 선형회귀로 맞춘 뒤 예측이 0.5보다 크면 1로 판정하면 어떨까?

문제는 두 가지다. 첫째, 직선의 출력은 0보다 작거나 1보다 클 수 있어 확률로 읽을 수 없다. 둘째, 이미 확실히 맞힌 먼 점(크기가 아주 큰 악성)이 "1보다 훨씬 큰 예측을 1로 낮추라"는 큰 잔차를 만들어 경계를 엉뚱하게 옮긴다. 필요한 것은 출력을 0과 1 사이로 눌러 주는 함수와, 분류에 맞는 손실이다.

시그모이드와 로지스틱 회귀

임의의 실수를 0과 1 사이로 매끄럽게 옮기는 함수가 시그모이드다.

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$
$z$−4−2024
$\sigma(z)$0.0180.1190.50.8810.982

성질 세 가지: $\sigma(0) = 0.5$, $\sigma(-z) = 1 - \sigma(z)$(0을 중심으로 대칭), $\sigma'(z) = \sigma(z)(1 - \sigma(z))$(5일차에서 유도). 선형 점수 $z = \mathbf w\cdot\mathbf x + b$에 시그모이드를 씌운 모델이 로지스틱 회귀다.

$$p = P(y = 1 \mid \mathbf x) = \sigma(\mathbf w\cdot\mathbf x + b)$$
입력 $\mathbf x$
선형 점수
$z = \mathbf w\cdot\mathbf x + b$
시그모이드
$p = \sigma(z)$
$p > 0.5$이면 1

이름에 "회귀"가 들어 있지만 분류 모델이다. 확률이라는 연속값을 회귀하고, 그것을 임계값으로 잘라 분류한다.

오즈와 로짓: 가중치의 해석

확률 $p$ 대신 "일어날 확률 대 안 일어날 확률의 비"를 쓰기도 한다. 이를 오즈라 한다. $p = 0.8$이면 오즈는 $0.8/0.2 = 4$, 즉 "4 대 1"이다. 오즈에 로그를 취한 것이 로짓이다.

$$\text{odds} = \frac{p}{1-p}, \qquad \mathrm{logit}(p) = \ln\frac{p}{1-p}$$

시그모이드를 거꾸로 풀면 $\ln\frac{p}{1-p} = z$다. 즉 로지스틱 회귀는 로그 오즈를 선형 모델로 예측한다. 그래서 신경망에서도 시그모이드나 소프트맥스에 들어가기 전의 점수 $z$를 로짓이라 부른다.

표준화한 특징 $x_j$의 가중치가 $w_j = 0.7$이면, $x_j$가 1(표준편차 하나만큼) 늘 때 로그 오즈가 0.7 늘고, 오즈는 $e^{0.7} \approx 2.01$배가 된다. 다른 특징이 같을 때 "악성일 오즈가 약 두 배"라는 뜻이다. $z = 2$인 표본은 $p = \sigma(2) = 0.881$, 오즈 $e^2 = 7.39$다.

결정 경계

$p > 0.5 \iff z > 0$이다. 따라서 두 클래스를 가르는 결정 경계는

$$\mathbf w\cdot\mathbf x + b = 0$$

인 점들의 집합이다. 입력이 2개면 직선, 3개면 평면, 그 이상이면 초평면이다. 3일차에서 본 대로 $\mathbf w$는 이 경계에 수직인 법선 벡터이고, $\mathbf w$가 가리키는 쪽이 $p > 0.5$인 쪽이다.

결정 경계가 직선이므로, 원 안과 밖처럼 직선으로 나눌 수 없는 데이터는 맞히지 못한다. 8일차의 다항 특징처럼 $x_1^2, x_2^2$을 특징에 추가하면 원래 공간에서 원·타원 모양의 경계를 만들 수 있다. 위 인터랙티브의 "제곱 특징 추가"가 이것이다. 신경망은 이런 특징 변환을 스스로 학습한다(16일차).

이진 교차 엔트로피

모델이 확률을 출력하므로 6일차의 최대우도를 그대로 쓴다. 정답이 1일 확률이 $p$인 베르누이 분포에서 관측 $y \in \{0, 1\}$의 확률은

$$P(y \mid \mathbf x) = p^{\,y}(1-p)^{1-y}$$

이다($y = 1$이면 $p$, $y = 0$이면 $1 - p$). 표본들이 독립이면 우도는 곱이고, 음의 로그우도를 평균하면 손실이 된다.

$$L = -\frac1N\sum_{i=1}^N\Big[y_i\ln p_i + (1 - y_i)\ln(1 - p_i)\Big]$$

이것이 이진 교차 엔트로피(BCE)다. 6일차의 교차 엔트로피 $H(p, q) = -\sum p\ln q$에서 정답 분포 $(y, 1-y)$와 예측 분포 $(p, 1-p)$를 넣은 것과 같다.

정답 $y = 1$일 때 예측 $p$0.990.90.50.10.01
손실 $-\ln p$0.0100.1050.6932.3034.605

맞으면 0에 가깝고, 확신을 갖고 틀릴수록 끝없이 커진다. 아무것도 모르고 항상 0.5를 말하는 모델의 손실이 $\ln2 \approx 0.693$이라는 것은 학습 곡선을 읽을 때 기준점이 된다.

왜 MSE를 쓰지 않는가

  • MSE에 시그모이드를 붙이면 그래디언트에 $\sigma'(z) = p(1-p)$가 곱해진다. 심하게 틀려 $p \approx 0$이면 이 값이 0에 가까워 학습이 멈춘다.
  • BCE는 $\ln$이 시그모이드의 지수를 상쇄해 그래디언트가 $p - y$로 깔끔해진다(다음 절). 틀린 만큼 그대로 신호가 간다.
  • 로지스틱 회귀의 BCE는 파라미터에 대해 볼록 함수다. 바닥이 하나뿐이므로 경사하강법이 전역 최솟값을 찾는다. MSE + 시그모이드는 볼록하지 않다.

그래디언트 유도

표본 하나의 손실 $\ell = -[y\ln p + (1-y)\ln(1-p)]$, $p = \sigma(z)$, $z = \mathbf w\cdot\mathbf x + b$. 연쇄법칙으로 사슬을 따라간다.

$$\frac{\partial\ell}{\partial p} = -\frac{y}{p} + \frac{1-y}{1-p} = \frac{p - y}{p(1-p)}, \qquad \frac{\partial p}{\partial z} = p(1-p)$$ $$\frac{\partial\ell}{\partial z} = \frac{p - y}{p(1-p)}\cdot p(1-p) = p - y$$

$p(1-p)$가 정확히 상쇄된다. 나머지는 $\partial z/\partial\mathbf w = \mathbf x$, $\partial z/\partial b = 1$이다. $N$개를 평균하고 행렬로 쓰면

$$\nabla_{\mathbf w}L = \frac1N X^\top(\mathbf p - \mathbf y), \qquad \frac{\partial L}{\partial b} = \frac1N\sum_i (p_i - y_i)$$
선형회귀 + MSE로지스틱 회귀 + BCE
예측$\hat y = X\boldsymbol\theta$$\mathbf p = \sigma(X\boldsymbol\theta)$
그래디언트$\frac2N X^\top(\hat{\mathbf y} - \mathbf y)$$\frac1N X^\top(\mathbf p - \mathbf y)$
닫힌 형태의 해있음 (정규방정식)없음 → 경사하강법

형태가 같다: (예측 − 정답)에 입력을 곱해 평균한다. 11일차의 소프트맥스 회귀도, 신경망의 마지막 층도 같은 모양이다.

표본 하나 $\mathbf x = (1, 2)$, $y = 1$, 현재 $\mathbf w = (0, 0)$, $b = 0$. $z = 0$, $p = 0.5$, $p - y = -0.5$. 그래디언트 $\nabla_{\mathbf w} = -0.5\cdot(1, 2) = (-0.5, -1)$, $\partial/\partial b = -0.5$. $\eta = 1$로 갱신하면 $\mathbf w = (0.5, 1)$, $b = 0.5$. 새 점수 $z = 0.5 + 2 + 0.5 = 3$, $p = \sigma(3) = 0.953$. 정답 1에 가까워졌다.

수치적으로 안전하게 계산하기

식을 그대로 코드로 옮기면 두 가지 사고가 난다. $p$가 정확히 0이나 1이 되면 $\ln 0 = -\infty$가 되고, $z = -1000$이면 $e^{1000}$이 넘쳐(overflow) inf가 된다. 로짓 $z$로 직접 손실을 쓰면 둘 다 피할 수 있다.

$$\ell = \ln(1 + e^{z}) - yz$$

(대입해 정리하면 원래 식과 같다.) $\ln(1 + e^z)$는 NumPy의 np.logaddexp(0, z)가 큰 $z$에서도 안전하게 계산한다. PyTorch에서는 시그모이드와 BCE를 합친 BCEWithLogitsLoss를 쓰는 것이 같은 이유다.

import numpy as np
z = np.array([-1000.0, -5.0, 0.0, 5.0, 1000.0])
y = np.array([1.0, 1.0, 1.0, 0.0, 0.0])
with np.errstate(over="ignore", divide="ignore", invalid="ignore"):
    p = 1 / (1 + np.exp(-z))
    naive = -(y * np.log(p) + (1 - y) * np.log(1 - p))
stable = np.logaddexp(0, z) - y * z
print("p        :", p)
print("그대로   :", naive)
print("로짓 형태:", stable)

코드 실습: 두 특징으로 종양 분류

유방 종양 데이터에서 두 특징(평균 반지름, 평균 오목점 수)만 써서 로지스틱 회귀를 학습하고 결정 경계를 그린다. 세포핵이 크고 윤곽이 오목하게 파인 곳이 많을수록 악성일 것이다.

import matplotlib.pyplot as plt
d = load_data("breast_cancer")
names = d["feature_names_ko"]
i, j = names.index("평균 반지름"), names.index("평균 오목점 수")
X2 = d["X"][:, [i, j]].astype(float); y = d["y"].astype(float)
mu, sd = X2.mean(axis=0), X2.std(axis=0)
# 열: 1, 반지름, 오목점 (표준화)
Z = np.c_[np.ones(len(y)), (X2 - mu) / sd]
sigmoid = lambda z: 1 / (1 + np.exp(-z))
th = np.zeros(3)
for step in range(2000):
    p = sigmoid(Z @ th)
    th = th - 0.5 * Z.T @ (p - y) / len(y)                  # BCE의 그래디언트
p = sigmoid(Z @ th)
print("θ = (b, w_반지름, w_오목점):", th.round(3))
print("학습 데이터 정확도:", ((p > 0.5) == y).mean().round(4), "  BCE:",
      (np.logaddexp(0, Z @ th) - y * (Z @ th)).mean().round(4))
g1, g2 = np.meshgrid(np.linspace(-2.2, 4, 200), np.linspace(-1.3, 4.2, 200))
P = sigmoid(th[0] + th[1] * g1 + th[2] * g2)
plt.figure(figsize=(5.8, 4.5))
cf = plt.contourf(g1, g2, P, levels=np.linspace(0, 1, 11), cmap="RdBu_r", alpha=.35)
cs = plt.contour(g1, g2, P, levels=[0.1, 0.5, 0.9], colors="k", linewidths=[1, 2, 1],
                 linestyles=["--", "-", "--"])
plt.clabel(cs, fmt="p=%.1f", fontsize=8)
plt.scatter(Z[y == 0, 1], Z[y == 0, 2], s=9, c="C0", label="양성 (y=0)")
plt.scatter(Z[y == 1, 1], Z[y == 1, 2], s=9, c="C3", label="악성 (y=1)")
plt.colorbar(cf, label="P(악성)")
plt.xlabel("평균 반지름 (표준화)")
plt.ylabel("평균 오목점 수 (표준화)")
plt.legend(loc="upper left")
plt.show()

두 가중치가 모두 양수이고, 오목점 쪽이 더 크다. 경계 근처의 점들은 두 특징만으로는 가를 수 없는 표본이다. 다음으로 MSE와 BCE의 그래디언트 크기를 비교한다.

zz = np.linspace(-8, 8, 200); s = sigmoid(zz)
plt.figure(figsize=(5.6, 3.3))

정리

  • 로지스틱 회귀: $p = \sigma(\mathbf w\cdot\mathbf x + b)$. 출력은 확률, $p > 0.5$이면 1.
  • 로짓 = 로그 오즈 = 선형 점수 $z$. 가중치 $w_j$는 특징 1단위당 로그 오즈 변화, 오즈는 $e^{w_j}$배.
  • 결정 경계 $\mathbf w\cdot\mathbf x + b = 0$은 초평면, $\mathbf w$는 법선. 다항 특징으로 곡선 경계.
  • 손실은 BCE = 베르누이 음의 로그우도. 볼록하고, MSE와 달리 크게 틀릴 때 신호가 강하다.
  • 그래디언트 $\frac1N X^\top(\mathbf p - \mathbf y)$. 구현은 로짓 형태 $\ln(1 + e^z) - yz$로 안전하게.

확인 문제

연습 문제

  1. $\ell = -[y\ln\sigma(z) + (1-y)\ln(1-\sigma(z))]$가 $\ln(1 + e^z) - yz$와 같음을 보여라.
    풀이

    $\ln\sigma(z) = -\ln(1 + e^{-z})$, $\ln(1 - \sigma(z)) = \ln\frac{e^{-z}}{1 + e^{-z}} = -z - \ln(1 + e^{-z})$. 대입하면 $\ell = y\ln(1+e^{-z}) + (1-y)(z + \ln(1+e^{-z})) = \ln(1 + e^{-z}) + z - yz$. 그리고 $\ln(1 + e^{-z}) + z = \ln(e^z + 1)$이므로 $\ell = \ln(1 + e^z) - yz$.

  2. 2차원 로지스틱 회귀 $\mathbf w = (2, -1)$, $b = 1$에서 (a) 결정 경계의 식, (b) 점 $(1, 1)$의 확률, (c) 경계 위의 한 점에서 $\mathbf w$ 방향으로 거리 1만큼 이동했을 때의 확률을 구하라.
    풀이

    (a) $2x_1 - x_2 + 1 = 0$, 즉 $x_2 = 2x_1 + 1$. (b) $z = 2 - 1 + 1 = 2$, $p = 0.881$. (c) 경계 위에서 $z = 0$, 단위 방향 $\mathbf w/\|\mathbf w\|$로 1만큼 가면 $z$는 $\|\mathbf w\| = \sqrt5 \approx 2.236$ 증가, $p = \sigma(2.236) \approx 0.903$.

  3. 데이터가 완벽하게 선형 분리 가능할 때(두 클래스를 직선 하나로 오류 없이 나눌 수 있을 때) BCE를 경사하강법으로 계속 최소화하면 $\|\mathbf w\|$는 어떻게 되는가? 왜 문제인가?
    풀이

    경계를 고정한 채 $\mathbf w$를 키우면 모든 표본의 $p$가 정답 쪽으로 더 극단적이 되어 손실이 계속 줄어든다. 손실의 최솟값이 무한대 크기의 $\mathbf w$에서야 달성되므로 $\|\mathbf w\|$가 끝없이 커진다. 확률이 0과 1로 극단화되어 새로운 데이터에 과신하게 된다. 12일차의 L2 규제가 이를 막는다.

  4. MSE + 시그모이드의 그래디언트 $\partial\ell/\partial z = 2(p - y)p(1 - p)$를 유도하고, $y = 1$일 때 이 값의 크기가 가장 큰 $p$를 구하라.
    풀이

    $\ell = (p - y)^2$, $\partial\ell/\partial p = 2(p - y)$, $\partial p/\partial z = p(1-p)$. $y = 1$이면 크기 $2(1-p)^2p$. $p$로 미분해 0으로 두면 $(1-p)(1-3p) = 0$, $p = 1/3$에서 최대 $2\cdot\frac49\cdot\frac13 \approx 0.296$. 즉 MSE의 학습 신호는 $p$가 아주 작을 때(가장 크게 틀릴 때) 오히려 약해진다.

import matplotlib.pyplot as plt

tr, te = [], []
for c in [0, 1]:
    idx = rng.permutation(np.where(y == c)[0]); cut = int(0.8 * len(idx))
    tr += list(idx[:cut]); te += list(idx[cut:])

mu, sd = X[tr].mean(axis=0), X[tr].std(axis=0)
design = lambda M: np.c_[np.ones(len(M)), (M - mu) / sd]
Ztr, Zte, ytr, yte = design(X[tr]), design(X[te]), y[tr], y[te]

  2. 손실과 그래디언트. 로짓 형태의 안정한 BCE와 그래디언트를 구현하고 수치 미분으로 검증한다. 
    def sigmoid(z):
    # 넘침 없는 시그모이드 (수학적으로 동일)
    return 0.5 * (1 + np.tanh(0.5 * z))
def bce(th, Z, t_):
    z = Z @ th
    # TODO 확인: ln(1 + e^z) − yz
    return np.mean(np.logaddexp(0, z) - t_ * z)
def grad(th, Z, t_):
    return Z.T @ (sigmoid(Z @ th) - t_) / len(t_)         # TODO 확인: Xᵀ(p − y)/N

th0 = np.random.default_rng(1).normal(size=Ztr.shape[1]) * 0.1
h = 1e-5; gn = np.zeros_like(th0)
for k in range(len(th0)):
    e = np.zeros_like(th0); e[k] = h
    gn[k] = (bce(th0 + e, Ztr, ytr) - bce(th0 - e, Ztr, ytr)) / (2 * h)
print("그래디언트 상대 오차:",
      np.abs(grad(th0, Ztr, ytr) - gn).max() / np.abs(gn).max())
  3. 학습과 학습 곡선. 학습률 0.5로 3000스텝 학습하며 학습·테스트 BCE와 정확도를 기록한다. 테스트 곡선은 관찰용으로만 그리고, 학습 길이는 미리 정한 1000스텝으로 한다. 
    th = np.zeros(Ztr.shape[1]); log = []

참고 답안과 해설
  • 1단계: 학습 454개, 테스트 115개, 악성 비율은 둘 다 약 0.37이다.
  • 3단계: 학습 BCE는 계속 줄지만 테스트 BCE는 약 780스텝에서 최소(0.062)가 된 뒤 천천히 다시 커져 3000스텝에서 0.071이 된다. 가중치가 계속 커지며 학습 데이터에 과하게 맞춰지는 과적합의 시작이다(연습 문제 3). 테스트 곡선을 보고 학습 길이를 고르면 테스트 세트가 학습에 관여한 셈이 되어 성능이 부풀려진다. 그래서 12일차에서 검증 세트를 따로 떼는 방법과 규제를 배운다.
  • 4단계: 1000스텝 모델의 테스트 정확도는 99.1%이고, 임계값 0.5에서 오류는 놓친 악성 1개뿐이다. 임계값을 0.2로 낮추면 놓친 악성이 0이 되는 대신 거짓 경보가 6개로 늘고, 0.1이면 9개가 된다. 암 진단에서는 놓친 악성(FN)의 비용이 거짓 경보(FP)보다 훨씬 크므로 임계값을 낮추는 쪽을 택한다. 정확도 하나로는 이 차이를 볼 수 없다. 12일차의 정밀도·재현율·ROC가 이 문제를 다룬다.
  • 5단계: 반지름, 넓이, 둘레의 표준오차와 최악 오목점 수, 최악 질감 등이 큰 양의 가중치를 받는다. 다만 반지름·둘레·넓이처럼 서로 거의 같은 정보를 담은 특징이 많아, 개별 가중치는 분할이나 학습 길이에 따라 크게 바뀔 수 있다. 상관이 강한 특징들 사이에서는 "누가 중요한가"보다 "그 묶음이 중요하다"고 읽는 것이 안전하다.
