• 벡터를 화살표(기하)와 숫자 목록(대수) 두 관점으로 다룰 수 있다.
  • 노름, 내적, 코사인 유사도, 투영을 계산하고 기하학적 의미를 설명할 수 있다.
  • 행렬곱의 형상 규칙과 계산 방법을 알고, 교환법칙이 성립하지 않음을 설명할 수 있다.
  • 신경망 층의 계산 $XW + b$를 형상과 함께 읽을 수 있다.

벡터: 화살표이자 숫자 목록

벡터 $\mathbf v = (3, 2)$는 원점에서 점 $(3, 2)$로 향하는 화살표다. 동시에 어떤 대상을 설명하는 숫자 목록이기도 하다. 붓꽃 한 송이는 (꽃받침 길이, 꽃받침 너비, 꽃잎 길이, 꽃잎 너비)라는 4차원 벡터이고, 손글씨 이미지 하나는 64차원 벡터다. 딥러닝에서 단어, 이미지, 사용자는 모두 수백~수천 차원의 벡터로 표현된다.

벡터의 크기는 노름으로 잰다. 가장 흔한 L2 노름은 피타고라스 정리로 구한 길이이고, L1 노름은 성분 절댓값의 합이다.

$$\|\mathbf v\|_2 = \sqrt{\textstyle\sum_i v_i^2}, \qquad \|\mathbf v\|_1 = \textstyle\sum_i |v_i|$$

$\mathbf v = (3, -4)$이면 $\|\mathbf v\|_2 = \sqrt{9 + 16} = 5$, $\|\mathbf v\|_1 = 3 + 4 = 7$이다. 길이로 나눈 $\mathbf v / \|\mathbf v\|_2 = (0.6, -0.8)$은 같은 방향의 단위벡터(길이 1)다.

import numpy as np
v = np.array([3.0, -4.0])
print("L2 노름:", np.linalg.norm(v), "  L1 노름:", np.abs(v).sum())
u = v / np.linalg.norm(v)
print("단위벡터:", u, "길이", np.linalg.norm(u))
a, b = np.array([1.0, 2.0]), np.array([3.0, -1.0])
print("a + b =", a + b, "  2a =", 2 * a, "  a - b =", a - b)

내적과 코사인 유사도

내적은 같은 길이의 두 벡터에서 하나의 수를 만든다. 정의는 두 가지이며, 둘은 항상 같은 값을 준다.

$$\mathbf a\cdot\mathbf b = \sum_{i} a_i b_i = \|\mathbf a\|\,\|\mathbf b\|\cos\theta$$

왼쪽은 계산 방법이고 오른쪽은 의미다. $\theta$는 두 화살표 사이의 각이다. 내적은 두 벡터가 같은 방향을 가리키는 정도를 잰다.

내적이 0인 두 벡터는 직교한다고 한다. 내적은 길이에도 비례하므로, 방향만 비교하려면 두 길이로 나눈다. 이것이 코사인 유사도이며 $-1$(정반대)에서 $1$(같은 방향) 사이 값을 가진다.

$$\cos\theta = \frac{\mathbf a\cdot\mathbf b}{\|\mathbf a\|\,\|\mathbf b\|}$$

$\mathbf a = (3, 1)$, $\mathbf b = (1, 2)$: $\mathbf a\cdot\mathbf b = 3\cdot1 + 1\cdot2 = 5$, $\|\mathbf a\| = \sqrt{10}$, $\|\mathbf b\| = \sqrt5$, $\cos\theta = 5/\sqrt{50} \approx 0.707$, 즉 $\theta = 45°$.

  • 뉴런 하나의 계산 $z = \mathbf w\cdot\mathbf x + b$: 입력 $\mathbf x$가 가중치 패턴 $\mathbf w$와 얼마나 닮았는가.
  • 어텐션(43일차)의 $QK^\top$: 모든 질의(Query)와 키(Key) 쌍의 내적 = 유사도 표.
  • 임베딩 검색, 추천: 벡터 사이 코사인 유사도로 비슷한 항목을 찾는다.
def cos_sim(u, v):
    return (u @ v) / (np.linalg.norm(u) * np.linalg.norm(v))
a, b = np.array([3.0, 1.0]), np.array([1.0, 2.0])
print("a·b =", a @ b, " cos =", round(cos_sim(a, b), 4), " 각도 =",
      round(np.degrees(np.arccos(cos_sim(a, b))), 1), "도")
print("직교 예:", np.array([1, 2]) @ np.array([-2, 1]))
print("길이를 10배 해도 코사인 유사도는 같다:", round(cos_sim(10 * a, b), 4))

투영

벡터 $\mathbf a$를 다른 벡터 $\mathbf b$ 방향의 성분과 그에 수직인 성분으로 나눌 수 있다. $\mathbf b$ 방향 성분을 투영이라 한다.

$$\text{투영 길이} = \frac{\mathbf a\cdot\mathbf b}{\|\mathbf b\|}, \qquad \mathrm{proj}_{\mathbf b}\,\mathbf a = \frac{\mathbf a\cdot\mathbf b}{\|\mathbf b\|^2}\,\mathbf b$$

$\mathbf a = (2, 3)$, $\mathbf b = (4, 0)$이면 $\mathbf a\cdot\mathbf b = 8$, $\|\mathbf b\| = 4$이므로 투영 길이는 2이고 투영 벡터는 $(2, 0)$이다. 수직 성분은 $\mathbf a - (2, 0) = (0, 3)$이며 $\mathbf b$와의 내적이 0이다.

4일차의 PCA는 데이터를 분산이 가장 큰 방향으로 투영해 차원을 줄인다.

행렬과 행렬곱

$m\times n$ 행렬은 $m$개의 행과 $n$개의 열로 배열한 수의 표다. $m\times n$ 행렬 $A$와 $n\times p$ 행렬 $B$의 행렬곱 $C = AB$는 $m\times p$ 행렬이며, 각 원소는 A의 행과 B의 열의 내적이다.

$$C_{ij} = \sum_{k=1}^{n} A_{ik}B_{kj}$$

$(m\times \underline{n})\,(\underline{n}\times p) = (m\times p)$. 안쪽 크기가 같아야 하고, 바깥쪽 크기가 남는다. 형상 오류가 나면 이 규칙부터 확인한다.

  • 교환법칙은 성립하지 않는다: $AB \ne BA$ (형상부터 다를 수 있다).
  • 결합법칙은 성립한다: $(AB)C = A(BC)$.
  • 전치 $A^\top$는 행과 열을 바꾼 행렬이며, 곱의 전치는 순서가 뒤집힌다: $(AB)^\top = B^\top A^\top$.
  • 단위행렬 $I$는 곱해도 변화가 없는 행렬이다: $AI = IA = A$.
A = np.array([[1, 2], [3, 4], [5, 6]])   # (3, 2)
B = np.array([[1, 0, -1], [2, 1, 0]])     # (2, 3)
C = A @ B
print("C = AB =\n", C, "\n형상", C.shape)
print("C[1, 2] = A[1] · B[:, 2] =", A[1] @ B[:, 2])
print("BA 형상:", (B @ A).shape, "→ AB와 형상부터 다르다")
print("(AB)^T == B^T A^T:", np.array_equal((A @ B).T, B.T @ A.T))
print("원소별 곱(*)과 행렬곱(@)은 다르다:\n",
      np.array([[1, 2], [3, 4]]) * np.array([[1, 2], [3, 4]]))

NumPy에서 *는 원소별 곱, @는 행렬곱이다. 1차원 배열끼리의 @는 내적이다.

신경망 층을 행렬로 읽기

샘플 하나 $\mathbf x\in\mathbb R^{d}$에서 출력 $k$개를 만드는 층은 출력마다 내적을 하나씩 계산한다. 샘플 $N$개를 행으로 쌓은 행렬 $X$를 쓰면 이 모든 내적이 행렬곱 한 번이 된다.

$$H = XW + \mathbf b, \qquad X\in\mathbb R^{N\times d},\; W\in\mathbb R^{d\times k},\; \mathbf b\in\mathbb R^{k},\; H\in\mathbb R^{N\times k}$$ 
rng = np.random.default_rng(0)
N, d, k = 4, 3, 2
X = rng.normal(size=(N, d))
W = rng.normal(size=(d, k))
b = np.array([0.5, -0.5])
H = X @ W + b                                  # (4,3)@(3,2) + (2,) → (4,2)
H_loop = np.array([[X[i] @ W[:, j] + b[j] for j in range(k)] for i in range(N)])
print("H 형상", H.shape, " 반복문 결과와 같음:", np.allclose(H, H_loop))
S = X @ X.T                                    # 모든 샘플 쌍의 내적
print("유사도 행렬 형상", S.shape, " 대칭:", np.allclose(S, S.T))

PyTorch의 nn.Linear는 가중치를 $(k, d)$로 저장하고 $XW^\top + b$를 계산한다. 저장 방식의 차이일 뿐 계산 내용은 같다.

실제 데이터: 손글씨 숫자의 유사도

손글씨 이미지 하나는 64차원 벡터다. 두 이미지의 코사인 유사도는 두 숫자 모양이 얼마나 비슷한지를 잰다. 숫자별 평균 이미지 10개 사이의 유사도를 표로 그려 본다.

import matplotlib.pyplot as plt
d = load_data("digits")
X, y = d["X"].astype(float), d["y"]
M = np.stack([X[y == k].mean(axis=0) for k in range(10)])   # (10, 64) 숫자별 평균
Mn = M / np.linalg.norm(M, axis=1, keepdims=True)             # 각 행을 길이 1로
# (10, 10) 코사인 유사도 표
S = Mn @ Mn.T
plt.figure(figsize=(4.8, 4))
plt.imshow(S, cmap="Blues", vmin=0.4, vmax=1); plt.colorbar(label="코사인 유사도")
plt.xticks(range(10)); plt.yticks(range(10)); plt.title("숫자별 평균 이미지의 유사도")
plt.show()
S2 = S.copy(); np.fill_diagonal(S2, 0)
i, j = np.unravel_index(S2.argmax(), S2.shape)
print(f"가장 비슷한 두 숫자: {i}와 {j} (유사도 {S2[i, j]:.3f})")

대각선은 자기 자신과의 유사도 1이다. 모양이 비슷한 숫자 쌍(예: 3·9, 1·7)의 값이 높다. 7일차에서 이 값으로 새 이미지를 분류한다.

정리

  • 노름 = 벡터의 크기. 내적 = $\sum a_ib_i = \|\mathbf a\|\|\mathbf b\|\cos\theta$, 방향이 비슷한 정도.
  • 코사인 유사도는 길이를 무시하고 방향만 비교한다. 직교하면 0.
  • 행렬곱의 각 원소는 행과 열의 내적. 형상은 $(m\times n)(n\times p) = (m\times p)$.
  • 신경망 층 = $XW + \mathbf b$: 샘플과 가중치 열 사이의 내적들을 한 번에 계산한 것.

확인 문제

연습 문제

  1. $\mathbf a = (2, 1, 2)$, $\mathbf b = (1, 0, -1)$의 내적, 각 노름, 코사인 유사도를 손으로 구하라.
    풀이

    $\mathbf a\cdot\mathbf b = 2 + 0 - 2 = 0$이므로 직교한다. $\|\mathbf a\| = 3$, $\|\mathbf b\| = \sqrt2$, 코사인 유사도 0.

  2. $\mathbf a = (3, 4)$를 $\mathbf b = (1, 1)$ 방향으로 투영한 벡터와, 그에 수직인 성분을 구하라. 두 성분의 내적이 0임을 확인하라.
    풀이

    $\mathbf a\cdot\mathbf b = 7$, $\|\mathbf b\|^2 = 2$이므로 투영은 $3.5(1, 1) = (3.5, 3.5)$. 수직 성분 $(3, 4) - (3.5, 3.5) = (-0.5, 0.5)$. 내적 $-1.75 + 1.75 = 0$.

  3. $X$(5×3)의 모든 행 쌍의 코사인 유사도 행렬(5×5)을 반복문 없이 구하라.
    풀이
    X = np.random.default_rng(1).normal(size=(5, 3))
Xn = X / np.linalg.norm(X, axis=1, keepdims=True)
C = Xn @ Xn.T          # 대각선은 모두 1
print(C.round(3))
  4. $A$가 (2, 3), $B$가 (3, 4), $C$가 (4, 2)일 때 $ABC$와 $CAB$ 중 계산 가능한 것은 무엇이며 형상은?
    풀이

    $ABC$: (2,3)(3,4)(4,2) = (2, 2). $CAB$: (4,2)(2,3)(3,4) = (4, 4). 둘 다 가능하지만 형상이 다르다.

미니 프로젝트: 코사인 유사도 추천기

사용자 30명이 영화 12편에 매긴 평점 행렬이 있다(일부는 비어 있다). 영화 벡터 사이의 코사인 유사도로 "이 영화를 좋아한 사람이 좋아할 영화"를 찾고, 사용자마다 보지 않은 영화를 추천한다.

  1. 데이터 만들기. 영화마다 장르 성향(액션, 로맨스, 공포)이 있고, 사용자마다 장르 취향이 있다. 평점은 두 벡터의 내적에 잡음을 더해 만든다. 평점의 40%는 가린다(보지 않은 영화). 
    import numpy as np
import matplotlib.pyplot as plt
rng = np.random.default_rng(7)
movies = ["액션1", "액션2", "액션3", "액션4", "로맨스1", "로맨스2", "로맨스3",
          "로맨스4", "공포1", "공포2", "공포3", "액션로맨스"]
# (12, 3) 영화의 장르
G = np.array([[1, 0, 0]] * 4 + [[0, 1, 0]] * 4 + [[0, 0, 1]] * 3 + [[.7, .7, 0]],
             float)
# (30, 3) 사용자의 취향 (합 1)
U = rng.dirichlet([.6, .6, .6], size=30)
# (30, 12) 평점 1~5
R = np.clip(1 + 4 * (U @ G.T) + rng.normal(0, .3, (30, 12)), 1, 5).round()
# 본 영화 표시
seen = rng.random((30, 12)) > 0.4
# 안 본 영화는 0
R_obs = np.where(seen, R, 0)
print("평점 행렬 형상:", R_obs.shape, " 관측 비율:", seen.mean().round(2))
plt.figure(figsize=(6, 4))
plt.imshow(R_obs, cmap="Blues", aspect="auto")
plt.colorbar(label="평점 (0 = 안 봄)")
plt.xticks(range(12), movies, rotation=60, fontsize=8)
plt.ylabel("사용자")
plt.show()
  2. 사용자별 평균 빼기. 사람마다 평점을 후하게 주거나 짜게 주는 습관이 다르다. 각 사용자의 평균 평점을 빼서 "평소보다 좋게 봤는가"만 남긴다. 안 본 영화는 0(평소와 같음)으로 둔다. 
    mu = (R_obs.sum(axis=1) / seen.sum(axis=1))[:, None]       # (30, 1) 사용자별 평균
C = np.where(seen, R_obs - mu, 0.0)                          # (30, 12) 중심화된 평점
print("사용자 0의 평균:", mu[0, 0].round(2), " 중심화된 평점:", C[0].round(1))
  3. 영화-영화 유사도. 각 영화를 "사용자들의 중심화된 평점" 30차원 벡터로 보고 코사인 유사도 행렬(12×12)을 만든다. 
    Mv = C.T                                                # (12, 30) 영화 벡터
norms = np.linalg.norm(Mv, axis=1, keepdims=True)       # (12, 1)
Sim = (Mv @ Mv.T) / (norms @ norms.T)                   # (12, 12) 코사인 유사도
plt.figure(figsize=(5, 4.2))
plt.imshow(Sim, cmap="RdBu", vmin=-1, vmax=1)
plt.colorbar()
plt.xticks(range(12), movies, rotation=60, fontsize=8)
plt.yticks(range(12), movies, fontsize=8)
plt.title("영화 간 코사인 유사도")
plt.show()
for m in [0, 4, 8, 11]:
    order = np.argsort(-Sim[m])[1:4]
    print(f"'{movies[m]}'와 비슷한 영화:", [movies[j] for j in order])
  4. 추천 점수. 사용자 $u$가 안 본 영화 $j$의 예측 평점은 "사용자 평균 + (본 영화들의 중심화된 평점을 영화 $j$와의 유사도로 가중평균한 값)"이다. 음수 유사도는 0으로 자른다. 행렬곱 한 번으로 모든 사용자·영화의 점수가 나온다. 
    # 양의 유사도만, 자기 자신 제외
W = np.clip(Sim, 0, None); np.fill_diagonal(W, 0)
pred = mu + (C @ W) / (seen.astype(float) @ W + 1e-9)    # (30,12)@(12,12) → (30, 12)
u = 3
cand = np.where(~seen[u])[0]
top = cand[np.argsort(-pred[u, cand])][:3]
print(f"사용자 {u}의 취향(액션, 로맨스, 공포):", U[u].round(2))
print("추천:", [(movies[j], round(float(pred[u, j]), 2)) for j in top])
  5. 평가. 가려 둔 평점(실제로는 매겨진 값)과 예측의 평균절대오차를 구하고, 두 기준선(전체 평균, 사용자 평균)과 비교한다. 
    hidden = ~seen
mae = np.abs(pred[hidden] - R[hidden]).mean()
base_all = np.abs(R_obs[seen].mean() - R[hidden]).mean()
base_user = np.abs(np.broadcast_to(mu, R.shape)[hidden] - R[hidden]).mean()
print(f"유사도 추천 MAE {mae:.3f}   전체 평균 기준선 {base_all:.3f}   사용자 평균 "
      f"기준선 {base_user:.3f}")
참고 답안과 해설
  • 중심화 없이 원래 평점(1~5)과 0을 섞어 유사도를 구하면, 모든 영화 벡터가 "양수"라 서로 비슷해지고 장르 구조가 묻힌다. 실제로 중심화를 빼고 실행하면 '액션1'과 비슷한 영화로 공포·로맨스 영화가 섞여 나온다. 평균을 빼는 것은 2일차의 표준화와 같은 생각이며, 내적 기반 방법에서 매우 중요하다.
  • 중심화 후에는 같은 장르끼리 유사도가 높고, "액션로맨스"는 액션·로맨스와 비슷하게 나온다. 장르 정보를 주지 않았는데도 평점 패턴만으로 장르 구조가 드러난다.
  • 추천 MAE가 두 기준선보다 크게 작다(약 0.5 대 1.0). 기준선과 비교해야 방법이 쓸모 있는지 판단할 수 있다(12일차).
  • 실제 추천 시스템은 행렬 분해(4일차 SVD의 응용)나 신경망으로 사용자·영화 벡터를 학습한다.
