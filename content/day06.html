• 확률변수와 확률분포(베르누이, 범주형, 가우시안)를 구분하고 기댓값과 분산을 계산할 수 있다.
  • 조건부 확률과 베이즈 정리로 사전확률을 갱신할 수 있다.
  • 최대우도추정의 원리를 설명하고, 손실 함수(MSE, 교차 엔트로피)가 어디서 나오는지 유도할 수 있다.
  • 엔트로피, 교차 엔트로피, KL 발산을 계산하고 의미를 설명할 수 있다.

확률변수와 확률분포

분류 모델은 "고양이다"라고 단정하지 않고 "고양이일 확률 0.92, 개일 확률 0.07"처럼 확률을 출력한다. 언어 모델도 매 순간 다음 단어에 대한 확률을 출력한다. 좋은 예측이 무엇인지 정의하려면 확률의 언어가 필요하다.

결과가 무작위인 실험의 결과에 수를 대응시킨 것을 확률변수라 하고, 확률변수가 각 값을 가질 확률을 정한 것을 확률분포라 한다. 값이 셀 수 있게 떨어져 있으면 확률질량함수(각 값의 확률)로, 연속이면 확률밀도함수(곡선 아래 넓이가 확률)로 나타낸다.

분포값파라미터딥러닝에서
베르누이 분포0 또는 1$p$ (1일 확률)이진 분류의 출력
범주형 분포$K$개 범주 중 하나$p_1, \dots, p_K$ (합 1)다중 분류, 다음 토큰 예측
가우시안 분포실수평균 $\mu$, 분산 $\sigma^2$회귀의 잡음, 가중치 초기화, VAE, 확산 모델
$$\mathcal N(x;\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

기댓값과 분산

기댓값은 확률로 가중한 평균이고, 분산은 값이 기댓값에서 퍼진 정도다. 분산의 제곱근이 표준편차다.

$$\mathbb E[X] = \sum_x x\,p(x), \qquad \mathrm{Var}[X] = \mathbb E\big[(X - \mathbb E[X])^2\big] = \mathbb E[X^2] - \mathbb E[X]^2$$

공정한 주사위: $\mathbb E[X] = \frac{1+2+\dots+6}{6} = 3.5$. $\mathbb E[X^2] = \frac{91}{6}$, $\mathrm{Var}[X] = \frac{91}{6} - 3.5^2 \approx 2.917$, 표준편차 약 1.71. 베르누이($p$)는 $\mathbb E = p$, $\mathrm{Var} = p(1-p)$이다.

표본이 많아질수록 표본 평균이 기댓값에 가까워진다는 정리가 큰 수의 법칙이다. 위 인터랙티브의 오른쪽 그래프가 이를 보여 준다. 미니배치 몇십 개로 계산한 기울기가 전체 데이터의 기울기를 잘 근사하는 근거이기도 하다(9일차).

import numpy as np
import matplotlib.pyplot as plt
rng = np.random.default_rng(0)
rolls = rng.integers(1, 7, size=100_000)
print("표본 평균:", rolls.mean().round(4), " 표본 분산:", rolls.var().round(4),
      " (이론 3.5, 2.917)")
coin = rng.random(10_000) < 0.3                      # 베르누이(0.3)
print("앞면 비율:", coin.mean(), " 이론 분산 p(1-p):", 0.3 * 0.7, " 표본 분산:",
      coin.var().round(4))
g = rng.normal(loc=2.0, scale=0.5, size=10_000)
print("가우시안 표본 평균, 표준편차:", g.mean().round(3), g.std().round(3))

조건부 확률과 베이즈 정리

사건 $B$가 일어났다는 조건 아래 $A$가 일어날 확률을 조건부 확률이라 한다.

$$P(A\mid B) = \frac{P(A\cap B)}{P(B)}$$

분류 모델의 출력은 정확히 조건부 확률 $p(y\mid x)$, 즉 "입력이 $x$일 때 레이블이 $y$일 확률"이다. 조건의 방향을 뒤집는 공식이 베이즈 정리다.

$$P(A\mid B) = \frac{P(B\mid A)\,P(A)}{P(B)}$$

$P(A)$는 관측 전의 믿음인 사전확률, $P(A\mid B)$는 관측 $B$를 반영한 사후확률이다.

유병률 1%인 질병의 검사가 있다. 환자는 99% 확률로 양성이 나오고, 건강한 사람도 5% 확률로 양성이 나온다. 양성이 나온 사람이 실제 환자일 확률은?

$$P(\text{환자}\mid +) = \frac{0.99 \times 0.01}{0.99\times0.01 + 0.05\times0.99} \approx 0.167$$

검사가 99% 정확해 보여도 양성 판정 중 실제 환자는 6명 중 1명꼴이다. 환자가 원래 드물기(사전확률이 낮기) 때문이다.

이 교훈은 머신러닝에서 그대로 반복된다. 양성 클래스가 드문 데이터(사기 탐지, 질병 진단)에서는 정확도가 높아도 양성 예측의 대부분이 틀릴 수 있다(12일차).

N = 1_000_000
sick = rng.random(N) < 0.01
pos = np.where(sick, rng.random(N) < 0.99, rng.random(N) < 0.05)
print("시뮬레이션 P(환자 | 양성) =", (sick & pos).sum() / pos.sum())

최대우도추정: 손실 함수는 어디서 오는가

동전을 10번 던져 앞면이 7번 나왔다. 앞면 확률 $p$의 가장 그럴듯한 값은 무엇인가?

파라미터가 $p$일 때 관측 데이터가 나올 확률을 $p$의 함수로 본 것을 우도라 한다. 던지기가 서로 독립이면

$$\mathcal L(p) = p^7(1-p)^3$$

우도를 최대로 만드는 파라미터를 추정값으로 고르는 방법이 최대우도추정(MLE)이다. 곱은 다루기 어렵고 아주 작은 수가 되므로 로그를 씌운다. 로그는 증가함수라 최댓값의 위치가 바뀌지 않는다.

$$\log\mathcal L(p) = 7\log p + 3\log(1-p), \qquad \frac{d}{dp}\log\mathcal L = \frac{7}{p} - \frac{3}{1-p} = 0 \;\Rightarrow\; \hat p = 0.7$$

최대화를 최소화로 바꾸려고 부호를 뒤집은 것이 음의 로그 우도(NLL)다. 데이터 $N$개에 대해

$$L(\theta) = -\frac1N\sum_{i=1}^N \log p_\theta(y_i\mid x_i)$$
  • 출력이 가우시안 분포를 따른다고 가정하면 → 평균제곱오차(MSE).
  • 출력이 베르누이·범주형 분포를 따른다고 가정하면 → 교차 엔트로피.

손실 함수는 임의로 고르는 것이 아니라 "데이터가 어떤 분포를 따른다고 가정하는가"에서 결정된다.

유도: 가우시안 가정에서 MSE가 나오는 과정

$y \sim \mathcal N(f_\theta(x), \sigma^2)$로 가정하면

$$-\log p(y\mid x) = \frac{\big(y - f_\theta(x)\big)^2}{2\sigma^2} + \frac12\log(2\pi\sigma^2)$$

$\sigma$가 상수면 둘째 항과 $\frac1{2\sigma^2}$은 최적화에 영향이 없으므로, 최소화할 것은 $(y - f_\theta(x))^2$의 평균, 즉 MSE다.

유도: 베르누이 가정에서 이진 교차 엔트로피가 나오는 과정

$y\in\{0, 1\}$, 모델이 출력한 확률 $\hat p$에 대해 $p(y) = \hat p^{\,y}(1-\hat p)^{1-y}$. 로그를 씌우고 부호를 바꾸면 $-[y\log\hat p + (1-y)\log(1-\hat p)]$. 10일차 로지스틱 회귀의 손실이다.

ps = np.linspace(0.01, 0.99, 99)
loglik = 7 * np.log(ps) + 3 * np.log(1 - ps)
print("로그 우도를 최대로 하는 p:", ps[loglik.argmax()].round(2))
# 가우시안의 MLE는 표본 평균과 표본 분산
x = rng.normal(5.0, 2.0, size=500)
print("평균의 MLE:", x.mean().round(3), "  분산의 MLE:",
      ((x - x.mean()) ** 2).mean().round(3), " (참값 5, 4)")

정보량과 엔트로피

확률 $p$인 사건이 일어났을 때의 놀람을 정보량 $-\log p$로 정의한다. 확실한 사건($p = 1$)은 정보량 0이고, 드문 사건일수록 정보량이 크다.

정보량의 기댓값, 즉 분포의 평균적인 불확실성을 엔트로피라 한다.

$$H(p) = -\sum_x p(x)\log p(x)$$

교차 엔트로피와 KL 발산

실제 분포가 $p$인데 모델은 $q$라고 믿을 때의 평균 놀람을 교차 엔트로피라 한다. 두 분포의 차이는 KL 발산으로 잰다.

$$H(p, q) = -\sum_x p(x)\log q(x), \qquad D_{KL}(p\,\|\,q) = \sum_x p(x)\log\frac{p(x)}{q(x)} = H(p, q) - H(p) \;\ge\; 0$$

$H(p)$는 데이터로 정해진 상수이므로 교차 엔트로피 최소화 = KL 발산 최소화 = 모델 분포를 실제 분포에 가깝게 만들기다. KL 발산은 $p = q$일 때만 0이고, $D_{KL}(p\|q) \ne D_{KL}(q\|p)$로 비대칭이다.

정답이 원-핫 분포(예: 클래스 2가 정답이면 $p = (0, 0, 1)$)이면 합에서 정답 항만 남는다.

$$H(p, q) = -\log q_{\text{정답}}$$

정답에 확률 1을 주면 손실 0, 0.5를 주면 0.69, 0.01을 주면 4.6이다. 확신을 가지고 틀릴수록 손실이 크게 커진다.

def entropy(p):
    p = np.asarray(p, float); p = p[p > 0]
    return -(p * np.log(p)).sum()
def cross_entropy(p, q, eps=1e-12):
    return -(np.asarray(p) * np.log(np.asarray(q) + eps)).sum()
def kl(p, q):
    return cross_entropy(p, q) - entropy(p)
print("H([1/3]*3) =", entropy([1/3] * 3).round(4), "  ln 3 =", np.log(3).round(4))
y = [0, 0, 1]
for q in ([0.1, 0.1, 0.8], [0.3, 0.3, 0.4], [0.7, 0.29, 0.01]):
    print(f"예측 {q}: CE = {cross_entropy(y, q):.4f}")
p, q = np.array([0.5, 0.3, 0.2]), np.array([0.4, 0.4, 0.2])
print("KL(p‖q) =", kl(p, q).round(5), "  KL(q‖p) =", kl(q, p).round(5), "← 비대칭")

$\log 0 = -\infty$다. 실제 구현은 확률 대신 소프트맥스 이전의 점수(로짓)를 받아 안정적인 방식으로 교차 엔트로피를 계산한다. PyTorch의 nn.CrossEntropyLoss가 로짓을 입력으로 받는 이유다(11일차).

정리

  • 분포: 베르누이(이진), 범주형(다중), 가우시안(실수). 기댓값 = 확률 가중 평균, 분산 = 퍼진 정도.
  • 베이즈 정리: 사후 ∝ 우도 × 사전. 드문 사건은 양성 판정이 많아도 실제로 드물다.
  • 최대우도추정 = 음의 로그 우도 최소화. 가우시안 → MSE, 베르누이·범주형 → 교차 엔트로피.
  • 엔트로피 = 불확실성. 교차 엔트로피 = 엔트로피 + KL 발산. 원-핫 정답이면 $-\log q_{\text{정답}}$.

미니 프로젝트: 나이브 베이즈 스팸 분류기

베이즈 정리와 최대우도추정만으로 스팸 분류기를 만든다. 메시지의 단어들이 클래스가 주어졌을 때 서로 독립이라고 가정하는 나이브 베이즈 모델이다.

$$P(\text{스팸}\mid w_1,\dots,w_n) \;\propto\; P(\text{스팸})\prod_{i=1}^{n} P(w_i\mid\text{스팸})$$
  1. 데이터 만들기. 스팸과 정상 메시지에서 단어가 나오는 확률이 다르도록 메시지 600개를 만든다. 공통 단어는 양쪽에 비슷하게 나온다. 
    import numpy as np
rng = np.random.default_rng(3)
spam_w = ["무료", "당첨", "대출", "클릭", "이벤트", "쿠폰", "광고", "수익", "지금",
          "혜택", "할인", "링크"]
ham_w = ["회의", "내일", "저녁", "과제", "수업", "엄마", "친구", "확인", "도착",
         "사진", "시간", "부탁"]
common = ["오늘", "정말", "그리고", "우리", "연락", "주세요", "감사", "보기"]
vocab = spam_w + ham_w + common
def make_msg(is_spam):
    n = rng.integers(4, 9)
    probs = np.array([3.0 if (w in spam_w) == is_spam and w not in common else 0.4
                      for w in vocab])
    probs[[vocab.index(c) for c in common]] = 1.5
    return list(rng.choice(vocab, size=n, p=probs / probs.sum()))
y = (rng.random(600) < 0.35).astype(int)                     # 1 = 스팸 (약 35%)
msgs = [make_msg(bool(t)) for t in y]
for m, t in list(zip(msgs, y))[:4]:
    print("스팸" if t else "정상", ":", " ".join(m))
  2. 단어 횟수 행렬. 메시지마다 각 단어가 몇 번 나왔는지 센 행렬 $C$(메시지 수 × 어휘 크기)를 만들고, 학습 450개·테스트 150개로 나눈다. 
    idx = {w: i for i, w in enumerate(vocab)}
C = np.zeros((len(msgs), len(vocab)))
for r, m in enumerate(msgs):
    for w in m:
        C[r, idx[w]] += 1
Ctr, ytr, Cte, yte = C[:450], y[:450], C[450:], y[450:]
print("횟수 행렬 형상:", C.shape, " 학습 스팸 비율:", ytr.mean().round(3))
  3. 최대우도로 확률 추정. 클래스 사전확률과 클래스별 단어 확률을 센다. 학습 데이터에 한 번도 안 나온 단어 때문에 확률이 0이 되지 않도록 모든 횟수에 1을 더한다(라플라스 평활화). TODO를 완성하라. 
    prior = np.array([(ytr == 0).mean(), (ytr == 1).mean()])            # P(정상), P(스팸)
# (2, V) 라플라스 평활화
counts = np.stack([Ctr[ytr == k].sum(axis=0) for k in (0, 1)]) + 1
# TODO 확인: 각 행의 합이 1
word_p = counts / counts.sum(axis=1, keepdims=True)
print("사전확률:", prior.round(3), " 행 합:", word_p.sum(axis=1))
  4. 로그 공간에서 분류. 확률의 곱은 언더플로가 나므로 로그 확률의 합을 쓴다. 행렬곱 한 번으로 모든 메시지의 두 클래스 점수를 계산한다. 
    # (150, V)@(V, 2) + (2,) → (150, 2)
log_score = Cte @ np.log(word_p).T + np.log(prior)
pred = log_score.argmax(axis=1)
acc = (pred == yte).mean()
print(f"테스트 정확도 {acc:.3f}   (모두 정상으로 찍는 기준선 {1 - yte.mean():.3f})")
post = np.exp(log_score - log_score.max(axis=1, keepdims=True))
post = post / post.sum(axis=1, keepdims=True)              # 정규화된 사후확률
print("첫 메시지:", " ".join(msgs[450]), "→ P(스팸) =", post[0, 1].round(3))
  5. 해석과 사용. 단어별로 $\log\frac{P(w\mid\text{스팸})}{P(w\mid\text{정상})}$을 계산해 스팸 신호가 강한 단어를 찾고, 직접 만든 문장을 분류한다. 
    ratio = np.log(word_p[1] / word_p[0])
order = np.argsort(ratio)
print("스팸 신호 단어:", [vocab[i] for i in order[::-1][:5]])
print("정상 신호 단어:", [vocab[i] for i in order[:5]])
def classify(text):
    v = np.zeros(len(vocab))
    for w in text.split():
        if w in idx: v[idx[w]] += 1
    s = v @ np.log(word_p).T + np.log(prior)
    p = np.exp(s - s.max()); p /= p.sum()
    return round(float(p[1]), 3)
for t in ["무료 쿠폰 지금 클릭", "내일 회의 시간 확인 부탁", "오늘 친구 사진 무료"]:
    print(f"'{t}' → P(스팸) = {classify(t)}")
참고 답안과 해설
  • 테스트 정확도는 기준선(약 0.6)보다 훨씬 높은 0.95 안팎이 나온다. 학습은 횟수를 세는 것뿐이다. 이것이 최대우도추정이다(범주형 분포의 MLE = 상대빈도).
  • 평활화를 빼면 학습 데이터의 한 클래스에 없던 단어가 나왔을 때 그 클래스의 확률이 0이 되어, 다른 단어의 증거와 상관없이 판정이 결정된다.
  • "단어들이 서로 독립"이라는 가정은 실제 언어에서 틀리지만 분류 성능은 의외로 좋다. 단어 순서와 문맥을 반영하는 모델은 6주차에서 다룬다.
  • 로그 점수 계산이 행렬곱 $C\,(\log P)^\top$ 한 번이라는 점에 주목한다. 확률 모델도 결국 선형대수로 계산된다.
