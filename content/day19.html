• 수치 미분, 기호 미분, 자동 미분의 차이와 역방향 모드가 신경망에 맞는 이유를 설명할 수 있다.
  • 연산을 기록해 계산 그래프를 만드는 스칼라 자동 미분 엔진을 구현할 수 있다.
  • 위상 정렬로 역전파 순서를 정하고, 기울기를 누적해야 하는 이유를 설명할 수 있다.
  • 엔진 위에 뉴런, 층, MLP를 만들고 분류기를 학습시킬 수 있다.
  • 스칼라 엔진과 PyTorch 같은 텐서 엔진의 관계를 설명할 수 있다.

자동 미분

18일차에서 층마다 역전파 공식을 손으로 유도하고 코드로 옮겼다. 새 층을 만들 때마다 이 일을 반복하는 것은 번거롭고 실수하기 쉽다. 컴퓨터가 순전파에서 수행한 연산을 기록해 두었다가 그 기록을 거꾸로 따라가며 미분을 자동으로 계산하게 할 수 있다. 이것이 자동 미분이다. PyTorch, TensorFlow, JAX의 핵심 기능이다.

방법원리정확도비용 (파라미터 $P$개)
수치 미분 (5일차)$\frac{f(x+h) - f(x-h)}{2h}$근사 (반올림 오차)순전파 $2P$번
기호 미분수식을 미분 규칙으로 변형 (계산기의 미분 기능)정확식이 기하급수적으로 길어질 수 있음
자동 미분 (역방향)연산 기록 + 노드별 국소 미분 + 연쇄법칙정확 (기계 정밀도)순전파 약 2~3번

자동 미분에는 입력 쪽부터 미분을 전달하는 전방 모드와, 출력 쪽부터 전달하는 역방향 모드가 있다. 신경망은 입력(파라미터)이 수백만 개이고 출력(손실)이 하나이므로, 한 번의 역방향 계산으로 모든 입력의 미분을 얻는 역방향 모드가 맞다. 역전파는 역방향 모드 자동 미분의 다른 이름이다.

값 객체와 연산 기록

숫자 하나를 감싼 객체 Value를 만든다. 이 객체는 값(data), 손실에 대한 기울기(grad), 자신을 만든 입력 노드들(_prev), 그리고 "내 기울기를 입력들에게 나눠 주는 방법"(_backward)을 기억한다. 파이썬의 연산자 오버로딩으로 a * b를 쓰면 곱셈 결과와 함께 그래프 노드가 자동으로 만들어진다.

class Value:
    def __init__(self, data, _children=(), _op=""):
        self.data, self.grad = data, 0.0
        self._prev, self._op = set(_children), _op
        self._backward = lambda: None             # 입력 노드는 할 일이 없다

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), "*")
        def _backward():                           # 곱셈 노드: 서로 바꿔 곱함
            self.grad += other.data * out.grad
            other.grad += self.data * out.grad
        out._backward = _backward
        return out

_backward는 순전파 시점의 self, other, out을 기억하는 클로저(closure)다. 나중에 out.grad(상류 기울기)가 정해지면 국소 기울기를 곱해 입력들의 grad에 더한다. 18일차 노드별 패턴표의 한 줄이 함수 하나가 된다.

위상 정렬과 역전파 순서

노드의 _backward를 호출하려면 그 노드의 grad가 이미 완성되어 있어야 한다. 즉 그 노드를 사용하는 모든 노드가 먼저 처리되어야 한다. 그래프의 노드를 "입력이 항상 출력보다 앞에 오도록" 나열하는 것을 위상 정렬이라 하며, 역전파는 이 순서를 거꾸로 따라간다.

    def backward(self):
        topo, visited = [], set()
        def build(v):                       # 깊이 우선 탐색
            if v not in visited:
                visited.add(v)
                for child in v._prev:
                    build(child)
                topo.append(v)              # 입력들을 모두 넣은 뒤에 자신을
        build(self)
        self.grad = 1.0                     # ∂L/∂L = 1
        for v in reversed(topo):
            v._backward()

기울기 누적과 초기화

_backward에서 self.grad = ...가 아니라 self.grad += ...를 쓴 이유는 18일차의 분기 규칙 때문이다. 값 하나가 여러 곳에서 쓰이면 각 경로의 기울기를 더해야 한다. 이를 기울기 누적이라 한다.

a = Value(3.0); b = a + a. 덧셈 노드의 _backward는 self와 other(둘 다 a)에 1씩 보낸다. +=면 $\partial b/\partial a = 2$(정답), =면 두 번째 대입이 첫 번째를 덮어 1이 된다. a * a도 마찬가지로 +=여야 $2a = 6$이 나온다.

누적의 대가로, 학습 스텝마다 역전파 전에 모든 파라미터의 grad를 0으로 되돌려야 한다. 안 하면 이전 스텝의 기울기가 계속 쌓인다. PyTorch에서 매 스텝 optimizer.zero_grad()를 호출하는 이유가 이것이다. 반대로 이 성질을 이용해, 메모리가 부족할 때 작은 배치 여러 개의 기울기를 일부러 누적한 뒤 한 번에 갱신하기도 한다.

연산 추가하기

연산마다 순전파 값과 국소 미분만 정의하면 된다.

연산순전파_backward (상류 g = out.grad)
덧셈$a + b$a.grad += g; b.grad += g
곱셈$ab$a.grad += b.data * g; b.grad += a.data * g
거듭제곱 (상수 $k$)$a^k$a.grad += k * a.data**(k-1) * g
지수$e^a$a.grad += out.data * g
로그$\ln a$a.grad += (1 / a.data) * g
tanh$\tanh a$a.grad += (1 - out.data**2) * g
ReLU$\max(0, a)$a.grad += (a.data > 0) * g

뺄셈, 나눗셈, 부호 바꾸기는 새 미분 없이 기존 연산의 조합으로 만든다: $a - b = a + (-1)b$, $a/b = a\cdot b^{-1}$. 2 * a나 1 / a처럼 왼쪽이 일반 숫자일 때도 동작하도록 __rmul__, __radd__, __rtruediv__를 정의한다.

엔진 위에 신경망 만들기

값 객체만 있으면 신경망은 평범한 파이썬 코드다. 뉴런은 가중치 Value들의 리스트이고, 층은 뉴런의 리스트, MLP는 층의 리스트다. 각 객체가 parameters()로 자기 아래의 모든 파라미터를 돌려주면, 학습 루프는 그 목록만 보고 갱신한다.

class Neuron:
    def __init__(self, n_in, act=True):
        self.w = [Value(random.uniform(-1, 1)) for _ in range(n_in)]
        self.b = Value(0.0); self.act = act
    def __call__(self, x):
        z = sum((wi * xi for wi, xi in zip(self.w, x)), self.b)
        return z.tanh() if self.act else z
    def parameters(self):
        return self.w + [self.b]

PyTorch의 nn.Module도 같은 구조다. 모듈이 하위 모듈과 파라미터를 품고, model.parameters()로 모두 꺼내 옵티마이저에 넘긴다(29일차).

코드 실습: 자동 미분 엔진 구현

전체 엔진이다. 이 셀을 실행한 뒤 아래 셀들로 검증한다.

import math, random
class Value:
    def __init__(self, data, _children=(), _op=""):
        self.data, self.grad = float(data), 0.0
        self._prev, self._op = set(_children), _op
        self._backward = lambda: None
    def __repr__(self): return f"Value(data={self.data:.4f}, grad={self.grad:.4f})"
    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), "+")
        def _backward():
            self.grad += out.grad; other.grad += out.grad
        out._backward = _backward; return out
    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), "*")
        def _backward():
            self.grad += other.data * out.grad; other.grad += self.data * out.grad
        out._backward = _backward; return out
    def __pow__(self, k):
        out = Value(self.data ** k, (self,), f"**{k}")
        def _backward(): self.grad += k * self.data ** (k - 1) * out.grad
        out._backward = _backward; return out
    def exp(self):
        out = Value(math.exp(self.data), (self,), "exp")
        def _backward(): self.grad += out.data * out.grad
        out._backward = _backward; return out
    def log(self):
        out = Value(math.log(self.data), (self,), "log")
        def _backward(): self.grad += (1 / self.data) * out.grad
        out._backward = _backward; return out
    def tanh(self):
        out = Value(math.tanh(self.data), (self,), "tanh")
        def _backward(): self.grad += (1 - out.data ** 2) * out.grad
        out._backward = _backward; return out
    def relu(self):
        out = Value(max(0.0, self.data), (self,), "relu")
        def _backward(): self.grad += (self.data > 0) * out.grad
        out._backward = _backward; return out
    def __neg__(self): return self * -1
    def __sub__(self, other): return self + (-other)
    def __truediv__(self, other):
        return self * (other ** -1 if isinstance(other, Value) else 1.0 / other)
    def __radd__(self, other): return self + other
    def __rmul__(self, other): return self * other
    def __rsub__(self, other): return (-self) + other
    def __rtruediv__(self, other): return other * self ** -1     # 숫자 / Value
    def backward(self):
        topo, visited = [], set()
        def build(v):
            if v not in visited:
                visited.add(v)
                for child in v._prev: build(child)
                topo.append(v)
        build(self)
        self.grad = 1.0
        for v in reversed(topo): v._backward()
        return topo
print("엔진 준비 완료")

스칼라 엔진과 텐서 엔진

오늘의 엔진은 숫자 하나마다 파이썬 객체를 만들어 느리다. 64 → 32 → 10 MLP의 표본 하나만 해도 노드가 수천 개다. PyTorch는 같은 일을 텐서(배열) 단위로 한다. 노드 하나가 행렬곱 전체이고, 그 노드의 _backward는 18일차의 $X^\top G$, $GW^\top$ 공식을 C++/CUDA로 구현한 것이다. 원리는 같다.

import torch                                   # 29일차 미리 보기 (브라우저에서는 실행되지 않음)
x = torch.tensor(-2.0, requires_grad=True)     # requires_grad: 연산을 기록하라
y = torch.tensor(5.0, requires_grad=True); z = torch.tensor(-4.0, requires_grad=True)
f = (x + y) * z
f.backward()                                   # 위상 정렬 + 역순 _backward
print(x.grad, y.grad, z.grad)                  # tensor(-4.) tensor(-4.) tensor(3.)

PyTorch는 코드가 실행되는 순간 그래프를 만들고(define-by-run), 역전파가 끝나면 버린다. 그래서 반복문이나 조건문으로 매번 다른 구조의 신경망을 만들어도 그대로 미분된다.

정리

  • 자동 미분 = 연산 기록 + 노드별 국소 미분 + 연쇄법칙. 역방향 모드는 출력 하나에 대한 모든 입력의 미분을 한 번에 구한다.
  • Value: data, grad, _prev, _backward(클로저). 연산자 오버로딩으로 순전파 중 그래프가 만들어진다.
  • backward: 위상 정렬 후 역순으로 _backward 호출, 출력 grad = 1에서 시작.
  • 기울기는 누적(+=)해야 분기가 맞다. 대신 매 스텝 0으로 초기화한다(zero_grad).
  • 새 연산은 순전파와 국소 미분만 정의하면 된다. PyTorch는 같은 원리를 텐서 단위로 구현한다.

        z = sum((wi * xi for wi, xi in zip(self.w, x)), self.b)
        return z.tanh() if self.act else z
    def parameters(self): return self.w + [self.b]
class Layer:
    def __init__(self, n_in, n_out, act=True):
        self.neurons = [Neuron(n_in, act) for _ in range(n_out)]
    def __call__(self, x):
        out = [nr(x) for nr in self.neurons]
        return out[0] if len(out) == 1 else out
    def parameters(self): return [p for nr in self.neurons for p in nr.parameters()]
class MLP:
    def __init__(self, n_in, sizes):
        dims = [n_in] + sizes
        self.layers = [Layer(dims[i], dims[i + 1],
                             act=(i < len(sizes) - 1)) for i in range(len(sizes))]
    def __call__(self, x):
        for layer in self.layers: x = layer(x)
        return x
    def parameters(self):
        return [p for layer in self.layers for p in layer.parameters()]
random.seed(1)
model = MLP(2, [6, 1])
print("파라미터 수:", len(model.parameters()))

참고 답안과 해설
  • 2단계: 파라미터는 $(2\times6 + 6) + (6 + 1) = 25$개다.
  • 3단계: 손실이 약 1.1에서 0.06 근처까지 내려가고 학습 정확도는 1.0이다. 경계가 두 반달 사이를 휘어 지난다. 엔진 연산으로 조립한 손실을 backward() 한 번으로 미분했으므로, 손실 함수를 바꿔도(예: 힌지 손실 (1 - yi * s).relu()) 학습 코드는 그대로다.
  • 4단계: 최대 차이는 $10^{-16}$ 수준(기계 정밀도)이다. 엔진은 근사가 아니라 정확한 미분을 계산한다.
  • 속도: 100스텝에 노드 수십만 개를 만들어 몇 초가 걸린다. 같은 계산을 NumPy 행렬로 하면 수 밀리초다. 20일차부터는 18일차 방식의 층 단위 역전파(행렬 연산)로 큰 신경망을 학습한다.
