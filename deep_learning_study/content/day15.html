• 인공 뉴런의 계산 $\phi(\mathbf w\cdot\mathbf x + b)$를 구성 요소별로 설명할 수 있다.
  • 퍼셉트론으로 AND, OR, NOT 게이트를 직접 설계할 수 있다.
  • 퍼셉트론 학습 규칙을 손으로 적용하고, 선형 분리 가능한 데이터에서 수렴함을 설명할 수 있다.
  • XOR이 선형 분리 불가능함을 증명하고, 층을 쌓아 해결하는 방법을 보일 수 있다.

생물 뉴런에서 인공 뉴런으로

뇌의 신경세포는 여러 가지돌기로 신호를 받아, 신호의 합이 어떤 문턱을 넘으면 축삭으로 신호를 내보낸다. 1943년 매컬러와 피츠는 이 동작을 수식으로 단순화했다. 입력마다 중요도를 곱해 더하고, 문턱과 비교해 출력을 정한다. 이것이 인공 뉴런이다.

$$a = \phi(z), \qquad z = w_1x_1 + w_2x_2 + \cdots + w_dx_d + b = \mathbf w\cdot\mathbf x + b$$
  • 가중치 $w_i$: 입력 $x_i$가 출력에 미치는 영향의 크기와 방향. 양수면 흥분, 음수면 억제.
  • 편향 $b$: 뉴런이 얼마나 쉽게 켜지는지 정하는 값. 문턱의 부호를 바꾼 것이다($z > 0 \iff \mathbf w\cdot\mathbf x > -b$).
  • 활성화 함수 $\phi$: 가중합을 출력으로 바꾸는 함수. 오늘은 계단 함수, 16일차부터는 매끄러운 함수를 쓴다.

2주차의 로지스틱 회귀는 $\phi = \sigma$인 뉴런 하나였다. 신경망은 이런 뉴런을 수천~수십억 개 연결한 것이다.

퍼셉트론과 논리 게이트

1958년 로젠블랫은 출력을 0 또는 1로 내는 뉴런에 학습 규칙을 붙인 퍼셉트론을 만들었다. 활성화 함수는 계단 함수다.

$$\hat y = \mathrm{step}(\mathbf w\cdot\mathbf x + b), \qquad \mathrm{step}(z) = \begin{cases}1 & z > 0\\ 0 & z \le 0\end{cases}$$

가중치와 편향을 잘 고르면 퍼셉트론 하나로 논리 게이트를 만들 수 있다.

$x_1$$x_2$AND: $\mathbf w = (1, 1), b = -1.5$OR: $\mathbf w = (1, 1), b = -0.5$NAND: $\mathbf w = (-1, -1), b = 1.5$

01$z = -0.5$ → 0$z = 0.5$ → 1$z = 0.5$ → 1
10$z = -0.5$ → 0$z = 0.5$ → 1$z = 0.5$ → 1
11$z = 0.5$ → 1$z = 1.5$ → 1$z = -0.5$ → 0

AND와 OR는 가중치가 같고 편향만 다르다. 편향이 문턱을 정한다: AND는 "두 입력의 합이 1.5를 넘어야" 켜지고, OR는 "0.5만 넘어도" 켜진다. 기하학적으로 퍼셉트론은 입력 평면을 직선 $\mathbf w\cdot\mathbf x + b = 0$으로 나누고 한쪽을 1, 다른 쪽을 0으로 판정한다(10일차의 결정 경계와 같다).

퍼셉트론 학습 규칙

게이트처럼 답을 알 때는 손으로 가중치를 고를 수 있다. 데이터만 있을 때는 틀린 표본을 보며 가중치를 고친다. 정답 $y$와 예측 $\hat y$가 다를 때만 다음과 같이 갱신한다.

$$\mathbf w \leftarrow \mathbf w + \eta\,(y - \hat y)\,\mathbf x, \qquad b \leftarrow b + \eta\,(y - \hat y)$$
상황$y - \hat y$갱신효과

틀린 표본에 대해 점수 $z$를 정답 쪽으로 미는 방향이다. 결정 직선은 그 점을 올바른 쪽에 두도록 회전·이동한다. 레이블을 $\{-1, +1\}$로 쓰면 같은 규칙이 "$y\,z \le 0$이면 $\mathbf w \leftarrow \mathbf w + \eta y\mathbf x$"로 간단해진다. 아래 인터랙티브는 이 형태를 쓴다.

수렴 정리

퍼셉트론은 언제 멈추는가? 로젠블랫과 노비코프(1962)가 답을 증명했다.

모든 표본이 반지름 $R$인 공 안에 있고($\|\mathbf x\| \le R$), 어떤 직선이 두 클래스를 여백 $\gamma > 0$ 이상으로 가른다면, 퍼셉트론이 저지르는 실수(갱신)의 총횟수는 $(R/\gamma)^2$ 이하다. 학습률이나 표본 순서와 무관하다.

증명의 뼈대: 갱신할 때마다 $\mathbf w$와 "정답 방향" 벡터의 내적은 적어도 $\gamma$씩 커지는데, $\|\mathbf w\|^2$은 많아야 $R^2$씩 커진다. $k$번 갱신 뒤 내적은 $k\gamma$ 이상, 길이는 $\sqrt k R$ 이하이고, 코사인은 1을 넘을 수 없으므로 $k\gamma \le \sqrt k R$, 즉 $k \le (R/\gamma)^2$이다. 의미는 두 가지다. 여백이 넓을수록 빨리 끝나고, 선형 분리가 불가능하면($\gamma$가 없으면) 끝나지 않는다.

선형 분리 가능성과 XOR

두 클래스를 직선(고차원에서는 초평면) 하나로 오류 없이 나눌 수 있으면 선형 분리 가능하다고 한다. AND, OR, NAND는 선형 분리 가능하다. 그런데 두 입력이 다를 때만 1인 XOR은 그렇지 않다.

$x_1$$x_2$XOR
000
011
101
110

퍼셉트론이 XOR을 맞힌다고 가정하면 네 부등식이 성립해야 한다.

$$b \le 0,\qquad w_2 + b > 0,\qquad w_1 + b > 0,\qquad w_1 + w_2 + b \le 0$$

가운데 두 식을 더하면 $w_1 + w_2 + 2b > 0$, 즉 $w_1 + w_2 + b > -b \ge 0$이다(첫 식에서 $-b \ge 0$). 이는 마지막 식 $w_1 + w_2 + b \le 0$과 모순이다. 따라서 그런 $\mathbf w, b$는 없다.

XOR 문제는 1969년 민스키와 패퍼트의 책에서 단층 퍼셉트론의 한계로 지적되었고, 신경망 연구가 한동안 침체되는 계기가 되었다(첫 번째 AI 겨울). XOR 문제는 지금도 "선형 모델로 풀 수 없는 가장 작은 문제"의 대명사다.

층을 쌓아 XOR 풀기

XOR은 "OR이면서 AND는 아닌 것"이다: $\mathrm{XOR}(x_1, x_2) = \mathrm{AND}(\mathrm{OR}(x_1, x_2), \mathrm{NAND}(x_1, x_2))$. 퍼셉트론 세 개를 두 층으로 연결하면 된다.

$(x_1, x_2)$$h_1 = \mathrm{OR}$$h_2 = \mathrm{NAND}$$\hat y = \mathrm{AND}(h_1, h_2)$
(0, 0)010
(0, 1)111
(1, 0)111
(1, 1)100

핵심은 은닉층이 입력을 "선형으로 가를 수 있는 새 표현"으로 바꾼다는 점이다. 새 좌표에서 네 점은 $(0, 1), (1, 1), (1, 1), (1, 0)$이 되고, 1인 점들($(1, 1)$)과 0인 점들($(0, 1), (1, 0)$)은 직선 $h_1 + h_2 = 1.5$로 갈린다. 남은 문제는 은닉층의 가중치를 손으로 고르지 않고 데이터로 학습하는 것이다. 계단 함수는 거의 모든 곳에서 미분이 0이라 경사하강법을 쓸 수 없다. 16일차에서 매끄러운 활성화 함수로, 18일차에서 역전파로 이 문제를 푼다.

코드 실습: 퍼셉트론 구현

퍼셉트론을 함수로 구현하고 AND, OR, XOR에 적용한다. 레이블은 0과 1, 갱신은 $(y - \hat y)$ 형태를 쓴다.

import numpy as np
import matplotlib.pyplot as plt
X4 = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
gates = {"AND": np.array([0, 0, 0, 1]), "OR": np.array([0, 1, 1, 1]),
         "XOR": np.array([0, 1, 1, 0])}

def train_perceptron(X, y, eta=1.0, epochs=20):
    w, b = np.zeros(X.shape[1]), 0.0
    errors = []                                   # 에폭별 틀린 수
    for ep in range(epochs):
        e = 0
        for xi, yi in zip(X, y):
            y_hat = 1 if xi @ w + b > 0 else 0
            if y_hat != yi:
                # TODO 확인: 퍼셉트론 규칙
                w = w + eta * (yi - y_hat) * xi
                b = b + eta * (yi - y_hat)
                e += 1
        errors.append(e)
        if e == 0:
            break
    return w, b, errors

for name, y in gates.items():
    w, b, errors = train_perceptron(X4, y)
    pred = (X4 @ w + b > 0).astype(int)
    print(f"{name:3s}: w = {w}, b = {b:4.1f}, 에폭별 틀린 수 {errors[:8]}, 예측 "
          f"{pred}, 정답 {y}")

AND는 위 예제와 같이 $\mathbf w = (2, 1)$, $b = -2$로 끝난다. XOR은 20에폭 동안 매번 틀리며 끝나지 않는다. 마지막으로 두 층 퍼셉트론으로 XOR을 계산한다.

step = lambda z: (z > 0).astype(int)
W1 = np.array([[1, -1],                           # 열 0: OR, 열 1: NAND
               [1, -1]], dtype=float)
b1 = np.array([-0.5, 1.5])
w2, b2 = np.array([1.0, 1.0]), -1.5                # AND
H = step(X4 @ W1 + b1)                             # (4, 2) 은닉 표현
y_hat = step(H @ w2 + b2)
print("은닉 표현 H:\n", H)
print("XOR 출력:", y_hat)

퍼셉트론과 로지스틱 회귀

퍼셉트론로지스틱 회귀 (10일차)
활성화계단 함수 (0 또는 1)시그모이드 (0~1 확률)
갱신틀린 표본에만 $\eta(y - \hat y)\mathbf x$모든 표본에 $\eta(y - p)\mathbf x$
선형 분리 불가능할 때영원히 흔들림BCE가 가장 작은 경계로 수렴

두 갱신식은 모양이 거의 같다. 퍼셉트론은 $\hat y \in \{0, 1\}$을, 로지스틱 회귀는 $p \in (0, 1)$을 쓸 뿐이다. 퍼셉트론 규칙은 손실 $\max(0, -y z)$($y = \pm1$)에 대한 확률적 경사하강법으로 볼 수도 있다. 이 손실은 13일차 SVM의 힌지 손실 $\max(0, 1 - yz)$에서 여백 1을 뺀 것이다.

정리

  • 인공 뉴런 $a = \phi(\mathbf w\cdot\mathbf x + b)$. 가중치는 영향의 크기와 방향, 편향은 문턱.
  • 퍼셉트론 = 계단 함수 뉴런. 결정 경계는 직선(초평면). AND, OR, NAND를 만들 수 있다.
  • 학습 규칙 $\mathbf w \leftarrow \mathbf w + \eta(y - \hat y)\mathbf x$: 틀린 표본의 점수를 정답 쪽으로 민다.
  • 선형 분리 가능하면 실수 횟수는 $(R/\gamma)^2$ 이하로 끝난다. 불가능하면 끝나지 않는다.
  • XOR은 선형 분리 불가능. 은닉층이 새 표현을 만들어 해결한다. 은닉층을 학습하려면 미분 가능한 활성화와 역전파가 필요하다.

    def perceptron_log(X, y, eta=1.0, epochs=2000):
    w, b = np.zeros(X.shape[1]), 0.0
    snaps, errors = [(w.copy(), b)], []
    for ep in range(epochs):
        e = 0
        for xi, yi in zip(X, y):
            y_hat = int(xi @ w + b > 0)
            if y_hat != yi:
                w = w + eta * (yi - y_hat) * xi; b = b + eta * (yi - y_hat)
                snaps.append((w.copy(), b)); e += 1
        errors.append(e)
        if e == 0:
            break
    return w, b, snaps, errors

    def bound(Xs, w, b):
    A = np.c_[Xs, np.ones(len(Xs))]; t = np.where(y == 1, 1, -1); v = np.r_[w, b]
    R = np.linalg.norm(A, axis=1).max()
    gamma = (t * (A @ v)).min() / np.linalg.norm(v)
    return R, gamma, (R / gamma) ** 2

def pocket(X, y, epochs=200, eta=1.0):
    w, b = np.zeros(X.shape[1]), 0.0
    best = (0.0, w.copy(), b)
    for ep in range(epochs):
        for xi, yi in zip(X, y):
            y_hat = int(xi @ w + b > 0)
            if y_hat != yi:
                w = w + eta * (yi - y_hat) * xi; b = b + eta * (yi - y_hat)
                acc = ((X @ w + b > 0).astype(int) == y).mean()
                if acc > best[0]:
                    best = (acc, w.copy(), b)      # TODO 확인: 더 나은 해를 주머니에
    return best, ((X @ w + b > 0).astype(int) == y).mean()

참고 답안과 해설
  • 2단계: 원래 입력에서는 686에폭, 1,489번 갱신해야 끝나지만, 중심화하면 3에폭, 4번 갱신으로 끝난다. 원래 데이터는 원점에서 멀리(꽃받침 길이 5cm 근처) 떨어져 있어, 편향 $b$를 1씩만 바꾸는 퍼셉트론은 경계를 데이터 쪽으로 옮기는 데 수많은 갱신이 필요하다. 9일차에서 표준화가 경사하강법을 빠르게 한 것과 같은 이유다.
  • 3단계: 첫 경계는 엉뚱한 방향이지만 갱신마다 틀린 점 쪽으로 회전·이동하며 네 번 만에 두 무리 사이에 자리 잡는다.
  • 4단계: 상한은 실제보다 훨씬 크다(중심화한 경우 약 4만 3천, 원래 입력은 약 190억). 최종 해의 여백 $\gamma_{\mathbf w}$가 작아(경계가 한 점에 아슬아슬하게 붙어 있음) 상한이 느슨해진다. 그래도 실제 갱신 수는 항상 상한 이하다. 정리는 "끝난다는 보장"이지 정확한 예측이 아니다.
  • 5단계: 마지막 가중치는 갱신 직후의 상태라 정확도가 들쭉날쭉하다(이번 실행에서 0.51). 주머니 속 가중치는 그동안 본 최선의 해(0.71)로, 꽃받침 두 특징만으로 얻을 수 있는 정확도에 가깝다. 분리 불가능한 데이터에서는 로지스틱 회귀처럼 손실을 최소화하는 방법이 더 체계적이다.
