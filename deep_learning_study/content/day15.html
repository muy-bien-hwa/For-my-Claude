1. 왜 PyTorch인가

  • Define-by-run: 파이썬 코드가 실행되는 순간 계산 그래프가 만들어집니다. if·for를 자유롭게 쓰고, 일반 파이썬 디버거로 디버깅할 수 있습니다.
  • GPU 가속: .to("cuda") 한 줄이면 됩니다.
  • 생태계: 연구 논문 구현의 대부분, Hugging Face, 최신 LLM 코드가 PyTorch입니다.

3. Autograd: 내가 만든 Value 클래스의 완성판

x = torch.tensor(-2.0, requires_grad=True)
y = torch.tensor(5.0, requires_grad=True)
z = torch.tensor(-4.0, requires_grad=True)
f = (x + y) * z                # 순전파와 동시에 그래프가 기록됨
print(f.grad_fn)               # <MulBackward0> ← Day 10의 _op, _backward와 같은 역할
f.backward()                   # 역전파
print(x.grad, y.grad, z.grad)  # tensor(-4.) tensor(-4.) tensor(3.)  ← Day 10과 동일!
🔑 Autograd 핵심 규칙
  • requires_grad=True인 텐서가 관여한 연산만 그래프에 기록됩니다. nn.Module의 파라미터는 자동으로 True입니다.
  • backward()는 스칼라에서 호출합니다(보통 손실).
  • .grad는 누적됩니다 → 매 스텝 optimizer.zero_grad().
  • 기본적으로 backward() 후 그래프는 해제됩니다(메모리 절약).
  • 추론·평가 시에는 with torch.no_grad():로 그래프 기록을 끕니다(메모리·속도).
  • 텐서를 그래프에서 떼어내려면 .detach(). 로깅할 때는 loss.item()으로 파이썬 숫자를 얻습니다.

4. nn.Module: 모델의 기본 단위

import torch.nn as nn
import torch.nn.functional as F

class MLP(nn.Module):
    def __init__(self, d_in=784, d_hidden=256, n_classes=10, p_drop=0.2):
        super().__init__()                          # 꼭 호출!
        self.fc1 = nn.Linear(d_in, d_hidden)        # 속성으로 등록하면 파라미터가 자동 추적됨
        self.fc2 = nn.Linear(d_hidden, d_hidden)
        self.fc3 = nn.Linear(d_hidden, n_classes)
        self.drop = nn.Dropout(p_drop)

    def forward(self, x):                           # (N, 1, 28, 28)
        x = x.flatten(1)                            # (N, 784)
        x = self.drop(F.relu(self.fc1(x)))          # (N, 256)
        x = self.drop(F.relu(self.fc2(x)))          # (N, 256)
        return self.fc3(x)                          # (N, 10) 로짓 — softmax는 붙이지 않는다!

model = MLP()
print(model)
print(sum(p.numel() for p in model.parameters()), "개 파라미터")
for name, p in model.named_parameters(): print(name, tuple(p.shape))
# fc1.weight (256, 784) ← PyTorch는 (out, in)으로 저장하고 x @ W.T 를 계산

# 간단한 모델은 Sequential로
model2 = nn.Sequential(
    nn.Flatten(), nn.Linear(784, 256), nn.ReLU(), nn.Dropout(0.2),
    nn.Linear(256, 256), nn.ReLU(), nn.Dropout(0.2), nn.Linear(256, 10))

5. 가장 짧은 완전한 학습 코드

from torchvision import datasets, transforms
from torch.utils.data import DataLoader

tf = transforms.Compose([transforms.ToTensor(), transforms.Normalize((0.1307,), (0.3081,))])
train_ds = datasets.MNIST("data", train=True, download=True, transform=tf)
test_ds  = datasets.MNIST("data", train=False, download=True, transform=tf)
train_dl = DataLoader(train_ds, batch_size=128, shuffle=True)
test_dl  = DataLoader(test_ds, batch_size=512)

model = MLP().to(device)
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)
loss_fn = nn.CrossEntropyLoss()

for epoch in range(5):
    model.train()                                   # 드롭아웃 ON
    for xb, yb in train_dl:
        xb, yb = xb.to(device), yb.to(device)
        logits = model(xb)                          # 1. 순전파
        loss = loss_fn(logits, yb)                  # 2. 손실
        opt.zero_grad()                             #    (기울기 초기화)
        loss.backward()                             # 3. 역전파
        opt.step()                                  # 4. 업데이트
    model.eval()                                    # 드롭아웃 OFF
    correct = 0
    with torch.no_grad():
        for xb, yb in test_dl:
            correct += (model(xb.to(device)).argmax(1) == yb.to(device)).sum().item()
    print(f"epoch {epoch}  loss {loss.item():.4f}  test acc {correct / len(test_ds):.4f}")

2주차에 NumPy로 수십 줄 걸렸던 것이 이 정도입니다. 그리고 GPU 덕분에 1에폭에 몇 초면 끝납니다.

6. 같은 모델, Keras 버전

TensorFlow/Keras는 더 높은 수준의 API를 제공합니다. 학습 루프를 fit()이 대신해 줍니다.

import tensorflow as tf
from tensorflow import keras

(x_tr, y_tr), (x_te, y_te) = keras.datasets.mnist.load_data()
x_tr, x_te = x_tr / 255.0, x_te / 255.0

model = keras.Sequential([
    keras.layers.Input((28, 28)),
    keras.layers.Flatten(),
    keras.layers.Dense(256, activation="relu"), keras.layers.Dropout(0.2),
    keras.layers.Dense(256, activation="relu"), keras.layers.Dropout(0.2),
    keras.layers.Dense(10),                                   # 로짓
])
model.compile(optimizer=keras.optimizers.AdamW(1e-3),
              loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),   # ← 로짓 입력임을 명시
              metrics=["accuracy"])
model.fit(x_tr, y_tr, batch_size=128, epochs=5, validation_split=0.1)
model.evaluate(x_te, y_te)

7. 자주 하는 실수 Top 7

  1. optimizer.zero_grad()를 빠뜨림 → 기울기 누적.
  2. 평가 전에 model.eval()을 안 함 → 드롭아웃·BN이 학습 모드로 동작.
  3. 평가 때 torch.no_grad()를 안 씀 → 메모리 폭증.
  4. 모델 끝에 softmax를 붙이고 CrossEntropyLoss에 넣음.
  5. 모델은 GPU, 데이터는 CPU → RuntimeError: Expected all tensors to be on the same device.
  6. 손실을 리스트에 모을 때 loss를 그대로 저장 → 그래프 전체가 메모리에 남음. loss.item()을 쓰세요.
  7. CrossEntropyLoss의 타깃에 원-핫이나 float을 넣음 → 정수 클래스 인덱스(torch.long)를 넣어야 함.
