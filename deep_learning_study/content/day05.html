• 확률변수, 확률분포(베르누이·범주형·가우시안), 기댓값과 분산을 이해한다.
  • 조건부 확률과 베이즈 정리를 읽을 수 있다.
  • 최대우도추정(MLE)이 무엇이며, 왜 대부분의 손실 함수가 MLE에서 나오는지 이해한다.
  • 엔트로피 · 교차 엔트로피 · KL 발산을 계산하고 의미를 설명한다.
👨‍🏫 딥러닝은 확률 기계다 분류 모델은 "고양이다"라고 단정하지 않습니다. "고양이일 확률 0.92, 개일 확률 0.07…"이라는 확률분포를 출력합니다. GPT도 매 순간 다음 단어에 대한 확률분포를 내놓습니다. 그래서 "좋은 예측"을 정의하려면 확률의 언어가 필요합니다. 오늘 배우는 교차 엔트로피는 앞으로 거의 매일 쓰게 될 손실 함수입니다.

1. 확률변수와 분포

확률변수 $X$는 결과가 무작위인 값이고, 확률분포는 각 값이 나올 확률을 정한 것입니다.

분포값파라미터딥러닝에서
베르누이0 또는 1$p$ (1일 확률)이진 분류 출력 (시그모이드)
범주형(Categorical)K개 클래스 중 하나$p_1..p_K$ (합 = 1)다중 분류 출력 (소프트맥스), 다음 토큰 예측
가우시안(정규)실수평균 $\mu$, 분산 $\sigma^2$회귀, 가중치 초기화, VAE, 확산 모델의 노이즈
$$\mathcal N(x;\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

기댓값 $\mathbb E[X] = \sum_x x\,p(x)$는 "평균적으로 나오는 값", 분산 $\mathrm{Var}[X] = \mathbb E[(X-\mathbb E X)^2]$는 "평균에서 얼마나 퍼져 있나"입니다.

import numpy as np
import matplotlib.pyplot as plt
rng = np.random.default_rng(0)

samples = rng.normal(loc=2.0, scale=0.5, size=10000)
print("표본 평균:", samples.mean().round(3), " 표본 표준편차:", samples.std().round(3))

coin = rng.random(10000) < 0.3          # 베르누이(p=0.3)
print("앞면 비율:", coin.mean())

probs = np.array([0.5, 0.3, 0.2])
draws = rng.choice(3, size=10000, p=probs)   # 범주형
print("클래스별 빈도:", np.bincount(draws) / len(draws))

xs = np.linspace(0, 4, 200)
pdf = np.exp(-(xs-2)**2 / (2*0.25)) / np.sqrt(2*np.pi*0.25)
plt.figure(figsize=(6, 3))
plt.hist(samples, bins=60, density=True, alpha=.5, label='샘플 히스토그램')
plt.plot(xs, pdf, lw=2, label='N(2, 0.5²) 밀도')
plt.legend(); plt.show()

2. 조건부 확률과 베이즈 정리

$P(A\mid B)$는 "B가 일어났을 때 A의 확률"입니다. 분류 모델이 출력하는 것은 정확히 $p(y\mid x)$, 즉 입력이 주어졌을 때 레이블의 확률입니다.

$$P(A\mid B) = \frac{P(B\mid A)\,P(A)}{P(B)}$$
💡 예: 질병 검사 유병률 1%, 검사 민감도 99%, 위양성률 5%. 양성이 나왔을 때 실제 환자일 확률은? $\frac{0.99\times0.01}{0.99\times0.01 + 0.05\times0.99} \approx 16.7\%$. 직관보다 훨씬 낮습니다. 사전확률(prior)이 중요하다는 교훈입니다. 클래스 불균형 데이터에서 같은 일이 일어납니다.

3. 최대우도추정 (MLE) — 손실 함수는 어디서 오는가

동전을 10번 던져 앞면이 7번 나왔습니다. 앞면 확률 $p$를 추정한다면? 대부분 0.7이라고 답할 겁니다. 그 직관을 수학으로 쓰면 이렇습니다.

우도(likelihood): 파라미터가 $p$일 때 관측된 데이터가 나올 확률.

$$\mathcal L(p) = p^7(1-p)^3$$

이 값을 최대로 만드는 $p$를 찾습니다. 곱셈은 다루기 어렵고 수치적으로 불안정(아주 작은 수의 곱)하므로 로그를 씌웁니다. 로그는 단조증가라 최댓값의 위치가 바뀌지 않습니다.

$$\log\mathcal L(p) = 7\log p + 3\log(1-p)$$

미분해서 0으로 두면 $\frac{7}{p} - \frac{3}{1-p} = 0 \Rightarrow p = 0.7$. 직관과 같습니다!

🔑 딥러닝의 손실 = 음의 로그 우도 (NLL) 최대화보다 최소화가 관례이므로 부호를 뒤집습니다. 데이터 $N$개에 대해 $$L(\theta) = -\frac1N\sum_{i=1}^N \log p_\theta(y_i\mid x_i)$$
  • $p_\theta$가 가우시안이라고 가정하면 → MSE가 나옵니다(아래 유도).
  • $p_\theta$가 베르누이/범주형이면 → 교차 엔트로피가 나옵니다.
즉 손실 함수는 임의로 고른 것이 아니라 "데이터가 어떤 분포를 따른다고 가정하는가"에서 자동으로 결정됩니다.
가우시안 가정 → MSE 유도

$y \sim \mathcal N(f_\theta(x), \sigma^2)$이라고 가정하면

$$-\log p(y\mid x) = \frac{(y - f_\theta(x))^2}{2\sigma^2} + \frac12\log(2\pi\sigma^2)$$

$\sigma$가 상수면 두 번째 항과 $\frac{1}{2\sigma^2}$은 최적화에 영향이 없으므로, 최소화할 것은 $(y - f_\theta(x))^2$의 평균, 즉 MSE입니다.

ps = np.linspace(0.01, 0.99, 99)
loglik = 7*np.log(ps) + 3*np.log(1-ps)
print("로그 우도를 최대로 하는 p:", ps[loglik.argmax()].round(2))
plt.figure(figsize=(6, 3)); plt.plot(ps, loglik); plt.axvline(0.7, ls='--', c='r')
plt.xlabel('p'); plt.ylabel('log L(p)'); plt.title('동전 7/10 앞면의 로그 우도'); plt.show()

4. 정보이론: 엔트로피

확률 $p$인 사건의 정보량(놀람의 정도)은 $-\log p$입니다. 확실한 사건($p=1$)은 정보량 0, 희귀한 사건일수록 정보량이 큽니다.

엔트로피는 정보량의 기댓값, 즉 분포의 불확실성입니다.

$$H(p) = -\sum_x p(x)\log p(x)$$
  • 균일분포일 때 최대(가장 불확실), 한 값에 몰려 있으면 0.
  • 공정한 동전: $H = \log 2 \approx 0.693$ (자연로그 기준, 1비트).

5. 교차 엔트로피와 KL 발산

진짜 분포가 $p$인데 우리 모델은 $q$라고 믿고 있을 때의 평균 놀람:

$$H(p, q) = -\sum_x p(x)\log q(x)$$

그리고 두 분포의 차이를 나타내는 KL 발산:

$$D_{KL}(p\,\|\,q) = \sum_x p(x)\log\frac{p(x)}{q(x)} = H(p,q) - H(p) \;\ge 0$$

$H(p)$는 데이터로 정해진 상수이므로, 교차 엔트로피를 최소화하는 것 = KL 발산을 최소화하는 것 = 모델 분포를 진짜 분포에 가깝게 만드는 것입니다.

🔑 분류에서의 교차 엔트로피 정답이 원-핫 벡터(예: 클래스 2가 정답이면 $p = (0,0,1)$)일 때 합에서 정답 항 하나만 남습니다. $$H(p,q) = -\log q_{\text{정답}}$$ "정답 클래스에 매긴 확률의 음의 로그". 정답에 확률 1을 주면 손실 0, 0.01을 주면 손실 4.6. 확신에 차서 틀릴수록 손실이 폭발적으로 커집니다.
def entropy(p):
    p = np.asarray(p, float); p = p[p > 0]
    return -(p * np.log(p)).sum()
def cross_entropy(p, q, eps=1e-12):
    return -(np.asarray(p) * np.log(np.asarray(q) + eps)).sum()
def kl(p, q): return cross_entropy(p, q) - entropy(p)

print("균일 [1/3]*3 엔트로피:", entropy([1/3]*3).round(4), "(= ln 3 =", np.log(3).round(4), ")")
print("치우친 [0.98,0.01,0.01]:", entropy([0.98, .01, .01]).round(4))

y = [0, 0, 1]   # 정답: 클래스 2
for q in ([0.1, 0.1, 0.8], [0.3, 0.3, 0.4], [0.7, 0.29, 0.01]):
    print(f"예측 {q} → CE = {cross_entropy(y, q):.4f}  (= -ln q[2] = {-np.log(q[2]):.4f})")

p = np.array([0.5, 0.3, 0.2]); q = np.array([0.4, 0.4, 0.2])
print("KL(p||q) =", kl(p, q).round(5), " KL(q||p) =", kl(q, p).round(5), "← 비대칭!")
⚠️ 수치 안정성 $\log 0 = -\infty$입니다. 그래서 실제 구현에서는 확률을 받지 않고 로짓(소프트맥스 이전 값)을 받아서 log-sum-exp 트릭으로 계산합니다. PyTorch의 nn.CrossEntropyLoss가 로짓을 입력으로 받는 이유입니다. 소프트맥스를 직접 씌워서 넣으면 안 됩니다! Day 7에서 자세히 다룹니다.
