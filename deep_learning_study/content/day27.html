• "실행은 되지만 학습이 안 되는" 신경망을 체계적인 절차로 디버깅할 수 있다.
  • 손실 곡선과 지표의 증상으로 원인을 좁힐 수 있다.
  • 학습 중 기록해야 할 값(손실, 기울기 노름, 갱신 비율)을 정하고 계산할 수 있다.
  • 무작위 탐색으로 하이퍼파라미터를 고르고 결과를 여러 시드로 보고할 수 있다.
  • 재현 가능한 실험을 위해 시드와 설정을 관리할 수 있다.

학습이 안 될 때

일반 프로그램의 버그는 대개 오류 메시지를 낸다. 신경망 학습 코드의 버그는 그렇지 않다. 레이블이 섞여도, 기울기가 틀려도, 정규화를 빠뜨려도 코드는 끝까지 실행되고 손실은 "조금" 줄어든다. 그래서 결과가 나쁠 때 원인이 데이터인지, 모델인지, 학습 설정인지, 단순한 코드 실수인지 알기 어렵다. 오늘은 경험 많은 연구자들이 쓰는 점검 절차를 정리하고, 버그가 여러 개 숨은 학습 코드를 실제로 고친다.

디버깅 절차

순서가 중요하다. 앞 단계가 통과해야 뒤 단계의 결과를 믿을 수 있다.

1. 데이터를 눈으로 본다
2. 첫 손실을 확인한다
3. 기울기를 검증한다
4. 작은 배치를 외우게 한다
5. 학습률을 탐색한다
6. 전체 학습을 기록하며 돌린다
7. 단순한 기준선과 비교한다
  1. 데이터를 본다. 입력의 형상, 자료형, 값의 범위(정규화되었는가), 레이블의 분포를 출력하고, 표본 몇 개를 레이블과 함께 그린다. 모델에 들어가기 직전의 배치를 보는 것이 가장 확실하다(증강·정규화 후). 레이블이 입력과 어긋난 버그는 이 단계에서만 잡힌다.
  2. 첫 손실. 무작위 초기화 직후의 손실이 이론값($K$클래스 분류면 $\ln K$, 이진이면 $\ln 2$) 근처인지 본다. 훨씬 크면 초기 로짓이 너무 크다(초기화나 입력 스케일 문제).
  3. 기울기 검증. 직접 쓴 역전파는 수치 미분과 비교한다(20일차). 프레임워크의 자동 미분을 쓰면 생략할 수 있지만, 직접 만든 손실이나 층이 있다면 그 부분을 검증한다.
  4. 작은 배치 외우기. 표본 몇~수십 개만으로 수백 스텝 학습해 손실이 0 근처까지 가는지 본다. 모델은 이 정도는 반드시 외울 수 있어야 한다. 실패하면 모델, 손실, 갱신 중 어딘가에 버그가 있다. 가장 강력한 시험이다.
  5. 학습률 탐색. 범위 테스트(23일차)로 최대 학습률의 범위를 정한다.
  6. 기록하며 학습. 학습·검증 손실과 지표, 학습률, 기울기 노름을 기록한다(다음 절).
  7. 기준선과 비교. 로지스틱 회귀, 최빈 클래스 같은 단순한 모델보다 나은지 확인한다. 복잡한 모델이 단순한 모델보다 못하면 무언가 잘못된 것이다.

무엇을 기록할까

학습 중 기록하는 값이 곧 디버깅의 단서다.

  • 손실과 지표: 학습(에폭 평균 또는 이동 평균)과 검증. 20일차의 학습 곡선.
  • 학습률: 스케줄을 쓸 때 실제 적용된 값.
  • 기울기 노름: 전체와 층별. 갑자기 커지면 폭발, 앞쪽 층만 아주 작으면 소실(24일차).
  • 갱신 비율: 층마다 $\|\Delta W\|/\|W\| = \eta\|\nabla W\|/\|W\|$. $10^{-3}$ 안팎이 적당하다는 경험칙이 있다(자릿수 수준의 기준). $10^{-1}$ 이상이면 가중치가 한 스텝에 크게 바뀌어 불안정하고, $10^{-6}$이면 사실상 학습되지 않는다.
  • 활성값 통계: 층별 평균, 표준편차, 0인 비율(죽은 ReLU).

실무에서는 TensorBoard나 Weights & Biases 같은 도구로 이 값들을 그래프로 본다. 원리는 같다. 값을 리스트에 모아 그리면 된다.

하이퍼파라미터 탐색

하이퍼파라미터가 여러 개면 조합이 많아진다. 격자 탐색은 각 축에서 값 몇 개를 골라 모든 조합을 시험한다. 무작위 탐색(Bergstra & Bengio, 2012)은 각 축에서 값을 무작위로 뽑는다. 같은 시도 횟수라면 무작위 탐색이 거의 항상 낫다.

  • 학습률, 가중치 감쇠처럼 규모가 넓은 값은 로그 눈금에서 뽑는다: $\eta = 10^{u}$, $u \sim \mathrm{U}(-4, -1)$.
  • 넓게 몇 번 → 좋은 영역으로 좁혀 다시(거친 탐색에서 세밀한 탐색으로).
  • 중요한 순서: 학습률 > 규제 강도·배치 크기 > 모델 크기 > 나머지. 학습률부터 맞춘다.
  • 탐색은 검증 세트로 한다. 테스트 세트는 마지막에 한 번(12일차).

재현성

같은 코드·데이터·설정으로 같은 결과를 다시 얻을 수 있는 성질을 재현성이라 한다. 신경망 학습에는 무작위성이 많다: 초기화, 데이터 섞기, 드롭아웃, 증강, 일부 GPU 연산의 순서. 난수 생성기의 시작값인 시드를 고정하면 대부분을 재현할 수 있다.

import random, numpy as np, torch       # PyTorch 예 (29일차)
def seed_everything(seed):
    random.seed(seed); np.random.seed(seed)
    torch.manual_seed(seed); torch.cuda.manual_seed_all(seed)
    torch.backends.cudnn.deterministic = True     # 느려질 수 있다
    torch.backends.cudnn.benchmark = False

시드를 고정하는 것과 결과를 하나의 시드로만 보고하는 것은 다른 문제다. 시드에 따른 성능의 흔들림이 비교하려는 차이보다 클 수 있다. 중요한 결론은 시드 3~5개의 평균과 표준편차로 보고한다. 그리고 실험마다 설정(하이퍼파라미터, 데이터 버전, 코드 버전, 라이브러리 버전)을 함께 기록한다.

코드 실습: 갱신 비율과 무작위 탐색

손글씨 MLP를 학습하며 층별 갱신 비율 $\eta\|\nabla W\|/\|W\|$를 기록한다. 학습률에 따라 이 값이 어떻게 달라지는지 본다.

import numpy as np
import math
import matplotlib.pyplot as plt
d = load_data("digits"); X, y = d["X"].astype(float) / 16, d["y"]
rng = np.random.default_rng(0); tr, te = [], []
for k in range(10):
    idx = rng.permutation(np.where(y == k)[0])
    cut = int(0.8 * len(idx))
    tr += list(idx[:cut])
    te += list(idx[cut:])
tr, te = np.array(tr), np.array(te)
r2 = np.random.default_rng(1); trn, val = [], []
for k in range(10):
    idx = r2.permutation(tr[y[tr] == k])
    cut = int(0.8 * len(idx))
    trn += list(idx[:cut])
    val += list(idx[cut:])
trn, val = np.array(trn), np.array(val)

def fb(params, xb, yb, wd=0.0):
    W1, b1, W2, b2 = params
    a = xb @ W1 + b1; h = np.maximum(0, a); z = h @ W2 + b2
    z = z - z.max(1, keepdims=True); p = np.exp(z) / np.exp(z).sum(1, keepdims=True)
    loss = -np.log(p[np.arange(len(yb)), yb]).mean()
    g = p.copy(); g[np.arange(len(yb)), yb] -= 1; g /= len(yb)
    dW2 = h.T @ g + wd * W2; dh = g @ W2.T; dh[a <= 0] = 0
    return loss, [xb.T @ dh + wd * W1, dh.sum(0), dW2, g.sum(0)]

def train(lr, wd=0.0, epochs=10, seed=1, log=False, idx_tr=trn):
    r = np.random.default_rng(seed)
    params = [r.normal(0, math.sqrt(2 / 64), (64, 64)), np.zeros(64),
              r.normal(0, math.sqrt(2 / 64), (64, 10)), np.zeros(10)]
    ratios = []
    for ep in range(epochs):
        order = r.permutation(idx_tr)
        for s in range(0, len(order), 32):
            i = order[s:s + 32]; loss, grads = fb(params, X[i], y[i], wd)
            if log:
                norm = np.linalg.norm
                ratios.append([lr * norm(grads[k]) / norm(params[k]) for k in (0, 2)])
            for p_, g_ in zip(params, grads): p_ -= lr * g_
    return params, np.array(ratios)
def accuracy(params, idx):
    W1, b1, W2, b2 = params
    return ((np.maximum(0, X[idx] @ W1 + b1) @ W2 + b2).argmax(1) == y[idx]).mean()

plt.figure(figsize=(6, 3.2))
for lr in [0.001, 0.1, 3.0]:
    params, ratios = train(lr, epochs=3, log=True)
    W1, b1 = params[0], params[1]
    # 모든 검증 입력에서 0인 유닛
    dead = (np.maximum(0, X[val] @ W1 + b1) == 0).all(0).mean()
    plt.semilogy(ratios[:, 0], label=f"η = {lr} (W1)")
    print(f"η = {lr}: W1 갱신 비율 중앙값 {np.median(ratios[:, 0]):.1e}, 최댓값 "
          f"{ratios[:, 0].max():.1e}")
    print(f"    죽은 은닉 유닛 {dead:.0%},  검증 정확도 {accuracy(params, val):.3f}")
plt.axhline(1e-3, color="gray", ls=":")
plt.xlabel("스텝")
plt.ylabel("‖ΔW‖ / ‖W‖")
plt.legend(fontsize=8)
plt.grid(alpha=.3)
plt.show()

η = 0.001은 갱신 비율이 $10^{-4}$ 안팎이다(중앙값 6.4e-05). 3에폭 동안 가중치가 거의 바뀌지 않아 검증 정확도가 찍기 수준(0.083)이다. η = 0.1은 비율이 $5\times10^{-3}$ 근처를 유지하며 정상적으로 학습된다. η = 3.0은 처음 몇 스텝의 비율이 1 안팎이다. 한 스텝에 가중치가 자기 크기만큼 바뀐다는 뜻이다. 그 사이 은닉 유닛 64개 중 62개가 죽고(모든 검증 입력에서 출력 0), 이후로는 살아남은 몇 개만 갱신되어 비율이 오히려 작아진다. 그래서 중앙값(4.1e-03)만 보면 η = 0.1과 비슷해 보인다. 요약값 하나가 아니라 곡선 전체를 봐야 하는 이유다. 비율이 작아진 것이 "안정되었다"는 뜻이 아닐 수 있다.

이번에는 학습률과 가중치 감쇠를 로그 눈금에서 무작위로 12번 뽑아 검증 정확도를 비교한다.

search = np.random.default_rng(42); trials = []
for t in range(12):
    lr = 10 ** search.uniform(-3, 0.3); wd = 10 ** search.uniform(-6, -1)
    with np.errstate(all="ignore"):
        params, _ = train(lr, wd, epochs=6)
    trials.append((accuracy(params, val), lr, wd))
trials.sort(reverse=True)
for acc_, lr, wd in trials[:5]:
    print(f"검증 정확도 {acc_:.3f}  η = {lr:.3g}, λ = {wd:.1e}")
plt.figure(figsize=(5, 3.4))
plt.scatter([t[1] for t in trials], [t[2] for t in trials], c=[t[0] for t in trials],
            cmap="viridis", s=60)
plt.xscale("log")
plt.yscale("log")
plt.colorbar(label="검증 정확도")
plt.xlabel("학습률")
plt.ylabel("가중치 감쇠")
plt.show()

상위 5개는 모두 η가 0.13~0.54 사이이고, λ는 $6\times10^{-5}$부터 $10^{-2}$까지 흩어져 있다. 이 설정(6에폭)에서는 성능을 학습률이 거의 결정하고, 가중치 감쇠는 이 범위에서 큰 차이를 만들지 않는다. η가 0.03보다 작은 시도는 6에폭 안에 충분히 학습되지 못했고(0.85 이하), η = 1.6은 발산해 찍기 수준(0.100)이다. 다음 단계라면 η를 0.1~0.6으로 좁혀 다시 탐색하고, 상위 설정 몇 개를 여러 시드로 비교한다.

정리

  • 순서: 데이터 보기 → 첫 손실($\ln K$) → 기울기 검증 → 작은 배치 외우기 → 학습률 탐색 → 기록하며 학습 → 기준선 비교.
  • 증상으로 원인을 좁힌다: NaN(넘침·학습률), $\ln K$ 정체(기울기·갱신), 찍기 수준 검증(레이블·전처리).
  • 기록: 손실·지표, 학습률, 기울기 노름, 갱신 비율(약 $10^{-3}$), 활성값 통계.
  • 무작위 탐색 + 로그 눈금 + 거친 탐색에서 세밀한 탐색으로. 학습률부터.
  • 재현성: 시드 고정, 설정 기록, 결론은 여러 시드의 평균 ± 표준편차로.

연습 문제

  1. "손실이 처음 몇 에폭은 잘 줄다가 갑자기 NaN이 된다." 가능한 원인 세 가지와 확인 방법을 쓰라.
    풀이

    (1) 학습률이 커서 어느 순간 발산: 기울기 노름 기록, 학습률을 줄여 재현되는지. (2) 로그나 나눗셈의 안정화 누락: 확률이 0이 되는 순간 $\ln 0$. 로짓 형태 손실(10, 11일차)로 바꾼다. (3) 기울기 폭발: 클리핑(24일차)을 넣고 노름을 기록한다.

  2. 시드 5개로 두 모델의 테스트 정확도가 A: 97.1, 97.4, 96.9, 97.3, 97.0, B: 97.5, 97.2, 97.6, 97.4, 97.3이다. 평균과 표준편차를 구하고 B가 낫다고 말할 수 있는지 판단하라.
    풀이

    A: 평균 97.14, 표준편차 약 0.18. B: 평균 97.40, 약 0.14. 차이 0.26은 표준편차보다 크고 B의 최솟값(97.2)이 A의 평균보다 높아 B가 나을 가능성이 높다. 엄밀하게는 통계 검정이나 더 많은 시드로 확인한다.

    A = np.array([97.1, 97.4, 96.9, 97.3, 97.0]); B = np.array([97.5, 97.2, 97.6, 97.4, 97.3])
print(A.mean(), A.std(ddof=1), B.mean(), B.std(ddof=1))

    풀이

    죽은 ReLU(16일차). 큰 학습률이나 나쁜 초기화로 대부분의 뉴런이 음수 영역에 빠졌다. 학습률을 줄이거나, He 초기화를 확인하거나, Leaky ReLU·정규화 층을 쓴다.

def init_params(rng):
    return [rng.normal(0, 1.0, (64, 64)), np.zeros(64), rng.normal(0, 1.0, (64, 10)),
            np.zeros(10)]
def forward_backward(params, xb, yb):
    W1, b1, W2, b2 = params
    h = np.maximum(0, xb @ W1 + b1); z = h @ W2 + b2
    p = np.exp(z) / np.exp(z).sum(1, keepdims=True)
    loss = -np.log(p[np.arange(len(yb)), yb]).mean()
    g = p.copy(); g[np.arange(len(yb)), yb] -= 1
    dW2 = h.T @ g; db2 = g.sum(0)
    dh = g @ W2.T; dh[h < 0] = 0
    dW1 = xb.T @ dh; db1 = dh.sum(0)
    return loss, [dW1, db1, dW2, db2]
def predict(params, Xq):
    W1, b1, W2, b2 = params
    return (np.maximum(0, Xq @ W1 + b1) @ W2 + b2).argmax(1)

    def grad_check(fb, params, xb, yb, n_each=40, seed=0):
    loss, grads = fb(params, xb, yb); r = np.random.default_rng(seed); out = []
    for P, G in zip(params, grads):
        worst, ratios = 0.0, []
        for _ in range(n_each):
            idx = tuple(r.integers(0, s) for s in P.shape); o = P[idx]
            P[idx] = o + 1e-5
            lp = fb(params, xb, yb)[0]
            P[idx] = o - 1e-5
            lm = fb(params, xb, yb)[0]
            P[idx] = o
            num = (lp - lm) / 2e-5
            if abs(num) > 1e-8: ratios.append(G[idx] / num)
            worst = max(worst, abs(num - G[idx]) / max(abs(num), abs(G[idx]), 1e-12))
        out.append((worst, np.median(ratios) if ratios else np.nan))
    return out

참고 답안: 버그 7개와 고친 코드
  1. 레이블 섞기(load): y[rng.permutation(tr)]가 입력과 다른 순서로 레이블을 뽑는다. 2단계 그림에서 숫자와 레이블이 맞지 않는다. y[tr]로 고친다.
  2. 입력 정규화 누락: 값이 0~16이다. 16으로 나눈다.
  3. 초기화가 너무 큼: 표준편차 1.0이면 정규화하지 않은 입력에서 로짓이 973까지 커진다. 입력을 16으로 나눠도 로짓이 60을 넘고 첫 손실이 17.9로, 기대값 2.303과 거리가 멀다(3단계). He 초기화 $\sqrt{2/64}$로 바꾼다.
  4. 소프트맥스 안정화 누락: 큰 로짓에서 exp가 넘쳐 NaN이 된다. 행마다 최댓값을 뺀다.
  5. 기울기를 N으로 나누지 않음: 손실은 평균인데 기울기는 합이다. 4단계에서 W2, b2의 비율 중앙값이 정확히 배치 크기 8이고, 최대 상대 오차도 $7/8 = 0.875$다. 모든 원소가 똑같이 8배라는 뜻이다. g /= len(yb)로 고친다.
  6. ReLU 마스크 오류: h는 ReLU 출력이라 음수가 없으므로 dh[h < 0] = 0은 아무것도 막지 못한다. 활성화 이전 값으로 dh[a <= 0] = 0. 4단계에서 W1, b1은 양상이 다르다. 최대 상대 오차가 0.875를 넘고(1.163, 1.000), b1의 비율 중앙값도 8이 아니다(10.58). 8배 말고 다른 오류가 하나 더 있다는 신호다. 꺼진 유닛으로 기울기가 새어 들어가 수치 미분이 0인 곳에서도 역전파 값이 0이 아니다.
  7. 학습 데이터로 평가: 정확도를 Xtr로 계산한다. 테스트 세트로 평가한다. 덧붙여 에폭마다 데이터를 섞지 않던 것도 섞도록 고친다.
def load_fixed():
    # 2. 정규화
    d = load_data("digits"); X_, y_ = d["X"].astype(float) / 16, d["y"]
    rng = np.random.default_rng(0); idx = rng.permutation(len(X_))
    tr_, te_ = idx[:1400], idx[1400:]
    # 1. 같은 순서
    return X_[tr_], y_[tr_], X_[te_], y_[te_]
def init_fixed(rng):
    # 3. He 초기화
    s = math.sqrt(2 / 64)
    return [rng.normal(0, s, (64, 64)), np.zeros(64), rng.normal(0, s, (64, 10)),
            np.zeros(10)]
def forward_backward_fixed(params, xb, yb):
    W1, b1, W2, b2 = params
    a = xb @ W1 + b1; h = np.maximum(0, a); z = h @ W2 + b2
    # 4. 안정화
    z = z - z.max(1, keepdims=True)
    p = np.exp(z) / np.exp(z).sum(1, keepdims=True)
    loss = -np.log(p[np.arange(len(yb)), yb]).mean()
    # 5. 평균의 기울기
    g = p.copy(); g[np.arange(len(yb)), yb] -= 1; g /= len(yb)
    dW2 = h.T @ g; db2 = g.sum(0)
    # 6. 활성화 이전 값으로
    dh = g @ W2.T; dh[a <= 0] = 0
    return loss, [xb.T @ dh, dh.sum(0), dW2, db2]
Xtr_f, ytr_f, Xte_f, yte_f = load_fixed()
errs = grad_check(forward_backward_fixed, init_fixed(np.random.default_rng(3)),
                  Xtr_f[:8], ytr_f[:8])
print("기울기 검증, 최대 상대 오차:", ", ".join(f"{w:.1e}" for w, _ in errs))

    loss, grads = forward_backward_fixed(p_small, Xtr_f[:32], ytr_f[:32])
    for p_, g_ in zip(p_small, grads): p_ -= 0.5 * g_
print(f"32개 외우기: 손실 {loss:.4f}")
def run_fixed(lr=0.1, epochs=20):
    params = init_fixed(np.random.default_rng(1)); r = np.random.default_rng(2)
    for ep in range(epochs):
        # 에폭마다 섞기
        order = r.permutation(len(Xtr_f))
        for s in range(0, len(order), 32):
            i = order[s:s + 32]
            loss, grads = forward_backward_fixed(params, Xtr_f[i], ytr_f[i])
            for p_, g_ in zip(params, grads): p_ -= lr * g_
    # 7. 테스트로 평가
    return (predict(params, Xte_f) == yte_f).mean()
print(f"고친 코드의 테스트 정확도: {run_fixed():.3f}")

버그 하나하나는 사소하지만, 여러 개가 겹치면 증상이 서로를 가린다. 예를 들어 레이블 섞기 버그가 있으면 다른 버그를 모두 고쳐도 정확도가 찍기 수준이라, 무엇을 고쳤는지 효과를 볼 수 없다. 절차의 앞 단계(데이터 보기)를 먼저 하는 이유다.
