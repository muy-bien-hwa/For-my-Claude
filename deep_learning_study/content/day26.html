• 판별 모델과 생성 모델의 차이, 그리고 "생성"이 확률분포 $p(x)$를 배우는 일임을 이해한다.
  • 오토인코더로 차원 축소·잡음 제거를 하고, 그 잠재 공간이 생성에 부적합한 이유를 안다.
  • VAE의 ELBO를 유도하고 재구성 항과 KL 항의 역할을 설명한다.
  • 재매개변수화 트릭이 왜 필요한지 이해하고 PyTorch로 VAE를 구현한다.
👨‍🏫 이해에서 창조로 지금까지의 모델은 대부분 "이 이미지는 고양이인가?"에 답했습니다($p(y\mid x)$). 이제 "고양이 이미지를 하나 그려 줘"에 답하는 모델을 만듭니다($p(x)$에서 샘플링). 오늘 배우는 VAE의 아이디어(인코더로 압축한 잠재 공간, KL 규제)는 Stable Diffusion 같은 최신 이미지 생성 모델의 한 부품으로 지금도 쓰이고 있습니다.

1. 판별 모델 vs 생성 모델

판별 모델생성 모델
학습 대상$p(y\mid x)$$p(x)$ 또는 $p(x\mid y)$
질문"이건 무엇인가?""이런 데이터는 어떻게 생겼나? 하나 만들어 봐"
예분류기, 회귀VAE, GAN, 확산 모델, GPT(텍스트의 $p(x)$)

28×28 이미지 공간은 784차원이고, 무작위로 점을 찍으면 거의 항상 잡음입니다. "진짜 같은 이미지"는 이 거대한 공간의 아주 얇은 영역(다양체)에 모여 있습니다. 생성 모델의 목표는 그 영역을 찾아서 거기서 샘플을 뽑는 것입니다.

2. 오토인코더

입력을 작은 잠재 벡터 $z$로 압축하는 인코더와, $z$에서 입력을 복원하는 디코더를 함께 학습합니다. 정답이 입력 자신이므로 레이블이 필요 없습니다.

$$z = f_{enc}(x),\qquad \hat x = f_{dec}(z),\qquad L = \|x - \hat x\|^2$$

병목(작은 $z$) 때문에 모델은 데이터의 핵심 구조만 남기도록 강제됩니다. 선형 오토인코더는 PCA와 같은 결과를 냅니다.

import numpy as np
import matplotlib.pyplot as plt
rng = np.random.default_rng(0)

# 2차원 곡선(다양체) 위의 3차원 데이터 → 1차원 잠재 공간으로 압축하는 선형 AE = PCA
t = rng.uniform(-1, 1, 500)
X = np.c_[t, 0.5 * t, 0.2 * t] + rng.normal(0, 0.05, (500, 3))
Xc = X - X.mean(0)
U, S, Vt = np.linalg.svd(Xc, full_matrices=False)
print("특잇값:", S.round(2), "→ 첫 성분이 대부분의 정보를 담는다")
z = Xc @ Vt[0]                     # 인코딩: 3D → 1D
Xhat = np.outer(z, Vt[0]) + X.mean(0)   # 디코딩: 1D → 3D
print("재구성 MSE:", ((X - Xhat)**2).mean().round(5))
⚠️ 오토인코더는 생성을 잘 못한다 학습된 잠재 공간은 학습 샘플이 놓인 점들 근처만 의미가 있고, 그 사이에는 구멍이 숭숭 뚫려 있습니다. 잠재 공간에서 무작위로 $z$를 뽑아 디코딩하면 이상한 결과가 나옵니다. "어디서 $z$를 뽑아야 하는지"를 모르기 때문입니다. VAE는 이 문제를 해결합니다.

오토인코더의 쓰임: 차원 축소, 잡음 제거(입력에 잡음을 넣고 깨끗한 원본을 복원하도록 학습), 이상 탐지(재구성 오차가 크면 이상치).

3. VAE: 잠재 공간을 확률적으로

VAE(Kingma & Welling, 2013)는 생성 과정을 이렇게 가정합니다.

  1. 잠재 변수를 간단한 분포에서 뽑는다: $z\sim p(z) = \mathcal N(0, I)$.
  2. 디코더가 $z$로부터 데이터를 만든다: $x\sim p_\theta(x\mid z)$.

학습이 끝나면 $\mathcal N(0, I)$에서 $z$를 뽑아 디코딩하기만 하면 새 샘플이 나옵니다. 문제는 학습입니다. 우도 $p_\theta(x) = \int p_\theta(x\mid z)p(z)\,dz$를 직접 계산할 수 없습니다.

해법: 인코더가 $x$에 대한 $z$의 분포를 근사하게 합니다: $q_\phi(z\mid x) = \mathcal N(\mu_\phi(x), \sigma^2_\phi(x))$. 그러면 로그 우도의 하한(ELBO)을 최대화할 수 있습니다.

$$\log p_\theta(x) \ \ge\ \underbrace{\mathbb E_{q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big]}_{\text{재구성: 잘 복원하라}} \;-\; \underbrace{D_{KL}\big(q_\phi(z\mid x)\,\|\,\mathcal N(0, I)\big)}_{\text{규제: 잠재 분포를 표준정규에 가깝게}}$$
ELBO 유도 (Day 5의 KL 발산을 떠올리며) $$\log p(x) = \mathbb E_q[\log p(x)] = \mathbb E_q\!\left[\log\frac{p(x,z)}{q(z\mid x)}\right] + \underbrace{D_{KL}\big(q(z\mid x)\,\|\,p(z\mid x)\big)}_{\ge 0}$$

KL은 항상 0 이상이므로 첫 항이 하한입니다. 첫 항을 $p(x,z) = p(x\mid z)p(z)$로 풀면 위 ELBO 식이 됩니다. ELBO를 최대화하면 우도도 올라가고, 동시에 $q$가 진짜 사후분포에 가까워집니다.

가우시안끼리의 KL은 닫힌 형태로 계산됩니다.

$$D_{KL}\big(\mathcal N(\mu,\sigma^2)\,\|\,\mathcal N(0,1)\big) = \frac12\sum_j\left(\mu_j^2 + \sigma_j^2 - \log\sigma_j^2 - 1\right)$$
🔑 두 항의 줄다리기
  • 재구성 항만 있으면: 각 샘플이 잠재 공간의 고립된 점이 됨 → 일반 오토인코더.
  • KL 항만 있으면: 모든 샘플이 $\mathcal N(0,I)$로 뭉개짐 → 아무것도 구분 못 함.
  • 둘 다: 비슷한 데이터는 가까이, 잠재 공간 전체가 빈틈없이 채워짐 → 어디서 뽑아도 그럴듯한 샘플, 부드러운 보간.

4. 재매개변수화 트릭

$z$를 $\mathcal N(\mu, \sigma^2)$에서 샘플링하는 연산은 미분이 안 됩니다. 무작위성을 바깥으로 빼면 됩니다.

$$z = \mu + \sigma\odot\epsilon,\qquad \epsilon\sim\mathcal N(0, I)$$

이제 $\epsilon$은 그냥 상수 입력이고, $z$는 $\mu$와 $\sigma$의 미분 가능한 함수입니다. 기울기가 인코더까지 흐릅니다. 수치 안정성을 위해 인코더는 $\sigma$ 대신 $\log\sigma^2$를 출력합니다.

# 재매개변수화의 효과를 수치로 확인: E[z^2]를 mu로 미분하면 2*mu 여야 한다
mu, log_var = 1.5, np.log(0.25)
eps = rng.normal(size=200000)
z = mu + np.exp(0.5 * log_var) * eps
# z^2의 mu에 대한 기울기 = 2z * dz/dmu = 2z * 1
print("몬테카를로 기울기 추정:", (2 * z).mean().round(3), "  해석적 값 2μ =", 2 * mu)
kl = 0.5 * (mu**2 + np.exp(log_var) - log_var - 1)
print("KL(N(1.5, 0.5²) || N(0,1)) =", round(kl, 4))

5. PyTorch VAE

class VAE(nn.Module):
    def __init__(self, d_in=784, d_h=400, d_z=16):
        super().__init__()
        self.enc = nn.Sequential(nn.Linear(d_in, d_h), nn.ReLU())
        self.mu, self.logvar = nn.Linear(d_h, d_z), nn.Linear(d_h, d_z)
        self.dec = nn.Sequential(nn.Linear(d_z, d_h), nn.ReLU(), nn.Linear(d_h, d_in))   # 로짓 출력
    def encode(self, x):
        h = self.enc(x.flatten(1)); return self.mu(h), self.logvar(h)
    def reparameterize(self, mu, logvar):
        return mu + torch.exp(0.5 * logvar) * torch.randn_like(mu)
    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.dec(z), mu, logvar

def vae_loss(x, x_logits, mu, logvar, beta=1.0):
    recon = F.binary_cross_entropy_with_logits(x_logits, x.flatten(1), reduction="sum") / x.size(0)
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp()) / x.size(0)
    return recon + beta * kl, recon, kl

# 생성: 사전분포에서 뽑아 디코딩
with torch.no_grad():
    z = torch.randn(64, 16, device=device)

  • β-VAE: KL 항에 β > 1을 곱하면 잠재 축들이 더 독립적이고 해석 가능한 요인(굵기, 기울기 등)을 담는 경향이 있습니다. 대신 재구성은 흐려집니다.
  • VAE 샘플이 다소 흐릿한 것은 잘 알려진 한계입니다. 픽셀별 독립 가우시안/베르누이 가정과 평균화 효과 때문입니다. 선명한 생성은 GAN과 확산 모델의 몫입니다(Day 27).
  • 잠재 확산: Stable Diffusion은 VAE(정확히는 KL 규제 오토인코더)로 이미지를 작은 잠재 공간으로 압축하고, 그 공간에서 확산 모델을 돌립니다.
