• 계산 그래프로 함수를 표현하고, 순전파·역전파를 노드 단위로 손으로 계산한다.
  • 덧셈·곱셈·분기 노드에서 기울기가 어떻게 흐르는지(게이트 직관) 이해한다.
  • 상류 기울기 × 국소 기울기 패턴을 체득한다.
  • Linear, ReLU, Softmax+CE 층의 역전파 공식을 행렬 형태로 유도한다.
  • 스칼라 자동 미분 엔진(micrograd 스타일)을 직접 만든다.
👨‍🏫 이 강의에서 가장 중요한 이틀 역전파를 "PyTorch가 알아서 해 주는 것"으로만 알면, 학습이 안 될 때 아무것도 할 수 없습니다. 기울기 소실, 폭발, NaN, 죽은 뉴런… 모든 학습 문제는 기울기가 어떻게 흐르는지 이해해야 진단할 수 있습니다. Andrej Karpathy는 "역전파를 직접 구현해 보지 않은 사람은 딥러닝을 이해한다고 말하기 어렵다"고 했습니다. 오늘은 펜과 종이를 꼭 준비하세요.

1. 계산 그래프

복잡한 함수를 기본 연산(+, ×, exp, …)의 노드로 쪼개 그래프로 그립니다. 예: $f(x,y,z) = (x+y)\cdot z$.

  1. 순전파: $q = x+y = 3$, $f = q\cdot z = -12$.
  2. 역전파는 출력에서 시작합니다. $\partial f/\partial f = 1$.
  3. 곱셈 노드 $f = qz$: $\partial f/\partial q = z = -4$, $\partial f/\partial z = q = 3$.
  4. 덧셈 노드 $q = x+y$: 국소 기울기 $\partial q/\partial x = 1$. 연쇄법칙으로 $\partial f/\partial x = \partial f/\partial q\cdot\partial q/\partial x = -4\cdot1 = -4$. $y$도 마찬가지로 $-4$.
🔑 역전파의 유일한 규칙 각 노드는 자기 입력에 대한 국소 기울기만 알면 됩니다. 위에서 내려온 상류 기울기(upstream gradient, $\partial L/\partial\text{출력}$)에 국소 기울기를 곱해서 아래로 내려보냅니다. $$\underbrace{\frac{\partial L}{\partial\text{입력}}}_{\text{하류}} = \underbrace{\frac{\partial L}{\partial\text{출력}}}_{\text{상류}}\times\underbrace{\frac{\partial\,\text{출력}}{\partial\,\text{입력}}}_{\text{국소}}$$ 각 노드는 그래프 전체를 몰라도 됩니다. 이 국소성 덕분에 어떤 복잡한 모델이든 자동 미분이 가능합니다.

2. 게이트별 기울기 직관

노드순전파역전파 동작별명
덧셈 $a+b$더함상류 기울기를 그대로 양쪽에 복사분배기
곱셈 $a\cdot b$곱함$a$에는 상류×$b$, $b$에는 상류×$a$ (서로 바꿔서)교환기
max$(a,b)$큰 값 선택큰 쪽에만 기울기 전달, 작은 쪽은 0라우터 (ReLU, MaxPool)
분기(한 값을 여러 곳에서 사용)복사여러 곳에서 온 기울기를 더함합산기
⚠️ 분기 규칙을 잊지 마세요 한 변수가 여러 곳에서 쓰이면 기울기를 누적(+=)해야 합니다. 예: $f = x\cdot x$이면 두 경로에서 $x$씩 와서 $2x$. RNN에서 같은 가중치를 매 시점 공유하는 것, ResNet의 잔차 연결도 모두 이 규칙을 따릅니다. PyTorch가 .grad를 덮어쓰지 않고 누적하는 이유이기도 합니다(그래서 zero_grad()가 필요합니다).

3. 인터랙티브: 뉴런 하나의 역전파

$f = \sigma(wx+b)$, $L = (f-y)^2$. 슬라이더를 움직이며 빨간 기울기가 어떻게 곱해지는지 따라가 보세요. 특히 $w x + b$가 아주 크거나 작을 때(시그모이드 포화) 기울기가 어떻게 되는지 보세요.

4. 층 단위 역전파 공식 (행렬)

실제 신경망에서는 스칼라가 아니라 행렬 단위로 계산합니다. 상류 기울기를 $G = \partial L/\partial(\text{출력})$이라 하면:

Linear: $Y = XW + \mathbf b$

$$\frac{\partial L}{\partial W} = X^\top G,\qquad \frac{\partial L}{\partial\mathbf b} = \sum_{\text{배치}} G,\qquad \frac{\partial L}{\partial X} = GW^\top$$

외우지 말고 형상으로 맞추세요. $X$:(N,d), $W$:(d,k), $G$:(N,k). $(d,k)$를 만들려면 $X^\top G$. $(N,d)$를 만들려면 $GW^\top$. 편향은 배치의 모든 샘플에 더해졌으므로(분기!) 배치 축으로 합합니다.

왜 $X^\top G$인가? (원소별 유도)

$Y_{nj} = \sum_i X_{ni}W_{ij} + b_j$. $W_{ij}$는 모든 샘플 $n$의 $Y_{nj}$에 영향을 줍니다(분기 → 합).

$$\frac{\partial L}{\partial W_{ij}} = \sum_n \frac{\partial L}{\partial Y_{nj}}\frac{\partial Y_{nj}}{\partial W_{ij}} = \sum_n G_{nj}X_{ni} = (X^\top G)_{ij}$$

ReLU: $Y = \max(0, X)$

$$\frac{\partial L}{\partial X} = G\odot\mathbb 1[X>0]$$

순전파 때 양수였던 위치만 기울기를 통과시킵니다($\odot$은 원소별 곱).

Sigmoid: $Y = \sigma(X)$

$$\frac{\partial L}{\partial X} = G\odot Y\odot(1-Y)$$

Softmax + 교차 엔트로피 (함께)

$$\frac{\partial L}{\partial Z} = \frac{1}{N}(P - Y_{\text{onehot}})$$

Day 7에서 유도한 바로 그 식입니다. 평균 손실이므로 $1/N$이 붙습니다.

6. 나만의 자동 미분 엔진 만들기

이제 원리를 코드로 옮깁니다. 각 값(Value)이 자신을 만든 연산과 입력을 기억하고, backward()를 호출하면 그래프를 위상 정렬된 역순으로 돌며 각 노드의 국소 역전파 함수를 실행합니다. PyTorch autograd의 핵심 아이디어를 50줄로 구현한 것입니다.

import math

class Value:
    def __init__(self, data, _children=(), _op=''):
        self.data = data
        self.grad = 0.0
        self._backward = lambda: None
        self._prev = set(_children)
        self._op = _op
    def __repr__(self): return f"Value(data={self.data:.4f}, grad={self.grad:.4f})"

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), '+')
        def _backward():
            self.grad += out.grad            # 분배기: 그대로 (+= 로 누적!)
            other.grad += out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), '*')
        def _backward():
            self.grad += other.data * out.grad   # 교환기
            other.grad += self.data * out.grad
        out._backward = _backward
        return out

    def __pow__(self, k):
        out = Value(self.data ** k, (self,), f'**{k}')
        def _backward(): self.grad += k * self.data ** (k - 1) * out.grad
        out._backward = _backward
        return out

    def tanh(self):
        t = math.tanh(self.data)
        out = Value(t, (self,), 'tanh')
        def _backward(): self.grad += (1 - t * t) * out.grad
        out._backward = _backward
        return out

    def relu(self):
        out = Value(max(0.0, self.data), (self,), 'relu')
        def _backward(): self.grad += (out.data > 0) * out.grad
        out._backward = _backward
        return out

    def backward(self):
        topo, seen = [], set()
        def build(v):
            if v not in seen:
                seen.add(v)
                for c in v._prev: build(c)
                topo.append(v)
        build(self)
        self.grad = 1.0
        for v in reversed(topo):     # 출력 → 입력 순서
            v._backward()

    __radd__ = __add__
    __rmul__ = __mul__
    def __neg__(self): return self * -1
    def __sub__(self, o): return self + (-o)

# 테스트 1: 위 그림의 예제
x, y, z = Value(-2.0), Value(5.0), Value(-4.0)
f = (x + y) * z
f.backward()
print("x:", x, "\ny:", y, "\nz:", z)

# 테스트 2: 뉴런 하나 + 손실
x1, w1, b = Value(1.5), Value(-0.8), Value(0.5)
out = (w1 * x1 + b).tanh()
loss = (out - 1.0) ** 2
loss.backward()
print("\nloss:", round(loss.data, 4), " dL/dw:", round(w1.grad, 4), " dL/db:", round(b.grad, 4))

이 엔진으로 신경망도 학습시킬 수 있습니다. 느리지만 원리는 PyTorch와 같습니다.

import random
random.seed(1)

class Neuron:
    def __init__(self, nin, act=True):
        self.w = [Value(random.uniform(-1, 1)) for _ in range(nin)]; self.b = Value(0.0); self.act = act
    def __call__(self, x):
        s = sum((wi * xi for wi, xi in zip(self.w, x)), self.b)
        return s.tanh() if self.act else s
    def parameters(self): return self.w + [self.b]

class MLP:
    def __init__(self, sizes):
        self.layers = [[Neuron(sizes[i], act=(i < len(sizes) - 2)) for _ in range(sizes[i + 1])] for i in range(len(sizes) - 1)]
    def __call__(self, x):
        for layer in self.layers:
            x = [n(x) for n in layer]
        return x[0] if len(x) == 1 else x
    def parameters(self): return [p for layer in self.layers for n in layer for p in n.parameters()]

# XOR 학습 (출력 -1 / +1)
xs = [[0, 0], [0, 1], [1, 0], [1, 1]]; ys = [-1, 1, 1, -1]
net = MLP([2, 4, 1])
print("파라미터 수:", len(net.parameters()))
for step in range(150):
    preds = [net(x) for x in xs]
    loss = sum(((p - t) ** 2 for p, t in zip(preds, ys)), Value(0.0))
    for p in net.parameters(): p.grad = 0.0       # zero_grad!
    loss.backward()
    for p in net.parameters(): p.data -= 0.05 * p.grad
    if step % 30 == 0: print(f"step {step:3d}  loss {loss.data:.4f}")
print("예측:", [round(net(x).data, 2) for x in xs], " 정답:", ys)
💡 실험: zero_grad를 빼 보세요 p.grad = 0.0 줄을 주석 처리하고 실행하면 어떻게 될까요? 기울기가 매 스텝 누적되어 학습이 엉망이 됩니다. PyTorch에서 optimizer.zero_grad()를 잊는 것은 초보자의 단골 실수입니다.

def _exp(self):
    out = Value(math.exp(self.data), (self,), 'exp')
    def _backward(): self.grad += out.data * out.grad     # (e^x)' = e^x
    out._backward = _backward
    return out
