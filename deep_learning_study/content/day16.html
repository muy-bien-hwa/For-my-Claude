• 다층 퍼셉트론의 구조와 층별 계산식을 쓸 수 있다.
  • 활성화 함수가 없으면 층을 쌓아도 선형 모델임을 보일 수 있다.
  • 시그모이드, tanh, ReLU, Leaky ReLU, GELU, SiLU의 모양과 도함수, 장단점을 비교할 수 있다.
  • 은닉층이 입력 공간을 변형해 선형 분리 가능한 표현을 만든다는 것을 설명할 수 있다.
  • 보편 근사 정리의 의미와 한계, 깊이가 주는 이점을 ReLU 조각으로 설명할 수 있다.

퍼셉트론을 쌓으면

15일차에서 퍼셉트론 세 개를 두 층으로 연결해 XOR을 풀었다. 이처럼 뉴런을 층으로 쌓고 한 층의 출력을 다음 층의 입력으로 쓰는 신경망을 다층 퍼셉트론(MLP)이라 한다. 입력층과 출력층 사이의 층을 은닉층이라 부른다. 은닉층의 값은 데이터에 직접 나타나지 않고 신경망이 스스로 만든 중간 표현이다.

이 강의는 입력을 행벡터 $\mathbf x$(형상 $(d,)$)로 쓰고 $\mathbf xW$로 곱한다. 코드의 배치 계산 $XW$와 같은 모양이다(17일차). 층 하나의 계산은 11일차의 소프트맥스 회귀와 같은 선형 변환에 활성화 함수 $\phi$를 씌운 것이다.

$$\mathbf h = \phi(\mathbf xW_1 + \mathbf b_1), \qquad \hat y = \mathbf hW_2 + \mathbf b_2 \quad(\text{분류면 뒤에 } \sigma \text{ 또는 softmax})$$

활성화 함수가 필요한 이유

층과 층 사이에 넣는 비선형 함수 $\phi$를 활성화 함수라 한다. 이것을 빼면 어떻게 될까? 두 선형층을 연달아 적용하면

$$(\mathbf xW_1 + \mathbf b_1)W_2 + \mathbf b_2 = \mathbf x\,\underbrace{(W_1W_2)}_{W} + \underbrace{(\mathbf b_1W_2 + \mathbf b_2)}_{\mathbf b}$$

로, 하나의 선형층 $\mathbf xW + \mathbf b$와 같다. 100층을 쌓아도 결국 하나의 행렬곱이다. 선형 함수의 합성은 선형이기 때문이다. 결정 경계도 여전히 직선이라 XOR조차 풀 수 없다.

$W_1 = \begin{bmatrix}1 & 2\\ 0 & 1\end{bmatrix}$, $W_2 = \begin{bmatrix}3\\ -1\end{bmatrix}$이면 $W_1W_2 = \begin{bmatrix}1\\ -1\end{bmatrix}$. 입력 $\mathbf x = (2, 5)$를 두 층에 차례로 넣으면 $(2, 9)$를 거쳐 $3\cdot2 - 9 = -3$, 합친 층에 넣으면 $2 - 5 = -3$이다. 같다. 중간에 ReLU를 넣으면 $(2, 9)$가 그대로 통과해 결과가 같지만, 입력이 $(-2, 1)$이면 첫 층 출력 $(-2, -3)$이 ReLU에서 $(0, 0)$이 되어 결과 0이 된다. 합친 선형층의 답은 $-2 - 1 = -3$이다. 활성화 함수가 입력에 따라 다르게 동작하는 "꺾임"을 만든다.

활성화 함수의 종류

쓸모 있는 활성화 함수는 비선형이면서 미분 가능(적어도 거의 모든 곳에서)해야 한다. 역전파에서 기울기가 층을 지날 때마다 $\phi'(z)$가 곱해지므로(18일차), 도함수의 모양이 학습의 성패를 가른다.

함수식범위특징
시그모이드$\sigma(z) = \frac1{1 + e^{-z}}$(0, 1)도함수 최대 0.25, 양 끝에서 포화. 지금은 출력층(확률)과 게이트(37일차)에만 쓴다.
tanh$\frac{e^z - e^{-z}}{e^z + e^{-z}} = 2\sigma(2z) - 1$(−1, 1)0을 중심으로 대칭. 도함수 최대 1. 양 끝 포화. RNN에서 쓴다.
ReLU$\max(0, z)$[0, ∞)양수 구간 도함수 1이라 기울기가 줄지 않는다. 계산이 가장 싸다. 음수만 들어오는 뉴런은 영원히 0(죽은 ReLU).
Leaky ReLU$\max(\alpha z, z)$, $\alpha = 0.01$ 등(−∞, ∞)음수 구간에도 작은 기울기를 남겨 죽은 뉴런을 막는다.
GELU$z\,\Phi(z)$ ($\Phi$: 표준정규 누적분포)약 [−0.17, ∞)ReLU를 매끄럽게 만든 모양. BERT, GPT 등 트랜스포머의 표준.
SiLU (Swish)$z\,\sigma(z)$약 [−0.28, ∞)GELU와 비슷하다. 최신 대형 언어 모델(SwiGLU)에서 쓴다.

시그모이드의 도함수는 $|z| = 5$에서 0.0066이다. 이런 구간을 포화 구간이라 한다. 시그모이드 층을 여러 개 쌓으면 기울기에 0.25 이하의 수가 계속 곱해져 앞쪽 층에 거의 전달되지 않는다(5일차 경고, 24일차). 2010년대 초 ReLU가 표준이 된 가장 큰 이유가 이것이다.

실무의 기본값: 은닉층은 ReLU(또는 GELU), 이진 분류의 출력은 시그모이드, 다중 분류의 출력은 소프트맥스, 회귀의 출력은 활성화 없음(항등).

은닉층은 공간을 바꾼다

4일차에서 행렬은 공간을 늘이고, 돌리고, 기울이는 선형변환이었다. 은닉층은 여기에 활성화 함수를 더한다. tanh는 먼 값을 −1과 1 근처로 눌러 담고, ReLU는 음수 쪽을 0으로 접는다. 선형변환이 공간을 늘이고 돌린 뒤 활성화가 그것을 휘거나 접는다. 이 과정을 거치면 원래 공간에서 뒤엉켜 있던 두 클래스가 직선 하나로 갈리는 배치로 바뀔 수 있다. 출력층은 그 새 공간에서 로지스틱 회귀를 할 뿐이다.

보편 근사 정리

MLP는 어떤 함수까지 표현할 수 있을까? 답은 "거의 모든 함수"다.

은닉층이 하나뿐인 MLP라도 은닉 뉴런이 충분히 많으면, 유계 구간 위의 임의의 연속 함수를 원하는 만큼 정확하게 근사할 수 있다(활성화 함수가 다항식이 아닌 한).

이것이 보편 근사 정리다. ReLU로 보면 직관이 쉽다. $\mathrm{ReLU}(x - c)$는 $x = c$에서 꺾이는 직선이다. 이런 꺾인 직선 여러 개에 가중치를 곱해 더하면 꺾은선이 된다. 꺾는 점을 촘촘히 두면 어떤 곡선도 꺾은선으로 따라 그릴 수 있다.

  • 필요한 뉴런 수: 함수가 복잡하면 기하급수적으로 많을 수 있다.
  • 학습 가능성: 그런 가중치가 "존재"한다는 것이지, 경사하강법이 그것을 "찾는다"는 보장이 아니다.
  • 일반화: 학습 데이터에 맞는 함수가 새 데이터에도 맞는다는 보장이 없다(12일차).

깊이의 의미

은닉층 하나로 충분하다면 왜 깊게 쌓는가? 같은 뉴런 수로 표현할 수 있는 함수의 복잡도가 깊이에 따라 훨씬 빠르게 늘기 때문이다. ReLU 신경망의 출력은 꺾은선(고차원에서는 조각난 평면)이고, 그 조각의 수가 복잡도의 척도다.

ReLU 두 개로 만든 "텐트" 함수 $t(x) = 2\,\mathrm{ReLU}(x) - 4\,\mathrm{ReLU}(x - 0.5)$는 $[0, 1]$에서 0 → 1 → 0으로 오르내리는 조각 2개짜리 함수다. 이것을 한 번 더 통과시킨 $t(t(x))$는 조각이 4개, 세 번이면 8개, $k$번이면 $2^k$개다. 층마다 ReLU 2개, 총 $2k$개의 뉴런으로 $2^k$개의 조각을 만든다. 은닉층 하나로 같은 함수를 만들려면 조각마다 뉴런 하나, 즉 약 $2^k$개가 필요하다. 깊이는 "같은 접기를 반복해 패턴을 기하급수적으로 늘리는" 능력이다. 실전의 데이터(이미지의 획 → 모양 → 부품 → 물체)도 이런 계층 구조를 가진다.

신경망 놀이터

입력 좌표 두 개만으로 여러 데이터를 분류하는 신경망을 학습시켜 본다. 은닉층과 뉴런 수를 바꿔 가며 위의 내용을 확인한다.

  1. "원" 데이터에서 은닉층 0개(로지스틱 회귀)로 학습한다. 경계가 직선이라 정확도가 50% 근처에 머문다.
  2. 은닉층 1개, 뉴런 2개 → 3개 → 4개로 늘린다. 뉴런 3개부터 원을 둘러싸는 경계가 생긴다(삼각형에 가까운 모양). 아래 작은 지도에서 각 뉴런이 직선 하나씩을 맡는 것을 확인한다.
  3. 활성화를 "없음(선형)"으로 바꾸고 은닉층을 3개로 늘린다. 경계는 여전히 직선이다.
  4. "나선"을 은닉층 1개, 뉴런 8개로 학습한 뒤, 은닉층 2~3개로 바꿔 비교한다.

코드 실습: 선형 붕괴, 보편 근사, 깊이

먼저 활성화 없는 두 층이 한 층과 같음을 확인하고, ReLU를 넣으면 달라지는 것을 본다.

import numpy as np
import matplotlib.pyplot as plt
relu = lambda z: np.maximum(0, z)
W1 = np.array([[1., 2.], [0., 1.]]); W2 = np.array([[3.], [-1.]])
for x in [np.array([2., 5.]), np.array([-2., 1.])]:
    two_linear = (x @ W1) @ W2
    one_linear = x @ (W1 @ W2)
    with_relu = relu(x @ W1) @ W2
    print(f"x = {x}: 선형 두 층 {two_linear}, 합친 한 층 {one_linear}, ReLU 사이에 {with_relu}")

보편 근사를 숫자로 확인한다. $[0, 2\pi]$에 꺾는 점 $N$개를 고르게 두고 $\mathrm{ReLU}(x - c_k)$를 은닉 뉴런으로 삼은 뒤, 출력 가중치만 8일차의 최소제곱으로 구한다.

x = np.linspace(0, 2 * np.pi, 400); y = np.sin(x)
plt.figure(figsize=(6, 3.4)); plt.plot(x, y, "k--", lw=1, label="sin x")
for N in [2, 4, 8, 16, 32]:
    knots = np.linspace(0, 2 * np.pi, N + 1)[:-1]
    # (400, N+1) 은닉 출력
    H = np.c_[np.ones_like(x), relu(x[:, None] - knots[None, :])]
    v = np.linalg.lstsq(H, y, rcond=None)[0]                         # 출력 가중치
    err = np.abs(H @ v - y).max()
    print(f"ReLU {N:2d}개: 최대 오차 {err:.4f}")
    if N in (4, 8): plt.plot(x, H @ v, lw=1.6, label=f"ReLU {N}개")
plt.legend(); plt.grid(alpha=.3); plt.show()

뉴런을 두 배로 늘릴 때마다 최대 오차가 약 4분의 1로 준다. 마지막으로 텐트 함수를 거듭 합성해 깊이에 따른 조각 수를 센다.

t = lambda z: 2 * relu(z) - 4 * relu(z - 0.5)                 # ReLU 2개짜리 층
xs = np.linspace(0, 1, 20001)
fig, axs = plt.subplots(1, 4, figsize=(11, 2.4), sharey=True)
f = xs.copy()
for k, ax in enumerate(axs, 1):
    f = t(f)                                                   # 층을 하나 더 통과
    slope = np.diff(f) / np.diff(xs)
    pieces = (np.abs(np.diff(slope)) > 1e-3).sum() + 1
    ax.plot(xs, f)
    ax.set_title(f"깊이 {k}: 조각 {pieces}개, ReLU {2 * k}개", fontsize=9)
plt.tight_layout(); plt.show()

정리

  • MLP: $\mathbf h = \phi(\mathbf xW_1 + \mathbf b_1)$, $\hat y = \mathbf hW_2 + \mathbf b_2$. 은닉층은 신경망이 만든 중간 표현.
  • 활성화 없이 쌓은 선형층은 하나의 선형층과 같다. 비선형 활성화가 꺾임을 만든다.
  • 은닉층의 기본은 ReLU(트랜스포머는 GELU). 시그모이드·tanh는 포화로 기울기가 사라진다.
  • 은닉층 = 선형변환 + 휘기·접기 → 선형 분리 가능한 새 표현. 출력층은 그 위의 선형 분류기.
  • 보편 근사 정리: 은닉층 하나로 어떤 연속 함수든 근사 가능(존재 보장). 깊이는 같은 뉴런 수로 기하급수적으로 복잡한 함수를 만든다.

확인 문제

연습 문제

  1. $\tanh(z) = 2\sigma(2z) - 1$임을 보이고, 이를 이용해 $\tanh'(0) = 1$을 구하라.
    풀이

    $2\sigma(2z) - 1 = \frac{2}{1 + e^{-2z}} - 1 = \frac{1 - e^{-2z}}{1 + e^{-2z}}$. 분자·분모에 $e^z$를 곱하면 $\frac{e^z - e^{-z}}{e^z + e^{-z}} = \tanh z$. 미분하면 $\tanh'(z) = 4\sigma'(2z) = 4\sigma(2z)(1 - \sigma(2z))$, $z = 0$에서 $4\cdot\frac14 = 1$.

  2. $\max(a, b)$와 $|x|$를 ReLU로 표현하라.
    풀이

    $\max(a, b) = a + \mathrm{ReLU}(b - a)$. $|x| = \mathrm{ReLU}(x) + \mathrm{ReLU}(-x)$. 둘 다 ReLU 신경망이 정확히 표현할 수 있는 함수다.

  3. 입력 784, 은닉 256과 128, 출력 10인 MLP의 파라미터 수를 구하라. 어느 층에 가장 많은가?
    풀이

    $784\cdot256 + 256 = 200{,}960$, $256\cdot128 + 128 = 32{,}896$, $128\cdot10 + 10 = 1{,}290$. 합 235,146개. 첫 층이 85%를 차지한다. 17일차의 형상 추적 인터랙티브에서 확인한다.

  4. 은닉층 두 개짜리 ReLU 신경망 $\mathbf x = (1, -1)$, $W_1 = \begin{bmatrix}1 & -1\\ 2 & 1\end{bmatrix}$, $\mathbf b_1 = (0, 1)$, $W_2 = \begin{bmatrix}1\\ 1\end{bmatrix}$, $b_2 = -0.5$의 출력을 손으로 계산하라.
    풀이

    $\mathbf xW_1 = (1\cdot1 + (-1)\cdot2,\; 1\cdot(-1) + (-1)\cdot1) = (-1, -2)$, $+\mathbf b_1 = (-1, -1)$, ReLU → $(0, 0)$. 출력 $0 + 0 - 0.5 = -0.5$. 두 은닉 뉴런이 모두 꺼져 출력은 편향만 남는다.

미니 프로젝트: 가중치를 직접 설계한 신경망

학습 알고리즘을 쓰지 않고 ReLU 신경망의 가중치를 직접 정해서 원하는 함수를 만든다. 절댓값과 혹, $x^2$의 꺾은선 근사, 원 모양 데이터의 분류기를 차례로 설계한다. 은닉 뉴런 하나하나가 무슨 일을 하는지 정확히 알게 되며, 이것이 학습된 신경망을 해석하는 기초가 된다.

  1. 도구 만들기. 1입력 MLP를 계산하는 함수를 만든다. 은닉 뉴런 $j$의 출력은 $\mathrm{ReLU}(w_jx + b_j)$, 출력은 $\sum_j v_j h_j + c$다. 
    import numpy as np
import matplotlib.pyplot as plt
relu = lambda z: np.maximum(0, z)
def mlp1d(x, w, b, v, c):
    """x: (N,), 은닉층 가중치 w, b: (H,), 출력 가중치 v: (H,), 출력 편향 c"""
    H = relu(x[:, None] * w[None, :] + b[None, :])    # (N, H)
    return H @ v + c
x = np.linspace(-3, 3, 601)
abs_net = mlp1d(x, w=np.array([1., -1.]), b=np.array([0., 0.]), v=np.array([1., 1.]),
                c=0.)
print("|x| 최대 오차:", np.abs(abs_net - np.abs(x)).max())
  2. 혹 만들기. 그림의 혹을 일반화해, 중심 $m$, 반폭 $s$, 높이 $a$인 삼각형 혹을 만드는 함수를 작성하라. 혹 두 개를 더해 쌍봉 모양을 그린다. 
    def bump(m, s, a):
    """중심 m, 반폭 s, 높이 a인 삼각형 혹의 (w, b, v)"""
    w = np.array([1., 1., 1.])
    b = np.array([-(m - s), -m, -(m + s)])            # 꺾는 점: m − s, m, m + s
    # TODO 확인: 기울기 변화 +1, −2, +1
    v = np.array([1., -2., 1.]) * a / s
    return w, b, v
w1, b1, v1 = bump(-1, 1, 1.0); w2, b2, v2 = bump(1.5, 0.5, 0.6)
twin = mlp1d(x, np.r_[w1, w2], np.r_[b1, b2], np.r_[v1, v2], 0.)
plt.figure(figsize=(5.6, 2.8))
plt.plot(x, twin)
plt.title("혹 두 개 = 은닉 뉴런 6개")

  3. $x^2$의 꺾은선 근사. $[-2, 2]$에서 $x^2$을 꺾는 점 $-2, -1, 0, 1$을 쓰는 ReLU 4개로 근사한다. 각 구간의 기울기는 $-3, -1, 1, 3$이므로 꺾는 점에서의 기울기 변화는 $-3$(첫 뉴런), $+2, +2, +2$다. 출력 편향은 $x = -2$에서의 값 4다. 최대 오차를 구하고, 꺾는 점을 0.5 간격으로 늘리면 어떻게 되는지 비교하라. 
    def square_net(step):
    knots = np.arange(-2, 2, step)                    # −2부터 step 간격
    vals = knots ** 2; nxt = (knots + step) ** 2
    slopes = (nxt - vals) / step                       # 각 구간의 기울기
    v = np.r_[slopes[0], np.diff(slopes)]               # 꺾는 점마다 기울기 변화
    return np.ones_like(knots), -knots, v, 4.0
xs = np.linspace(-2, 2, 801)
for step in [1.0, 0.5, 0.25]:
    w, b, v, c = square_net(step)
    err = np.abs(mlp1d(xs, w, b, v, c) - xs ** 2).max()
    print(f"간격 {step}: 은닉 뉴런 {len(w)}개, 최대 오차 {err:.4f}, 출력 가중치 {np.round(v, 2)[:5]}")
  4. 원 모양 데이터 분류기. 놀이터의 "원" 데이터처럼, 안쪽 원(클래스 1)과 바깥 고리(클래스 0)를 가르는 신경망을 설계한다. 은닉 뉴런 4개 $\mathrm{ReLU}(x_1), \mathrm{ReLU}(-x_1), \mathrm{ReLU}(x_2), \mathrm{ReLU}(-x_2)$의 합은 $|x_1| + |x_2|$(마름모 모양의 거리)다. 출력 $\mathrm{step}(r - \sum_j h_j)$는 마름모 안쪽을 1로 판정한다. $r$을 바꿔 가며 정확도를 구하라. 
    r = np.random.default_rng(5); pts = []
for i in range(400):
    c = i % 2
    rad = r.random() * 1.0 if c else 1.6 + r.random() * .7
    th = r.random() * 2 * np.pi
    pts.append([rad * np.cos(th), rad * np.sin(th), c])
pts = np.array(pts); X, y = pts[:, :2], pts[:, 2]
W1 = np.array([[1., -1., 0., 0.], [0., 0., 1., -1.]])        # (2, 4)
H = relu(X @ W1)                                              # (400, 4)
for rad in [1.0, 1.2, 1.4, 1.6, 2.0]:
    # 출력 가중치 −1, 편향 rad
    pred = (rad - H.sum(axis=1) > 0).astype(int)
    print(f"r = {rad}: 정확도 {(pred == y).mean():.3f}")
g1, g2 = np.meshgrid(np.linspace(-2.5, 2.5, 200), np.linspace(-2.5, 2.5, 200))
Z = (1.4 - relu(np.c_[g1.ravel(), g2.ravel()] @ W1).sum(1) > 0).reshape(g1.shape)
plt.figure(figsize=(4.2, 4))
plt.contourf(g1, g2, Z, levels=[-.5, .5, 1.5], colors=["#f3d6d3", "#d6e1f3"])
plt.scatter(X[:, 0], X[:, 1], c=y, cmap="coolwarm_r", s=8)
plt.gca().set_aspect("equal")
plt.title("r = 1.4 마름모 경계")
plt.show()
참고 답안과 해설
  • 1단계: $|x| = \mathrm{ReLU}(x) + \mathrm{ReLU}(-x)$이므로 오차는 정확히 0이다.
  • 2단계: 꺾는 점 $m - s, m, m + s$에서 기울기가 $+a/s, -2a/s, +a/s$만큼 바뀌어 높이 $a$인 혹이 된다. 혹은 국소적인 "기본 벽돌"이고, 벽돌을 쌓아 원하는 모양을 만드는 것이 보편 근사의 직관이다.
  • 3단계: 간격 1에서 뉴런 4개, 최대 오차 0.25(구간 가운데). 간격 0.5에서 뉴런 8개, 오차 0.0625. 간격을 절반으로 하면 오차가 4분의 1이 된다. 꺾은선 근사의 오차는 간격의 제곱에 비례하기 때문이다. 코드 실습의 sin 근사와 같은 비율이다.
  • 4단계: $r$이 1.4~1.6일 때 정확도 1.0이다. 안쪽 원의 마름모 거리는 최대 $\sqrt2 \approx 1.41$이고 바깥 고리는 최소 1.6이므로 그 사이의 $r$이면 완벽히 가른다. 은닉 뉴런마다 직선 하나를 맡고, 출력층이 그것을 합쳐 다각형 경계를 만든다. 놀이터에서 학습된 뉴런 3~4개짜리 신경망도 비슷한 다각형을 스스로 찾는다.
