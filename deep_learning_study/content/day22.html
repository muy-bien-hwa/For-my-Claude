• Seq2Seq의 정보 병목 문제와 어텐션이 등장한 동기를 이해한다.
  • 어텐션을 "부드러운 사전 검색(soft lookup)"으로 해석하고 Query·Key·Value의 역할을 설명한다.
  • Scaled dot-product attention 식을 유도하고, $\sqrt{d_k}$로 나누는 이유를 실험으로 확인한다.
  • 셀프 어텐션, 패딩 마스크, causal 마스크를 NumPy로 구현한다.
👨‍🏫 현대 AI의 심장 ChatGPT, Claude, 이미지 생성 모델, AlphaFold… 지금 여러분이 듣는 거의 모든 AI의 중심에 오늘 배우는 식 하나가 있습니다. $$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$ 이번 주가 끝나면 이 식이 공기처럼 자연스러워질 것입니다. 놀랍게도 재료는 이미 다 배웠습니다. 내적(Day 3), 소프트맥스(Day 7), 행렬곱이 전부입니다.

1. 동기: 하나의 벡터에 모든 것을 담을 수 없다

RNN 기반 번역(Seq2Seq, 2014)은 인코더가 입력 문장 전체를 마지막 은닉 상태 하나로 요약하고, 디코더가 그것만 보고 번역합니다. 문장이 길어지면 이 고정 크기 벡터가 병목이 되어 성능이 급격히 떨어졌습니다.

Bahdanau 등(2015)의 아이디어: 디코더가 단어를 하나 만들 때마다, 인코더의 모든 시점 은닉 상태를 다시 보고, 지금 필요한 부분에 집중(attend)하자. "I love cats"를 번역하며 "고양이를"을 쓸 때는 "cats"에 집중하는 식입니다.

2. 어텐션 = 부드러운 사전 검색

파이썬 사전 d[query]는 query와 정확히 일치하는 key 하나의 value를 돌려줍니다. 어텐션은 이것을 부드럽게 만든 것입니다.

  1. Query와 모든 Key의 유사도를 잰다 (내적).
  2. 유사도를 소프트맥스로 가중치(합 = 1)로 바꾼다.
  3. Value들을 그 가중치로 가중평균한다.
역할비유 (도서관)의미
Query $q$내가 찾는 주제"나는 지금 무엇을 찾고 있나"
Key $k_j$각 책의 색인 키워드"나는 이런 정보를 가지고 있어"
Value $v_j$책의 실제 내용"선택되면 전달할 내용"
$$\alpha_j = \frac{\exp(q\cdot k_j)}{\sum_{j'}\exp(q\cdot k_{j'})},\qquad \text{output} = \sum_j\alpha_j v_j$$ 
import numpy as np
np.set_printoptions(precision=3, suppress=True)
softmax = lambda z, ax=-1: np.exp(z - z.max(ax, keepdims=True)) / np.exp(z - z.max(ax, keepdims=True)).sum(ax, keepdims=True)

keys   = np.array([[1, 0], [0, 1], [1, 1]], float)        # 3개 항목의 키
values = np.array([[10, 0], [0, 10], [5, 5]], float)      # 각 항목의 값
for q in ([3, 0], [0, 3], [1, 1], [0, 0]):
    q = np.array(q, float)
    w = softmax(keys @ q)                                   # 유사도 → 가중치
    print(f"query {q} → 가중치 {w} → 출력 {w @ values}")

query가 첫 번째 key와 비슷하면 첫 번째 value가 주로 나오고, 어느 것과도 특별히 비슷하지 않으면(query = 0) 모든 value의 평균이 나옵니다. 전부 미분 가능하므로 무엇에 집중할지를 학습할 수 있습니다.

3. 행렬로: Scaled Dot-Product Attention

Query가 $n$개, Key·Value가 $m$개일 때 행으로 쌓습니다: $Q\in\mathbb R^{n\times d_k}$, $K\in\mathbb R^{m\times d_k}$, $V\in\mathbb R^{m\times d_v}$.

$$\underbrace{QK^\top}_{n\times m\ \text{유사도 표}}\ \xrightarrow{\ \div\sqrt{d_k}\ }\ \xrightarrow{\ \text{행별 softmax}\ }\ \underbrace{A}_{n\times m\ \text{가중치}}\ \longrightarrow\ \underbrace{AV}_{n\times d_v}$$ 
def attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]
    scores = Q @ K.swapaxes(-1, -2) / np.sqrt(d_k)          # (..., n, m)
    if mask is not None:
        scores = np.where(mask, scores, -1e9)                # mask가 False인 곳은 -∞ → softmax 후 0
    A = softmax(scores, -1)
    return A @ V, A

rng = np.random.default_rng(0)
Q = rng.normal(size=(4, 8)); K = rng.normal(size=(6, 8)); V = rng.normal(size=(6, 16))
out, A = attention(Q, K, V)
print("출력:", out.shape, " 가중치:", A.shape, " 행 합:", A.sum(1))

4. 왜 $\sqrt{d_k}$로 나누는가

$q$, $k$의 각 성분이 평균 0, 분산 1이면 내적 $q\cdot k = \sum_{i=1}^{d_k}q_ik_i$의 분산은 $d_k$입니다. $d_k = 512$면 표준편차가 약 22. 이런 큰 값이 소프트맥스에 들어가면 하나만 거의 1이고 나머지는 0인 원-핫에 가까운 분포가 되어, 기울기가 거의 0이 됩니다(포화). $\sqrt{d_k}$로 나누면 분산이 1로 돌아옵니다. Day 13의 분산 보존 원리와 같은 생각입니다.

for d in [4, 64, 512]:
    q = rng.normal(size=(1000, d)); k = rng.normal(size=(1000, 10, d))
    raw = np.einsum('nd,nmd->nm', q, k)
    for name, s in [("나누기 전", raw), ("√d로 나눈 후", raw / np.sqrt(d))]:
        A = softmax(s, -1)
        print(f"d={d:3d} {name:8s} 점수 표준편차 {s.std():6.2f}  최대 가중치 평균 {A.max(1).mean():.3f}")

$d=512$에서 나누기 전에는 가중치 최댓값 평균이 거의 1에 가깝습니다. 사실상 argmax가 되어 학습이 어려워집니다.

5. 셀프 어텐션: 문장이 자기 자신을 본다

Q, K, V를 모두 같은 시퀀스 $X$에서 서로 다른 선형변환으로 만듭니다.

$$Q = XW_Q,\quad K = XW_K,\quad V = XW_V$$

그러면 각 토큰이 문장의 다른 모든 토큰을 보고, 필요한 정보를 모아 자신의 표현을 갱신합니다. "그 동물은 너무 피곤해서 길을 건너지 않았다. 그것은 …"에서 "그것"의 표현이 "동물"의 정보를 가져오는 식입니다.

(위 시각화는 학습된 모델이 아니라, 철자가 비슷한 단어끼리 비슷해지는 장난감 임베딩을 씁니다. 같은 단어 "고양이"끼리 서로 강하게 참고하는 것을 볼 수 있습니다. 실제 모델은 의미·문법 관계를 학습합니다.)

🔑 RNN과 비교한 셀프 어텐션의 장점
  • 경로 길이 1: 첫 단어와 마지막 단어가 한 단계 만에 직접 연결됩니다. RNN은 $T$단계를 거쳐야 해서 장기 의존성이 어렵습니다.
  • 병렬화: 모든 위치를 행렬곱 한 번에 계산합니다. RNN은 순차적이라 GPU를 제대로 못 씁니다. 이것이 대규모 학습을 가능하게 했습니다.
  • 단점: 모든 쌍을 계산하므로 연산·메모리가 $O(T^2)$입니다. 긴 문맥이 비싼 이유이고, FlashAttention 등 최적화 연구가 활발한 이유입니다.

6. 마스크: 보면 안 되는 것 가리기

  • 패딩 마스크: 배치를 맞추려고 넣은 PAD 토큰은 Key로서 무시해야 합니다.
  • Causal(인과) 마스크: 다음 단어를 예측하는 언어 모델(GPT)은 학습 중에 미래 토큰을 보면 안 됩니다. 위치 $i$는 $j \le i$인 위치만 봅니다. 하삼각 행렬 마스크를 씁니다.
T, d = 5, 8
X = rng.normal(size=(T, d))
Wq, Wk, Wv = (rng.normal(0, 1/np.sqrt(d), (d, d)) for _ in range(3))
Q, K, V = X @ Wq, X @ Wk, X @ Wv

causal = np.tril(np.ones((T, T), bool))               # 하삼각: j <= i 만 True
print("causal 마스크:\n", causal.astype(int))
out, A = attention(Q, K, V, mask=causal)
print("\n어텐션 가중치 (윗삼각은 0이어야 함):\n", A)

# 패딩 마스크: 마지막 2개 토큰이 PAD
pad = np.array([True, True, True, False, False])
_, A2 = attention(Q, K, V, mask=pad[None, :])           # 모든 query에 대해 PAD key 차단
print("\n패딩 마스크 적용 가중치 (마지막 두 열 0):\n", A2)
💡 Causal 마스크가 학습을 효율적으로 만드는 방법 문장 길이가 $T$면, causal 마스크 덕분에 한 번의 순전파로 $T$개 위치의 다음 토큰 예측을 동시에 학습합니다("teacher forcing"). RNN처럼 하나씩 돌릴 필요가 없습니다. 생성할 때만 한 토큰씩 순차적으로 만듭니다.
