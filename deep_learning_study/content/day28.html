• 6만 장 규모의 실제 이미지 데이터로 학습 파이프라인 전체(데이터 준비 → 점검 → 학습률 선택 → 학습 → 개선 → 최종 평가 → 저장)를 직접 구성한다.
  • 4주차의 기법(He 초기화, AdamW, 워밍업·코사인 스케줄, 드롭아웃, 가중치 감쇠, 데이터 증강)을 하나의 학습 코드로 통합한다.
  • 검증 세트로만 설정을 고르고 테스트 세트는 한 번만 쓰는 실험 규율을 지킨다.
  • 혼동 행렬과 틀린 이미지로 남은 오류의 성격을 분석한다.

프로젝트 개요

지금까지 쓴 손글씨 데이터는 8×8 픽셀 이미지 1,797장이었다. 이번에는 딥러닝의 표준 입문 데이터셋인 MNIST를 쓴다. 28×28 픽셀 이미지 7만 장으로, 입력 차원은 약 12배(64 → 784), 데이터 수는 약 39배다. PyTorch 없이 3주차의 NumPy 프레임워크에 4주차의 학습 기법을 더해 테스트 정확도 98% 이상에 도달하는 것이 목표다.

분할

정규화와 자료형

픽셀을 255로 나눠 0~1로 만든 뒤 학습 세트의 평균 0.1307과 표준편차 0.3081로 표준화한다. 평균과 표준편차는 픽셀마다가 아니라 전체에 대해 값 하나씩이다. 학습 세트 5만 장 모두에서 값이 0인 테두리 픽셀이 68개나 있어서, 픽셀마다 표준화하면 그 픽셀들은 표준편차 0으로 나누게 된다.

자료형은 float32를 쓴다. 학습 입력만 해도 50,000 × 784개의 수라 float64로는 314 MB, float32로는 157 MB다. 행렬곱도 약 2배 빠르다. 대신 유효숫자가 7자리 정도라 수치 미분에는 쓰지 않는다(3단계).

def step(self):                                  # AdamW
    self.t += 1
    c1, c2 = 1 - self.b1 ** self.t, 1 - self.b2 ** self.t      # 편향 보정
    for (p, g, decay), m, v in zip(self.params, self.m, self.v):
        m *= self.b1; m += (1 - self.b1) * g
        v *= self.b2; v += (1 - self.b2) * g * g
        if decay and self.wd > 0:
            p -= self.lr * self.wd * p                          # 분리된 가중치 감쇠
        p -= self.lr * (m / c1) / (np.sqrt(v / c2) + self.eps)

배치 크기 128이면 한 에폭이 $\lceil 50000/128 \rceil = 391$스텝이다. 10에폭 학습이면 전체 3,910스텝 중 처음 391스텝 동안 학습률을 0에서 최댓값까지 올리고, 나머지 동안 코사인 곡선으로 0까지 내린다.

이동 증강

학습 배치의 각 이미지를 가로, 세로로 −2~+2픽셀 무작위로 옮긴다(26일차). 빈 곳은 배경값으로 채운다. 숫자를 조금 옮겨도 레이블은 같다. 그런데 다층 퍼셉트론은 픽셀 784개를 서로 무관한 입력으로 받으므로, 같은 숫자를 2픽셀 옮기면 입력 벡터가 크게 달라진다. 증강은 "위치가 조금 달라도 같은 숫자"라는 사실을 데이터로 가르친다.

첫 손실이 $\ln 10$보다 조금 큰 것은 초기화 직후의 로짓이 이미 클래스마다 다르기 때문이다. 한 표본 안에서 로짓 10개의 표준편차가 약 1.5다. 로짓이 모두 같으면 확률이 모두 0.1이 되어 손실이 정확히 $\ln 10$이다. 27일차의 버그 코드에서 본 17.9나 inf와 달리 같은 자릿수이므로 정상이다. 마지막 층의 가중치를 0.1배로 줄이면 첫 손실이 $\ln 10$에 가까워지는 것도 노트북에서 확인할 수 있다.

20일차에는 원소 하나씩의 상대 오차를 봤다. MNIST에서는 테두리 픽셀에 연결된 가중치처럼 기울기가 아주 작은($10^{-5}$ 이하) 원소가 많다. 이런 원소에서는 수치 미분 자체의 반올림 오차만으로 원소별 상대 오차가 $10^{-6}$을 넘는다(실제로 $2.4\times10^{-6}$이 나왔다). 그래서 파라미터마다 고른 원소들을 벡터로 묶어 비교한다.

$$\text{상대 오차} = \frac{\lVert g_{\text{역전파}} - g_{\text{수치}}\rVert}{\lVert g_{\text{역전파}}\rVert + \lVert g_{\text{수치}}\rVert}$$

이 기준으로 올바른 코드는 $1.8\times10^{-10}$, ReLU 역전파에서 마스크를 빼먹은 코드는 0.80이 나와 둘이 확실히 갈린다.

4단계: 학습률 범위 테스트

학습률을 $10^{-5}$부터 스텝마다 지수적으로 키우며 한 번 학습하고, 손실의 지수 이동 평균을 학습률에 대해 그린다(23일차). 손실이 최저점의 4배를 넘으면 발산으로 보고 멈춘다.

23일차의 기준대로 최저점의 1/10~1/3 범위($1.1\times10^{-3}$~$3.7\times10^{-3}$)에서 고른다. 여기서는 그 아래 끝에 가까운 $10^{-3}$을 쓴다. 범위 테스트는 학습률이 매 스텝 바뀌는 짧은 학습이라, 최저점 근처의 학습률은 긴 학습에서는 이미 불안정할 수 있다. 여러 설정을 비교할 6단계에서는 안전한 값을 쓰는 편이 비교를 공정하게 만든다.

5단계: 기준 모델

784-256-128-10 모델을 규제 없이 10에폭 학습한다. 최대 학습률 $10^{-3}$, 배치 128, 워밍업 1에폭 뒤 코사인 감소.

검증 정확도는 1에폭 뒤 95.0%, 10에폭 뒤 98.14%다. 목표에 거의 닿았지만 학습 손실(0.0034)이 검증 손실(0.0696)의 약 20분의 1이다. 모델이 학습 데이터를 외우고 있다는 신호다. 이 간격을 줄이면 검증 성능이 더 오를 여지가 있다. 6단계의 실험은 이 간격을 줄이는 방법들을 차례로 시험한다.

6단계: 개선 실험

한 번에 하나씩 바꾸고, 모두 같은 시드와 같은 에폭 수(15)로 학습해 검증 정확도로 비교한다. 다섯 실험을 모두 돌리는 데 Colab에서 수 분에서 10분 정도 걸린다.

  1. 기준. 15에폭으로 늘리자 학습 손실은 0.0008까지 줄었지만 검증 손실은 10에폭 때(0.0696)보다 오히려 커졌다(0.0737). 과적합이 진행되고 있다.
  2. 드롭아웃. 검증 손실은 0.0737에서 0.0626으로 줄었지만 정확도 차이(+0.10%p)는 시드에 따른 흔들림 수준이다. 같은 설정도 시드만 바꾸면 검증 정확도가 0.1%p 넘게 달라진다(확장 과제 2). 이것만으로는 낫다고 결론 내리기 어렵다(27일차).
  3. 이동 증강. 정확도 +0.32%p, 검증 손실 0.0468로 가장 큰 단일 효과다. 학습 손실(0.0448)과 검증 손실이 거의 같아져 과적합의 간격이 사라졌다.
  4. 드롭아웃 + 증강. 증강만 쓴 것보다 나아지지 않았다(98.35%). 학습 손실이 0.1049로 검증 손실보다 크다. 23만 개 파라미터의 모델에 규제를 둘 다 걸자 학습 데이터조차 충분히 맞히지 못하는 과소적합 쪽으로 넘어간 것이다. 규제를 더하는 것이 늘 이득은 아니다.
  5. 넓게 + 모두. 은닉층을 512-256(파라미터 535,818개)으로 키워 모델의 용량을 늘리고 규제를 모두 쓰자 98.67%로 기준보다 0.58%p 올랐다. 큰 모델 + 강한 규제가 작은 모델 + 약한 규제보다 나은 경우가 많다.

표의 학습 손실은 학습 중에 잰 값이라 드롭아웃과 증강이 켜진 상태다. 그래서 규제를 쓴 설정의 학습 손실은 실제 학습 데이터에 대한 손실보다 크게 나온다. 검증 손실이 학습 손실보다 작게 나오는 것도 이 때문이다(27일차 확인 문제 7).

노트북의 EPOCHS를 20으로 바꾸면 "넓게 + 모두"의 검증 정확도가 98.87%까지 오른다. 학습 시간과 맞바꾸는 선택이다.

7단계: 최종 평가와 오류 분석

검증 정확도가 가장 높은 "넓게 + 모두"를 고르고, 이 모델로 테스트 세트를 한 번 평가한다.

테스트 정확도 98.76% (10,000장 중 124장 틀림), 테스트 손실 0.0383. 목표 98%를 넘었다. 테스트 정확도가 검증 정확도(98.67%)와 비슷하다. 다섯 설정 중 하나를 고르는 정도로는 검증 세트에 맞춘 효과(낙관적 편향)가 크지 않았다는 뜻이다.

가장 많이 헷갈린 쌍은 5 → 3(13장), 7 → 2(11장), 9 → 4(7장), 8 → 7과 4 → 6(각 5장)이다. 모양이 비슷한 숫자끼리다. 5와 3은 아래쪽 곡선이 같고 위쪽 획만 다르다. 7과 2는 아래쪽 가로획이 있는지, 9와 4는 위쪽 고리가 닫혔는지로 구별된다.

틀린 이미지에는 사람이 봐도 헷갈리는 것(획이 끊기거나 기울어진 숫자)과 레이블 자체가 의심스러운 것이 섞여 있다. 모델은 이런 이미지에도 0.95 이상의 확률을 준다. 틀릴 때도 자신 있게 틀리는 것이다. 남은 오류를 줄이는 방향은 두 가지다. 회전이나 두께 변화 같은 증강을 더하거나, 이웃 픽셀의 관계를 직접 이용하는 모델을 쓴다. 다층 퍼셉트론은 픽셀의 위치 관계를 모르기 때문이다. 5주차의 합성곱 신경망은 같은 데이터에서 99%를 넘는다.

확장 과제

  1. 가중치의 지수 이동 평균(EMA). 매 스텝 각 파라미터의 이동 평균 $\bar\theta \leftarrow 0.999\,\bar\theta + 0.001\,\theta$를 따로 저장하고, 학습이 끝난 뒤 이동 평균으로 평가하라(22일차).
    풀이
    def fit_ema(model, epochs=15, lr=1e-3, wd=0.01, bs=128, aug=2, decay=0.999, seed=1):
    """fit과 같은 학습에 파라미터의 지수 이동 평균(EMA)을 더한다."""
    r, loss_fn = np.random.default_rng(seed), SoftmaxCE()
    opt = AdamW(model.params(), lr, weight_decay=wd)
    ema = [p.copy() for p, _, _ in model.params()]
    steps_per_epoch = math.ceil(len(Xtr) / bs)
    total, warmup, step = epochs * steps_per_epoch, steps_per_epoch, 0
    for ep in range(epochs):
        order = r.permutation(len(Xtr))
        for s in range(0, len(Xtr), bs):
            idx = order[s:s + bs]
            xb = shift_batch(Xtr[idx], r, aug) if aug else Xtr[idx]
            opt.lr = lr_at(step, total, lr, warmup)
            loss_fn.forward(model(xb), ytr[idx])
            model.backward(loss_fn.backward())
            opt.step()
            step += 1
            for e, (p, _, _) in zip(ema, model.params()):
                e *= decay
                e += (1 - decay) * p
    print(f"마지막 가중치: 검증 정확도 {evaluate(model, Xva, yva)[1]:.4f}")
    for e, (p, _, _) in zip(ema, model.params()):
        p[...] = e
    print(f"EMA 가중치:   검증 정확도 {evaluate(model, Xva, yva)[1]:.4f}")

    실행 결과: 마지막 가중치 98.67%, EMA 가중치 98.64%로 차이가 없다. 코사인 스케줄이 끝에서 학습률을 0까지 줄여 마지막 가중치가 이미 거의 움직이지 않기 때문이다. EMA는 학습률을 끝까지 크게 유지하는 학습(상수 학습률, 아주 긴 학습)에서 효과가 크다. 같은 기법도 함께 쓰는 기법에 따라 효과가 달라진다.

  2. 앙상블. 시드만 다른 "넓게 + 모두" 모델 3개의 소프트맥스 확률을 평균해 예측하고, 개별 모델과 검증 정확도를 비교하라(26일차).
    풀이
    probs = []
for seed in range(3):
    m = make_mlp([784, 512, 256, 10], 0.2, seed=seed)
    fit(m, epochs=15, lr=1e-3, wd=0.01, aug=2, seed=seed + 1, verbose=False)
    m.eval()
    Z = m(Xva)
    m.train()
    P = np.exp(Z - Z.max(1, keepdims=True))
    probs.append(P / P.sum(1, keepdims=True))
    print(f"모델 {seed}: 검증 정확도 {(probs[-1].argmax(1) == yva).mean():.4f}")
print(f"앙상블 3개: 검증 정확도 {(np.mean(probs, 0).argmax(1) == yva).mean():.4f}")

  3. 전체 데이터로 다시 학습. 설정을 정한 뒤에는 검증용 1만 장까지 합친 6만 장으로 같은 설정을 다시 학습하는 경우가 많다. 이때 에폭 수를 미리 정해 두어야 하는 이유를 설명하라.
    풀이

    검증 세트가 남지 않으므로 조기 종료처럼 "검증 성능을 보며 멈출 시점을 고르는 일"을 할 수 없다. 그래서 검증 세트가 있을 때 정한 에폭 수(와 스케줄)를 그대로 쓴다. 데이터가 20% 늘었으므로 같은 에폭 수면 스텝 수도 20% 늘어난다는 점을 감안한다. 이렇게 학습한 모델은 테스트 세트로만 평가한다.

  4. 배치 정규화. 25일차의 BatchNorm 층을 각 Linear와 ReLU 사이에 넣고, 최대 학습률 $3\times10^{-3}$으로 학습해 기준 모델과 비교하라. 주의할 점은 무엇인가?
    풀이

    BatchNorm의 params()를 이 노트북 형식(파라미터, 기울기, 감쇠 여부)에 맞춰 γ, β를 감쇠 없이 반환하도록 고친다. 평가 전에는 반드시 eval()로 이동 평균 통계를 쓰게 한다. evaluate 함수는 이미 model.eval()을 호출하므로 Sequential.eval()이 모든 층에 전달되는지만 확인하면 된다. 배치 정규화는 더 큰 학습률을 허용하므로 범위 테스트를 다시 해 학습률을 정한다.
