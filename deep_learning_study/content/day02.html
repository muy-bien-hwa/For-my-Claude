• 스칼라·벡터·행렬·텐서를 구분하고 각 텐서의 형상(shape)을 읽을 수 있다.
  • NumPy 배열을 만들고, 인덱싱·슬라이싱·reshape를 자유롭게 한다.
  • 벡터화(vectorization)가 왜 for 문보다 수십~수백 배 빠른지 이해한다.
  • 브로드캐스팅 규칙을 정확히 적용하고, 축(axis) 단위 집계를 할 수 있다.
👨‍🏫 왜 NumPy부터인가 PyTorch의 torch.Tensor는 사실상 "GPU에서 돌아가고 미분이 되는 NumPy 배열"입니다. 문법도 거의 같습니다. 오늘 배열을 다루는 감각을 확실히 익혀 두면 3주차에 PyTorch로 넘어가는 데 하루면 충분합니다. 반대로 오늘을 대충 넘기면, 앞으로 만날 버그의 80%를 차지하는 형상(shape) 오류에 계속 시달리게 됩니다.

1. 텐서: 딥러닝의 기본 자료형

차원(ndim)이름예시shape 예
0스칼라손실값 하나()
1벡터단어 하나의 임베딩(512,)
2행렬표 데이터 배치, 가중치 행렬(batch, features)
33D 텐서문장 배치 (토큰 시퀀스)(batch, seq_len, d_model)
44D 텐서컬러 이미지 배치(batch, channels, H, W)
🔑 형상을 소리 내어 읽는 습관 (32, 3, 224, 224)를 보면 "224×224 크기의 RGB 이미지 32장"이라고 바로 읽혀야 합니다. 딥러닝 코드를 읽을 때 각 줄 옆에 형상을 주석으로 적는 습관을 들이세요. 실력 있는 연구자들도 모두 그렇게 합니다.

2. 배열 만들기와 기본 속성

import numpy as np

a = np.array([1, 2, 3])                 # 리스트에서 생성
B = np.array([[1, 2, 3], [4, 5, 6]])
print("a:", a, "| shape", a.shape, "| ndim", a.ndim, "| dtype", a.dtype)
print("B shape:", B.shape)             # (2, 3): 2행 3열

print(np.zeros((2, 3)))                  # 0으로 채운 2x3
print(np.ones(4))
print(np.arange(0, 10, 2))               # [0 2 4 6 8]
print(np.linspace(0, 1, 5))              # 0~1을 5등분

rng = np.random.default_rng(0)           # 재현 가능한 난수 생성기
X = rng.normal(0, 1, size=(3, 4))        # 표준정규분포 3x4
print(X.round(2))
print("float32로:", X.astype(np.float32).dtype)

dtype도 중요합니다. 딥러닝은 보통 float32를 씁니다(NumPy 기본값은 float64). 메모리가 절반이고 GPU에서 훨씬 빠릅니다.

3. 인덱싱, 슬라이싱, reshape

M = np.arange(12).reshape(3, 4)
print(M)
print("M[1, 2] =", M[1, 2])        # 1행 2열 (0부터 셈)
print("1행 전체:", M[1])            # = M[1, :]
print("2열 전체:", M[:, 2])
print("부분 행렬:\n", M[0:2, 1:3])  # 0~1행, 1~2열

# 불리언 마스킹: 조건을 만족하는 원소만
print("짝수만:", M[M % 2 == 0])

# reshape: 원소 수만 같으면 모양을 바꿀 수 있다. -1은 '알아서 계산'
print(M.reshape(4, 3).shape, M.reshape(-1).shape, M.reshape(2, -1).shape)

# 전치 (transpose)
print("M.T shape:", M.T.shape)

# 축 추가: None 또는 np.newaxis
v = np.array([1, 2, 3])
print(v[:, None].shape, v[None, :].shape)   # (3,1) 열벡터, (1,3) 행벡터
⚠️ 뷰(view)와 복사(copy) 슬라이싱 결과는 원본의 뷰입니다. s = M[0]; s[0] = 999를 하면 원본 M도 바뀝니다. 독립적인 사본이 필요하면 M[0].copy()를 쓰세요. PyTorch에서도 같은 함정이 있습니다.

4. 벡터화: for 문을 버려라

신경망은 수백만 개의 숫자를 다룹니다. 파이썬 for 문은 원소 하나마다 인터프리터를 거치기 때문에 느립니다. NumPy 연산은 C로 구현된 루프를 한 번에 실행합니다(SIMD, 캐시 최적화까지).

import time
x = np.random.rand(1_000_000)
y = np.random.rand(1_000_000)

t = time.perf_counter()
s = 0.0
for i in range(len(x)):
    s += x[i] * y[i]
t_loop = time.perf_counter() - t

t = time.perf_counter()
s2 = np.dot(x, y)            # 또는 (x * y).sum(), x @ y
t_vec = time.perf_counter() - t

print(f"for 문:   {t_loop*1000:8.1f} ms  결과 {s:.4f}")
print(f"벡터화:   {t_vec*1000:8.2f} ms  결과 {s2:.4f}")
print(f"속도 차이: 약 {t_loop/t_vec:.0f}배")

원소별(element-wise) 연산은 그냥 산술 연산자를 쓰면 됩니다: x + y, x * y, np.exp(x), np.maximum(x, 0)(= ReLU!).

5. 브로드캐스팅 — 가장 강력하고 가장 위험한 규칙

형상이 다른 두 배열을 연산하면 NumPy는 다음 규칙으로 맞춥니다.

  1. 두 형상을 오른쪽 끝부터 나란히 맞춘다. 차원 수가 적은 쪽은 왼쪽에 1을 채운다.
  2. 각 축에서 크기가 같거나, 둘 중 하나가 1이면 호환된다. 1인 쪽이 늘어난다.
  3. 그 외에는 에러.
AB결과설명
(32, 10)(10,)(32, 10)모든 행에 같은 편향 벡터를 더함 ← 신경망 층의 XW + b
(3, 1)(1, 4)(3, 4)외적(outer)처럼 펼쳐짐
(32, 10)(32,)❌ 에러오른쪽 끝 10 vs 32
(32, 10)(32, 1)(32, 10)각 행마다 다른 값을 더함
X = np.arange(6).reshape(2, 3).astype(float)   # (2,3)
b = np.array([10., 20., 30.])                     # (3,)
print("X + b =\n", X + b)

# 각 행을 그 행의 평균으로 빼기: keepdims로 (2,1) 유지가 핵심
row_mean = X.mean(axis=1, keepdims=True)          # (2,1)
print("행 평균:", row_mean.ravel())
print("행 중심화:\n", X - row_mean)

# 실수하기 쉬운 예: keepdims 없이
try:
    print(X - X.mean(axis=1))                     # (2,3) - (2,) → 오른쪽 맞춤 3 vs 2
except ValueError as e:
    print("에러!", e)

# 외적 만들기
a = np.array([1, 2, 3])[:, None]   # (3,1)
c = np.array([1, 10, 100, 1000])[None, :]   # (1,4)
print(a * c)
⚠️ 조용한 버그 브로드캐스팅의 진짜 위험은 에러가 나지 않는 경우입니다. 예측값 y_hat의 shape이 (N, 1)이고 정답 y가 (N,)이면, y_hat - y는 (N, N) 행렬이 됩니다! 손실이 이상한 값이 나오는데 에러는 없습니다. 손실 계산 직전에 항상 두 shape이 같은지 확인하세요.
N = 4
y_hat = np.array([[1.], [2.], [3.], [4.]])  # (4,1)
y = np.array([1., 2., 3., 4.])              # (4,)
print("잘못된 MSE:", ((y_hat - y) ** 2).mean(), " shape:", (y_hat - y).shape)
print("올바른 MSE:", ((y_hat.ravel() - y) ** 2).mean())

6. 축(axis)을 따라 집계하기

axis=k는 "k번 축을 없애면서 집계한다"고 기억하세요.

scores = np.array([[90, 80, 70],
                   [60, 85, 95]])   # (학생 2명, 과목 3개)
print("전체 평균:", scores.mean())
print("과목별 평균 (axis=0, 학생 축 제거):", scores.mean(axis=0))
print("학생별 평균 (axis=1, 과목 축 제거):", scores.mean(axis=1))
print("학생별 최고 과목 인덱스:", scores.argmax(axis=1))

# 이미지 배치 예: (N, C, H, W)에서 채널별 평균 → 정규화에 사용
imgs = np.random.rand(8, 3, 32, 32)
ch_mean = imgs.mean(axis=(0, 2, 3))
print("채널별 평균 shape:", ch_mean.shape)

7. 행렬곱 미리 보기

원소별 곱 *와 행렬곱 @는 완전히 다릅니다. 행렬곱은 내일 깊이 다루지만, 신경망 한 층이 결국 아래 한 줄이라는 것만 기억해 두세요.

X = np.random.randn(32, 784)    # 배치 32개, 입력 특성 784개 (28x28 이미지)
W = np.random.randn(784, 128)   # 가중치
b = np.zeros(128)               # 편향
H = np.maximum(0, X @ W + b)    # 선형변환 + 브로드캐스팅 + ReLU = 신경망 한 층!
print("H shape:", H.shape)      # (32, 128)
