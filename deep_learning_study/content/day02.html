• 스칼라·벡터·행렬·텐서를 구분하고, 텐서의 형상을 보고 데이터의 구조를 읽을 수 있다.
  • NumPy 배열을 만들고 인덱싱·슬라이싱·형상 변환을 자유롭게 할 수 있다.
  • 벡터화가 반복문보다 빠른 이유를 설명하고 반복문 없이 계산을 표현할 수 있다.
  • 브로드캐스팅 규칙을 정확히 적용하고, 그로 인한 조용한 버그를 피할 수 있다.
  • 축(axis)을 따라 합·평균·최댓값을 구할 수 있다.

텐서와 형상

딥러닝의 모든 데이터와 파라미터는 숫자 배열로 표현된다. 축의 개수에 따라 이름이 다르며, 이들을 통틀어 텐서라 한다.

텐서의 각 축 길이를 나열한 튜플이 형상이다. 각 방향을 축이라 하며 0번부터 센다. 형상을 보면 데이터의 구조가 보인다.

데이터형상읽는 법
손실 값 하나()스칼라

흑백 이미지 묶음(64, 28, 28)28×28 이미지 64장

슬라이싱 결과는 원본과 메모리를 공유하는 뷰다. 뷰를 수정하면 원본도 바뀐다. 독립된 배열이 필요하면 .copy()를 쓴다. 불리언·정수 배열 인덱싱의 결과는 복사본이다.

A = np.arange(6)

print("원본도 바뀜:", A)

c[0] = -1
print("원본 그대로:", A)

벡터화

반복문 대신 배열 전체에 대한 연산으로 계산을 표현하는 것을 벡터화라 한다. Python 반복문은 원소마다 인터프리터를 거치지만, NumPy 연산은 컴파일된 C 코드가 연속된 메모리를 한 번에 처리하므로 수십~수백 배 빠르다.

import time
x = np.random.default_rng(0).random(500_000)
y = np.random.default_rng(1).random(500_000)

t = time.perf_counter()
total = 0.0
for i in range(len(x)):
    total += x[i] * y[i]
t_loop = time.perf_counter() - t

t = time.perf_counter()
total2 = x @ y            # 내적: (x * y).sum()과 같음
t_vec = time.perf_counter() - t
print(f"반복문 {t_loop * 1000:7.1f} ms   벡터화 {t_vec * 1000:6.2f} ms   약 {t_loop / t_vec:.0f}배")
print("결과 같음:", np.isclose(total, total2))

원소별 연산은 산술 연산자와 수학 함수를 그대로 쓴다. x + y, x * y, np.exp(x), np.maximum(x, 0)은 모두 원소마다 적용된다. 마지막 식은 3주차의 ReLU 활성화 함수다.

z = np.array([-2.0, -0.5, 0.0, 1.5, 3.0])
print("ReLU   :", np.maximum(z, 0))
print("시그모이드:", (1 / (1 + np.exp(-z))).round(3))
print("제곱   :", z ** 2)
print("클리핑 :", np.clip(z, -1, 1))

브로드캐스팅

형상이 다른 배열끼리 연산하면 NumPy는 브로드캐스팅 규칙으로 형상을 맞춘다.

  1. 두 형상을 오른쪽 끝부터 나란히 놓는다. 축이 적은 쪽은 왼쪽에 크기 1인 축이 있다고 본다.
  2. 각 축에서 길이가 같거나, 둘 중 하나가 1이면 호환된다. 1인 쪽을 늘려 맞춘다.
  3. 그 밖의 경우는 오류다.
AB결과쓰임
(32, 10)(10,)(32, 10)모든 샘플에 같은 편향 벡터를 더함: 신경망 층의 $XW + b$
(32, 10)(32, 1)(32, 10)샘플마다 다른 값을 빼거나 나눔: 행별 정규화
(3, 1)(1, 4)(3, 4)모든 쌍의 연산: 외적, 거리 행렬
(32, 10)(32,)오류오른쪽 끝이 10과 32로 다름
 
X = np.arange(6, dtype=float).reshape(2, 3)     # (2, 3)
b = np.array([10.0, 20.0, 30.0])                  # (3,)
print("X + b =\n", X + b)
row_mean = X.mean(axis=1, keepdims=True)          # (2, 1): keepdims로 축을 남긴다
print("행 평균", row_mean.ravel(), "\n행 중심화 =\n", X - row_mean)
try:
    X - X.mean(axis=1)                            # (2, 3) - (2,) → 오른쪽 끝 3 대 2
except ValueError as e:
    print("오류:", e)

브로드캐스팅의 진짜 위험은 오류가 나지 않는 경우다. 예측 y_hat이 (N, 1)이고 정답 y가 (N,)이면 y_hat - y는 (N, N) 행렬이 되고, 손실은 틀린 값이 조용히 계산된다. 손실을 계산하기 직전에 두 형상이 같은지 확인한다.

y_hat = np.array([[1.0], [2.0], [3.0], [4.0]])    # (4, 1)
y = np.array([1.0, 2.0, 3.0, 4.0])                # (4,)
print("잘못된 MSE:", ((y_hat - y) ** 2).mean(), " 차의 형상", (y_hat - y).shape)
print("올바른 MSE:", ((y_hat.ravel() - y) ** 2).mean())

평균 이미지가 이미 각 숫자의 모양을 잘 보여 준다. 7일차 주간 프로젝트에서 이 평균 이미지만으로 분류기를 만든다.

정리

  • 텐서 = 축이 여러 개인 숫자 배열. 형상은 데이터의 구조를 나타낸다.
  • 슬라이싱은 뷰를 만든다. 독립된 배열이 필요하면 복사한다.
  • 반복문 대신 배열 연산(벡터화)을 쓴다.
  • 브로드캐스팅: 오른쪽부터 비교, 같거나 1이면 호환. 오류 없는 형상 불일치를 경계한다.
  • axis=k 집계는 k번 축을 없앤다. keepdims=True는 크기 1로 남긴다.

미니 프로젝트: NumPy 이미지 처리기

이미지는 숫자 행렬이다. 밝기 조절, 뒤집기, 자르기, 흐리게 하기, 경계 검출을 모두 NumPy 배열 연산만으로 구현한다. 마지막에는 손글씨 이미지 1797장에 같은 처리를 한 번에 적용한다.

  1. 테스트 이미지 만들기. 좌표 격자로 원, 사각형, 그라데이션이 있는 64×64 이미지를 만든다. 값은 0(검정)~1(흰색)이다. 
    import numpy as np
import matplotlib.pyplot as plt
H = W = 64
# 각 픽셀의 (행, 열) 좌표, 형상 (64, 64)
yy, xx = np.mgrid[0:H, 0:W]
img = 0.2 + 0.4 * xx / W                             # 가로 그라데이션
img[(xx - 22) ** 2 + (yy - 24) ** 2 < 12 ** 2] = 1.0  # 원 (불리언 마스크)
img[38:56, 36:58] = 0.0                              # 사각형 (슬라이싱)
def show(*ims, titles=None):
    fig, axs = plt.subplots(1, len(ims), figsize=(2.6 * len(ims), 2.6))
    for i, (ax, im) in enumerate(zip(np.atleast_1d(axs), ims)):
        ax.imshow(im, cmap="gray", vmin=0, vmax=1); ax.axis("off")
        if titles: ax.set_title(titles[i], fontsize=10)
    plt.show()
show(img, titles=["원본"])
  2. 밝기와 대비. 밝기는 더하기, 대비는 0.5를 중심으로 곱하기다. 결과를 np.clip으로 0~1에 가둔다. 
    bright = np.clip(img + 0.3, 0, 1)
contrast = np.clip((img - 0.5) * 2.0 + 0.5, 0, 1)
inverted = 1 - img
show(img, bright, contrast, inverted, titles=["원본", "밝게", "대비 2배", "반전"])
  3. 뒤집기, 회전, 자르기. 모두 인덱싱으로 표현된다. 회전은 전치와 뒤집기의 조합이다. 
    flip_lr = img[:, ::-1]          # 좌우 뒤집기
flip_ud = img[::-1, :]          # 상하 뒤집기
rot90 = img.T[::-1, :]          # 반시계 90도 회전 (np.rot90과 같음)
crop = img[10:42, 6:38]         # 32×32 자르기
print("자른 이미지 형상:", crop.shape, " 회전 확인:",
      np.array_equal(rot90, np.rot90(img)))
show(flip_lr, flip_ud, rot90, crop, titles=["좌우", "상하", "회전", "자르기"])
  4. 흐리게 하기. 각 픽셀을 주변 3×3 픽셀의 평균으로 바꾼다. 반복문 대신, 가장자리를 덧댄 이미지를 9가지 방향으로 밀어 더한다. 빈칸을 채워 완성하라. 
    def box_blur(im):
    p = np.pad(im, 1, mode="edge")             # (66, 66): 가장자리 한 칸 덧대기
    out = np.zeros_like(im)
    for dy in range(3):
        for dx in range(3):
            out += p[dy:dy + H, dx:dx + W]      # 9개 위치를 밀어서 더함
    return out / 9                              # TODO: 평균이 되도록 나누기
blur = img
for _ in range(3):
    blur = box_blur(blur)
show(img, blur, titles=["원본", "흐리게 ×3"])
  5. 경계 검출. 가로 방향으로 이웃 픽셀과의 차, 세로 방향의 차를 구하고 크기를 합친다. 값이 큰 곳이 경계다. 이 연산은 31일차 합성곱의 원형이다. 
    gx = np.zeros_like(img); gy = np.zeros_like(img)
gx[:, 1:-1] = img[:, 2:] - img[:, :-2]        # 오른쪽 - 왼쪽
gy[1:-1, :] = img[2:, :] - img[:-2, :]        # 아래 - 위
edge = np.sqrt(gx ** 2 + gy ** 2)
show(np.abs(gx), np.abs(gy), edge / edge.max(),
     titles=["가로 변화", "세로 변화", "경계 크기"])
  6. 묶음 처리. 손글씨 1797장 전체를 한 번에 처리한다. 각 이미지를 0~1로 정규화하고, 좌우 뒤집은 버전을 만들어 원본과 이어 붙인다(3600장 가까운 데이터 증강). 형상을 주석으로 적으며 진행한다. 
    d = load_data("digits")
batch = d["X"].reshape(-1, 8, 8) / 16.0                 # (1797, 8, 8), 0~1
# 모든 이미지를 한 번에 좌우 뒤집기
flipped = batch[:, :, ::-1]
both = np.concatenate([batch, flipped], axis=0)          # (3594, 8, 8)
per_img_mean = both.mean(axis=(1, 2))                    # 이미지별 평균 밝기 (3594,)
print(both.shape, per_img_mean.shape, per_img_mean[:3].round(3))
show(batch[0], flipped[0], batch[5], flipped[5],
     titles=["원본", "뒤집기", "원본", "뒤집기"])
참고 답안과 해설
  • 흐리게 하기에서 / 9가 빠지면 값이 9배로 커져 이미지가 하얗게 포화된다. 반복문은 9번(커널 크기)만 돌고 이미지 크기와 무관하다. 픽셀 수만큼 도는 반복문보다 훨씬 빠르다.
  • 경계 검출 결과에서 원과 사각형의 윤곽만 밝게 남는다. 그라데이션은 변화가 작아 거의 보이지 않는다.
  • 손글씨 숫자를 좌우로 뒤집으면 2, 3, 7 같은 숫자는 다른 모양이 된다. 증강은 레이블을 바꾸지 않는 변환만 써야 한다(34일차).
