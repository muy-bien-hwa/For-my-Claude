• 학습률 범위 테스트로 적절한 최대 학습률을 찾을 수 있다.
  • 잡음 섞인 SGD에서 학습률을 줄여야 하는 이유를 설명할 수 있다.
  • 계단 감쇠, 코사인 감쇠, 워밍업, 원사이클 스케줄을 식으로 쓰고 구현할 수 있다.
  • 배치 크기를 바꿀 때 학습률을 어떻게 조정하는지 설명할 수 있다.
  • 같은 예산에서 여러 스케줄을 비교하는 실험을 설계할 수 있다.

가장 중요한 하이퍼파라미터

하이퍼파라미터를 하나만 조정할 수 있다면 학습률을 고른다. 너무 작으면 학습이 느리고(9일차), 너무 크면 발산하며, 그 사이에서도 값에 따라 최종 성능이 크게 달라진다. 22일차에서 본 대로 옵티마이저가 바뀌면 좋은 학습률의 범위도 완전히 바뀐다. 오늘은 학습률을 정하는 두 가지 질문에 답한다. 처음에 얼마로 시작할 것인가(범위 테스트)와 학습하는 동안 어떻게 바꿀 것인가(스케줄)다.

학습률 범위 테스트

학습률을 아주 작은 값부터 매 스텝 지수적으로 키우며 한 번 학습하고, 학습률에 따른 손실을 기록하는 방법이 학습률 범위 테스트다(Smith, 2015). 몇백 스텝이면 끝나므로 본 학습 전에 싸게 할 수 있다.

  1. 학습률을 $10^{-5}$~$10^{-4}$에서 시작해 매 스텝 일정 비율로 키운다(예: 200스텝에 걸쳐 10까지).
  2. 손실의 지수 이동 평균(22일차)을 기록한다. 미니배치 잡음을 걸러 내기 위해서다.
  3. 손실이 최저치의 몇 배를 넘으면 멈춘다.
  4. 최저점 학습률의 1/10~1/3 근처, 또는 손실이 가장 가파르게 내려가는 학습률을 최대 학습률로 고른다.

이 테스트는 학습 초반의 동작만 보므로 정답을 주지는 않는다. 그러나 "0.001과 1 사이 어디쯤"이라는 막막한 질문을 몇 배 범위로 좁혀 준다.

왜 학습률을 줄이는가

미니배치 그래디언트는 잡음이 섞인 추정치다(9일차). 손실의 바닥 근처에서는 진짜 그래디언트가 작아지지만 잡음은 그대로라, 일정한 학습률로는 파라미터가 바닥 주변을 계속 떠돈다. 떠도는 범위는 학습률에 비례한다. 학습률을 줄이면 이 떨림이 줄어 더 낮은 손실에 닿는다.

그래서 대부분의 학습은 "처음에는 크게, 나중에는 작게"를 따른다. 큰 학습률은 빠르게 이동하며 넓고 평평한 지역을 찾는 데 유리하고, 작은 학습률은 그 안에서 정밀하게 바닥을 찾는다. 학습 진행에 따라 학습률을 바꾸는 계획을 학습률 스케줄이라 한다.

스케줄의 종류

전체 스텝 수를 $T$, 최대 학습률을 $\eta_{\max}$라 한다.

스케줄식특징
계단 감쇠정해진 시점마다 $\eta \leftarrow 0.1\eta$ResNet 같은 고전 CNN 학습. 감쇠 시점을 정해야 한다.
코사인 감쇠$\eta_t = \eta_{\min} + \frac12(\eta_{\max} - \eta_{\min})\left(1 + \cos\frac{\pi t}{T}\right)$부드럽게 0 근처까지. 하이퍼파라미터가 거의 없어 현재 가장 흔하다.
선형 감쇠$\eta_t = \eta_{\max}(1 - t/T)$사전학습 모델 미세조정에서 흔하다.
원사이클약 30% 지점까지 $\eta_{\max}/25$에서 $\eta_{\max}$로 올린 뒤 끝까지 내림짧은 학습에서 강하다(Smith, 2018).

$\eta_{\max} = 0.1$, $\eta_{\min} = 0$, $T = 1000$. $t = 0$에서 0.1, $t = 250$에서 $0.05(1 + \cos45°) = 0.0854$, $t = 500$에서 0.05, $t = 750$에서 0.0146, $t = 1000$에서 0. 처음과 끝에서는 천천히, 가운데서는 빠르게 줄어든다.

워밍업

학습 초반 몇백~몇천 스텝 동안 학습률을 0 근처에서 목표값까지 선형으로 올리는 것을 워밍업이라 한다. 큰 학습률을 처음부터 쓰면 생기는 문제를 막는다.

  • 무작위 초기 상태에서는 그래디언트가 크고 방향이 들쭉날쭉하다. 큰 첫 걸음이 파라미터를 나쁜 지역으로 던질 수 있다.
  • Adam의 2차 모멘트 추정치 $\hat{\mathbf v}$는 처음 몇 스텝 동안 표본이 적어 부정확하다. 작은 학습률로 시작하면 이 기간의 위험이 줄어든다.
  • 배치 정규화(25일차)의 이동 평균 통계가 아직 자리 잡지 않았다.

트랜스포머 학습은 거의 항상 "워밍업 + 코사인(또는 선형) 감쇠"를 쓴다. 워밍업 길이는 보통 전체의 1~10%다.

배치 크기와 학습률

배치를 $k$배 키우면 그래디언트 잡음의 분산이 $1/k$로 준다. 같은 에폭 수에서 스텝 수는 $1/k$가 되므로, 학습률을 $k$배로 키워 한 스텝에 더 멀리 가게 하는 것이 자연스럽다. 이를 선형 스케일링 규칙이라 한다(Goyal 등, 2017). 이 논문은 배치 8192, 학습률을 32배로 키우고 워밍업을 써서 ResNet-50을 1시간에 학습했다.

  • 선형 규칙은 어느 크기(임계 배치 크기)까지만 통한다. 그보다 크면 학습률을 더 키워도 불안정해지기만 한다.
  • Adam 계열에서는 학습률을 $\sqrt k$배로 키우는 규칙이 더 잘 맞는 경우가 많다.
  • 배치를 바꾸면 학습률을 다시 탐색하는 것이 가장 확실하다.

코드 실습: 스케줄 함수와 범위 테스트

스케줄을 "스텝 번호 → 학습률" 함수로 만든다. 모든 스케줄이 같은 인터페이스를 가지면 학습 루프에서 쉽게 바꿔 끼울 수 있다.

import numpy as np
import math
import matplotlib.pyplot as plt
def make_schedule(kind, T, lr_max, warmup=0, lr_min=0.0):
    def f(t):
        if kind == "일정": return lr_max
        if kind == "계단": return lr_max * 0.1 ** math.floor(t / (T / 3))
        if kind == "코사인":
            return lr_min + 0.5 * (lr_max - lr_min) * (1 + math.cos(math.pi * t / T))
        if kind == "워밍업+코사인":
            if t < warmup: return lr_max * (t + 1) / warmup
            prog = (t - warmup) / (T - warmup)                  # 0 → 1
            return lr_min + 0.5 * (lr_max - lr_min) * (1 + math.cos(math.pi * prog))
        if kind == "원사이클":
            up = int(0.3 * T)
            if t < up: return lr_max / 25 + (lr_max - lr_max / 25) * t / up
            prog = (t - up) / (T - up)
            return lr_max * 0.5 * (1 + math.cos(math.pi * prog)) + lr_max * 1e-4
    return f
T = 360
plt.figure(figsize=(6, 3.2))
for kind in ["일정", "계단", "코사인", "워밍업+코사인", "원사이클"]:
    f = make_schedule(kind, T, 0.1, warmup=36)
    plt.plot([f(t) for t in range(T)], label=kind)
plt.xlabel("스텝")
plt.ylabel("학습률")
plt.legend(fontsize=8)
plt.grid(alpha=.3)
plt.show()
print("코사인 t = 0, 90, 180, 270:",
      [round(make_schedule("코사인", T, 0.1)(t), 4) for t in (0, 90, 180, 270)])

다음은 손글씨 MLP(64 → 128 → 128 → 10, 모멘텀 SGD)에서 학습률 범위 테스트를 한다. 22일차 프로젝트와 같은 층과 옵티마이저를 쓴다.

class Linear:
    def __init__(self, d_in, d_out, rng):
        self.W = rng.normal(0, np.sqrt(2 / d_in), (d_in, d_out))
        self.b = np.zeros(d_out)
        self.dW = np.zeros_like(self.W); self.db = np.zeros_like(self.b)
    def forward(self, X):
        self.X = X; return X @ self.W + self.b
    def backward(self, G):
        self.dW[...] = self.X.T @ G; self.db[...] = G.sum(0); return G @ self.W.T
    def params(self): return [(self.W, self.dW), (self.b, self.db)]
class ReLU:
    def forward(self, X):
        self.m = X > 0; return X * self.m
    def backward(self, G): return G * self.m
    def params(self): return []
class Net:
    def __init__(self, seed=1):
        r = np.random.default_rng(seed)
        self.layers = [Linear(64, 128, r), ReLU(), Linear(128, 128, r), ReLU(),
                       Linear(128, 10, r)]
    def forward(self, X):
        for l in self.layers: X = l.forward(X)
        return X
    def backward(self, G):
        for l in reversed(self.layers): G = l.backward(G)
    def params(self): return [pg for l in self.layers for pg in l.params()]
class Momentum:
    def __init__(self, params, lr, beta=0.9):
        self.params, self.lr, self.beta = params, lr, beta
        self.v = [np.zeros_like(p) for p, _ in params]
    def zero_grad(self):
        for _, g in self.params: g[...] = 0
    def step(self):
        for (p, g), v in zip(self.params, self.v):
            v *= self.beta; v += g; p -= self.lr * v
def ce(Z, y):
    Z = Z - Z.max(1, keepdims=True); P = np.exp(Z) / np.exp(Z).sum(1, keepdims=True)
    G = P.copy(); G[np.arange(len(y)), y] -= 1
    return -np.log(P[np.arange(len(y)), y] + 1e-12).mean(), G / len(y)
d = load_data("digits"); X, y = d["X"].astype(float) / 16, d["y"]
rng = np.random.default_rng(0); tr, te = [], []
for k in range(10):
    idx = rng.permutation(np.where(y == k)[0])
    cut = int(0.8 * len(idx))
    tr += list(idx[:cut])
    te += list(idx[cut:])
tr, te = np.array(tr), np.array(te)

def lr_range_test(lo=1e-4, hi=10.0, steps=200, seed=1):
    net = Net(seed); opt = Momentum(net.params(), lo); r = np.random.default_rng(seed)
    order = np.concatenate([r.permutation(len(tr)) for _ in range(6)])
    lrs, losses, avg, best = [], [], None, np.inf
    for s in range(steps):
        lr = lo * (hi / lo) ** (s / (steps - 1)); opt.lr = lr       # 지수적으로 증가
        i = tr[order[s * 32:(s + 1) * 32]]
        with np.errstate(all="ignore"):
            L, G = ce(net.forward(X[i]), y[i])
            opt.zero_grad()
            net.backward(G)
            opt.step()
        avg = L if avg is None else 0.9 * avg + 0.1 * L                # 손실의 EMA
        lrs.append(lr); losses.append(avg); best = min(best, avg)
        if not np.isfinite(avg) or avg > 4 * best: break               # 발산하면 멈춤
    return np.array(lrs), np.array(losses)

lrs, losses = lr_range_test()
plt.figure(figsize=(6, 3.2)); plt.semilogx(lrs, losses)
plt.xlabel("학습률"); plt.ylabel("손실 (EMA)"); plt.grid(alpha=.3); plt.show()
print(f"최저점 학습률 {lrs[np.argmin(losses)]:.3f}, 멈춘 학습률 {lrs[-1]:.3f}")

손실은 학습률 0.01 근처부터 빠르게 내려가고, 약 0.16에서 최저, 0.5 근처에서 폭증한다. 최대 학습률로 0.05~0.1을 고르면 적당하다.

정리

  • 학습률 범위 테스트: 학습률을 지수적으로 키우며 손실 EMA 기록. 최저점의 1/10~1/3, 또는 가장 가파른 구간을 고른다.
  • 잡음 섞인 SGD는 일정한 학습률로는 바닥 주변을 떠돈다. 학습률을 줄여야 더 낮은 손실에 닿는다.
  • 계단 감쇠, 코사인 감쇠(가장 흔함), 선형 감쇠, 원사이클.
  • 워밍업: 초반 불안정(큰 그래디언트, 부정확한 Adam 통계)을 막는다. 트랜스포머는 워밍업 + 감쇠가 표준.
  • 배치 $k$배 → 학습률 $k$배(선형 규칙, SGD), Adam은 $\sqrt k$배 근처. 한계가 있으니 다시 탐색이 확실.

  2. 배치 크기 32, 학습률 0.05로 잘 되던 SGD 학습을 배치 512로 바꿨다. 선형 규칙에 따른 학습률과 함께 고려해야 할 점은?
    풀이

    16배이므로 0.8. 이렇게 큰 학습률은 초반에 발산하기 쉬우므로 워밍업을 붙이고, 실제로 잘 되는지 범위 테스트로 확인한다. 같은 에폭 수에서 스텝 수가 1/16이 되므로 에폭을 조금 늘려야 할 수도 있다.

  3. 지수 감쇠 $\eta_t = \eta_0\gamma^t$에서 1000스텝 동안 학습률을 1/100로 줄이려면 $\gamma$는 얼마여야 하는가?
    풀이

    $\gamma^{1000} = 0.01$, $\gamma = 0.01^{1/1000} = e^{\ln 0.01/1000} \approx 0.99540$. 아주 작은 차이가 1000번 곱해져 100배가 된다.

코드 실습에서 범위 테스트로 고른 최대 학습률 0.1로, 다섯 가지 스케줄을 같은 8에폭(약 360스텝) 동안 적용해 학습 손실과 테스트 정확도를 비교한다. 이어서 최대 학습률을 지나치게 크게(0.3) 잡았을 때 스케줄이 어떤 차이를 만드는지 본다. 학습을 10번 하므로 브라우저에서 수십 초 걸린다.

  1. 스케줄을 받는 학습 함수. 매 스텝 전에 스케줄 함수로 학습률을 바꾼다. 
    def train_with_schedule(kind, lr_max, epochs=8, seed=1):
    net = Net(seed)
    opt = Momentum(net.params(), lr_max)
    r = np.random.default_rng(seed)
    steps_per_epoch = math.ceil(len(tr) / 32); T = epochs * steps_per_epoch
    sched = make_schedule(kind, T, lr_max, warmup=int(0.1 * T)); t = 0; curve = []
    for ep in range(epochs):
        order = r.permutation(len(tr)); tot = 0.0
        for s in range(0, len(order), 32):
            # TODO 확인: 스텝마다 학습률 갱신
            opt.lr = sched(t); t += 1
            i = tr[order[s:s + 32]]
            with np.errstate(all="ignore"):
                L, G = ce(net.forward(X[i]), y[i])
                opt.zero_grad()
                net.backward(G)
                opt.step()
            tot += L * len(i)
        curve.append(tot / len(tr))
    acc = (net.forward(X[te]).argmax(1) == y[te]).mean()
    return np.array(curve), acc
print("준비 완료")

  • 2단계: 학습률이 끝까지 줄어드는 코사인, 워밍업+코사인, 원사이클의 마지막 에폭 학습 손실이 약 0.01로 가장 낮다. 일정한 학습률은 약 0.06, 계단 감쇠는 약 0.03이다. 테스트 정확도는 98.1~98.6%로 차이가 작다. 테스트 364개에서 0.5%p는 2개 정도라, 이 정도 차이는 시드를 바꾸면 순위가 뒤바뀔 수 있다. 결론은 손실 곡선과 여러 시드의 평균으로 내야 한다.
  • 3단계: 최대 학습률 0.3에서는 일정한 학습률이 학습에 실패한다(정확도가 10~50%). 학습률을 줄이는 스케줄은 후반에 회복해 93~96%에 닿지만, 0.1로 시작한 경우보다 나쁘다. 스케줄은 좋은 최대 학습률을 대신하지 못한다. 범위 테스트로 최대 학습률을 먼저 고르는 이유다.
  • 워밍업은 이 작은 MLP에서는 효과가 거의 없다. 깊은 망, 큰 배치, Adam과 트랜스포머처럼 초반이 불안정한 경우에 효과가 크다.
