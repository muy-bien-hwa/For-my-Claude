• 멀티헤드 어텐션의 동기와 형상 변환(split heads / merge heads)을 정확히 구현한다.
  • 어텐션에 순서 정보가 없다는 것을 확인하고, 위치 인코딩(사인파, 학습형, RoPE 개념)을 이해한다.
  • Transformer 블록(어텐션 + FFN + 잔차 + LayerNorm)의 구조와 각 부품의 역할을 설명한다.
  • 인코더(BERT형) · 디코더(GPT형) · 인코더-디코더(T5형) 구조를 구분한다.
👨‍🏫 "Attention Is All You Need" (2017) 이 논문의 제목은 도발적이었습니다. RNN도 CNN도 없이 어텐션만으로 번역 최고 성능을 냈으니까요. 그런데 오늘 보면 알겠지만, Transformer는 완전히 새로운 발명이라기보다 지금까지 배운 부품들의 영리한 조립입니다. 잔차 연결(Day 18), 층 정규화(Day 13), MLP(Day 8), 어텐션(Day 22). 하나하나 짚어 봅시다.

1. 멀티헤드 어텐션

어텐션 하나는 각 토큰에 대해 가중치 분포를 하나만 만듭니다. 그런데 한 단어는 여러 관계를 동시에 맺습니다. "그녀가 어제 산 책을 읽었다"에서 "읽었다"는 주어(그녀), 목적어(책), 시제 단서(어제)와 모두 관련이 있습니다.

멀티헤드: $d_{model}$ 차원을 $h$개의 헤드로 나눠 각 헤드가 $d_k = d_{model}/h$ 차원에서 독립적으로 어텐션을 수행하고, 결과를 이어 붙인 뒤 선형변환합니다.

$$\mathrm{head}_i = \mathrm{Attention}(XW_Q^{(i)}, XW_K^{(i)}, XW_V^{(i)}),\qquad \mathrm{MHA}(X) = [\mathrm{head}_1;\dots;\mathrm{head}_h]\,W_O$$

계산량은 헤드 하나짜리와 거의 같습니다(차원을 나눴으니까요). 실제 모델을 분석하면 어떤 헤드는 바로 앞 토큰을, 어떤 헤드는 문법적 주어를, 어떤 헤드는 같은 단어의 이전 등장을 봅니다.

import numpy as np
rng = np.random.default_rng(0)
softmax = lambda z: np.exp(z - z.max(-1, keepdims=True)) / np.exp(z - z.max(-1, keepdims=True)).sum(-1, keepdims=True)

def multi_head_attention(X, Wq, Wk, Wv, Wo, n_heads, mask=None):
    B, T, D = X.shape; dk = D // n_heads
    def split(M):                                   # (B, T, D) → (B, h, T, dk)
        return M.reshape(B, T, n_heads, dk).transpose(0, 2, 1, 3)
    Q, K, V = split(X @ Wq), split(X @ Wk), split(X @ Wv)
    scores = Q @ K.transpose(0, 1, 3, 2) / np.sqrt(dk)            # (B, h, T, T)
    if mask is not None: scores = np.where(mask, scores, -1e9)
    A = softmax(scores)
    out = (A @ V).transpose(0, 2, 1, 3).reshape(B, T, D)          # 헤드 합치기 (B, T, D)
    return out @ Wo, A

B, T, D, h = 2, 6, 32, 4
X = rng.normal(size=(B, T, D))
W = [rng.normal(0, 1/np.sqrt(D), (D, D)) for _ in range(4)]
out, A = multi_head_attention(X, *W, n_heads=h, mask=np.tril(np.ones((T, T), bool)))
print("입력", X.shape, "→ 출력", out.shape, " 어텐션 가중치", A.shape, "(배치, 헤드, query, key)")
print("파라미터 수 (Wq,Wk,Wv,Wo):", 4 * D * D, "= 4·D²")

2. 어텐션은 순서를 모른다

셀프 어텐션은 입력 토큰의 순서를 바꾸면 출력도 똑같이 순서만 바뀝니다(순열 등변). "개가 사람을 물었다"와 "사람이 개를 물었다"를 구분하지 못합니다! 직접 확인해 봅시다.

perm = rng.permutation(T)
out1, _ = multi_head_attention(X, *W, n_heads=h)
out2, _ = multi_head_attention(X[:, perm], *W, n_heads=h)
print("순서를 섞은 입력의 출력 == 원래 출력을 같은 순서로 섞은 것?", np.allclose(out2, out1[:, perm]))

그래서 각 토큰 임베딩에 위치 정보를 더해 줍니다.

3. 위치 인코딩

사인파 위치 인코딩 (원 논문)

$$PE_{(pos,2i)} = \sin\!\left(\frac{pos}{10000^{2i/d}}\right),\qquad PE_{(pos,2i+1)} = \cos\!\left(\frac{pos}{10000^{2i/d}}\right)$$

차원마다 주파수가 다른 사인·코사인 파동입니다. 시계의 초침·분침·시침처럼, 빠른 파동과 느린 파동의 조합으로 각 위치에 고유한 "지문"을 줍니다. 또 $PE_{pos+k}$가 $PE_{pos}$의 선형변환으로 표현되어 상대 위치를 학습하기 쉽습니다.

import matplotlib.pyplot as plt
def sinusoidal_pe(T, d):
    pos = np.arange(T)[:, None]; i = np.arange(0, d, 2)[None, :]
    ang = pos / (10000 ** (i / d))
    pe = np.zeros((T, d)); pe[:, 0::2] = np.sin(ang); pe[:, 1::2] = np.cos(ang)
    return pe
pe = sinusoidal_pe(100, 64)
fig, ax = plt.subplots(1, 2, figsize=(12, 3.4))
im = ax[0].imshow(pe, aspect='auto', cmap='RdBu'); ax[0].set_xlabel('차원'); ax[0].set_ylabel('위치'); ax[0].set_title('사인파 위치 인코딩')
sim = pe @ pe.T; ax[1].plot(sim[50]); ax[1].set_title('위치 50과 다른 위치들의 내적'); ax[1].set_xlabel('위치')
plt.tight_layout(); plt.show()

오른쪽 그래프: 가까운 위치일수록 내적이 큽니다. 위치 인코딩이 "거리" 정보를 담고 있다는 뜻입니다.

다른 방식들

  • 학습형 위치 임베딩: nn.Embedding(max_len, d). GPT-2, BERT. 간단하지만 학습한 최대 길이를 넘지 못합니다.
  • RoPE (회전 위치 임베딩): Q와 K 벡터를 위치에 비례한 각도로 회전시킵니다(Day 3의 회전 행렬!). 그러면 $q_m\cdot k_n$이 상대 거리 $m-n$에만 의존하게 됩니다. LLaMA 등 대부분의 최신 LLM이 사용합니다.

4. Transformer 블록

$$\begin{aligned} \mathbf x &\leftarrow \mathbf x + \mathrm{MHA}(\mathrm{LN}(\mathbf x)) &&\text{토큰끼리 정보 교환 ("소통")}\\ \mathbf x &\leftarrow \mathbf x + \mathrm{FFN}(\mathrm{LN}(\mathbf x)) &&\text{토큰별로 독립적인 계산 ("생각")} \end{aligned}$$

FFN은 토큰마다 같은 2층 MLP입니다: $\mathrm{FFN}(x) = W_2\,\mathrm{GELU}(W_1x + b_1) + b_2$. 은닉 차원은 보통 $4\cdot d_{model}$입니다. 모델 파라미터의 약 2/3가 FFN에 있고, 사실(지식)이 주로 여기에 저장된다는 연구가 있습니다.

🔑 각 부품이 거기 있는 이유
  • 어텐션: 토큰 사이의 정보 이동. 유일하게 토큰끼리 섞이는 곳.
  • FFN: 모은 정보를 토큰별로 가공. 비선형성의 원천.
  • 잔차 연결: 깊이 수십~수백 층까지 기울기 흐름 보장. 각 블록은 "잔차 스트림"에 정보를 더하는 역할.
  • LayerNorm: 각 서브층 입력의 스케일 안정화. Pre-LN(서브층 앞)이 Post-LN(원 논문, 뒤)보다 학습이 안정적이라 표준이 되었습니다.
def layer_norm(x, eps=1e-5):
    return (x - x.mean(-1, keepdims=True)) / np.sqrt(x.var(-1, keepdims=True) + eps)
def gelu(x): return 0.5 * x * (1 + np.tanh(0.7978845608 * (x + 0.044715 * x**3)))

def transformer_block(x, p, n_heads, mask=None):
    a, _ = multi_head_attention(layer_norm(x), p['Wq'], p['Wk'], p['Wv'], p['Wo'], n_heads, mask)
    x = x + a                                                   # 잔차 1
    x = x + gelu(layer_norm(x) @ p['W1']) @ p['W2']              # 잔차 2 (FFN)
    return x

def init_block(D):
    s = 1 / np.sqrt(D)
    return {'Wq': rng.normal(0, s, (D, D)), 'Wk': rng.normal(0, s, (D, D)), 'Wv': rng.normal(0, s, (D, D)), 'Wo': rng.normal(0, s, (D, D)),
            'W1': rng.normal(0, s, (D, 4*D)), 'W2': rng.normal(0, 1/np.sqrt(4*D), (4*D, D))}

# 미니 GPT 순전파: 토큰 ID → 임베딩 + 위치 → 블록 N개 → LN → 어휘 로짓
V, T, D, h, N = 50, 8, 32, 4, 3
tok_emb = rng.normal(0, 0.02, (V, D)); pos = sinusoidal_pe(T, D)
blocks = [init_block(D) for _ in range(N)]
ids = rng.integers(0, V, (2, T))
x = tok_emb[ids] + pos                                           # (2, T, D)
mask = np.tril(np.ones((T, T), bool))
for p in blocks: x = transformer_block(x, p, h, mask)
logits = layer_norm(x) @ tok_emb.T                               # 가중치 공유(weight tying): 출력층 = 임베딩의 전치
print("로짓:", logits.shape, "→ 각 위치에서 다음 토큰에 대한 점수")
n_params = V*D + N * (4*D*D + 8*D*D)
print(f"대략적 파라미터 수: {n_params:,} (블록당 12·D² = {12*D*D:,})")
💡 파라미터 수 어림 공식 블록 하나는 어텐션 $4D^2$ + FFN $8D^2$ = $12D^2$. GPT-3 (D = 12,288, 96층): $12\times12288^2\times96\approx 1{,}740$억. 실제 1,750억과 거의 같습니다!

6. PyTorch 구현 미리보기

class Block(nn.Module):
    def __init__(self, d, n_heads, p_drop=0.1):
        super().__init__()
        self.ln1, self.ln2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.attn = nn.MultiheadAttention(d, n_heads, dropout=p_drop, batch_first=True)
        self.ffn = nn.Sequential(nn.Linear(d, 4 * d), nn.GELU(), nn.Linear(4 * d, d), nn.Dropout(p_drop))
    def forward(self, x, causal_mask):
        h = self.ln1(x)
        x = x + self.attn(h, h, h, attn_mask=causal_mask, need_weights=False)[0]
        return x + self.ffn(self.ln2(x))
# 주의: nn.MultiheadAttention의 attn_mask는 True가 '가리는' 위치 (우리 NumPy 구현과 반대!)
causal_mask = torch.triu(torch.ones(T, T, dtype=torch.bool), diagonal=1)

내일은 이것을 F.scaled_dot_product_attention으로 직접 짜서 실제로 학습시킵니다.
