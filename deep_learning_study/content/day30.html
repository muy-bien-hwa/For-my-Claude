🔑 개선의 우선순위 (경험칙)
  1. 데이터: 레이블 오류 수정, 데이터 추가, 증강. 대부분 가장 효과가 큽니다.
  2. 사전학습 모델: 처음부터 학습하는 대신 미세조정.
  3. 학습률과 스케줄.
  4. 규제: 학습-검증 격차가 크다면.
  5. 모델 크기·구조: 학습 성능부터 낮다면(과소적합).
  6. 앙상블: 마지막에 몇 % 더 짜낼 때. 서로 다른 시드나 구조의 모델 예측을 평균.

과적합인지 과소적합인지 먼저 판단하세요(학습 vs 검증 곡선). 과소적합인데 규제를 추가하거나, 과적합인데 모델을 키우면 시간만 낭비합니다.

2. 최종 평가와 오류 분석

  1. 검증 세트 기준 최고 모델을 고릅니다. 여기까지가 모든 결정입니다.
  2. 봉인했던 테스트 세트로 단 한 번 평가합니다.
  3. 혼동 행렬과 클래스별 지표를 봅니다(Day 11).
  4. 가장 확신하며 틀린 샘플 20개를 직접 봅니다. 패턴이 있나요? (레이블 오류? 모호한 샘플? 특정 조건에서 실패?)
  5. 모델이 무엇을 보고 판단하는지 확인해 보세요. 이미지라면 Grad-CAM 같은 시각화로 엉뚱한 곳(배경, 워터마크)을 보고 있지 않은지 점검합니다.
@torch.no_grad()
def most_confident_errors(model, loader, k=20):
    model.eval(); errs = []
    for xb, yb in loader:
        p = F.softmax(model(xb.to(device)), -1).cpu()
        conf, pred = p.max(-1)
        for x, y, c, pr in zip(xb, yb, conf, pred):
            if pr != y: errs.append((c.item(), x, y.item(), pr.item()))
    return sorted(errs, key=lambda e: -e[0])[:k]       # 확신도가 높은 오류부터

3. 결과 보고서 (README) 템플릿

  1. 문제: 무엇을, 왜 풀었나 (2~3문장)
  2. 데이터: 출처, 크기, 분할, 전처리, 특이사항
  3. 방법: 최종 모델 구조, 손실, 옵티마이저, 주요 하이퍼파라미터
  4. 결과: 베이스라인 사다리 표 + 실험 표 + 최종 테스트 점수
  5. 분석: 학습 곡선, 혼동 행렬, 대표적 오류 사례와 원인 추정
  6. 한계와 다음 단계: 무엇이 부족하고, 시간이 더 있다면 무엇을 할지
  7. 재현 방법: 실행 명령, 환경, 시드
