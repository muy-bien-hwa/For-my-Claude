학습의 정의: 함수 근사와 최적화

이 과정 전체는 다음 한 문장 위에 서 있다.

모델은 파라미터 $\theta$를 가진 함수 $f_\theta(x)$이다. 학습이란 데이터에 대한 손실 $L(\theta)$를 가장 작게 만드는 $\theta$를 찾는 일이다.

세 가지 구성 요소

  • 모델 $f_\theta$: 입력 $x$를 받아 예측 $\hat y = f_\theta(x)$를 내는 함수. 함수의 "모양"을 정한다. 직선, 신경망, 트랜스포머는 모두 서로 다른 모양의 함수다.
  • 파라미터 $\theta$: 모델 안에서 학습으로 정해지는 수. 직선 $\hat y = wx+b$라면 $w$와 $b$다. GPT 같은 모델은 수천억 개의 파라미터를 가진다.
  • 손실 함수 $L(\theta)$: 예측이 정답과 얼마나 다른지를 하나의 수로 잰 것. 작을수록 좋다.

손실을 가장 작게 만드는 파라미터를 찾는 과정이 최적화이며, 이 과정을 데이터에 대해 수행하는 것이 학습이다. 학습이 끝난 모델로 새 입력의 답을 계산하는 것은 추론이라 한다.

$$\theta^* = \arg\min_{\theta}\; L(\theta), \qquad L(\theta) = \frac{1}{N}\sum_{i=1}^{N} \ell\big(f_\theta(x_i),\, y_i\big)$$

읽는 법: 데이터 $N$개 각각에 대해 예측 $f_\theta(x_i)$와 정답 $y_i$의 오차 $\ell$을 구하고, 그 평균 $L(\theta)$를 가장 작게 만드는 $\theta$를 $\theta^*$라 한다. $\arg\min$은 "최솟값을 만드는 입력"이라는 뜻이다.

데이터 세 점 $(1, 3), (2, 5), (3, 7)$에 모델 $\hat y = wx$를 맞춘다고 하자. 손실은 평균제곱오차 $L(w) = \frac13\sum(wx_i - y_i)^2$로 정한다.

  • $w=2$: 예측 $(2, 4, 6)$, 오차 $(-1, -1, -1)$, $L = \frac{1+1+1}{3} = 1$.
  • $w=2.5$: 예측 $(2.5, 5, 7.5)$, 오차 $(-0.5, 0, 0.5)$, $L = \frac{0.25+0+0.25}{3} \approx 0.167$.
  • $w=3$: 예측 $(3, 6, 9)$, 오차 $(0, 1, 2)$, $L = \frac{0+1+4}{3} \approx 1.667$.

세 후보 중 $w=2.5$의 손실이 가장 작다. 학습은 이런 비교를 체계적으로, 그리고 효율적으로 하는 방법이다.

아래 인터랙티브에서 파라미터를 바꾸며 손실이 어떻게 변하는지 직접 확인한다.

여기서는 $w$를 0.05 간격으로 모두 시험했다(무차별 탐색). 파라미터가 1개라 가능했다. 파라미터가 100만 개이고 각각 10개 값만 시험해도 조합은 $10^{1{,}000{,}000}$개다. 그래서 딥러닝은 손실이 줄어드는 방향을 미분으로 계산해 그쪽으로 조금씩 이동하는 경사하강법(9일차)을 쓴다.

학습 전에 사람이 정하는 값도 있다. 학습률, 층 수, 학습 반복 횟수처럼 학습으로 정해지지 않는 설정값을 하이퍼파라미터라 한다.

def mse(pred, target):
    """평균제곱오차"""
    n = len(pred)
    return sum((p - t) ** 2 for p, t in zip(pred, target)) / n

print("MSE:", mse([2, 4, 6], [3, 5, 7]))
for i, (p, t) in enumerate(zip([2, 4, 6], [3, 5, 7])):

클래스

3주차에 신경망의 층을 클래스로 만든다. 상태(파라미터)와 동작(계산)을 묶는 방법이다.

class Line:
    """직선 모델 y = w x + b"""
    def __init__(self, w, b):
        self.w = w
        self.b = b
    def __call__(self, x):                  # 객체를 함수처럼 호출
        return self.w * x + self.b
    def __repr__(self):
        return f"Line(w={self.w}, b={self.b})"

m = Line(1.8, 32)
print(m, "→ 섭씨 25도 =", m(25), "화씨")
m.w = 2.0                                   # 파라미터 변경
print(m, "→", m(25))

정리

  • 머신러닝은 데이터와 정답으로부터 규칙(모델)을 학습한다. 딥러닝은 여러 층의 신경망으로 특징까지 학습한다(표현 학습).
  • 모델 = 파라미터를 가진 함수, 손실 = 예측의 틀린 정도, 학습 = 손실을 최소화하는 파라미터 찾기.
  • 파라미터가 많으면 무차별 탐색은 불가능하므로 미분을 이용한 경사하강법을 쓴다.
  • 지도학습의 두 과제: 수를 예측하는 회귀, 범주를 예측하는 분류.

    정답은 $y = 2x+1$이다. $w=1$: 예측 $(1, 2, 3)$, 오차 $(0, -1, -2)$, $L = 5/3 \approx 1.667$. $w=2$: 오차 0, $L=0$. $w=3$: 예측 $(1, 4, 7)$, 오차 $(0, 1, 2)$, $L = 5/3$. 손실은 $w=2$에서 최소이고 양쪽으로 대칭적으로 커진다.

    (a) 다중 분류(10개 범주) (b) 회귀 (c) 이진 분류 (d) 다중 분류(3개 범주).

  3. 파라미터가 2개($w$, $b$)인 모델에서 각 파라미터를 0.01 간격으로 $[-10, 10]$ 범위에서 무차별 탐색하면 손실을 몇 번 계산해야 하는가? 파라미터가 10개라면?
    풀이

    한 축에 $20/0.01 + 1 = 2001$개 값. 2개면 $2001^2 \approx 4\times10^6$번, 10개면 $2001^{10}\approx 10^{33}$번이다. 차원이 늘면 탐색량이 지수적으로 증가한다(차원의 저주).

  4. 붓꽃 데이터에서 꽃받침 길이(0번 특징)와 꽃받침 너비(1번 특징)로 산점도를 그리고, 꽃잎 특징을 쓴 그래프와 비교해 어느 쪽이 품종을 더 잘 나누는지 설명하라.
    풀이

    위의 산점도 코드에서 인덱스 2, 3을 0, 1로 바꾼다. 꽃받침 특징에서는 versicolor와 virginica가 크게 겹친다. 꽃잎 특징이 품종을 더 잘 나눈다. 어떤 특징을 쓰느냐가 성능을 좌우하며, 딥러닝은 이런 특징을 스스로 만든다.

미니 프로젝트: 무차별 탐색으로 관계 학습하기

측정 오차가 섞인 (섭씨, 화씨) 데이터만 보고 변환식 $y = wx + b$의 $w$와 $b$를 찾는다. 2차원 무차별 탐색으로 손실 지형을 그리고, 이 방법의 한계를 확인한다.

  1. 데이터 만들기. 실제 관계 $y = 1.8x + 32$에 표준편차 3의 잡음을 더한 측정값 30개를 만든다. 
    import numpy as np
import matplotlib.pyplot as plt
rng = np.random.default_rng(0)
x = rng.uniform(-10, 40, 30)                 # 섭씨
y = 1.8 * x + 32 + rng.normal(0, 3, 30)      # 화씨 (측정 오차 포함)
plt.figure(figsize=(5, 3.5)); plt.scatter(x, y, s=15)
plt.xlabel("섭씨"); plt.ylabel("화씨"); plt.show()
  2. 손실 함수 정의. 파라미터 w, b를 받아 평균제곱오차를 돌려주는 함수를 완성한다. 
    def loss(w, b):
    pred = w * x + b
    # TODO: pred와 y의 평균제곱오차를 반환
    return ((pred - y) ** 2).mean()

print(loss(1.8, 32), loss(2.0, 30), loss(1.0, 0))
  3. 2차원 무차별 탐색. $w\in[0, 3.5]$, $b\in[0, 60]$을 격자로 나눠 모든 조합의 손실을 계산하고 최소인 곳을 찾는다. 
    ws = np.linspace(0, 3.5, 141)
bs = np.linspace(0, 60, 121)
L = np.array([[loss(w, b) for w in ws] for b in bs])      # 형상 (b 개수, w 개수)
i, j = np.unravel_index(L.argmin(), L.shape)
print(f"계산 횟수 {L.size}회, 최적 w = {ws[j]:.3f}, b = {bs[i]:.2f}, 손실 {L[i, j]:.3f}")
  4. 손실 지형 시각화. 손실을 등고선으로 그린다. 등고선 하나는 손실이 같은 $(w, b)$의 모임이다(5일차에서 자세히 다룬다). 
    plt.figure(figsize=(6, 4.2))
cs = plt.contour(ws, bs, L, levels=[5, 10, 25, 50, 100, 200, 400, 800], cmap="Blues_r")
plt.clabel(cs, fmt="%d", fontsize=8)
plt.plot(ws[j], bs[i], "r*", ms=12, label="탐색으로 찾은 최소점")
plt.plot(1.8, 32, "kx", ms=9, label="참값 (1.8, 32)")
plt.xlabel("w"); plt.ylabel("b"); plt.legend(); plt.title("손실 L(w, b)의 등고선")
plt.show()
  5. 결과 해석. 찾은 직선을 데이터 위에 그리고, 참값과 다른 이유를 설명한다. 등고선이 한 방향으로 길쭉한 이유도 생각한다. 
    w_best, b_best = ws[j], bs[i]
xs = np.linspace(-10, 40, 50)
plt.figure(figsize=(5, 3.5))
plt.scatter(x, y, s=15, label="측정값")
plt.plot(xs, w_best * xs + b_best, "r", label=f"학습 결과 y = {w_best:.2f}x + {b_best:.1f}")
plt.plot(xs, 1.8 * xs + 32, "k--", lw=1, label="참값")
plt.legend(); plt.xlabel("섭씨"); plt.ylabel("화씨"); plt.show()
참고 답안과 해설
  • 찾은 값은 대략 $w\approx1.8$, $b\approx 32$ 근처지만 정확히 같지는 않다. 측정 오차가 있는 30개 데이터로는 참값을 정확히 복원할 수 없고, 격자 간격만큼의 오차도 생긴다.
  • 등고선이 길쭉한 이유: $x$ 값이 수십 단위라 $w$를 조금만 바꿔도 예측이 크게 변하지만, $b$는 예측을 1씩만 바꾼다. 두 파라미터에 대한 손실의 민감도가 다르면 등고선이 길쭉해진다. 9일차에서 이것이 경사하강법을 느리게 만드는 원인이며, 입력 표준화로 해결함을 다룬다.
  • 계산 횟수는 $141\times121 = 17{,}061$회였다. 파라미터가 하나 늘 때마다 이 수가 100배 이상 늘어난다.
