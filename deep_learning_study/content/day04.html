• 행렬을 공간의 선형변환으로 해석하고, 행렬의 열이 기저벡터의 행선지임을 설명할 수 있다.
  • 행렬식을 넓이 배율로, 역행렬을 되돌리는 변환으로 이해한다.
  • 선형변환을 여러 번 해도 하나의 선형변환이라는 사실에서 신경망에 비선형성이 필요한 이유를 설명할 수 있다.
  • 고윳값·고유벡터를 계산하고 의미를 설명할 수 있다.
  • SVD와 PCA로 데이터의 주요 방향을 찾고 차원을 줄일 수 있다.

행렬 = 공간의 변환

행렬 $A$를 벡터 $\mathbf x$에 곱하면 새 벡터 $A\mathbf x$가 나온다. 모든 점에 같은 행렬을 곱하면 공간 전체가 늘어나고, 돌고, 기울고, 뒤집힌다. 이런 변환을 선형변환이라 한다. 선형변환에서 직선은 직선으로, 원점은 원점으로, 평행한 격자선은 평행한 격자선으로 옮겨진다.

공간의 모든 벡터는 기본 방향 벡터들의 조합으로 쓸 수 있다. 2차원에서는 $\hat\imath = (1, 0)$과 $\hat\jmath = (0, 1)$이며, 이렇게 공간을 만드는 기본 벡터의 집합을 기저라 한다. $\mathbf x = (x_1, x_2) = x_1\hat\imath + x_2\hat\jmath$이므로

$$A\mathbf x = x_1 (A\hat\imath) + x_2 (A\hat\jmath)$$

행렬의 첫째 열은 $\hat\imath$가 옮겨 간 위치, 둘째 열은 $\hat\jmath$가 옮겨 간 위치다. 기저벡터 두 개의 행선지만 알면 모든 벡터의 행선지가 정해진다.

행렬식, 역행렬, 랭크

변환 후 단위 정사각형(넓이 1)이 차지하는 넓이를 행렬식 $\det A$라 한다. 넓이 배율이며, 음수면 방향이 뒤집힌 것이다.

$$\det\begin{bmatrix}a & b\\ c & d\end{bmatrix} = ad - bc$$

$A\mathbf x$를 다시 $\mathbf x$로 되돌리는 변환이 역행렬 $A^{-1}$이다: $A^{-1}A = I$. 행렬식이 0인 변환은 서로 다른 점을 같은 점으로 보내므로 되돌릴 수 없고, 역행렬이 없다.

변환 결과가 차지하는 공간의 차원을 랭크라 한다. 위 오른쪽 행렬은 2차원 평면을 직선으로 보내므로 랭크가 1이다. 랭크는 행렬의 선형독립인 열의 최대 개수와 같다.

$2x + y = 5$, $x + 3y = 10$은 $A\mathbf x = \mathbf b$, $A = \begin{bmatrix}2&1\\1&3\end{bmatrix}$, $\mathbf b = (5, 10)$이다. $\det A = 5 \ne 0$이므로 해가 하나 있고 $\mathbf x = A^{-1}\mathbf b = (1, 3)$이다.

A = np.array([[2.0, 1.0], [1.0, 3.0]])
b = np.array([5.0, 10.0])
print("det A =", np.linalg.det(A).round(6), " rank =", np.linalg.matrix_rank(A))
print("A^-1 =\n", np.linalg.inv(A))
print("해 x =", np.linalg.solve(A, b))          # 역행렬을 직접 곱하는 것보다 빠르고 정확
S = np.array([[2.0, 1.0], [1.0, 0.5]])
print("납작한 행렬: det =", np.linalg.det(S).round(6), " rank =", np.linalg.matrix_rank(S))

변환을 이어 붙이면: 신경망에 비선형성이 필요한 이유

고윳값과 고유벡터

변환 후에도 방향이 그대로이고 길이만 바뀌는 특별한 벡터가 있다. $A\mathbf v = \lambda\mathbf v$를 만족하는 $\mathbf v\ne\mathbf 0$을 고유벡터, 배율 $\lambda$를 고윳값이라 한다.

$A = \begin{bmatrix}2&1\\1&2\end{bmatrix}$. $(A - \lambda I)\mathbf v = 0$이 $\mathbf v \ne 0$인 해를 가지려면 $\det(A - \lambda I) = 0$이어야 한다.

$$(2-\lambda)^2 - 1 = 0 \;\Rightarrow\; \lambda = 3 \text{ 또는 } 1$$

$\lambda = 3$: $\begin{bmatrix}-1&1\\1&-1\end{bmatrix}\mathbf v = 0 \Rightarrow \mathbf v = (1, 1)$. $\lambda = 1$: $\mathbf v = (-1, 1)$. 대칭행렬의 고유벡터는 서로 직교한다.

행렬을 같은 벡터에 계속 곱하면 가장 큰 고윳값 방향의 성분만 살아남는다. $|\lambda| > 1$이면 길이가 폭발하고 $|\lambda| < 1$이면 0으로 사라진다. 36일차에서 순환 신경망의 기울기 폭발·소실이 정확히 이 현상임을 본다.

A = np.array([[2.0, 1.0], [1.0, 2.0]])
vals, vecs = np.linalg.eig(A)
print("고윳값:", vals, "\n고유벡터(열):\n", vecs.round(3))
v = vecs[:, 0]
print("Av =", A @ v, " λv =", vals[0] * v)
x = np.array([1.0, 0.0])                      # 거듭 곱하기 (거듭제곱법)
for t in range(6):
    x = A @ x
    print(t + 1, "번 곱함:", x, " 방향:", (x / np.linalg.norm(x)).round(4))

$\sigma_1 \ge \sigma_2 \ge \dots \ge 0$을 특잇값이라 한다. 오른쪽 식은 행렬을 랭크 1 행렬 $\mathbf u_i\mathbf v_i^\top$들의 가중합으로 쓴 것이다. 큰 특잇값 $k$개만 남긴 $A_k$는 랭크 $k$ 행렬 중 $A$에 가장 가까운 행렬이다(에카르트-영 정리). 이미지 압축, 추천 시스템, 47일차의 LoRA가 이 성질을 쓴다.

M = np.random.default_rng(1).normal(size=(5, 3))
U, s, Vt = np.linalg.svd(M, full_matrices=False)
print("U", U.shape, " 특잇값", s.round(3), " Vt", Vt.shape)
print("복원 확인:", np.allclose(U @ np.diag(s) @ Vt, M))
M1 = s[0] * np.outer(U[:, 0], Vt[0])            # 랭크 1 근사
print("랭크 1 근사 상대 오차:", (np.linalg.norm(M - M1) / np.linalg.norm(M)).round(3))

주성분 분석

고차원 데이터는 대개 일부 방향으로만 크게 퍼져 있다. 주성분 분석(PCA)은 데이터가 가장 크게 퍼진 방향(분산이 최대인 방향)부터 차례로 찾아, 상위 몇 방향으로 투영해 차원을 줄인다.

  1. 각 특징의 평균을 뺀다(중심화): $X_c = X - \bar{\mathbf x}$.
  2. 특징 사이의 공분산 행렬 $\Sigma = \frac{1}{N-1}X_c^\top X_c$를 구한다. 공분산은 두 특징이 함께 변하는 정도다.
  3. $\Sigma$의 고유벡터가 주성분, 고윳값이 그 방향의 분산이다. 실제로는 $X_c$를 SVD해서 $V$의 행을 쓰는 것이 더 정확하다.
  4. 상위 $k$개 주성분 $V_k$로 투영한다: $Z = X_c V_k^\top$ (형상 $N\times k$).
iris = load_data("iris")
X, y = iris["X"], iris["y"]
Xc = X - X.mean(axis=0)                                   # 1. 중심화
U, s, Vt = np.linalg.svd(Xc, full_matrices=False)         # 3. SVD: Vt의 행 = 주성분
var = s ** 2 / (len(X) - 1)                               # 각 주성분 방향의 분산
print("설명된 분산 비율:", (var / var.sum()).round(3))
Z = Xc @ Vt[:2].T                                         # 4. 2차원으로 투영 (150, 2)
plt.figure(figsize=(5.2, 3.8))
for k, name in enumerate(iris["target_names"]):
    plt.scatter(Z[y == k, 0], Z[y == k, 1], s=16, label=name)
plt.xlabel("제1 주성분"); plt.ylabel("제2 주성분"); plt.legend(); plt.title("붓꽃 4차원 → 2차원")
plt.show()

4차원 데이터의 분산 중 약 98%가 처음 두 주성분에 담겨 있다. 2차원 그림만으로 세 품종의 구조가 보인다.

정리

  • 행렬 = 선형변환. 열은 기저벡터의 행선지. 합성은 행렬곱이며 여전히 선형이다.
  • 행렬식 = 넓이 배율. 0이면 납작해져 역행렬이 없다. 랭크 = 결과 공간의 차원.
  • 고유벡터는 방향이 유지되는 벡터, 고윳값은 그 방향의 배율. 거듭 곱하면 큰 고윳값 방향이 지배한다.
  • SVD: 모든 행렬 = 회전·늘이기·회전. 상위 $k$개로 최적 저랭크 근사.
  • PCA: 중심화 → SVD → 분산이 큰 방향으로 투영.

  • 분산의 90%를 설명하려면 약 21개, 95%에는 약 29개 성분이 필요하다. 64개 픽셀 중 절반 이하로 대부분의 정보가 표현된다. 가장자리 픽셀은 거의 항상 0이라 정보가 없기 때문이다.
  • 2차원 지도에서 0, 4, 6 같은 숫자는 비교적 잘 떨어지지만 1·7·9, 3·5·8은 겹친다. 선형 투영 2개로는 10개 범주를 다 나눌 수 없다. 이후 주차의 신경망은 비선형 변환으로 이 문제를 푼다.
  • $k = 16$(25%)만으로도 숫자를 알아볼 수 있게 복원된다. 이것이 손실 압축의 원리이며, 50일차의 오토인코더는 PCA를 비선형으로 확장한 것이다.
