• 실제 데이터를 불러와 형상, 분포, 표본을 점검하는 탐색 과정을 수행한다.
  • 평균 벡터와 거리(또는 내적)만으로 동작하는 분류기를 직접 구현하고 평가한다.
  • 혼동 행렬로 오류를 분석하고, PCA로 차원을 줄였을 때 성능이 어떻게 변하는지 측정한다.
  • 1주차의 도구(NumPy, 벡터·행렬, 확률)를 하나의 작업 흐름으로 연결한다.

모델을 만들기 전에 데이터를 본다. 형상, 값의 범위, 클래스 균형, 표본 몇 개를 확인하는 것은 모든 프로젝트의 첫 단계다(27일차의 디버깅 절차도 여기서 시작한다).

층화 분할

테스트 세트의 클래스 비율이 전체와 같도록, 클래스마다 따로 섞어 80:20으로 나눈다. 테스트 세트는 마지막 평가 전까지 쓰지 않는다.

rng = np.random.default_rng(0)
tr_idx, te_idx = [], []
for k in range(10):
    idx = rng.permutation(np.where(y == k)[0])
    cut = int(0.8 * len(idx))
    tr_idx += list(idx[:cut]); te_idx += list(idx[cut:])
tr_idx, te_idx = np.array(tr_idx), np.array(te_idx)
Xtr, ytr, Xte, yte = X[tr_idx], y[tr_idx], X[te_idx], y[te_idx]
print("학습", Xtr.shape, " 테스트", Xte.shape)
print("테스트 클래스 비율:", (np.bincount(yte) / len(yte)).round(3))

2단계: 기준선

아무것도 배우지 않은 예측의 성능을 먼저 잰다. 모든 입력에 학습 세트의 최빈 클래스를 답하는 기준선과, 무작위로 답하는 기준선이다. 모델이 이보다 나아야 의미가 있다.

major = np.bincount(ytr).argmax()
acc_major = (yte == major).mean()
acc_rand = (rng.integers(0, 10, size=len(yte)) == yte).mean()
print(f"최빈 클래스({major}) 기준선 정확도: {acc_major:.3f}")
print(f"무작위 추측 정확도: {acc_rand:.3f}  (기댓값 0.1)")

3단계: 최근접 중심 분류기

최근접 중심 분류기는 학습 데이터에서 클래스별 평균 벡터(중심)를 구해 두고, 새 입력을 가장 가까운 중심의 클래스로 분류한다.

모든 테스트 샘플과 모든 중심 사이의 거리를 반복문 없이 구한다. $\|\mathbf a - \mathbf b\|^2 = \|\mathbf a\|^2 - 2\,\mathbf a\cdot\mathbf b + \|\mathbf b\|^2$를 쓰면 행렬곱 한 번으로 계산된다.

centroids = np.stack([Xtr[ytr == k].mean(axis=0) for k in range(10)])     # (10, 64)
def sq_dist(A, B):
    """A (n, d)와 B (m, d) 사이 모든 쌍의 제곱 거리 (n, m)"""
    return (A ** 2).sum(1)[:, None] - 2 * A @ B.T + (B ** 2).sum(1)[None, :]
D = sq_dist(Xte, centroids)                    # (364, 10)
pred = D.argmin(axis=1)
acc_euc = (pred == yte).mean()
print("거리 행렬 형상:", D.shape,
      f"  최근접 중심(유클리드) 테스트 정확도: {acc_euc:.3f}")
fig, axs = plt.subplots(1, 10, figsize=(10, 1.4))
for k, ax in enumerate(axs):
    ax.imshow(centroids[k].reshape(8, 8), cmap="gray_r")
    ax.set_title(k, fontsize=9)
    ax.axis("off")
plt.show()

코사인 유사도 버전

거리 대신 코사인 유사도가 가장 큰 중심을 고르면 이미지의 전체 밝기(벡터의 길이)에 덜 민감해진다. 빈칸을 채워 비교하라.

def normalize_rows(A):
    return A / np.linalg.norm(A, axis=1, keepdims=True)
# TODO 확인: (364, 10) 코사인 유사도
S = normalize_rows(Xte) @ normalize_rows(centroids).T
pred_cos = S.argmax(axis=1)
acc_cos = (pred_cos == yte).mean()
print(f"유클리드 {acc_euc:.3f}   코사인 {acc_cos:.3f}")

4단계: 혼동 행렬과 오류 분석

정확도 하나로는 어디서 틀리는지 알 수 없다. 정답(행)과 예측(열) 조합의 개수를 센 혼동 행렬을 만든다(12일차에서 자세히 다룬다).

5단계: PCA 공간에서 분류

4일차의 PCA로 64차원을 $k$차원으로 줄인 뒤 같은 분류기를 적용한다. 주성분은 학습 세트로만 구하고, 테스트 세트에는 같은 변환을 적용한다. 테스트 데이터로 변환을 만들면 테스트 정보가 학습에 새어 들어간다.

mean = Xtr.mean(axis=0)
U, s, Vt = np.linalg.svd(Xtr - mean, full_matrices=False)
ks = [1, 2, 3, 5, 8, 12, 16, 24, 32, 64]
accs = []
for k in ks:
    Ztr = (Xtr - mean) @ Vt[:k].T
    Zte = (Xte - mean) @ Vt[:k].T
    cen = np.stack([Ztr[ytr == c].mean(axis=0) for c in range(10)])
    accs.append((sq_dist(Zte, cen).argmin(1) == yte).mean())
plt.figure(figsize=(5.5, 3.3)); plt.semilogx(ks, accs, "o-")
plt.axhline(acc_euc, color="gray", ls="--", label="원래 64차원")
plt.xlabel("PCA 차원 k")
plt.ylabel("테스트 정확도")
plt.legend()
plt.grid(alpha=.3)
plt.show()
print({k: round(float(a), 3) for k, a in zip(ks, accs)})

Ztr = (Xtr - mean) @ Vt[:2].T

plt.scatter(Ztr[:, 0], Ztr[:, 1], c=ytr, cmap="tab10", s=6)

최근접 중심 분류기의 결정 영역은 중심들 사이의 수직이등분선으로 나뉜 다각형(보로노이 영역)이다. 경계가 모두 직선이라는 점이 이 방법의 한계다.

참고 보고서

손글씨 숫자 1797장(64차원, 클래스 거의 균등)을 층화 분할했다(학습 1433, 테스트 364). 최빈 클래스 기준선은 약 10%, 최근접 중심 분류기는 테스트 91.5%(코사인 버전 92.0%)로 기준선보다 크게 좋다. 1을 9나 2로, 5를 9로 가장 많이 헷갈렸으며, 숫자 1의 정확도가 70%로 가장 낮았다(1을 쓰는 방식이 다양해 평균 하나로 표현되지 않는다). PCA 12차원에서 90.7%, 24차원에서 원래 64차원과 같은 정확도를 보였다. 평균 하나로 다양한 필체를 표현하는 데 한계가 있고 결정 경계가 직선뿐이므로, 비선형 모델이 필요하다.

확장 과제

  1. k-최근접 이웃. 중심 대신 학습 샘플 전체와의 거리를 구해, 가장 가까운 $k$개의 다수결로 예측하라. $k = 1, 3, 5, 10$의 정확도를 비교하라. (13일차 미리 보기)
    풀이
    Dall = sq_dist(Xte, Xtr)                        # (364, 1433)
for k in [1, 3, 5, 10]:
    nn = np.argsort(Dall, axis=1)[:, :k]         # 가까운 k개의 인덱스
    votes = ytr[nn]                              # (364, k)
    pk = np.array([np.bincount(v, minlength=10).argmax() for v in votes])
    print(k, (pk == yte).mean().round(3))

    k-최근접 이웃은 99% 이상으로 최근접 중심보다 훨씬 좋다. 평균 하나가 아니라 학습 샘플 전체를 기억해 필체의 다양성을 반영하기 때문이다. 대신 예측할 때마다 모든 학습 샘플과의 거리를 계산해야 한다.

  2. 클래스별 여러 중심. 숫자마다 학습 샘플을 3개 무리로 나누고(무작위 초기화 후 "가장 가까운 무리에 배정 → 무리 평균 갱신"을 10번 반복), 30개 중심으로 분류하라. 정확도가 오르는가? (13일차 k-평균 미리 보기)
    힌트

    숫자 $c$의 샘플 $X_c$에서 무작위로 3개를 골라 초기 중심으로 둔다. sq_dist(X_c, C).argmin(1)로 배정하고, 배정된 샘플의 평균으로 중심을 갱신한다. 숫자 하나의 여러 필체(예: 7의 가로획 유무)가 서로 다른 중심으로 나뉜다.

  3. 평행이동에 대한 취약성. 테스트 이미지를 오른쪽으로 한 칸 민(np.roll) 뒤 정확도를 다시 재라. 얼마나 떨어지는가? 왜 그런가?
    풀이
    shifted = np.roll(Xte.reshape(-1, 8, 8), 1, axis=2).reshape(-1, 64)
print((sq_dist(shifted, centroids).argmin(1) == yte).mean().round(3))

    정확도가 약 30%로 크게 떨어진다. 픽셀 위치를 그대로 비교하는 방법은 모양이 조금만 이동해도 다른 벡터로 본다. 31일차의 합성곱 신경망은 위치 이동에 강한 구조로 이 문제를 해결한다.
