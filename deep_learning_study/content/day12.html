• 학습·검증·테스트 세트의 역할을 구분하고, 테스트 세트를 한 번만 써야 하는 이유를 설명할 수 있다.
  • 과소적합과 과적합을 학습·검증 오차로 진단하고 편향-분산 관점에서 설명할 수 있다.
  • L2·L1 규제의 식과 효과를 설명하고 경사하강법에 넣을 수 있다.
  • k겹 교차검증으로 하이퍼파라미터를 고를 수 있다.
  • 혼동 행렬, 정밀도, 재현율, F1, ROC, AUC를 계산하고 상황에 맞는 지표와 임계값을 고를 수 있다.

일반화와 데이터 분할

모델의 목적은 학습 데이터를 외우는 것이 아니라 처음 보는 데이터에서 잘 맞히는 것이다. 이 능력을 일반화라 한다. 일반화 성능은 학습에 쓰지 않은 데이터로만 잴 수 있으므로 데이터를 세 부분으로 나눈다.

  • 학습 세트: 파라미터를 맞추는 데 쓴다.
  • 검증 세트: 학습률, 규제 강도, 모델 크기 같은 하이퍼파라미터를 고르고, 언제 학습을 멈출지 정한다.
  • 테스트 세트: 모든 결정이 끝난 뒤 최종 성능을 한 번 잰다.

검증 세트로 여러 후보 중 가장 좋은 것을 고르면, 고른 모델의 검증 점수는 운 좋게 높게 나온 쪽으로 치우친다. 그래서 고르는 데 쓰지 않은 테스트 세트가 따로 필요하다. 10일차 프로젝트에서 "테스트 곡선을 보고 학습 길이를 고르지 말라"고 한 이유다.

과소적합과 과적합

학습 오차와 검증 오차를 함께 보면 모델의 상태를 진단할 수 있다. 모델이 너무 단순해서 학습 데이터의 패턴조차 못 잡는 상태가 과소적합, 학습 데이터의 잡음까지 외워서 새 데이터에서 틀리는 상태가 과적합이다.

증상진단처방
학습 오차가 높다과소적합더 큰 모델, 더 나은 특징, 더 오래 학습, 규제 줄이기
학습 오차는 낮은데 검증 오차가 높다과적합데이터 늘리기, 규제, 작은 모델, 조기 종료, 데이터 증강(34일차)
둘 다 낮고 비슷하다양호테스트 세트로 최종 확인

편향과 분산

같은 방식으로 다른 학습 데이터를 뽑아 모델을 여러 번 학습한다고 상상한다. 예측의 평균이 정답에서 벗어난 정도를 편향, 학습 데이터에 따라 예측이 흔들리는 정도를 분산이라 한다. 제곱 오차의 기댓값은 정확히 세 부분으로 나뉜다.

$$\mathbb E\big[(y - \hat f(x))^2\big] = \underbrace{\big(\mathbb E[\hat f(x)] - f(x)\big)^2}_{\text{편향}^2} + \underbrace{\mathbb E\big[(\hat f(x) - \mathbb E[\hat f(x)])^2\big]}_{\text{분산}} + \underbrace{\sigma^2}_{\text{잡음}}$$

모델이 복잡해지면 편향은 줄고 분산은 커진다. 이 맞바꿈을 편향-분산 트레이드오프라 한다. 위 인터랙티브에서 데이터 수를 8 → 40으로 늘리면 고차 다항식의 분산이 줄어드는 것을 볼 수 있다. 데이터가 많을수록 복잡한 모델을 감당할 수 있다.

파라미터가 데이터보다 훨씬 많은 현대 신경망에서는 이 U자 그림이 그대로 성립하지 않는 경우가 관찰된다(복잡도를 더 키우면 검증 오차가 다시 내려가는 이중 하강). 그래도 "검증 오차로 진단한다"는 원칙은 같다.

규제

모델이 너무 복잡한 해를 고르지 못하도록 손실에 벌점을 더하는 기법을 통틀어 규제라 한다. 가장 흔한 벌점은 가중치의 크기다. 큰 가중치는 입력이 조금 변해도 예측이 크게 변하는, 들쭉날쭉한 함수를 만든다.

$$L_{\text{L2}} = L + \lambda\sum_j w_j^2, \qquad L_{\text{L1}} = L + \lambda\sum_j |w_j|$$

제곱합 벌점이 L2 규제(릿지), 절댓값 합 벌점이 L1 규제(라쏘)다. $\lambda$는 벌점의 세기를 정하는 하이퍼파라미터다. 편향 $b$는 함수의 들쭉날쭉함과 무관하므로 보통 벌점에서 뺀다.

L2: 가중치 감쇠

L2 벌점의 그래디언트는 $2\lambda\mathbf w$다. 경사하강법의 한 걸음은

$$\mathbf w \leftarrow \mathbf w - \eta(\nabla L + 2\lambda\mathbf w) = (1 - 2\eta\lambda)\,\mathbf w - \eta\nabla L$$

로, 매 걸음 가중치를 $(1 - 2\eta\lambda)$배로 살짝 줄인 뒤 원래의 갱신을 한다. 그래서 가중치 감쇠(weight decay)라고도 부른다. 선형회귀에서는 정규방정식이 $(X^\top X + N\lambda I)\boldsymbol\theta = X^\top\mathbf y$가 되어, 8일차에서 본 "$X^\top X$의 역행렬이 없는" 문제도 사라진다.

8일차의 네 점 $(1, 2), (2, 3), (3, 5), (4, 6)$에 원점을 지나는 직선 $\hat y = wx$를 맞춘다. $L = \frac1N\sum(wx_i - y_i)^2 + \lambda w^2$을 미분해 0으로 두면 $w = \frac{\sum x_iy_i}{\sum x_i^2 + N\lambda} = \frac{47}{30 + 4\lambda}$. $\lambda = 0$이면 1.567, $\lambda = 1$이면 1.382, $\lambda = 10$이면 0.671. 벌점이 클수록 가중치가 0 쪽으로 끌려간다.

L1: 희소한 해

L1은 일부 가중치를 정확히 0으로 만드는 경향이 있다. 쓸모없는 특징을 스스로 버리는 특징 선택 효과다. 이유는 그림으로 보는 것이 쉽다. 규제 문제는 "가중치가 일정 영역 안에 있어야 한다"는 조건 아래 손실을 최소화하는 것과 같다. L2의 영역은 원, L1의 영역은 꼭짓점이 축 위에 있는 마름모다.

교차검증

데이터가 수백 개뿐이면 검증 세트가 작아 점수가 운에 크게 좌우된다. 8일차 프로젝트에서 테스트 $R^2$가 분할에 따라 0.62~0.90으로 흔들린 것이 그 예다. 학습 데이터를 $k$개의 겹(fold)으로 나눠, 한 겹씩 돌아가며 검증에 쓰고 나머지로 학습해 $k$개 점수를 평균하는 방법이 교차검증이다.

  1. 후보 하이퍼파라미터(예: $\lambda$)마다 $k$겹 교차검증 점수를 구한다.
  2. 평균 점수가 가장 좋은 후보를 고른다.
  3. 고른 하이퍼파라미터로 학습 데이터 전체에서 다시 학습한다.
  4. 테스트 세트로 한 번 평가한다.

분류 문제에서는 각 겹의 클래스 비율이 전체와 같도록 층화해서 나눈다. 비용은 학습을 $k$배 하는 것이라, 학습에 며칠씩 걸리는 큰 신경망에서는 쓰지 않고 검증 세트 하나로 대신한다.

분류 지표

정확도 하나로는 부족하다. 이진 분류의 예측과 정답을 2×2 표로 센 것이 혼동 행렬이다. 관심 있는 클래스(병, 사기, 스팸)를 양성이라 부른다.

예측 양성예측 음성
실제 양성TP (참 양성)FN (거짓 음성, 놓침)
실제 음성FP (거짓 양성, 오경보)TN (참 음성)

이 네 칸에서 여러 지표를 만든다.

지표식질문
정확도$\frac{TP + TN}{\text{전체}}$전체 중 몇 개를 맞혔나
정밀도$\frac{TP}{TP + FP}$양성이라고 한 것 중 진짜 양성은 몇 %인가
재현율$\frac{TP}{TP + FN}$진짜 양성 중 몇 %를 찾아냈나
F1 점수$\frac{2PR}{P + R}$정밀도와 재현율의 조화평균

환자 10명, 정상 90명. 모델 결과 TP = 8, FN = 2, FP = 5, TN = 85. 정확도 $93/100 = 0.93$, 정밀도 $8/13 = 0.615$, 재현율 $8/10 = 0.80$, F1 $= 2(0.615)(0.80)/(1.415) = 0.696$. "양성 판정을 받은 사람 중 62%만 실제 환자이고, 환자의 80%를 찾아냈다"고 읽는다.

같은 100명에게 "모두 정상"이라고 말하는 모델의 정확도는 0.90이다. 위 모델(0.93)과 비슷해 보이지만 환자를 한 명도 찾지 못한다(재현율 0). 이처럼 클래스 비율이 크게 치우친 상태를 클래스 불균형이라 한다. 사기 탐지(0.1%), 희귀병처럼 불균형이 심할수록 정확도는 쓸모가 없어지고 재현율·정밀도·AUC를 봐야 한다.

정밀도와 재현율 중 무엇이 중요한지는 오류의 비용이 정한다. 암 검진에서 놓친 환자(FN)는 치명적이고 오경보(FP)는 재검사 비용이므로 재현율을 우선한다. 스팸 필터에서 중요한 메일을 스팸으로 버리는 것(FP)은 치명적이므로 정밀도를 우선한다.

임계값과 ROC 곡선

로지스틱 회귀는 확률을 내고, $p > 0.5$에서 자르는 것은 하나의 선택일 뿐이다. 양성 판정의 기준이 되는 이 값을 임계값이라 한다. 임계값을 낮추면 양성 판정이 늘어 재현율은 오르고 정밀도는 내려간다. 10일차 프로젝트에서 임계값을 0.5에서 0.2로 낮췄을 때 놓친 악성이 사라지고 오경보가 늘어난 것이 이것이다.

임계값을 1에서 0까지 내리며 (거짓 양성률, 참 양성률)을 찍어 이은 곡선이 ROC 곡선이다.

$$\text{TPR} = \frac{TP}{TP + FN}\;(=\text{재현율}), \qquad \text{FPR} = \frac{FP}{FP + TN}$$

ROC 곡선 아래 넓이를 AUC라 한다. 완벽한 분류기는 1, 무작위로 찍는 분류기는 대각선이라 0.5다. AUC는 "무작위로 고른 양성 하나와 음성 하나 중 양성의 점수가 더 높을 확률"과 같다. 임계값과 무관하게 모델이 양성과 음성을 얼마나 잘 줄 세우는지를 재므로, 모델끼리 비교할 때 좋다. 실제 운용에서는 그 위에서 비용에 맞는 임계값 하나를 고른다.

데이터 누수

평가 데이터의 정보가 어떤 경로로든 학습에 섞여 들어가 성능이 실제보다 좋게 측정되는 것을 데이터 누수라 한다. 실험에서는 훌륭한데 배포하면 무너지는 모델의 가장 흔한 원인이다.

  • 전처리 누수: 전체 데이터로 표준화 평균·표준편차를 구한 뒤 나눈다. 통계는 학습 세트(교차검증이면 학습 겹)에서만 구한다.
  • 중복 누수: 같은 환자의 사진 여러 장이 학습과 테스트에 나뉘어 들어간다. 환자 단위로 나눠야 한다.
  • 시간 누수: 주가 예측에서 미래 데이터로 학습하고 과거를 테스트한다. 시간 순서로 나눠야 한다.
  • 정답 누수: 정답이 정해진 뒤에야 알 수 있는 특징(예: "치료 시작 여부")을 입력에 넣는다.
  • 선택 누수: 테스트 점수를 보며 모델을 고친다.

코드 실습: 지표를 직접 계산하기

10일차의 유방암 로지스틱 회귀(규제 없음, 1000스텝)를 다시 학습하고, 지표와 ROC 곡선을 직접 구현한다.

import numpy as np
import matplotlib.pyplot as plt
d = load_data("breast_cancer")
X, y = d["X"].astype(float), d["y"].astype(float)
rng = np.random.default_rng(0); tr, te = [], []
for c in [0, 1]:
    idx = rng.permutation(np.where(y == c)[0]); cut = int(0.8 * len(idx))
    tr += list(idx[:cut]); te += list(idx[cut:])
tr, te = np.array(tr), np.array(te)
sigmoid = lambda z: 0.5 * (1 + np.tanh(0.5 * z))
def fit_logreg(X_, y_, lam=0.0, steps=1000, lr=0.5):
    # 학습에 쓰는 데이터로만 표준화 통계
    mu, sd = X_.mean(axis=0), X_.std(axis=0)
    Z = np.c_[np.ones(len(X_)), (X_ - mu) / sd]; th = np.zeros(Z.shape[1])
    for _ in range(steps):
        g = Z.T @ (sigmoid(Z @ th) - y_) / len(y_)
        # L2 벌점의 그래디언트 (편향 제외)
        g[1:] += 2 * lam * th[1:]
        th -= lr * g
    return th, mu, sd
def predict_proba(model, X_):
    th, mu, sd = model
    return sigmoid(np.c_[np.ones(len(X_)), (X_ - mu) / sd] @ th)
def confusion(p, t_, thr=0.5):
    pred = p >= thr
    return dict(TP=int((pred & (t_ == 1)).sum()), FN=int((~pred & (t_ == 1)).sum()),
                FP=int((pred & (t_ == 0)).sum()), TN=int((~pred & (t_ == 0)).sum()))
def metrics(c):
    P = c["TP"] / max(c["TP"] + c["FP"], 1); R = c["TP"] / max(c["TP"] + c["FN"], 1)
    return dict(acc=(c["TP"] + c["TN"]) / sum(c.values()), precision=P, recall=R,
                f1=2 * P * R / max(P + R, 1e-12))
model = fit_logreg(X[tr], y[tr])
p_te = predict_proba(model, X[te])
c = confusion(p_te, y[te]); print(c)
print({k: round(v, 4) for k, v in metrics(c).items()})
# 항상 "양성 아님"이라고 말하는 모델
base = confusion(np.zeros(len(te)), y[te])
print("항상 음성:", {k: round(v, 4) for k, v in metrics(base).items()})

"항상 음성" 모델도 정확도가 0.63이다. 이제 임계값을 모든 점수 값으로 바꿔 가며 ROC 곡선을 그리고 AUC를 두 방법으로 계산한다.

def roc_curve(p, t_):
    order = np.argsort(-p)                                  # 점수 높은 순
    tp = np.cumsum(t_[order] == 1); fp = np.cumsum(t_[order] == 0)
    tpr = np.r_[0, tp / tp[-1]]; fpr = np.r_[0, fp / fp[-1]]
    return fpr, tpr
fpr, tpr = roc_curve(p_te, y[te])
# 사다리꼴 넓이의 합
auc_trap = ((fpr[1:] - fpr[:-1]) * (tpr[1:] + tpr[:-1]) / 2).sum()
pos, neg = p_te[y[te] == 1], p_te[y[te] == 0]
auc_rank = ((pos[:, None] > neg[None, :]).mean()
            + 0.5 * (pos[:, None] == neg[None, :]).mean())
print(f"AUC (사다리꼴) = {auc_trap:.4f},  AUC (양성이 음성보다 높을 확률) = "
      f"{auc_rank:.4f}")
plt.figure(figsize=(4.4, 4.2))
plt.plot(fpr, tpr, lw=2, label=f"로지스틱 회귀 (AUC {auc_rank:.3f})")
plt.plot([0, 1], [0, 1], "k--", lw=1, label="무작위 (AUC 0.5)")
plt.xlabel("거짓 양성률 FPR")
plt.ylabel("참 양성률 TPR (재현율)")
plt.legend(loc="lower right")
plt.grid(alpha=.3)
plt.show()

정리

  • 학습 세트로 파라미터, 검증 세트(또는 교차검증)로 하이퍼파라미터, 테스트 세트로 최종 평가를 한 번.
  • 학습 오차가 높으면 과소적합, 학습은 낮고 검증이 높으면 과적합. 복잡도에 따라 편향↓ 분산↑.
  • L2 규제 = 가중치 감쇠, 해를 작게. L1 규제는 일부 가중치를 0으로(특징 선택). 편향은 규제하지 않는다.
  • k겹 교차검증: 겹마다 돌아가며 검증, 점수 평균. 전처리 통계도 겹 안에서 계산.
  • 혼동 행렬 → 정밀도·재현율·F1. 불균형 데이터에서 정확도는 무의미. ROC·AUC는 임계값과 무관한 순위 성능, 임계값은 비용으로 고른다.

확인 문제

연습 문제

  1. 양성 1%인 데이터 10,000개에서 모델이 양성 150개를 예측했고 그중 80개가 실제 양성이다. 혼동 행렬, 정확도, 정밀도, 재현율, F1을 구하라.
    풀이

    실제 양성 100. TP = 80, FP = 70, FN = 20, TN = 9830. 정확도 0.991, 정밀도 0.533, 재현율 0.80, F1 $= 2(0.533)(0.8)/1.333 = 0.64$.

  2. L2 규제 선형회귀의 정규방정식 $(X^\top X + N\lambda I')\boldsymbol\theta = X^\top\mathbf y$를 유도하라. 여기서 $I'$는 편향 자리만 0인 단위 행렬이다.
    풀이

    $L = \frac1N\|X\boldsymbol\theta - \mathbf y\|^2 + \lambda\boldsymbol\theta^\top I'\boldsymbol\theta$. 그래디언트 $\frac2N X^\top(X\boldsymbol\theta - \mathbf y) + 2\lambda I'\boldsymbol\theta = 0$. 양변에 $N/2$를 곱하면 $X^\top X\boldsymbol\theta + N\lambda I'\boldsymbol\theta = X^\top\mathbf y$.

  3. 점수가 양성 $\{0.9, 0.8, 0.4\}$, 음성 $\{0.7, 0.3, 0.2, 0.1\}$일 때 AUC를 "양성이 음성보다 높을 확률"로 계산하라.
    풀이

    양성-음성 쌍 12개 중 양성이 높은 쌍: 0.9는 4개 모두, 0.8도 4개, 0.4는 0.3·0.2·0.1의 3개. 합 11, AUC $= 11/12 \approx 0.917$.

    pos = np.array([0.9, 0.8, 0.4]); neg = np.array([0.7, 0.3, 0.2, 0.1])
print((pos[:, None] > neg[None, :]).mean())

미니 프로젝트: 교차검증으로 규제 강도와 임계값 고르기

유방암 분류기의 하이퍼파라미터(L2 규제 강도 $\lambda$)를 테스트 세트를 보지 않고 5겹 교차검증으로 고른다. 교차검증의 겹 밖 예측으로 "악성의 98% 이상을 찾는" 임계값을 정한 뒤, 테스트 세트로 단 한 번 평가한다. 위 코드 실습의 함수(fit_logreg, predict_proba, confusion, metrics)를 그대로 쓴다.

  1. 층화 5겹 나누기. 학습 세트(454개)의 각 클래스를 섞어 다섯 겹에 번갈아 배정한다. 
    Xtr, ytr = X[tr], y[tr]
def stratified_folds(t_, k=5, seed=0):
    r = np.random.default_rng(seed); folds = [[] for _ in range(k)]
    for c in [0, 1]:
        for i, j in enumerate(r.permutation(np.where(t_ == c)[0])):
            folds[i % k].append(j)                          # 클래스마다 돌아가며 배정
    return [np.array(sorted(f)) for f in folds]
folds = stratified_folds(ytr)
print("겹 크기:", [len(f) for f in folds], " 겹별 악성 비율:",
      [round(ytr[f].mean(), 3) for f in folds])
  2. λ에 따른 교차검증 곡선. 각 $\lambda$에서 다섯 번 학습해 검증 겹의 BCE 평균과 표준편차를 구한다. 표준화는 fit_logreg 안에서 학습 겹만으로 계산된다. 
    def bce(p, t_):
    p = np.clip(p, 1e-12, 1 - 1e-12)
    return -np.mean(t_ * np.log(p) + (1 - t_) * np.log(1 - p))
lams = [0, 1e-4, 1e-3, 3e-3, 1e-2, 3e-2, 1e-1, 3e-1, 1]
cv_mean, cv_std, oof_all = [], [], {}
for lam in lams:
    scores, oof = [], np.zeros(len(ytr))
    for k in range(5):
        va = folds[k]; trn = np.setdiff1d(np.arange(len(ytr)), va)
        # TODO 확인: 학습 겹으로만 학습
        m = fit_logreg(Xtr[trn], ytr[trn], lam)
        oof[va] = predict_proba(m, Xtr[va])                 # 겹 밖 예측 저장
        scores.append(bce(oof[va], ytr[va]))
    cv_mean.append(np.mean(scores)); cv_std.append(np.std(scores)); oof_all[lam] = oof
    print(f"λ = {lam:<7g} 검증 BCE = {np.mean(scores):.4f} ± {np.std(scores):.4f}")
best = lams[int(np.argmin(cv_mean))]
# λ = 0을 로그축에 그리기 위해 1e-5에 표시
xs = [1e-5] + lams[1:]
plt.figure(figsize=(5.6, 3.3))
plt.errorbar(xs, cv_mean, yerr=cv_std, fmt="o-", capsize=3); plt.xscale("log")
plt.axvline(best if best > 0 else 1e-5, color="C3", ls="--",
            label=f"선택: λ = {best}")
plt.xlabel("λ (맨 왼쪽 점은 λ = 0)")
plt.ylabel("5겹 검증 BCE")
plt.legend()
plt.grid(alpha=.3)
plt.show()
  3. 임계값 정하기. 고른 $\lambda$의 겹 밖 예측(모든 학습 표본이 한 번씩 검증으로 쓰인 예측)에서, 재현율이 0.98 이상이 되는 가장 높은 임계값을 찾는다. 
    oof = oof_all[best]
# 높은 임계값부터 내려가며
cands = np.sort(np.unique(oof))[::-1]
thr = next(t_ for t_ in cands if metrics(confusion(oof, ytr, t_))["recall"] >= 0.98)
for t_ in [0.5, thr]:
    m_ = metrics(confusion(oof, ytr, t_))
    print(f"겹 밖 예측, 임계값 {t_:.3f}: 정밀도 {m_['precision']:.3f}, 재현율 "
          f"{m_['recall']:.3f}")
  4. 최종 평가 (한 번만). 고른 $\lambda$로 학습 세트 전체에서 다시 학습하고, 테스트 세트에서 임계값 0.5와 위에서 정한 임계값의 결과를 보고한다. 
    final = fit_logreg(Xtr, ytr, best)
p_test = predict_proba(final, X[te])
for t_ in [0.5, thr]:
    c = confusion(p_test, y[te], t_); m_ = metrics(c)
    print(f"테스트, 임계값 {t_:.3f}: {c}  정밀도 {m_['precision']:.3f} 재현율 "
          f"{m_['recall']:.3f} F1 {m_['f1']:.3f}")
pos, neg = p_test[y[te] == 1], p_test[y[te] == 0]
print("테스트 AUC = %.4f,  테스트 BCE = %.4f" % ((pos[:, None] > neg[None, :]).mean(),
                                                 bce(p_test, y[te])))
참고 답안과 해설
  • 2단계: 검증 BCE는 $\lambda = 0.003$ 근처에서 가장 낮고(약 0.078), $\lambda$가 0.03을 넘으면 빠르게 나빠진다(과소적합). $\lambda = 0$은 평균은 조금 높고 표준편차가 커서(겹마다 들쭉날쭉) 덜 안정적이다. 전형적인 U자 곡선이다.
  • 3단계: 임계값 0.5에서 겹 밖 재현율은 약 0.95다. 재현율 0.98을 얻으려면 임계값을 약 0.1까지 내려야 하고, 그 대가로 정밀도가 약 0.98에서 0.84로 떨어진다.
  • 4단계: 테스트에서 임계값 0.5는 악성 1개를 놓치고 오경보 0개, 정한 임계값(약 0.1)은 악성을 모두 찾고 오경보 12개다. AUC는 0.999 수준이다. 테스트 결과를 본 뒤 $\lambda$나 임계값을 다시 바꾸면 안 된다. 바꾸고 싶다면 그 근거를 교차검증 안에서 다시 찾아야 한다.
  • 참고: 이 테스트 세트에서는 $\lambda = 0$의 BCE(0.062)가 고른 $\lambda$(0.082)보다 오히려 낮다. 테스트가 115개뿐이라 생기는 흔들림이며, 교차검증으로 고른 값이 틀렸다는 뜻이 아니다. 선택 절차가 정직하면 이런 결과도 그대로 보고한다.
