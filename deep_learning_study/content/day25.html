• 사전학습 → 미세조정 패러다임과 BERT(MLM)·GPT(다음 토큰) 학습 목표의 차이를 이해한다.
  • 스케일링 법칙과 창발 능력이 무엇인지 설명한다.
  • LLM이 만들어지는 전 과정: 사전학습 → 지시 튜닝(SFT) → 선호 학습(RLHF/DPO)을 이해한다.
  • LoRA 등 효율적 미세조정의 원리를 수식으로 이해한다.
  • Hugging Face로 사전학습 모델을 불러와 추론·미세조정하는 방법을 안다.

1. 사전학습 + 미세조정 패러다임

Day 19의 전이학습이 NLP에서 폭발적으로 성공한 것이 2018년의 BERT와 GPT입니다.

  2. 미세조정: 소량의 레이블 데이터로 특정 과제에 맞춥니다.

2. 스케일링 법칙

Kaplan 등(2020), Hoffmann 등(Chinchilla, 2022)은 언어 모델의 손실이 파라미터 수 $N$, 데이터 토큰 수 $D$, 연산량 $C$에 대해 멱법칙을 따라 매끄럽게 줄어든다는 것을 보였습니다.

$$L(N, D) \approx E + \frac{A}{N^{\alpha}} + \frac{B}{D^{\beta}}$$
  • 모델을 키우고 데이터를 늘리면 성능이 예측 가능하게 좋아집니다. 이 예측 가능성 덕분에 수백억 원짜리 학습에 투자할 수 있었습니다.
  • Chinchilla 법칙: 주어진 연산 예산에서 최적은 대략 파라미터 1개당 토큰 20개. 그 전의 모델들은 크기에 비해 데이터가 부족했습니다. (요즘은 추론 비용을 줄이려고 작은 모델을 이보다 훨씬 많은 토큰으로 학습시키기도 합니다.)
  • Day 9의 $C\approx 6ND$ 공식이 여기서 쓰입니다.
💡 창발 능력 (Emergent abilities) 산술, 다단계 추론 같은 일부 능력은 작은 모델에서는 거의 0이다가 특정 크기를 넘으면 갑자기 나타나는 것처럼 보입니다. 다만 이것이 평가 지표의 선택(정답/오답 이진 채점) 때문에 생기는 착시라는 반론도 있습니다. 활발히 연구 중인 주제입니다.

3. 사전학습 모델이 비서가 되기까지

사전학습만 된 모델("베이스 모델")은 문서를 이어 쓰는 기계입니다. "프랑스의 수도는?"이라고 물으면 "독일의 수도는? 이탈리아의 수도는?"처럼 시험지를 이어 쓸 수도 있습니다.

  1. 지도 미세조정 (SFT, Instruction tuning): (지시, 좋은 응답) 쌍 수만~수십만 개로 학습. "질문에는 답한다"는 형식을 배웁니다. 손실은 똑같이 다음 토큰 예측이고, 보통 응답 부분에만 손실을 줍니다.
  2. 선호 학습: 같은 질문에 대한 두 응답 중 사람이 더 좋다고 고른 데이터로 학습.
    • RLHF: 선호 데이터로 보상 모델을 학습한 뒤, 강화학습(PPO)으로 LLM이 높은 보상을 받도록 최적화. KL 페널티로 원래 모델에서 너무 멀어지지 않게 합니다.
    • DPO: 보상 모델과 강화학습 없이, 선호 쌍에서 바로 분류 손실 비슷한 형태로 최적화. 더 단순하고 안정적이라 널리 쓰입니다.
  3. 그 밖에 AI 피드백을 활용하는 방법(Constitutional AI 등), 추론 과정을 강화학습으로 키우는 방법 등이 활발히 연구되고 있습니다.

4. 효율적 미세조정: LoRA

70억 파라미터 모델을 전부 미세조정하려면 파라미터·기울기·Adam 상태까지 수십 GB 메모리가 필요합니다. LoRA(Low-Rank Adaptation)는 원래 가중치 $W_0$를 동결하고, 변화량을 저랭크 행렬 두 개의 곱으로 표현합니다.

$$W = W_0 + \Delta W = W_0 + \frac{\alpha}{r}BA,\qquad B\in\mathbb R^{d\times r},\ A\in\mathbb R^{r\times k},\ r\ll\min(d,k)$$

$d = k = 4096$, $r = 8$이면 학습 파라미터가 $4096^2\approx1{,}677$만 개에서 $2\cdot4096\cdot8 = 65{,}536$개로, 256분의 1이 됩니다. 미세조정에 필요한 변화는 본질적으로 저차원이라는 가정이 실험적으로 잘 맞습니다.

import numpy as np
rng = np.random.default_rng(0)
d, k, r, alpha = 512, 512, 8, 16
W0 = rng.normal(0, 0.02, (d, k))                    # 동결된 사전학습 가중치
A = rng.normal(0, 0.01, (r, k)); B = np.zeros((d, r)) # B=0으로 시작 → 처음엔 ΔW=0 (원래 모델과 동일)
x = rng.normal(size=(4, k))
y = x @ W0.T + (alpha / r) * (x @ A.T) @ B.T          # LoRA 순전파: 큰 행렬 ΔW를 만들지 않는다
print("출력 형상:", y.shape)
print(f"전체 미세조정 파라미터: {d*k:,}  vs  LoRA 파라미터: {r*(d+k):,}  ({d*k/(r*(d+k)):.0f}배 적음)")
# 학습 후에는 W = W0 + (alpha/r) B@A 로 합쳐서 추론 속도 손실 없음

QLoRA는 여기에 더해 동결된 $W_0$를 4비트로 양자화해 메모리를 더 줄입니다. 덕분에 70억 파라미터 모델도 Colab 무료 GPU에서 미세조정할 수 있습니다.

out = model.generate(ids, max_new_tokens=100, do_sample=True, temperature=0.7, top_p=0.9)
print(tok.decode(out[0][ids.shape[1]:], skip_special_tokens=True))
