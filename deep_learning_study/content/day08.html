• 회귀 문제를 가설 함수, 잔차, 손실 함수로 정식화할 수 있다.
  • 평균제곱오차와 평균절대오차를 계산하고, 이상치에 대한 민감도 차이를 설명할 수 있다.
  • 미분으로 1변수 선형회귀의 해를 유도하고, 행렬 형태의 정규방정식으로 일반화할 수 있다.
  • 정규방정식을 사영(그림자)으로 해석할 수 있다.
  • 다항 특징으로 곡선 관계를 선형 모델로 맞추고, 결정계수로 성능을 평가할 수 있다.

회귀 문제와 가설 함수

1일차에서 머신러닝을 "데이터로부터 입력과 출력의 관계를 찾는 일"로 정의했다. 출력이 연속적인 수일 때 이를 회귀라 한다. 꽃잎 길이로 꽃잎 너비를, 집의 넓이로 가격을, 종양의 반지름으로 넓이를 예측하는 문제가 모두 회귀다.

학습에 앞서 "어떤 모양의 함수 중에서 찾을 것인가"를 정해야 한다. 이 함수의 틀을 가설 함수라 한다. 가장 단순한 틀은 직선이다.

$$\hat y = h(x) = wx + b$$

$x$는 입력, $\hat y$("와이 햇")는 예측, $w$는 기울기(가중치), $b$는 절편(편향)이다. 입력이 $d$개인 경우 각 입력에 가중치를 곱해 더한다.

$$\hat y = w_1x_1 + w_2x_2 + \cdots + w_dx_d + b = \mathbf w\cdot\mathbf x + b$$

출력이 입력의 가중합인 이 모델이 선형회귀다. 학습은 데이터에 가장 잘 맞는 $\mathbf w$와 $b$를 찾는 일이다.

선형회귀는 신경망의 가장 작은 부품이기도 하다. 15일차의 인공 뉴런은 선형회귀 출력에 비선형 함수 하나를 씌운 것이고, 신경망의 완전연결층은 선형회귀 여러 개를 나란히 놓은 것이다.

잔차와 손실 함수

"잘 맞는다"를 수로 정의해야 최적화할 수 있다. 표본 $i$에서 정답과 예측의 차이를 잔차라 한다.

$$e_i = y_i - \hat y_i$$

잔차는 양수도 음수도 되므로 그냥 더하면 서로 상쇄된다. 부호를 없애는 두 가지 방법이 있다.

$$\text{MSE} = \frac1N\sum_{i=1}^N (y_i - \hat y_i)^2, \qquad \text{MAE} = \frac1N\sum_{i=1}^N |y_i - \hat y_i|$$

제곱의 평균이 평균제곱오차(MSE), 절댓값의 평균이 평균절대오차(MAE)다. 위 그림의 직선은 MSE $= (0.25 \times 4)/4 = 0.25$, MAE $= 0.5$다. MSE의 제곱근(RMSE)은 $y$와 단위가 같아 "평균적으로 몇만큼 틀리는가"로 읽기 쉽다.

위 인터랙티브의 정사각형 넓이가 각 잔차의 제곱이다. MSE를 최소화한다는 것은 정사각형 넓이의 합을 최소화한다는 뜻이다. 직선에서 먼 점일수록 정사각형이 급격히 커지므로, 직선은 먼 점 쪽으로 강하게 끌려간다.

잔차가 $1, 1, 1, 1, 10$인 다섯 표본. MAE $= 14/5 = 2.8$이고 MSE $= (4 + 100)/5 = 20.8$이다. MSE에서 마지막 표본 하나가 차지하는 몫은 $100/104 \approx 96\%$다. MSE로 학습한 모델은 이 한 점을 맞추려고 나머지 네 점을 희생한다.

6일차의 최대우도와 연결된다. 관측값이 $y = \hat y + \varepsilon$이고 잡음 $\varepsilon$이 평균 0, 분산 $\sigma^2$인 가우시안이라 가정하면 음의 로그우도는 $\frac{(y - \hat y)^2}{2\sigma^2} + \text{상수}$다. 따라서 MSE 최소화는 "잡음이 가우시안"이라는 가정 아래의 최대우도 추정과 같다.

1변수 선형회귀의 해

손실 $L(w, b) = \frac1N\sum_i (wx_i + b - y_i)^2$은 $w$와 $b$에 대한 2차 함수, 즉 아래로 볼록한 그릇 모양이다. 그릇의 바닥에서는 기울기가 0이므로 두 편미분을 0으로 놓고 푼다.

$$\frac{\partial L}{\partial b} = \frac2N\sum_i (wx_i + b - y_i) = 0 \;\Rightarrow\; b = \bar y - w\bar x$$ $$\frac{\partial L}{\partial w} = \frac2N\sum_i (wx_i + b - y_i)\,x_i = 0 \;\Rightarrow\; w = \frac{\sum_i (x_i - \bar x)(y_i - \bar y)}{\sum_i (x_i - \bar x)^2}$$

$\bar x$, $\bar y$는 평균이다. 두 번째 식은 첫 번째 결과를 대입해 정리한 것이다. 이 해를 최소제곱 해라 부른다.

  • $b = \bar y - w\bar x$이므로 최적 직선은 항상 평균점 $(\bar x, \bar y)$를 지난다.
  • 기울기 $w$는 $x$와 $y$의 공분산을 $x$의 분산으로 나눈 값이다. $x$와 $y$가 함께 커지는 경향이 강할수록 기울기가 크다.
  • $\partial L/\partial b = 0$에서 잔차의 합은 0이다. 즉 최적 직선 위아래의 잔차는 정확히 상쇄된다.

점 $(1, 2), (2, 3), (3, 5), (4, 6)$. $\bar x = 2.5$, $\bar y = 4$.

다중 선형회귀와 정규방정식

입력이 여러 개면 행렬로 쓰는 것이 간결하다. 각 표본의 입력 앞에 1을 붙여 행으로 쌓은 행렬을 설계 행렬 $X$라 하고, 편향과 가중치를 한 벡터 $\boldsymbol\theta$로 모은다.

$$X = \begin{bmatrix}1 & x_{11} & \cdots & x_{1d}\\ 1 & x_{21} & \cdots & x_{2d}\\ \vdots & \vdots & & \vdots\\ 1 & x_{N1} & \cdots & x_{Nd}\end{bmatrix}_{N\times(d+1)}, \qquad \boldsymbol\theta = \begin{bmatrix} b\\ w_1\\ \vdots\\ w_d\end{bmatrix}, \qquad \hat{\mathbf y} = X\boldsymbol\theta$$

1로 채운 첫 열이 $b$와 곱해져 모든 예측에 $b$를 더한다. 이 덕분에 편향을 따로 다루지 않아도 된다. 손실과 그래디언트는 다음과 같다(5일차의 $\partial(XW)/\partial W$ 결과를 쓴다).

$$L(\boldsymbol\theta) = \frac1N\|X\boldsymbol\theta - \mathbf y\|^2, \qquad \nabla L = \frac2N X^\top(X\boldsymbol\theta - \mathbf y)$$

그래디언트를 0으로 놓으면 정규방정식을 얻는다.

$$X^\top X\,\boldsymbol\theta = X^\top\mathbf y \qquad\Rightarrow\qquad \boldsymbol\theta^* = (X^\top X)^{-1}X^\top\mathbf y$$

앞 예제의 네 점. $X$의 행은 $(1, 1), (1, 2), (1, 3), (1, 4)$, $\mathbf y = (2, 3, 5, 6)$.

$$X^\top X = \begin{bmatrix}4 & 10\\ 10 & 30\end{bmatrix},\quad X^\top\mathbf y = \begin{bmatrix}16\\ 47\end{bmatrix},\quad (X^\top X)^{-1} = \frac1{20}\begin{bmatrix}30 & -10\\ -10 & 4\end{bmatrix}$$

$\boldsymbol\theta^* = \frac1{20}(30\cdot16 - 10\cdot47,\; -10\cdot16 + 4\cdot47) = \frac1{20}(10, 28) = (0.5, 1.4)$. 1변수 공식의 $b = 0.5$, $w = 1.4$와 같다.

기하학적 의미: 사영

$X\boldsymbol\theta$는 $X$의 열들의 선형결합이다. $\boldsymbol\theta$를 어떻게 바꾸든 예측 벡터는 $X$의 열들이 만드는 평면(열공간) 안에 있다. 정답 $\mathbf y$는 보통 이 평면 밖에 있으므로, 평면에서 $\mathbf y$와 가장 가까운 점을 고르는 것이 최선이다. 그 점은 3일차의 사영, 즉 $\mathbf y$에서 평면으로 내린 수선의 발이다.

  • 역행렬을 직접 구하지 않는다. np.linalg.solve(X.T @ X, X.T @ y)나 np.linalg.lstsq(X, y)가 더 빠르고 정확하다.
  • 특징끼리 선형 종속이면(같은 길이를 cm와 mm로 두 번 넣은 경우, 또는 특징 수가 표본 수보다 많은 경우) $X^\top X$의 역행렬이 없다. 해가 무수히 많아진다. 12일차의 규제가 해결책이다.
  • $X^\top X$는 $(d+1)\times(d+1)$ 행렬이고 이를 푸는 데 대략 $d^3$에 비례하는 연산이 든다. 파라미터가 수백만 개인 신경망에는 쓸 수 없다. 그래서 9일차의 경사하강법이 필요하다.

다항 특징: 직선으로 곡선 맞추기

관계가 곡선이면 직선은 맞지 않는다. 그런데 입력 $x$ 대신 $(x, x^2, x^3, \dots)$를 새 특징으로 쓰면 같은 선형회귀로 곡선을 맞출 수 있다. 이렇게 만든 특징을 다항 특징이라 한다.

$$\hat y = \theta_0 + \theta_1x + \theta_2x^2 + \cdots + \theta_px^p$$

이 식은 $x$에 대해서는 곡선이지만 파라미터 $\theta$에 대해서는 여전히 가중합(선형)이다. 설계 행렬의 열만 $1, x, x^2, \dots$로 바뀔 뿐 정규방정식은 그대로 쓴다. "선형 모델"의 "선형"은 파라미터에 대한 선형을 말한다.

입력 $x$
특징 변환
$\phi(x) = (1, x, x^2)$
선형회귀
$\boldsymbol\theta\cdot\phi(x)$
곡선 예측

입력을 바꿔 선형 모델의 표현력을 넓히는 생각은 딥러닝의 핵심과 이어진다. 고전 머신러닝에서는 사람이 $\phi$를 설계했고, 신경망은 $\phi$ 자체를 데이터로부터 학습한다(16일차).

차수를 높이면 학습 데이터에는 점점 더 잘 맞지만 새로운 데이터에는 오히려 틀릴 수 있다(과적합, 12일차). 또 $x = 10$이면 $x^{10} = 10^{10}$처럼 특징의 크기 차이가 커져 계산이 불안정해진다.

결정계수 R²

MSE는 $y$의 단위에 따라 값이 달라 "0.4가 좋은가 나쁜가"를 판단하기 어렵다. 결정계수는 가장 단순한 예측(항상 평균 $\bar y$를 말하기)과 비교한 상대적 점수다.

$$R^2 = 1 - \frac{\sum_i (y_i - \hat y_i)^2}{\sum_i (y_i - \bar y)^2}$$
$R^2$의미
1모든 점을 정확히 맞힘
0평균만 말하는 것과 같은 수준
음수평균보다도 못함 (테스트 데이터에서 일어날 수 있음)

네 점 예제: $\sum(y_i - \bar y)^2 = 4 + 1 + 1 + 4 = 10$, 잔차 제곱합 $0.2$이므로 $R^2 = 1 - 0.2/10 = 0.98$이다. "$y$의 변동 중 98%를 $x$로 설명한다"고 읽는다.

코드 실습: 붓꽃과 종양 데이터

붓꽃 150송이의 꽃잎 길이로 꽃잎 너비를 예측한다. 먼저 1변수 공식을 그대로 코드로 옮긴다.

import numpy as np
import matplotlib.pyplot as plt
d = load_data("iris")
x, y = d["X"][:, 2], d["X"][:, 3]                 # 꽃잎 길이 → 꽃잎 너비 (cm)
w = ((x - x.mean()) * (y - y.mean())).sum() / ((x - x.mean()) ** 2).sum()
b = y.mean() - w * x.mean()
pred = w * x + b
res = y - pred
print(f"w = {w:.4f}, b = {b:.4f}")
print(f"MSE = {(res ** 2).mean():.4f}, MAE = {np.abs(res).mean():.4f}, 잔차의 합 = {res.sum():.1e}")
print(f"R² = {1 - (res ** 2).sum() / ((y - y.mean()) ** 2).sum():.3f}")
plt.figure(figsize=(5.4, 3.6))
plt.scatter(x, y, s=14, alpha=.6, label="붓꽃 150송이")
xs = np.linspace(0.8, 7.2, 50)
plt.plot(xs, w * xs + b, "C3", lw=2, label=f"ŷ = {w:.3f}x {b:+.3f}")
plt.xlabel("꽃잎 길이 (cm)")
plt.ylabel("꽃잎 너비 (cm)")
plt.legend()
plt.grid(alpha=.3)
plt.show()

꽃잎이 1cm 길어질 때 너비는 약 0.42cm 늘어난다. 잔차의 합은 반올림 오차 수준(사실상 0)이다. 같은 결과를 정규방정식으로 확인한다.

X1 = np.c_[np.ones_like(x), x]                       # 설계 행렬 [1, x], (150, 2)
theta = np.linalg.solve(X1.T @ X1, X1.T @ y)         # XᵀX θ = Xᵀy
print("정규방정식 θ = (b, w):", theta.round(4))
print("lstsq            :", np.linalg.lstsq(X1, y, rcond=None)[0].round(4))
print("잔차와 열들의 내적 Xᵀ(y − Xθ):", (X1.T @ (y - X1 @ theta)).round(10))

마지막 줄이 사영 그림의 "잔차는 모든 열과 수직"을 확인한다. 다음은 곡선 관계다. 유방 종양 569개의 평균 반지름으로 평균 넓이를 예측한다. 넓이는 반지름의 제곱에 비례할 것이다.

d = load_data("breast_cancer")
r, area = d["X"][:, 0], d["X"][:, 3]                 # 평균 반지름, 평균 넓이
def poly(x, deg):
    return np.stack([x ** k for k in range(deg + 1)], axis=1)   # 열: 1, x, x², ...
plt.figure(figsize=(5.6, 3.8))
plt.scatter(r, area, s=8, alpha=.4, label="종양 569개")
rs = np.linspace(r.min(), r.max(), 100)
for deg in [1, 2]:
    A = poly(r, deg)
    th = np.linalg.solve(A.T @ A, A.T @ area)
    res = area - A @ th
    r2 = 1 - (res ** 2).sum() / ((area - area.mean()) ** 2).sum()
    print(f"{deg}차: θ = {th.round(3)}  RMSE = {np.sqrt((res ** 2).mean()):.1f}  R² = {r2:.4f}")
    plt.plot(rs, poly(rs, deg) @ th, lw=2, label=f"{deg}차 다항식")
plt.xlabel("평균 반지름")
plt.ylabel("평균 넓이")
plt.legend()
plt.grid(alpha=.3)
plt.show()

직선은 양 끝에서 체계적으로 빗나가고(RMSE 55.7), 2차 다항식은 거의 완벽하다(RMSE 14.7). 2차 계수는 약 3.11로 원의 넓이 공식 $\pi r^2$의 $\pi \approx 3.14$에 가깝다. 모델이 데이터에서 넓이 공식을 다시 찾아낸 셈이다.

정리

  • 선형회귀: $\hat y = \mathbf w\cdot\mathbf x + b$. 학습 = 손실을 최소로 하는 $\mathbf w, b$ 찾기.
  • 잔차 $e = y - \hat y$. MSE는 큰 오차와 이상치에 민감하고, MAE는 덜 민감하다. MSE 최소화는 가우시안 잡음 가정의 최대우도.
  • 1변수 해: $w = \mathrm{Cov}(x, y)/\mathrm{Var}(x)$, $b = \bar y - w\bar x$. 직선은 평균점을 지나고 잔차의 합은 0.
  • 정규방정식 $X^\top X\boldsymbol\theta = X^\top\mathbf y$. 예측은 정답의 열공간 사영. 큰 모델에는 비용이 커서 쓸 수 없음.
  • 다항 특징으로 곡선 관계도 선형 모델로 맞춘다. $R^2$는 평균 예측 대비 상대 점수.

    풀이

    $\bar x = 1.5$, $\bar y = 2.25$. $\sum(x_i - \bar x)(y_i - \bar y) = 1.875 + 0.125 - 0.125 + 2.625 = 4.5$, $\sum(x_i - \bar x)^2 = 5$. $w = 0.9$, $b = 2.25 - 1.35 = 0.9$. 예측 $0.9, 1.8, 2.7, 3.6$, 잔차 $0.1, 0.2, -0.7, 0.4$, 합 0. MSE $= 0.7/4 = 0.175$.

  2. 입력 단위를 cm에서 mm로 바꾸면($x' = 10x$) 최적의 $w$와 $b$는 어떻게 변하는가? 예측값은 변하는가?
    풀이

    $w' = w/10$, $b' = b$. $w'x' = (w/10)(10x) = wx$이므로 예측은 그대로다. 가중치의 크기는 특징의 단위에 따라 달라지므로, 가중치 크기로 특징의 중요도를 비교하려면 단위를 먼저 맞춰야 한다(미니 프로젝트 4단계).

  3. 편향 없이 원점을 지나는 모델 $\hat y = wx$의 최소제곱 해가 $w = \sum x_iy_i / \sum x_i^2$임을 보이고, 네 점 예제 $(1, 2), (2, 3), (3, 5), (4, 6)$에 적용하라. 편향이 있을 때보다 MSE가 커지는가?
    풀이

    $\frac{dL}{dw} = \frac2N\sum(wx_i - y_i)x_i = 0 \Rightarrow w = \sum x_iy_i/\sum x_i^2 = 47/30 \approx 1.567$. 예측 $1.567, 3.133, 4.700, 6.267$, 잔차 $0.433, -0.133, 0.300, -0.267$, MSE $\approx 0.092$. 편향이 있을 때의 0.05보다 크다. 선택지가 줄었으니 최솟값은 같거나 커질 수밖에 없다.

    x = np.array([1, 2, 3, 4.]); y = np.array([2, 3, 5, 6.])
w0 = (x * y).sum() / (x ** 2).sum()
print(w0, ((y - w0 * x) ** 2).mean())
  4. $\partial L/\partial w = 0$ 조건에서 $\sum_i e_i x_i = 0$임을 보여라. 이 식과 $\sum_i e_i = 0$을 사영 그림과 연결해 설명하라.
    풀이

    $\frac{\partial L}{\partial w} = -\frac2N\sum_i (y_i - \hat y_i)x_i = -\frac2N\sum_i e_ix_i = 0$. 잔차 벡터 $\mathbf e$가 $X$의 두 열 $\mathbf 1$과 $\mathbf x$ 모두와 내적 0, 즉 수직이라는 뜻이다. 사영 그림에서 잔차가 평면에 수직인 것과 같은 말이다.

미니 프로젝트: 정규방정식 회귀기

와인 178병의 화학 성분 12가지로 13번째 성분인 플라보노이드 함량을 예측하는 회귀기를 직접 만든다. 정규방정식 회귀 클래스를 구현하고, 기준선·단일 특징·전체 특징 모델을 비교한 뒤, 잔차를 분석하고 특징의 중요도를 해석한다.

  1. 데이터 준비. 플라보노이드 열을 정답 $y$로 떼어 내고 나머지 12개를 입력으로 쓴다. 학습 80%, 테스트 20%로 무작위로 나눈다. 테스트 세트는 마지막 평가에만 쓴다. 
    import numpy as np
import matplotlib.pyplot as plt
d = load_data("wine")
names = d["feature_names_ko"]
A_all = d["X"].astype(float)
t = names.index("플라보노이드")
y = A_all[:, t]
X = np.delete(A_all, t, axis=1)                       # 나머지 12개 성분
feat = [n for i, n in enumerate(names) if i != t]
rng = np.random.default_rng(0)
idx = rng.permutation(len(y)); cut = int(0.8 * len(y))
tr, te = idx[:cut], idx[cut:]
print("입력", X.shape, " 학습", len(tr), " 테스트", len(te))
print("플라보노이드: 평균 %.2f, 표준편차 %.2f, 범위 %.2f ~ %.2f" % (y.mean(), y.std(),
                                                                    y.min(), y.max()))
  2. 회귀 클래스 구현. fit은 1의 열을 붙여 정규방정식을 풀고, predict는 $X\boldsymbol\theta$를 계산하고, r2는 결정계수를 반환한다. 아래 코드를 보지 않고 먼저 직접 작성한 뒤 비교하라. 
    class LinReg:
    def fit(self, X, y):
        A = np.c_[np.ones(len(X)), X]                       # TODO 확인: 편향용 1의 열
        self.theta = np.linalg.solve(A.T @ A, A.T @ y)      # TODO 확인: 정규방정식
        return self
    def predict(self, X):
        return self.theta[0] + X @ self.theta[1:]
    def mse(self, X, y):
        return ((y - self.predict(X)) ** 2).mean()
    def r2(self, X, y):
        res = y - self.predict(X)
        return 1 - (res ** 2).sum() / ((y - y.mean()) ** 2).sum()

# 네 점 예제로 검증: (b, w) = (0.5, 1.4)가 나와야 한다
print(LinReg().fit(np.array([[1.], [2.], [3.], [4.]]),
                   np.array([2., 3., 5., 6.])).theta)
  3. 세 모델 비교. (a) 학습 세트 평균만 말하는 기준선, (b) 상관이 가장 큰 특징 하나(총 페놀), (c) 12개 전체. 학습·테스트의 $R^2$를 표로 비교한다. 
    base = np.full(len(te), y[tr].mean())
r2_base = 1 - ((y[te] - base) ** 2).sum() / ((y[te] - y[te].mean()) ** 2).sum()
print(f"(a) 기준선        테스트 R² = {r2_base:.3f}")

print(f"(b) 총 페놀 하나  학습 R² = {m1.r2(X[tr][:, [j]], y[tr]):.3f}  테스트 R² = {m1.r2(X[te][:, [j]], y[te]):.3f}")
m12 = LinReg().fit(X[tr], y[tr])
print(f"(c) 12개 전체     학습 R² = {m12.r2(X[tr], y[tr]):.3f}  테스트 R² = {m12.r2(X[te], y[te]):.3f}")
  4. 잔차 분석. 테스트 세트에서 예측 대 정답을 그리고, 잔차가 가장 큰 표본을 찾는다. 그 표본 하나를 뺐을 때 테스트 MSE가 어떻게 변하는지 계산하라. 
    p = m12.predict(X[te]); e = y[te] - p
plt.figure(figsize=(4.6, 4.2))
plt.scatter(y[te], p, s=22)
plt.plot([0, 5.5], [0, 5.5], "k--", lw=1, label="완벽한 예측")

plt.xlabel("실제 플라보노이드")
plt.ylabel("예측")

mask = np.arange(len(e)) != k
print(f"그 한 병을 뺀 MSE = {(e[mask] ** 2).mean():.3f},  MAE = {np.abs(e[mask]).mean():.3f}")
  5. 특징 중요도. 원래 단위의 가중치는 비교할 수 없다(연습 문제 2). 학습 세트의 평균과 표준편차로 모든 특징을 표준화한 뒤 다시 학습해 가중치를 막대그래프로 그린다. 표준화해도 예측은 그대로임을 확인하라.

  • 4단계: 테스트 세트에 플라보노이드 5.08인 와인이 한 병 있다(전체 178병 중 최댓값, 두 번째가 3.93). 이 한 병의 잔차가 약 2.61로 테스트 MSE의 약 46%를 차지한다. 빼고 나면 MSE가 0.414에서 0.232로 떨어진다. MSE가 이상치에 민감하다는 표의 내용 그대로다.
