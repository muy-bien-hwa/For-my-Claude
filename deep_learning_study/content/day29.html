4. 베이스라인 사다리

한 칸씩 올라가며 각 결과를 기록합니다. 각 칸이 이전 칸보다 나아야 다음으로 갑니다.

  1. 바보 베이스라인: 최빈 클래스 예측 / 평균값 예측. (불균형 데이터면 정확도가 의외로 높게 나올 것입니다 → 지표 선택이 중요한 이유)
  2. 단순 모델: 로지스틱 회귀 / 선형 회귀 / (표 데이터) 트리 모델 / (텍스트) TF-IDF + 로지스틱 회귀.
  3. 첫 신경망: 작은 모델 + 기본 하이퍼파라미터(AdamW 3e-4~1e-3). 먼저 배치 하나 과적합 테스트를 통과시킵니다(Day 28).
  4. 사전학습 모델 (이미지·텍스트): 특징 추출 → 미세조정 (Day 19, 25).
💡 오늘의 목표는 '최고 성능'이 아니다 오늘 끝날 때 처음부터 끝까지 돌아가는 파이프라인(데이터 → 학습 → 평가 → 결과 기록)이 있으면 성공입니다. 성능 개선은 내일입니다. 완벽한 모델을 설계하느라 하루를 다 쓰는 것이 가장 흔한 실패입니다.
