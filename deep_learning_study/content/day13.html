• 가중치를 0이나 너무 크게/작게 초기화하면 왜 안 되는지 실험으로 확인한다.
  • Xavier(Glorot)와 He(Kaiming) 초기화를 분산 보존 원리로 유도한다.
  • 기울기 소실과 폭발의 원인과 대처법(활성화, 초기화, 정규화, 잔차, 클리핑)을 정리한다.
  • 배치 정규화와 층 정규화의 계산, 학습/추론 모드 차이, 사용처를 구분한다.
👨‍🏫 깊은 망을 학습 가능하게 만든 기술들 1990년대에 깊은 망이 학습되지 않았던 이유의 상당 부분은 "숫자가 층을 지나며 폭발하거나 사라지는" 문제였습니다. 오늘 배우는 초기화와 정규화는 화려하지 않지만, 이것 없이는 ResNet도 Transformer도 학습되지 않습니다.

1. 0으로 초기화하면?

모든 가중치가 같으면 같은 층의 모든 뉴런이 같은 값을 출력하고, 같은 기울기를 받고, 같게 업데이트됩니다. 뉴런 100개가 사실상 1개처럼 동작합니다. 이것을 대칭성 문제라고 하며, 무작위 초기화로 깨뜨려야 합니다. (편향은 0으로 시작해도 괜찮습니다.)

2. 너무 작거나 너무 크면?

깊은 망에서 활성화 값의 분포를 층별로 봅시다.

import numpy as np
import matplotlib.pyplot as plt
rng = np.random.default_rng(0)

def forward_stats(init_std, act, n_layers=10, width=256):
    x = rng.normal(size=(512, width)); stats = []
    for _ in range(n_layers):
        W = rng.normal(0, init_std(width), (width, width))
        x = act(x @ W)
        stats.append(x)
    return stats

acts = {"tanh": np.tanh, "relu": lambda z: np.maximum(0, z)}
inits = {
  "std=0.01 (너무 작음)": lambda n: 0.01,
  "std=1 (너무 큼)":      lambda n: 1.0,
  "Xavier √(1/n)":        lambda n: np.sqrt(1 / n),
  "He √(2/n)":            lambda n: np.sqrt(2 / n),
}
fig, axs = plt.subplots(2, 4, figsize=(14, 5.2))
for r, (an, act) in enumerate(acts.items()):
    for c, (iname, init) in enumerate(inits.items()):
        st = forward_stats(init, act)
        ax = axs[r, c]
        for i in [0, 4, 9]:
            ax.hist(st[i].ravel(), bins=50, alpha=.5, label=f'층 {i+1}', range=(-2, 2) if an == 'tanh' else (0, 3), density=True)
        ax.set_title(f"{an} / {iname}\n10층 std={st[-1].std():.2e}", fontsize=9); ax.set_yticks([])
        if r == 0 and c == 0: ax.legend(fontsize=7)
plt.tight_layout(); plt.show()
  • 너무 작음: 층을 지날수록 활성화가 0으로 수축. 기울기도 0이 됨 → 학습 안 됨.
  • 너무 큼: tanh는 ±1로 포화(기울기 0), ReLU는 값이 폭발.
  • tanh + Xavier, ReLU + He: 깊은 층까지 분포가 유지됨.

3. 분산 보존 원리로 유도하기

뉴런 하나의 사전 활성화 $z = \sum_{i=1}^{n} w_i x_i$ ($n$ = 입력 수, fan-in). $w_i$와 $x_i$가 독립이고 평균 0이면

$$\mathrm{Var}(z) = n\,\mathrm{Var}(w)\,\mathrm{Var}(x)$$

층을 지나도 분산이 유지되려면 $n\,\mathrm{Var}(w) = 1$, 즉

$$\mathrm{Var}(w) = \frac{1}{n}\quad\text{(Xavier/LeCun, tanh 등 0 중심 활성화)}$$

ReLU는 음수 절반을 0으로 만들어 분산을 절반으로 줄이므로 2배로 보상합니다.

$$\mathrm{Var}(w) = \frac{2}{n}\quad\text{(He/Kaiming, ReLU 계열)}$$

(원래 Xavier 논문은 순전파·역전파를 모두 고려해 $\frac{2}{n_{in}+n_{out}}$을 제안했습니다.) PyTorch의 nn.Linear, nn.Conv2d는 기본적으로 Kaiming 계열(uniform) 초기화를 사용합니다.

4. 기울기 소실과 폭발 — 원인과 대책

역전파에서 기울기는 층마다 $W^\top$와 활성화 도함수가 곱해집니다. 이 곱의 크기가 1보다 작으면 지수적으로 사라지고(소실), 크면 폭발합니다.

5. 배치 정규화 (Batch Normalization)

2015년 등장해 깊은 CNN 학습을 획기적으로 쉽게 만든 기법입니다. 미니배치의 각 특성(채널)을 평균 0, 분산 1로 정규화한 뒤, 학습 가능한 스케일 $\gamma$와 이동 $\beta$를 적용합니다.

$$\mu_B = \frac1m\sum_i x_i,\quad \sigma_B^2 = \frac1m\sum_i(x_i-\mu_B)^2,\quad \hat x_i = \frac{x_i-\mu_B}{\sqrt{\sigma_B^2+\epsilon}},\quad y_i = \gamma\hat x_i + \beta$$
  • $\gamma, \beta$ 덕분에 필요하면 원래 분포로 되돌릴 수도 있습니다(표현력 손실 없음).
  • 학습 시: 현재 배치의 통계 사용 + 이동 평균(running mean/var)을 EMA로 갱신.
  • 추론 시: 저장된 이동 평균 사용. 배치 크기 1이어도 동작해야 하니까요.
  • 효과: 더 큰 학습률 허용, 초기화에 덜 민감, 약간의 규제 효과(배치 노이즈).
⚠️ model.train() / model.eval()을 잊지 마세요 PyTorch에서 BN(과 드롭아웃)은 학습/추론 모드에 따라 동작이 다릅니다. 평가 전에 model.eval()을 호출하지 않으면 테스트 배치의 통계로 정규화되어 결과가 들쭉날쭉해집니다. 매우 흔한 버그입니다.
class BatchNorm1d:
    def __init__(self, d, momentum=0.1, eps=1e-5):
        self.gamma, self.beta = np.ones(d), np.zeros(d)
        self.running_mean, self.running_var = np.zeros(d), np.ones(d)
        self.m, self.eps, self.training = momentum, eps, True
    def forward(self, x):
        if self.training:
            mu, var = x.mean(0), x.var(0)
            self.running_mean = (1 - self.m) * self.running_mean + self.m * mu
            self.running_var = (1 - self.m) * self.running_var + self.m * var
        else:
            mu, var = self.running_mean, self.running_var
        self.xhat = (x - mu) / np.sqrt(var + self.eps); self.var = var
        return self.gamma * self.xhat + self.beta
    def backward(self, g):
        # 학습 모드 역전파 (유도는 아래 '더 알아보기' 참고)
        N = g.shape[0]
        self.dgamma = (g * self.xhat).sum(0); self.dbeta = g.sum(0)
        dxhat = g * self.gamma
        return (dxhat - dxhat.mean(0) - self.xhat * (dxhat * self.xhat).mean(0)) / np.sqrt(self.var + self.eps)

bn = BatchNorm1d(3)
x = rng.normal(loc=[5, -3, 100], scale=[2, 0.1, 30], size=(64, 3))
y = bn.forward(x)
print("입력 평균:", x.mean(0).round(2), " 표준편차:", x.std(0).round(2))
print("BN 출력 평균:", y.mean(0).round(4), " 표준편차:", y.std(0).round(4))
bn.training = False
print("추론 모드 (running 통계 사용) 출력 평균:", bn.forward(x).mean(0).round(2), " ← 아직 running 통계가 덜 쌓임")
더 알아보기: BN 역전파 유도의 핵심

$\hat x_i$는 $x_i$뿐 아니라 $\mu_B$, $\sigma_B$를 통해 배치의 모든 $x_j$에 의존합니다(분기!). 세 경로의 기울기를 모두 더해 정리하면

$$\frac{\partial L}{\partial x_i} = \frac{1}{\sqrt{\sigma_B^2+\epsilon}}\left(g_i - \overline{g} - \hat x_i\,\overline{g\hat x}\right),\quad g_i = \frac{\partial L}{\partial\hat x_i}$$

(윗줄은 배치 평균.) 직접 유도해 보고 Day 11의 grad_check로 검증해 보세요. 좋은 연습입니다.

6. 층 정규화 (Layer Normalization)

BN은 배치 축으로 통계를 냅니다. 그래서 배치가 작거나, 시퀀스 길이가 제각각인 RNN/Transformer에는 맞지 않습니다. LN은 샘플 하나의 특성 축으로 통계를 냅니다.

def layer_norm(x, gamma, beta, eps=1e-5):
    mu = x.mean(-1, keepdims=True); var = x.var(-1, keepdims=True)
    return gamma * (x - mu) / np.sqrt(var + eps) + beta

x = rng.normal(size=(2, 5, 8)) * 10 + 3     # (배치, 시퀀스 길이, d_model)
y = layer_norm(x, np.ones(8), np.zeros(8))
print("토큰별 평균:", y.mean(-1).round(4)[0])
print("토큰별 표준편차:", y.std(-1).round(4)[0])
print("→ 배치 크기와 무관하게, 토큰 하나하나가 독립적으로 정규화된다")
