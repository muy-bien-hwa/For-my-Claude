• 전이학습이 왜 작동하는지(범용 특징의 재사용) 설명한다.
  • 특징 추출과 미세조정을 구분하고, 데이터 양과 유사도에 따라 전략을 고른다.
  • torchvision의 사전학습 모델을 불러와 분류기를 교체하고, 층 동결·차등 학습률을 적용한다.
  • 데이터 증강 파이프라인을 설계하고, Mixup/CutMix 같은 고급 증강을 안다.
👨‍🏫 거인의 어깨 위에서 현업에서 이미지 모델을 처음부터 학습시키는 일은 드뭅니다. ImageNet 120만 장으로 며칠 동안 학습된 모델을 가져와 내 데이터 수백 장으로 몇 분만 조정하면, 처음부터 학습한 모델보다 거의 항상 더 좋습니다. LLM 시대의 "사전학습 + 미세조정" 패러다임(Day 25)도 정확히 이 아이디어입니다.

1. 왜 전이학습이 되는가

Day 17에서 봤듯이 CNN의 앞쪽 층은 선, 모서리, 색, 질감 같은 범용 특징을 학습합니다. 이것은 고양이 사진이든 X-ray든 위성 사진이든 쓸모가 있습니다. 뒤쪽 층으로 갈수록 원래 과제(ImageNet 1000클래스)에 특화된 특징이 됩니다.

그래서 앞쪽은 그대로 두고 뒤쪽만 새 과제에 맞게 바꾸면, 적은 데이터로도 좋은 성능을 낼 수 있습니다.

2. 두 가지 전략

전략방법언제
특징 추출 (Feature extraction)백본 전체를 동결(requires_grad=False)하고 새 분류기만 학습데이터가 아주 적음 (클래스당 수십 장), 원래 도메인과 비슷
미세조정 (Fine-tuning)새 분류기를 먼저 학습한 뒤, 백본 일부 또는 전체를 작은 학습률로 함께 학습데이터가 수백~수천 장 이상, 도메인이 다를수록 더 많은 층을 풂
🔑 의사결정 가이드
도메인 비슷 (예: 일상 사진)도메인 다름 (예: 의료, 위성)
데이터 적음특징 추출특징 추출 (앞쪽 층 특징만 사용) — 어려운 경우
데이터 많음전체 미세조정전체 미세조정 (더 많은 에폭, 처음부터 학습도 고려)

3. 코드: 특징 추출 → 미세조정

import torch, torch.nn as nn
from torchvision import models, transforms, datasets

weights = models.ResNet50_Weights.IMAGENET1K_V2
model = models.resnet50(weights=weights)
print(model.fc)                                   # Linear(in_features=2048, out_features=1000)

# 1) 백본 동결
for p in model.parameters():
    p.requires_grad = False
# 2) 분류기 교체 (새로 만든 층은 requires_grad=True)
n_classes = 5
model.fc = nn.Sequential(nn.Dropout(0.2), nn.Linear(model.fc.in_features, n_classes))

# 3) 학습 가능한 파라미터만 옵티마이저에
opt = torch.optim.AdamW([p for p in model.parameters() if p.requires_grad], lr=1e-3)
# ... 몇 에폭 학습 (Day 16 템플릿) ...

# 4) 미세조정: 마지막 스테이지(layer4)를 풀고, 층마다 다른 학습률
for p in model.layer4.parameters():
    p.requires_grad = True
opt = torch.optim.AdamW([
    {"params": model.layer4.parameters(), "lr": 1e-4},     # 사전학습 층: 작게
    {"params": model.fc.parameters(),     "lr": 1e-3},     # 새 층: 크게
], weight_decay=0.01)
⚠️ 미세조정 3대 주의사항
  1. 입력 전처리를 사전학습과 똑같이: 이미지 크기, 정규화 평균/표준편차(weights.transforms()로 얻을 수 있음).
  2. 작은 학습률: 큰 학습률은 사전학습된 좋은 특징을 망가뜨립니다(파국적 망각). 보통 처음 학습의 1/10 ~ 1/100.
  3. 분류기 먼저: 무작위 초기화된 분류기의 큰 기울기가 백본으로 흘러가 특징을 망가뜨리지 않도록, 분류기를 먼저 몇 에폭 학습한 뒤 백본을 풉니다.

BN 층은 데이터가 적을 때 동결한 채(eval 모드) 두는 것이 안정적인 경우가 많습니다. 이미지 외에 timm 라이브러리는 수백 개의 최신 사전학습 모델(ConvNeXt, ViT, EfficientNet 등)을 같은 인터페이스로 제공합니다.

4. 데이터 증강

레이블을 바꾸지 않는 변환으로 학습 데이터를 매번 다르게 보여 줍니다. "고양이를 좌우로 뒤집어도 고양이"라는 사전 지식을 모델에 주입하는 방법입니다.

mean, std = (0.485, 0.456, 0.406), (0.229, 0.224, 0.225)     # ImageNet 통계
train_tf = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.6, 1.0)),       # 무작위 영역 잘라 크기 조정
    transforms.RandomHorizontalFlip(),                           # 좌우 뒤집기
    transforms.ColorJitter(0.3, 0.3, 0.3, 0.05),                 # 밝기·대비·채도·색조
    transforms.RandomRotation(10),
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
    transforms.RandomErasing(p=0.25),                           # 일부 영역 지우기
])
val_tf = transforms.Compose([                                    # 검증·테스트에는 증강 없음!
    transforms.Resize(256), transforms.CenterCrop(224),
    transforms.ToTensor(), transforms.Normalize(mean, std)])
⚠️ 증강은 레이블을 보존해야 한다 숫자 인식에서 상하 뒤집기를 하면 6이 9가 됩니다. 의료 영상에서 좌우 뒤집기는 심장 위치를 바꿉니다. 텍스트가 있는 이미지의 좌우 반전은 글자를 망가뜨립니다. 도메인 지식으로 증강을 고르세요.

5. 고급 증강: Mixup과 CutMix

  • Mixup: 두 이미지를 섞고 레이블도 같은 비율로 섞습니다. $\tilde x = \lambda x_i + (1-\lambda)x_j$, $\tilde y = \lambda y_i + (1-\lambda)y_j$.
  • CutMix: 한 이미지의 사각형 영역을 다른 이미지로 붙이고, 면적 비율로 레이블을 섞습니다.
  • RandAugment / TrivialAugment: 여러 증강 중 무작위로 골라 적용. transforms.TrivialAugmentWide() 한 줄로 쓸 수 있습니다.
  • Label smoothing: 정답을 1.0 대신 0.9로, 나머지에 0.1을 나눠 줘서 과신을 막습니다. nn.CrossEntropyLoss(label_smoothing=0.1).
def mixup(x, y, n_classes, alpha=0.2):
    lam = torch.distributions.Beta(alpha, alpha).sample().item()
    idx = torch.randperm(x.size(0), device=x.device)
    y1 = F.one_hot(y, n_classes).float()
    return lam * x + (1 - lam) * x[idx], lam * y1 + (1 - lam) * y1[idx]
# CrossEntropyLoss는 확률 분포 타깃(soft label)도 받는다
