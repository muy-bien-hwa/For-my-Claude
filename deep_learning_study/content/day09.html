• 경사하강법의 갱신 규칙을 쓰고, 한 걸음씩 손으로 계산할 수 있다.
  • 학습률에 따라 수렴, 진동, 발산이 일어나는 조건을 곡률로 설명할 수 있다.
  • 손실 지형의 등고선이 길쭉할 때 학습이 느려지는 이유와 표준화의 효과를 설명할 수 있다.
  • 배치, 확률적, 미니배치 경사하강법을 구별하고 에폭과 스텝 수를 계산할 수 있다.
  • 학습 곡선을 보고 학습률이 적절한지 판단할 수 있다.

왜 반복해서 푸는가

8일차의 정규방정식은 한 번에 답을 준다. 그러나 두 가지 이유로 딥러닝에서는 쓸 수 없다.

  • 파라미터가 $d$개면 $(d\times d)$ 행렬을 풀어야 한다. $d$가 1억이면 행렬 원소만 $10^{16}$개다.
  • 신경망의 손실은 파라미터에 대해 2차 함수가 아니다. "기울기 = 0"을 식으로 풀 수 없다.

대신 아무 곳에서 출발해 손실이 줄어드는 방향으로 조금씩 움직인다. 5일차에서 본 대로 그 방향은 그래디언트의 반대 방향이다. 이 방법이 경사하강법이며, 모든 딥러닝 학습의 기본 알고리즘이다.

초기값 $\boldsymbol\theta_0$
손실 $L(\boldsymbol\theta_t)$ 계산
그래디언트
$\nabla L(\boldsymbol\theta_t)$
$\boldsymbol\theta_{t+1} = \boldsymbol\theta_t - \eta\nabla L$
멈출 때까지 반복

갱신 규칙과 학습률

$$\boldsymbol\theta_{t+1} = \boldsymbol\theta_t - \eta\,\nabla L(\boldsymbol\theta_t)$$

$t$는 반복 번호, $\eta$(에타)는 한 걸음의 크기를 정하는 학습률이다. 그래디언트가 크면(가파르면) 걸음이 크고, 바닥에 가까워 그래디언트가 작아지면 걸음도 저절로 작아진다.

$L(w) = (w - 2)^2$, $L'(w) = 2(w - 2)$, 출발 $w_0 = -1$, $\eta = 0.1$.

$t$$w_t$$L'(w_t)$$w_{t+1} = w_t - 0.1L'$최솟값까지 거리
0−1−6−0.43 → 2.4
1−0.4−4.80.082.4 → 1.92
20.08−3.840.4641.92 → 1.536

매 걸음 거리가 0.8배가 된다. 20걸음 뒤 거리는 $3\times0.8^{20}\approx0.035$다.

0.8은 어디서 왔는가? 최솟값 $w^*$로부터의 거리를 $e_t = w_t - w^*$라 하면, 2차 함수에서 $L'(w) = L''\,(w - w^*)$이므로

$$e_{t+1} = e_t - \eta L''e_t = (1 - \eta L'')\,e_t$$

위 예제는 $L'' = 2$, $\eta = 0.1$이므로 배율이 $1 - 0.2 = 0.8$이다. 배율의 절댓값이 1보다 작아야 거리가 줄어든다. 즉 $0 < \eta < 2/L''$일 때 수렴하고, 그보다 크면 거리가 매번 커지는 발산이 일어난다.

  • 안정 조건: $\eta < 2/L''$. 가장 빠른 학습률은 $\eta = 1/L''$(2차 함수에서는 한 걸음에 도착).
  • 실제 손실은 2차 함수가 아니어서 곡률이 위치마다 다르다. 그래서 학습률은 실험으로 정한다. 보통 $10^{-1}, 10^{-2}, 10^{-3}, \dots$처럼 10배 간격으로 시도한다.

손실 지형과 조건수

파라미터 공간의 각 점에 손실값을 높이로 대응시킨 지형을 손실 지형이라 한다. 선형회귀의 MSE는 파라미터에 대한 2차 함수이므로 지형이 그릇 모양이고 바닥이 하나뿐이다. 문제는 그릇의 모양이다.

그릇이 한 방향으로는 가파르고 다른 방향으로는 완만하다고 하자. 학습률은 가장 가파른 방향의 곡률 $\lambda_{\max}$ 때문에 $2/\lambda_{\max}$보다 작아야 한다. 그런데 이 작은 학습률로는 완만한 방향(곡률 $\lambda_{\min}$)으로 거의 움직이지 못한다. 필요한 반복 횟수는 두 곡률의 비에 비례한다.

$$\kappa = \frac{\lambda_{\max}}{\lambda_{\min}} \quad(\text{조건수})$$

여기서 곡률은 손실의 2차 미분 행렬(헤세 행렬)의 고유값이다. 선형회귀에서 헤세 행렬은 $\frac2N X^\top X$로 데이터만으로 정해진다. 4일차의 고유값이 "각 축 방향으로 늘어나는 정도"였듯, 여기서는 "각 방향으로 그릇이 휜 정도"다.

아래 인터랙티브의 지형 메뉴에서 "선형회귀 손실 L(w, b) (원래 입력)"과 "같은 데이터, 표준화한 입력"을 비교한다. 같은 데이터, 같은 모델인데 입력의 단위만 바꿨다. "길쭉한 골짜기"에서는 학습률을 올려 지그재그가 심해지는 것을 확인한다.

특성 스케일링

그릇이 길쭉해지는 가장 흔한 원인은 특징마다 값의 크기가 다른 것이다. 와인 데이터의 프롤린은 수백~천 단위이고 색조는 1 근처다. 가중치를 조금 바꿨을 때 프롤린 쪽은 예측이 크게 변하고(가파름) 색조 쪽은 거의 변하지 않는다(완만함). 특징들의 크기를 맞추는 전처리를 특성 스케일링이라 한다.

방법식결과
표준화$z = \dfrac{x - \mu}{\sigma}$평균 0, 표준편차 1
최소-최대 정규화$z = \dfrac{x - x_{\min}}{x_{\max} - x_{\min}}$범위 [0, 1]

$x = (2, 4, 6, 8)$. 평균 $\mu = 5$, 표준편차 $\sigma = \sqrt{(9 + 1 + 1 + 9)/4} = \sqrt5 \approx 2.236$. 표준화: $(-1.342, -0.447, 0.447, 1.342)$. 최소-최대: $(0, 0.333, 0.667, 1)$. 이상치 100이 추가되면 최소-최대 결과는 원래 네 값이 모두 0~0.06에 몰리고, 표준화는 상대적으로 덜 찌그러진다.

  • 평균과 표준편차는 학습 세트에서만 계산하고, 그 값으로 검증·테스트 세트를 변환한다. 테스트 세트의 통계를 쓰면 테스트 정보가 학습에 새어 들어간다(12일차의 데이터 누수).
  • 스케일링은 예측 성능의 상한을 바꾸지 않는다. 같은 해에 더 빨리 도달하게 할 뿐이다(8일차 프로젝트에서 예측이 그대로임을 확인했다).
  • 신경망의 입력도 항상 스케일링한다. 이미지는 보통 픽셀을 255로 나누거나 채널별로 표준화한다.

배치, 확률적, 미니배치

MSE의 그래디언트는 표본별 그래디언트의 평균이다. 이 평균을 몇 개의 표본으로 계산하느냐에 따라 세 가지 방식이 있다.

$$\nabla L = \frac1N\sum_{i=1}^N\nabla\ell_i \;\approx\; \frac1B\sum_{i\in\mathcal B}\nabla\ell_i$$
방식한 번 갱신에 쓰는 표본특징
배치 경사하강법전체 $N$개정확한 그래디언트, 매끄러운 경로. 한 걸음이 비싸다.
확률적 경사하강법(SGD)무작위 1개한 걸음이 매우 싸지만 경로가 요동친다. 병렬화가 어렵다.
미니배치 경사하강법무작위 $B$개 (보통 32~512)두 장점의 절충. GPU에서 $B$개를 동시에 계산한다. 딥러닝의 표준.

무작위로 고른 표본 묶음을 미니배치라 한다. 미니배치 그래디언트는 전체 그래디언트의 추정치이며 평균은 정확하고 잡음이 섞여 있다. 잡음의 표준편차는 $1/\sqrt B$에 비례하므로 배치를 4배로 키우면 잡음은 절반이 된다. 실무에서는 미니배치 방식도 흔히 SGD라 부른다.

학습 데이터 전체를 한 번 훑는 단위를 에폭, 파라미터를 한 번 갱신하는 단위를 스텝(반복)이라 한다.

학습 표본 $N = 60{,}000$개, 배치 크기 $B = 64$. 한 에폭의 스텝 수는 $\lceil 60000/64\rceil = 938$이다(마지막 배치는 32개). 20에폭이면 18,760번 갱신한다. 같은 20에폭을 배치 경사하강법으로 돌리면 갱신은 20번뿐이다.

  1. 에폭마다 학습 데이터의 순서를 무작위로 섞는다.
  2. 앞에서부터 $B$개씩 잘라 미니배치를 만든다.
  3. 각 미니배치로 그래디언트를 계산하고 한 걸음 갱신한다.
  4. 모든 미니배치를 쓰면 한 에폭이 끝난다. 검증 손실을 기록하고 1로 돌아간다.

데이터가 클래스 순서로 정렬되어 있으면, 섞지 않은 미니배치는 한동안 한 클래스만 보게 되어 파라미터가 그 클래스 쪽으로 쏠렸다가 다음 클래스에서 되돌아간다. 섞으면 각 미니배치가 전체 분포를 대표한다.

학습 곡선 읽기

스텝 또는 에폭에 따른 손실 그래프를 학습 곡선이라 한다. 학습이 잘 되고 있는지를 가장 먼저 알려 주는 신호다. 손실의 범위가 넓으므로 세로축은 보통 로그 눈금으로 그린다.

언제 멈추는가? 정해진 에폭 수를 다 돌거나, 손실의 감소량이 기준(예: 상대 변화 $10^{-6}$) 아래로 떨어지거나, 검증 손실이 더 이상 줄지 않을 때 멈춘다. 마지막 기준은 12일차와 26일차의 조기 종료다.

코드 실습: 경사하강법 직접 구현

8일차의 붓꽃 회귀(꽃잎 길이 → 너비)를 경사하강법으로 다시 푼다. 파라미터는 $\boldsymbol\theta = (b, w)$ 두 개다. 그래디언트는 $\frac2N X^\top(X\boldsymbol\theta - \mathbf y)$이다.

import numpy as np
import matplotlib.pyplot as plt
d = load_data("iris")
x, y = d["X"][:, 2], d["X"][:, 3]
N = len(y)
X1 = np.c_[np.ones(N), x]                                    # 원래 입력
theta_ne = np.linalg.solve(X1.T @ X1, X1.T @ y)               # 정답 (정규방정식)
L_star = ((X1 @ theta_ne - y) ** 2).mean()

def gd(X, y, lr, steps):
    th = np.zeros(X.shape[1]); hist = []
    for _ in range(steps):
        grad = 2 / len(y) * X.T @ (X @ th - y)
        th = th - lr * grad
        hist.append(((X @ th - y) ** 2).mean())
    return th, np.array(hist)

H = 2 / N * X1.T @ X1                                          # 헤세 행렬
lam = np.linalg.eigvalsh(H)
print("곡률(고유값):", lam.round(3), " 조건수:", (lam[1] / lam[0]).round(1),
      " 학습률 상한 2/λmax:", (2 / lam[1]).round(4))
plt.figure(figsize=(5.6, 3.4))
for lr in [0.01, 0.05, 0.056]:
    th, h = gd(X1, y, lr, 300)
    plt.semilogy(np.clip(h - L_star, 1e-12, 1e3), label=f"η = {lr}")
    print(f"η = {lr}: θ = {th.round(4)}, 300스텝 후 L − L* = {h[-1] - L_star:.2e}")
plt.xlabel("스텝")
plt.ylabel("L − L* (로그)")
plt.legend()
plt.grid(alpha=.3)
plt.title("원래 입력")
plt.show()

원래 입력에서는 조건수가 약 105이고, 학습률 상한 0.0554를 조금만 넘겨도(0.056) 발산한다. 이제 꽃잎 길이를 표준화한다.

xs = (x - x.mean()) / x.std()
Xs = np.c_[np.ones(N), xs]
lam_s = np.linalg.eigvalsh(2 / N * Xs.T @ Xs)
print("표준화 후 곡률:", lam_s.round(3), " 조건수:", (lam_s[1] / lam_s[0]).round(2))
for lr in [0.1, 0.5]:
    th, h = gd(Xs, y, lr, 30)
    k = np.argmax(h < L_star * 1.01) + 1
    print(f"η = {lr}: 손실이 최솟값의 1% 이내에 들기까지 {k}스텝")

표준화하면 두 곡률이 모두 2가 되어 그릇이 완전히 둥글어진다. $\eta = 1/2$이면 한 걸음에 바닥에 도착한다. 원래 입력에서는 $\eta = 0.05$로 300스텝을 돌아야 $L - L^*$가 $10^{-6}$ 수준이 되던 일이다. 마지막으로 표준화된 지형 위에서 배치 크기에 따른 경로를 그린다.

bs = np.linspace(-0.2, 2.6, 120); ws = np.linspace(-0.5, 1.9, 120)
BB, WW = np.meshgrid(bs, ws)
# 격자 위 모든 (b, w)의 손실
LL = ((BB[..., None] + WW[..., None] * xs - y) ** 2).mean(axis=-1)
# 표준화 입력의 최적 (b, w)
theta_s = np.linalg.solve(Xs.T @ Xs, Xs.T @ y)
def minibatch_path(B, lr, epochs, seed=0):
    rng = np.random.default_rng(seed); th = np.array([0.0, 1.6]); path = [th.copy()]
    for _ in range(epochs):
        idx = rng.permutation(N)
        for s in range(0, N, B):
            b = idx[s:s + B]
            th = th - lr * 2 / len(b) * Xs[b].T @ (Xs[b] @ th - y[b])
            path.append(th.copy())
    return np.array(path)
fig, axs = plt.subplots(1, 3, figsize=(10, 3.4), sharey=True)
for ax, (B, lr) in zip(axs, [(N, 0.1), (10, 0.05), (1, 0.02)]):
    cs = ax.contour(BB, WW, LL, levels=[0.05, 0.1, 0.2, 0.4, 0.8, 1.6, 3.2],
                    cmap="Blues_r")
    ax.clabel(cs, fmt="%g", fontsize=7)
    P = minibatch_path(B, lr, 2)
    ax.plot(P[:, 0], P[:, 1], ".-", color="C3", ms=2, lw=.8)
    ax.plot(*theta_s, "k*", ms=12)
    ax.set_title(f"B = {B}, 2에폭 = {len(P) - 1}스텝"); ax.set_xlabel("b")
axs[0].set_ylabel("w"); plt.tight_layout(); plt.show()

배치 경사하강법(B = 150)은 2에폭 동안 2걸음만 간다. 미니배치(B = 10)는 30걸음을 가며 약간 흔들리고, SGD(B = 1)는 300걸음을 가지만 바닥 근처에서 계속 요동친다. 요동은 학습률을 줄이면 작아진다(23일차의 학습률 스케줄).

정리

  • 경사하강법: $\boldsymbol\theta \leftarrow \boldsymbol\theta - \eta\nabla L$. 정규방정식을 쓸 수 없는 큰 모델·비선형 모델의 기본 해법.
  • 2차 함수에서 오차는 매 걸음 $(1 - \eta L'')$배. $\eta < 2/L''$이면 수렴, 넘으면 발산.
  • 조건수 $\kappa = \lambda_{\max}/\lambda_{\min}$이 크면 길쭉한 그릇에서 지그재그로 느리게 수렴한다. 표준화로 $\kappa$를 줄인다.
  • 스케일링 통계는 학습 세트에서만 계산한다.
  • 미니배치 SGD가 딥러닝의 표준. 에폭 = 데이터 한 바퀴, 스텝 = 갱신 한 번. 학습 곡선으로 학습률을 진단한다.

연습 문제

  1. $L(w) = (w-2)^2$, $w_0 = -1$, $\eta = 0.25$로 세 걸음을 손으로 계산하라. 거리의 배율은 얼마인가?
    풀이

    배율 $1 - 0.25\times2 = 0.5$. $w$: $-1 \to 0.5 \to 1.25 \to 1.625$. 거리 $3 \to 1.5 \to 0.75 \to 0.375$로 매번 절반이 된다.

  2. $L(w) = 5w^2$에서 (a) 수렴하는 $\eta$의 범위, (b) 한 걸음에 도착하는 $\eta$, (c) $\eta = 0.2$와 $\eta = 0.3$에서 일어나는 일을 설명하라.
    풀이

    $L'' = 10$. (a) $0 < \eta < 0.2$. (b) $\eta = 0.1$이면 배율 0. (c) $\eta = 0.2$이면 배율 $-1$: $w$가 $+a, -a, +a, \dots$로 영원히 진동한다. $\eta = 0.3$이면 배율 $-2$: 매번 부호가 바뀌며 두 배씩 멀어져 발산한다.

  3. 2차원 손실 $L(w_1, w_2) = w_1^2 + 25w_2^2$에서 학습률의 상한은 얼마이고, 그 상한 근처의 학습률로 $w_1$ 방향의 거리가 $1/100$이 되려면 대략 몇 걸음이 필요한가?
    풀이

    곡률은 2와 50. 상한 $\eta < 2/50 = 0.04$. $\eta = 0.039$이면 $w_1$ 방향 배율은 $1 - 0.078 = 0.922$, $0.922^k = 0.01$에서 $k = \ln0.01/\ln0.922 \approx 57$걸음. 조건수 25가 걸음 수를 늘린다. 같은 그릇을 $w_2$ 축으로 5배 늘려(스케일링) 둥글게 만들면 $\eta = 0.5$로 한 걸음이면 된다.

    w = np.array([1.0, 1.0]); lr = 0.039
for k in range(1, 200):
    w = w - lr * np.array([2 * w[0], 50 * w[1]])
    if abs(w[0]) < 0.01: print(k, w); break
  4. 표본 $N = 50{,}000$개를 배치 크기 128로 10에폭 학습한다. 총 스텝 수는? 한 스텝에 0.05초가 걸리면 학습 시간은?
    풀이

    에폭당 $\lceil 50000/128\rceil = 391$스텝, 10에폭 3,910스텝, 약 196초(3분 16초).

미니 프로젝트: 경사하강법 회귀와 학습률 실험

8일차의 와인 플라보노이드 회귀를 정규방정식 없이 경사하강법으로 푼다. 그래디언트를 수치 미분으로 검증하고, 학습률·입력 스케일·배치 크기가 수렴에 주는 영향을 측정한다. 이론으로 계산한 학습률 상한이 실험과 맞는지 확인한다.

  1. 데이터 준비. 8일차와 같은 분할(시드 0)을 쓴다. 학습 세트 통계로 표준화하고 1의 열을 붙인다. 비교용 정답은 정규방정식으로 구한다. 
    import numpy as np
import matplotlib.pyplot as plt
d = load_data("wine")
names = d["feature_names_ko"]; A_all = d["X"].astype(float)
t = names.index("플라보노이드")
y = A_all[:, t]; X = np.delete(A_all, t, axis=1)
rng = np.random.default_rng(0)
idx = rng.permutation(len(y)); cut = int(0.8 * len(y)); tr, te = idx[:cut], idx[cut:]
mu, sd = X[tr].mean(axis=0), X[tr].std(axis=0)
design = lambda M: np.c_[np.ones(len(M)), M]
Ztr, Zte = design((X[tr] - mu) / sd), design((X[te] - mu) / sd)
ytr, yte = y[tr], y[te]
theta_ne = np.linalg.solve(Ztr.T @ Ztr, Ztr.T @ ytr)
mse = lambda th, Z, t_: ((Z @ th - t_) ** 2).mean()
L_star = mse(theta_ne, Ztr, ytr)
print("학습", Ztr.shape, " 최소 학습 MSE L* =", round(L_star, 4))
  2. 그래디언트 검증. 해석적 그래디언트 함수를 만들고 5일차의 수치 미분과 비교한다. 두 값의 상대 오차가 $10^{-6}$ 이하이면 구현이 맞다. 
    def grad(th, Z, t_):
    return 2 / len(t_) * Z.T @ (Z @ th - t_)                # TODO 확인: (13,) 형상

def num_grad(f, v, h=1e-5):
    v = np.array(v, dtype=float); g = np.zeros_like(v)
    for i in range(len(v)):
        old = v[i]
        v[i] = old + h; fp = f(v)
        v[i] = old - h; fm = f(v)
        v[i] = old; g[i] = (fp - fm) / (2 * h)
    return g

th0 = np.random.default_rng(1).normal(size=Ztr.shape[1])
ga, gn = grad(th0, Ztr, ytr), num_grad(lambda v: mse(v, Ztr, ytr), th0)
print("상대 오차:", np.abs(ga - gn).max() / np.abs(ga).max())
  3. 학습 함수. 배치 크기 B를 받는 미니배치 경사하강법을 만든다. B가 학습 표본 수와 같으면 배치 경사하강법이 된다. 에폭마다 학습 MSE를 기록한다. 
    def fit_gd(Z, t_, lr, epochs, B=None, seed=0):
    n = len(t_); B = B or n
    r = np.random.default_rng(seed)
    th = np.zeros(Z.shape[1]); hist = []
    for ep in range(epochs):
        order = r.permutation(n)                              # 에폭마다 섞기
        for s in range(0, n, B):
            b = order[s:s + B]
            th = th - lr * grad(th, Z[b], t_[b])              # TODO 확인: 한 스텝
        hist.append(mse(th, Z, t_))
    return th, np.array(hist)

th, h = fit_gd(Ztr, ytr, lr=0.1, epochs=300)
print("θ_GD와 θ_정규방정식의 최대 차이:", np.abs(th - theta_ne).max().round(6))
print("테스트 MSE  GD:", round(mse(th, Zte, yte), 4), "  정규방정식:",
      round(mse(theta_ne, Zte, yte), 4))
  4. 학습률 상한 실험. 헤세 행렬 $\frac2N Z^\top Z$의 최대 고유값으로 상한 $2/\lambda_{\max}$를 계산한다. 학습률을 바꿔 가며 200스텝 후의 손실을 그리고, 발산이 시작되는 지점이 이론값과 맞는지 확인하라. 
    lam = np.linalg.eigvalsh(2 / len(ytr) * Ztr.T @ Ztr)
eta_max = 2 / lam[-1]
print(f"λmax = {lam[-1]:.3f}, λmin = {lam[0]:.3f}, 조건수 = {lam[-1] / lam[0]:.1f}, 이론 상한 = {eta_max:.4f}")

final = []
with np.errstate(over="ignore", invalid="ignore"):

final = np.nan_to_num(np.array(final), nan=1e6, posinf=1e6)
plt.figure(figsize=(5.6, 3.4))

plt.axvline(eta_max, color="C3", ls="--", label=f"이론 상한 {eta_max:.3f}")

plt.ylabel("200스텝 후 L − L*")
plt.legend()

참고 답안과 해설
  • 2단계: 상대 오차는 $10^{-10}$ 수준이다. 그래디언트를 새로 구현할 때마다 이 검사를 하는 습관이 20일차의 신경망 구현에서 큰 도움이 된다.
  • 3단계: 표준화 입력과 $\eta = 0.1$이면 300에폭(배치 GD이므로 300스텝) 후 정규방정식 해와 소수 다섯째 자리 이하에서 일치한다.
  • 4단계: 이론 상한은 약 0.256이다. 0.243까지는 학습률이 클수록 200스텝 후의 손실이 작고, 0.312에서는 손실이 $10^{62}$ 수준으로 폭발한다. 발산이 시작되는 경계가 이론값과 일치한다. 2차 함수가 아닌 실제 신경망에서도 "어느 학습률을 넘으면 갑자기 발산한다"는 모양은 같으며, 보통 그 경계의 절반쯤에서 학습률을 고른다.
  • 5단계: 원래 입력의 조건수는 약 $4\times10^8$이고 학습률 상한은 $10^{-6}$ 수준이다. 이 학습률로는 프롤린 방향만 움직이고 나머지 방향은 거의 움직이지 않아, 5000스텝 후에도 손실이 최솟값의 몇 배에 머문다. 표준화 입력은 수십 스텝이면 끝난다.
  • 6단계: 1에폭만 보면 SGD(B = 1)가 142번 갱신하므로 가장 빨리 떨어진다. 그러나 잡음 때문에 최솟값 근처에서 계속 흔들려 30에폭 후 값은 배치 GD가 더 낮다. 미니배치는 그 중간이다. 큰 데이터에서는 배치 GD의 한 걸음이 너무 비싸서 미니배치가 시간 대비 가장 효율적이다.
