• MLP의 순전파를 층별로 계산하고, 역전파를 위해 무엇을 저장해야 하는지 설명할 수 있다.
  • 배치 행렬곱 $Z = XW + \mathbf b$로 여러 표본을 한 번에 계산하고 브로드캐스팅을 설명할 수 있다.
  • 각 텐서의 형상을 추적하고, 형상 오류를 진단할 수 있다.
  • 층별 파라미터 수, FLOPs, 활성값 메모리를 계산할 수 있다.
  • 층을 객체로 설계해 순전파 프레임워크를 만들 수 있다.

순전파

입력에서 출력 방향으로 각 층의 계산을 차례로 수행하는 것을 순전파라 한다. 16일차의 MLP라면 다음 순서다.

입력 $X$
$Z_1 = XW_1 + \mathbf b_1$
$A_1 = \mathrm{ReLU}(Z_1)$
$Z_2 = A_1W_2 + \mathbf b_2$
$P = \mathrm{softmax}(Z_2)$
손실 $L$

순전파는 예측을 내는 것뿐 아니라 역전파의 준비이기도 하다. 18일차에서 보듯 각 층의 기울기를 계산하려면 그 층의 입력($X$, $A_1$)과 활성화 이전 값($Z_1$)이 필요하다. 그래서 순전파는 중간값을 버리지 않고 저장(캐시)해 둔다. 학습할 때 메모리를 많이 쓰는 주된 이유가 이 저장이다.

한 표본에서 배치로

표본 하나 $\mathbf x$(형상 $(d,)$)에 대해 은닉층은 $\mathbf z = \mathbf xW + \mathbf b$를 계산한다. $W$는 $(d, h)$이고, $\mathbf z$는 $(h,)$다. $N$개의 표본을 행으로 쌓은 $X$(형상 $(N, d)$)에 같은 식을 쓰면 모든 표본을 한 번에 계산한다.

$$\underbrace{Z}_{(N,\,h)} = \underbrace{X}_{(N,\,d)}\;\underbrace{W}_{(d,\,h)} + \underbrace{\mathbf b}_{(h,)}$$

$XW$의 $i$번째 행은 $i$번째 표본의 결과이고, $\mathbf b$는 2일차의 브로드캐스팅으로 모든 행에 더해진다. 반복문 대신 행렬곱 하나로 계산하므로 빠르고(2일차의 벡터화), GPU는 이 행렬곱을 수천 개의 코어에 나눠 동시에 처리한다.

$X = \begin{bmatrix}1 & 2\\ 0 & -1\end{bmatrix}$ (표본 2개, 특징 2개), $W = \begin{bmatrix}1 & 0 & -1\\ 2 & 1 & 0\end{bmatrix}$ (뉴런 3개), $\mathbf b = (0, -1, 1)$.

$$XW = \begin{bmatrix}5 & 2 & -1\\ -2 & -1 & 0\end{bmatrix},\qquad Z = XW + \mathbf b = \begin{bmatrix}5 & 1 & 0\\ -2 & -2 & 1\end{bmatrix},\qquad \mathrm{ReLU}(Z) = \begin{bmatrix}5 & 1 & 0\\ 0 & 0 & 1\end{bmatrix}$$

첫 행은 첫 표본, 둘째 행은 둘째 표본의 은닉 표현이다. $\mathbf b$는 두 행에 똑같이 더해졌다.

교과서에 따라 $\mathbf z = W\mathbf x + \mathbf b$(열벡터, $W$는 $(h, d)$)로 쓰기도 한다. 둘은 전치 관계다. 이 강의와 NumPy·PyTorch 코드는 "표본 = 행" 규약을 쓴다. PyTorch의 nn.Linear는 내부에 $(h, d)$ 모양의 가중치를 저장하고 $XW^\top$를 계산하지만, 결과의 형상 $(N, h)$는 같다(29일차).

완전연결층

$Z = XW + \mathbf b$를 계산하는 층을 완전연결층(선형층, dense layer)이라 한다. 입력의 모든 원소가 출력의 모든 원소에 가중치 하나로 연결되어 있다는 뜻이다. 입력 크기 $d_{\text{in}}$, 출력 크기 $d_{\text{out}}$이면

$$\text{파라미터 수} = \underbrace{d_{\text{in}}\times d_{\text{out}}}_{W} + \underbrace{d_{\text{out}}}_{\mathbf b}$$

이다. 배치 크기 $N$과 무관하다. 같은 가중치를 모든 표본이 함께 쓰기 때문이다. 활성화 함수 층(ReLU 등)은 파라미터가 없다.

형상 추적

신경망 코드에서 가장 흔한 오류는 형상 오류다. 층을 지날 때마다 각 텐서의 형상을 적어 보는 습관이 디버깅 시간을 크게 줄인다. 규칙은 하나다. 행렬곱 $(a, b)\,@\,(c, d)$는 $b = c$일 때만 가능하고 결과는 $(a, d)$다.

텐서형상손글씨 MLP (배치 32)
입력 $X$$(N, d)$(32, 64)
$W_1$, $\mathbf b_1$$(d, h)$, $(h,)$(64, 32), (32,)
$Z_1$, $A_1$$(N, h)$(32, 32)
$W_2$, $\mathbf b_2$$(h, K)$, $(K,)$(32, 10), (10,)
$Z_2$, $P$$(N, K)$(32, 10)
레이블 $\mathbf y$$(N,)$ 정수(32,)
  • (N,)과 (N, 1)을 섞으면 브로드캐스팅이 조용히 (N, N)을 만든다. 예: y.shape = (32,), p.shape = (32, 1)이면 p - y는 (32, 32)다. 오류 없이 잘못된 손실이 나온다.
  • 입력 하나를 넣을 때 (64,)가 아니라 (1, 64)로 바꿔(x[None, :]) 배치 차원을 유지하는 편이 안전하다.
  • 이미지를 MLP에 넣으려면 (N, 8, 8)을 (N, 64)로 펴야 한다(reshape(N, -1)).

연산량과 메모리

행렬곱 $(N, d)\,@\,(d, h)$는 결과 원소 $N\times h$개마다 곱셈 $d$번과 덧셈 약 $d$번을 하므로 약 $2Ndh$번의 부동소수점 연산이 필요하다. 이 횟수를 FLOPs라 한다. 신경망의 계산 비용은 거의 전부 행렬곱이므로, 순전파 FLOPs는 각 선형층의 $2N d_{\text{in}}d_{\text{out}}$을 더해 어림한다. 역전파는 순전파의 약 2배가 든다(18일차).

784 → 256 → 128 → 10, 배치 64. 순전파 FLOPs $= 2\times64\times(784\cdot256 + 256\cdot128 + 128\cdot10) = 2\times64\times234{,}752 \approx 3.0\times10^7$. 파라미터 235,146개는 float32(4바이트)로 약 0.92MB. 저장할 활성값은 $64\times(256 + 128 + 10) = 25{,}216$개(약 0.1MB). 학습 1에폭(6만 장)의 순전파는 약 $2.8\times10^{10}$ FLOPs로, 초당 수조 번 계산하는 GPU에서는 순식간이다.

규모 감각: GPT-3는 파라미터 1750억 개로, 16비트로 저장해도 350GB다. 토큰 하나를 처리하는 순전파가 약 $2\times$파라미터 수 $= 3.5\times10^{11}$ FLOPs다. 거대 모델의 비용도 이 강의의 $2Ndh$ 계산으로 어림할 수 있다.

출력층과 손실

분류 신경망의 마지막 선형층 출력 $Z_L$이 로짓이다. 11일차와 똑같이 소프트맥스로 확률 $P$를 만들고, 정답 클래스의 $-\ln p$를 평균해 손실을 구한다. 계산은 로그-합-지수 트릭으로 한다. 무작위로 초기화한 신경망의 첫 손실은 $\ln K$ 근처여야 한다(10클래스면 2.30). 크게 다르면 초기화나 입력 스케일이 잘못된 것이다.

층을 객체로 설계하기

층이 많아지면 함수 하나로 순전파를 쓰기 어렵다. 각 층을 "파라미터와 순전파 방법을 가진 객체"로 만들고, 층들을 리스트로 이어 붙인 컨테이너가 차례로 호출하게 하면 어떤 구조든 같은 방식으로 만들 수 있다. PyTorch의 nn.Module과 nn.Sequential이 이 설계다(29일차).

class Linear:
    def __init__(self, d_in, d_out, rng):
        self.W = rng.normal(0, np.sqrt(2 / d_in), size=(d_in, d_out))
        self.b = np.zeros(d_out)
    def forward(self, X):
        self.X = X                      # 역전파에 쓸 입력을 저장 (18일차)
        return X @ self.W + self.b

class Sequential:
    def __init__(self, *layers): self.layers = layers
    def forward(self, X):
        for layer in self.layers:
            X = layer.forward(X)
        return X

가중치를 표준편차 $\sqrt{2/d_{\text{in}}}$인 정규분포로 초기화하는 이유는 24일차에서 다룬다(He 초기화). 지금은 "층을 지나도 값의 크기가 대략 유지되게 하는 크기"로 기억한다.

코드 실습: 손글씨 숫자 MLP의 순전파

64 → 32 → 10 MLP를 무작위 가중치로 만들고 손글씨 숫자 전체에 순전파한다. 층마다 형상을 출력한다.

import numpy as np
import time
d = load_data("digits")
X, y = d["X"].astype(float) / 16, d["y"]
rng = np.random.default_rng(0)
W1, b1 = rng.normal(0, np.sqrt(2 / 64), (64, 32)), np.zeros(32)
W2, b2 = rng.normal(0, np.sqrt(2 / 32), (32, 10)), np.zeros(10)

def softmax(Z):
    Z = Z - Z.max(axis=1, keepdims=True); E = np.exp(Z)
    return E / E.sum(axis=1, keepdims=True)

Z1 = X @ W1 + b1;  A1 = np.maximum(0, Z1)
Z2 = A1 @ W2 + b2; P = softmax(Z2)
for name, T in [("X", X), ("W1", W1), ("Z1", Z1), ("A1", A1), ("W2", W2), ("Z2", Z2), ("P", P)]:
    print(f"{name:3s} {str(T.shape):10s}")
print("확률 행 합 (처음 3개):", P.sum(axis=1)[:3])
loss = -np.log(P[np.arange(len(y)), y]).mean()
print(f"손실 {loss:.4f} (ln 10 = {np.log(10):.4f}),  정확도 {(P.argmax(1) == y).mean():.3f}")

학습하지 않은 신경망의 손실은 $\ln10$ 근처이고 정확도는 찍기 수준(약 10%)이다. 이 기준선에서 학습이 시작된다(20일차). 이번에는 표본마다 반복문으로 계산한 결과와 배치 계산이 같은지, 속도는 얼마나 다른지 잰다.

def forward_one(x):
    return np.maximum(0, x @ W1 + b1) @ W2 + b2
t0 = time.perf_counter()
out_loop = np.array([forward_one(x) for x in X])
t_loop = time.perf_counter() - t0
t0 = time.perf_counter()
out_batch = np.maximum(0, X @ W1 + b1) @ W2 + b2
t_batch = time.perf_counter() - t0
print("결과 일치:", np.allclose(out_loop, out_batch))
print(f"반복문 {t_loop * 1000:.2f} ms, 배치 {t_batch * 1000:.2f} ms, 약 {t_loop / t_batch:.0f}배")

마지막으로 FLOPs를 세는 함수를 만든다. 형상 오류를 일부러 내 보고 오류 메시지를 읽는다.

def mlp_cost(sizes, N):
    params = sum(a * b + b for a, b in zip(sizes[:-1], sizes[1:]))
    flops = sum(2 * N * a * b for a, b in zip(sizes[:-1], sizes[1:]))
    return params, flops
for sizes in [(64, 32, 10), (784, 256, 128, 10)]:
    p, f = mlp_cost(sizes, N=64)
    print(f"{sizes}: 파라미터 {p:,}, 배치 64 순전파 FLOPs {f:,}")
try:
    X @ W2                                                  # (1797, 64) @ (32, 10)
except ValueError as e:
    print("형상 오류:", e)

정리

  • 순전파 = 입력에서 출력으로 층별 계산. 역전파를 위해 중간값을 저장한다.
  • 배치 계산 $Z = XW + \mathbf b$: $X$ $(N, d)$, $W$ $(d, h)$, $\mathbf b$ 브로드캐스팅. 표본 = 행.
  • 완전연결층의 파라미터 $d_{\text{in}}d_{\text{out}} + d_{\text{out}}$, 배치 크기와 무관.
  • 형상 규칙 $(a, b)@(b, c) \to (a, c)$. $(N,)$과 $(N, 1)$의 혼용을 조심.
  • FLOPs $\approx 2Nd_{\text{in}}d_{\text{out}}$의 합. 무작위 초기화의 첫 손실은 $\ln K$ 근처.

확인 문제

연습 문제

  1. 입력 이미지 28×28 흑백을 받아 은닉 512, 512, 출력 10인 MLP의 각 층 가중치 형상과 총 파라미터 수를 구하라.
    풀이

    입력은 펴서 784. $W_1$ (784, 512), $W_2$ (512, 512), $W_3$ (512, 10). 파라미터 $401{,}920 + 262{,}656 + 5{,}130 = 669{,}706$.

  2. 연습 1의 신경망에 배치 256을 넣을 때 순전파 FLOPs와 저장할 활성값 수(은닉층과 출력의 출력만)를 구하라.
    풀이

    FLOPs $= 2\times256\times(784\cdot512 + 512\cdot512 + 512\cdot10) = 2\times256\times669{,}184 \approx 3.43\times10^8$. 활성값 $256\times(512 + 512 + 10) = 264{,}704$개. ReLU 이전 값 $Z$도 저장하면 은닉층 몫이 두 배가 된다.

  3. 열벡터 규약 $\mathbf z = W\mathbf x + \mathbf b$에서 $W$의 형상은 무엇이며, 배치 $X$(행 = 표본)에 적용하려면 어떻게 쓰는가?
    풀이

    $W$는 $(h, d)$. 배치에는 $Z = XW^\top + \mathbf b$로 쓴다. PyTorch의 nn.Linear가 정확히 이 형태다.

미니 프로젝트: 층 객체 기반 순전파 프레임워크

층을 객체로 만들고 이어 붙여 신경망을 구성하는 작은 프레임워크를 만든다. 각 층은 순전파와 파라미터 목록을 갖고, 컨테이너는 층별 출력 형상과 파라미터 수, FLOPs를 요약표로 보여 준다. 18~21일차에 역전파와 학습 기능을 붙여 완성한다.

  1. 층 클래스. 모든 층이 forward(X)와 params()를 갖게 한다. 선형층은 He 초기화를 쓴다. 
    import numpy as np
class Layer:
    def forward(self, X): raise NotImplementedError
    def params(self): return {}
class Linear(Layer):
    def __init__(self, d_in, d_out, rng):
        self.W = rng.normal(0, np.sqrt(2 / d_in), size=(d_in, d_out))
        self.b = np.zeros(d_out)
    def forward(self, X):
        self.X = X
        return X @ self.W + self.b                      # TODO 확인: (N, d_out)
    def params(self): return {"W": self.W, "b": self.b}
class ReLU(Layer):
    def forward(self, X):
        self.mask = X > 0                               # 역전파용 (18일차)
        return X * self.mask
class Tanh(Layer):
    def forward(self, X):
        self.out = np.tanh(X)
        return self.out
class Softmax(Layer):
    def forward(self, X):
        Z = X - X.max(axis=1, keepdims=True); E = np.exp(Z)
        return E / E.sum(axis=1, keepdims=True)
  2. 컨테이너와 요약표. Sequential은 층을 차례로 호출한다. summary(N, d)는 가짜 입력을 흘려 보내며 층별 출력 형상, 파라미터 수, 선형층의 FLOPs를 표로 출력한다. 
    class Sequential:
    def __init__(self, *layers): self.layers = list(layers)
    def forward(self, X):
        for layer in self.layers:
            X = layer.forward(X)
        return X
    def summary(self, N, d):
        X = np.zeros((N, d)); tot_p = tot_f = 0
        print(f"{'층':10s} {'출력 형상':14s} {'파라미터':>10s} {'FLOPs':>12s}")
        for layer in self.layers:
            X_in = X; X = layer.forward(X)
            p = sum(v.size for v in layer.params().values())
            f = 2 * X_in.shape[0] * X_in.shape[1] * X.shape[1] if isinstance(layer, Linear) else 0
            tot_p += p; tot_f += f
            print(f"{type(layer).__name__:10s} {str(X.shape):14s} {p:>10,} {f:>12,}")
        print(f"{'합계':10s} {'':14s} {tot_p:>10,} {tot_f:>12,}")
rng = np.random.default_rng(0)
net = Sequential(Linear(64, 32, rng), ReLU(), Linear(32, 10, rng), Softmax())
net.summary(N=32, d=64)
  3. 점검. 손글씨 숫자 전체에 순전파해 확률의 행 합이 1인지, 손실이 $\ln10$ 근처인지 확인한다. 표본 하나를 (1, 64)로 넣은 결과가 배치 결과의 같은 행과 같은지도 확인하라. 
    d = load_data("digits"); X, y = d["X"].astype(float) / 16, d["y"]
P = net.forward(X)
print("형상", P.shape, " 행 합 최대 오차", np.abs(P.sum(1) - 1).max())
print("손실 %.4f (ln 10 = %.4f)" % (-np.log(P[np.arange(len(y)), y]).mean(),
                                    np.log(10)))
p_one = net.forward(X[5:6])                              # (1, 64)
print("단일 표본 = 배치의 같은 행:", np.allclose(p_one[0], P[5]))
  4. 구조 바꾸기. 같은 프레임워크로 64 → 128 → 64 → 10(Tanh) 신경망을 만들어 요약표를 비교하라. 배치 크기를 1과 256으로 바꿔 무엇이 변하고 무엇이 그대로인지 확인한다.

참고 답안과 해설
  • 2단계: 64 → 32 → 10 신경망의 파라미터는 2,080 + 330 = 2,410개, 배치 32의 FLOPs는 131,072 + 20,480 = 151,552다. 형상 추적 인터랙티브의 숫자와 같다.
  • 3단계: 행 합 오차는 $10^{-16}$ 수준, 손실은 약 2.3이다. 단일 표본 결과가 배치의 행과 같다는 것은 신경망이 표본마다 독립적으로 계산된다는 뜻이다(25일차의 배치 정규화는 이 성질을 깨는 예외다).
  • 4단계: 파라미터 수(8,320 + 8,256 + 650 = 17,226)는 배치 크기와 무관하고, 출력 형상의 첫 차원과 FLOPs만 배치 크기에 비례한다.
  • 이 프레임워크에 18일차에 backward를, 20일차에 학습 루프를, 21일차에 옵티마이저와 저장 기능을 붙인다.
