• 시퀀스 데이터의 특징과, 고정 크기 입력 모델(MLP, CNN)로는 다루기 어려운 이유를 안다.
  • RNN의 은닉 상태 갱신 식과 시간 축으로 펼친 계산 그래프를 이해한다.
  • BPTT와 장기 의존성 문제(기울기 소실·폭발)를 수식으로 설명한다.
  • LSTM과 GRU의 게이트 구조가 문제를 해결하는 원리를 이해한다.
  • PyTorch nn.LSTM의 입출력 형상을 정확히 다루고 문자 단위 언어 모델을 학습한다.

1. 시퀀스 데이터

  • 텍스트(단어/문자의 열), 음성, 주가·센서 시계열, DNA, 동영상 프레임.
  • 특징: 길이가 제각각이고, 순서가 의미를 가지며, 멀리 떨어진 원소끼리 관련될 수 있습니다.
  • 과제 유형: 다대일(감정 분류), 일대다(이미지 캡션), 다대다(번역, 품사 태깅), 다음 원소 예측(언어 모델).

2. RNN: 같은 층을 시간마다 반복

$$\mathbf h_t = \tanh(W_{xh}\mathbf x_t + W_{hh}\mathbf h_{t-1} + \mathbf b_h),\qquad \mathbf y_t = W_{hy}\mathbf h_t + \mathbf b_y$$

은닉 상태 $\mathbf h_t$는 "지금까지 본 것의 요약"입니다. 핵심은 모든 시점에서 같은 가중치($W_{xh}, W_{hh}$)를 쓴다는 것입니다. CNN이 공간에서 가중치를 공유하듯 RNN은 시간에서 가중치를 공유합니다. 그래서 어떤 길이의 시퀀스든 처리할 수 있습니다.

import numpy as np
rng = np.random.default_rng(0)
D, H, T = 4, 8, 6                       # 입력 차원, 은닉 차원, 시퀀스 길이
Wxh = rng.normal(0, 0.5, (D, H)); Whh = rng.normal(0, 0.5, (H, H)); bh = np.zeros(H)

def rnn_forward(X, h0):
    """X: (T, D) → 모든 시점의 은닉 상태 (T, H)"""
    h, hs = h0, []
    for t in range(len(X)):
        h = np.tanh(X[t] @ Wxh + h @ Whh + bh)    # 같은 가중치를 매 시점 재사용
        hs.append(h)
    return np.stack(hs)

X = rng.normal(size=(T, D))
hs = rnn_forward(X, np.zeros(H))
print("은닉 상태들:", hs.shape, " 마지막 h:", hs[-1].round(2))
print("파라미터 수:", Wxh.size + Whh.size + bh.size, "— 시퀀스 길이와 무관!")

3. BPTT와 장기 의존성 문제

RNN을 시간 축으로 펼치면 아주 깊은 feedforward 망이 되고, 여기에 일반 역전파를 적용하는 것이 BPTT(Backpropagation Through Time)입니다. 시점 $T$의 손실에서 시점 $1$까지 기울기가 가려면

$$\frac{\partial\mathbf h_T}{\partial\mathbf h_1} = \prod_{t=2}^{T}\frac{\partial\mathbf h_t}{\partial\mathbf h_{t-1}} = \prod_{t=2}^{T}\mathrm{diag}(1-\mathbf h_t^2)\,W_{hh}^\top$$

같은 행렬 $W_{hh}$가 $T-1$번 곱해집니다. $W_{hh}$의 가장 큰 특잇값이 1보다 작으면 지수적으로 소실, 크면 폭발합니다. 깊은 CNN보다 훨씬 심합니다. 매번 같은 행렬을 곱하기 때문입니다.

def grad_norms(scale, T=50):
    W = rng.normal(0, scale / np.sqrt(H), (H, H)); h = np.zeros(H); J = np.eye(H); norms = []
    for t in range(T):
        h = np.tanh(rng.normal(size=D) @ Wxh + h @ W)
        J = J @ (W * (1 - h**2)[None, :])          # ∂h_t/∂h_1 누적 (행 벡터 관례)
        norms.append(np.linalg.norm(J))
    return norms
import matplotlib.pyplot as plt
plt.figure(figsize=(7, 3.2))
for s in [0.5, 1.0, 3.0]: plt.semilogy(grad_norms(s), label=f'W 스케일 {s}')
plt.xlabel('거슬러 올라간 시간 스텝'); plt.ylabel('‖∂h_t/∂h_1‖'); plt.legend(); plt.title('BPTT 기울기 크기'); plt.show()
  • 폭발 대책: 기울기 클리핑 clip_grad_norm_(params, 1.0). 간단하고 효과적입니다.
  • 소실 대책: 구조를 바꿔야 합니다 → LSTM, GRU.
  • 실무 팁: 아주 긴 시퀀스는 일정 길이로 잘라서 역전파합니다(Truncated BPTT).

4. LSTM: 기억을 위한 컨베이어 벨트

LSTM(1997)은 별도의 셀 상태 $\mathbf c_t$를 두고, 정보를 넣고 빼는 것을 게이트(0~1 사이 값을 곱하는 밸브)로 조절합니다.

$$\begin{aligned} \mathbf f_t &= \sigma(W_f[\mathbf h_{t-1}, \mathbf x_t] + \mathbf b_f) &&\text{망각 게이트: 이전 기억을 얼마나 남길까}\\ \mathbf i_t &= \sigma(W_i[\mathbf h_{t-1}, \mathbf x_t] + \mathbf b_i) &&\text{입력 게이트: 새 정보를 얼마나 쓸까}\\ \tilde{\mathbf c}_t &= \tanh(W_c[\mathbf h_{t-1}, \mathbf x_t] + \mathbf b_c) &&\text{후보 기억}\\ \mathbf c_t &= \mathbf f_t\odot\mathbf c_{t-1} + \mathbf i_t\odot\tilde{\mathbf c}_t &&\text{셀 상태 갱신}\\ \mathbf o_t &= \sigma(W_o[\mathbf h_{t-1}, \mathbf x_t] + \mathbf b_o),\quad \mathbf h_t = \mathbf o_t\odot\tanh(\mathbf c_t) &&\text{출력 게이트} \end{aligned}$$
🔑 왜 기울기가 살아남는가 셀 상태 갱신 $\mathbf c_t = \mathbf f_t\odot\mathbf c_{t-1} + \dots$는 행렬곱이 아니라 원소별 곱과 덧셈입니다. $\partial\mathbf c_t/\partial\mathbf c_{t-1} = \mathbf f_t$. 망각 게이트가 1에 가까우면 기울기가 거의 그대로 흐릅니다. ResNet의 잔차 연결과 같은 원리이고, 실제로 ResNet보다 18년 먼저 나온 아이디어입니다. 실무 팁: 망각 게이트 편향을 1로 초기화하면 초반 학습이 안정됩니다.

GRU(2014)는 LSTM을 단순화한 것입니다. 게이트가 2개(리셋, 업데이트)이고 셀 상태가 따로 없습니다. 파라미터가 적고 성능은 비슷한 경우가 많습니다.

5. PyTorch nn.LSTM 형상 완전 정복

lstm = nn.LSTM(input_size=32, hidden_size=64, num_layers=2, batch_first=True, dropout=0.2, bidirectional=False)
x = torch.randn(8, 50, 32)                 # (배치, 시퀀스 길이, 입력 차원)  ← batch_first=True
out, (h_n, c_n) = lstm(x)
print(out.shape)    # (8, 50, 64)   마지막 층의 '모든 시점' 은닉 상태
print(h_n.shape)    # (2, 8, 64)    '마지막 시점'의 각 층 은닉 상태 (num_layers, 배치, hidden)
print(c_n.shape)    # (2, 8, 64)    마지막 셀 상태

# 다대일 분류: 마지막 시점 은닉 상태 사용
logits = nn.Linear(64, n_classes)(out[:, -1])         # 또는 h_n[-1]
# 양방향이면 out의 마지막 차원이 2*hidden, h_n은 (num_layers*2, 배치, hidden)
⚠️ batch_first의 함정 PyTorch RNN의 기본값은 batch_first=False, 즉 입력이 (시퀀스, 배치, 특성)입니다. 반면 h_n은 batch_first와 상관없이 항상 (층 수, 배치, 은닉)입니다. 형상 버그의 단골 원인이니 꼭 출력해서 확인하세요. 길이가 다른 시퀀스를 패딩해 묶을 때는 pack_padded_sequence를 쓰면 패딩 부분을 계산에서 뺄 수 있습니다.

6. 문자 단위 언어 모델

텍스트의 다음 글자를 예측하도록 학습시키면, 모델은 철자, 단어, 문법을 스스로 익힙니다. 학습 후 한 글자씩 뽑아 다시 입력하면 새 텍스트를 생성합니다. GPT와 같은 원리(자기회귀 생성)의 작은 버전입니다.

class CharLSTM(nn.Module):
    def __init__(self, vocab_size, emb=64, hidden=256, layers=2):
        super().__init__()
        self.emb = nn.Embedding(vocab_size, emb)                  # 글자 ID → 벡터 (Day 21)
        self.lstm = nn.LSTM(emb, hidden, layers, batch_first=True, dropout=0.2)
        self.head = nn.Linear(hidden, vocab_size)
    def forward(self, idx, state=None):                          # idx: (B, T)
        out, state = self.lstm(self.emb(idx), state)             # (B, T, hidden)
        return self.head(out), state                             # (B, T, vocab) — 모든 시점에서 다음 글자 예측

# 손실: 입력 x = text[i:i+T], 타깃 y = text[i+1:i+T+1]  (한 칸 밀기)
loss = F.cross_entropy(logits.reshape(-1, vocab_size), y.reshape(-1))

@torch.no_grad()
def generate(model, start_ids, n=300, temperature=0.8):
    idx, state, out = torch.tensor([start_ids]), None, list(start_ids)
    for _ in range(n):
        logits, state = model(idx, state)
        probs = F.softmax(logits[0, -1] / temperature, dim=-1)   # 온도: 낮을수록 보수적, 높을수록 창의적
        nxt = torch.multinomial(probs, 1).item()
        out.append(nxt); idx = torch.tensor([[nxt]])
    return out
