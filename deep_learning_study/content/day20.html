• 층별 forward/backward와 파라미터·기울기 인터페이스를 갖춘 MLP를 NumPy로 구현할 수 있다.
  • 전체 파라미터에 대한 기울기 검증을 수행하고 상대 오차를 해석할 수 있다.
  • 미니배치 학습 루프를 작성하고 학습·검증 지표를 기록할 수 있다.
  • 학습 곡선으로 과적합, 과소적합, 학습률 문제를 진단할 수 있다.
  • 검증 세트로 하이퍼파라미터를 비교하고 결과의 잡음을 고려해 결론을 내릴 수 있다.

18일차에 층별 역전파 공식을, 19일차에 자동 미분의 원리를 배웠다. 오늘은 행렬 연산 기반의 MLP를 처음부터 끝까지 구현해 손글씨 숫자를 학습시킨다. 구성 요소는 다섯 가지다.

각 부품을 따로 검증한 뒤 조립한다. 특히 역전파는 학습 전에 반드시 기울기 검증을 통과해야 한다. 역전파에 버그가 있어도 손실은 대개 조금씩 줄어들어서, 학습 결과만 보고는 버그를 알아채기 어렵기 때문이다.

층의 공통 인터페이스

모든 층이 같은 세 가지 메서드를 가지면, 학습 루프와 옵티마이저는 층의 종류를 몰라도 된다.

메서드하는 일선형층ReLU
forward(X)출력 계산, 역전파용 값 저장$XW + \mathbf b$, $X$ 저장$\max(0, X)$, 마스크 저장
backward(G)파라미터 기울기 저장, 입력 기울기 반환$dW = X^\top G$, $d\mathbf b = \sum G$, 반환 $GW^\top$반환 $G\odot\text{마스크}$
params()(파라미터, 기울기) 쌍의 목록$[(W, dW), (\mathbf b, d\mathbf b)]$$[\,]$

갱신은 모든 층의 params()를 돌며 p -= lr * g를 하면 된다. NumPy의 -=는 배열을 제자리에서 바꾸므로 층 안의 가중치가 실제로 갱신된다(p = p - lr * g로 쓰면 새 배열이 만들어져 층의 가중치는 그대로다. 흔한 버그다).

기울기 검증

역전파로 구한 기울기를 수치 미분과 비교해 구현 오류를 찾는 절차를 기울기 검증이라 한다. 두 값의 차이는 크기에 상관없이 비교할 수 있도록 상대 오차로 잰다.

$$\text{상대 오차} = \frac{|g_{\text{역전파}} - g_{\text{수치}}|}{\max(|g_{\text{역전파}}|, |g_{\text{수치}}|, \varepsilon)}$$
최대 상대 오차판단
$10^{-6}$ 이하정상 (꺾인 점이 없는 매끄러운 함수면 $10^{-8}$ 이하까지 내려간다)
$10^{-4}$ 근처의심. ReLU의 꺾인 점($z = 0$) 바로 옆의 원소라면 괜찮을 수 있다.
$10^{-2}$ 이상거의 확실히 버그
  • float64로 한다. float32는 수치 미분 자체가 부정확하다.
  • 작은 신경망, 작은 배치(표본 몇 개)로 한다. 파라미터마다 순전파 2번이 필요하다.
  • 드롭아웃(26일차)처럼 무작위성이 있는 부분은 끄고 한다.
  • 손실에 규제 항이 있으면 그것까지 포함해 검증한다.
  • 모든 파라미터 종류(가중치, 편향, 층마다)를 검사한다. 편향 기울기만 틀리는 버그도 흔하다.

학습 루프

  1. 에폭마다 학습 데이터의 순서를 섞는다(9일차).
  2. 미니배치마다: 순전파 → 손실 → 손실의 backward → 층들을 역순으로 backward → 모든 파라미터를 p -= lr * g로 갱신.
  3. 에폭이 끝나면 학습 세트와 검증 세트 전체에서 손실과 정확도를 계산해 기록한다.
  4. 정해진 에폭 수를 채우면 멈춘다. 검증 성능이 가장 좋았던 시점의 가중치를 따로 저장해 두기도 한다(조기 종료, 26일차).

평가할 때는 기울기 계산이 필요 없다. 이 강의의 NumPy 코드에서는 상관없지만, PyTorch에서는 평가 때 torch.no_grad()로 그래프 기록을 끈다(29일차).

학습 곡선 해석

에폭(또는 스텝)에 따른 학습·검증 손실과 정확도의 그래프를 학습 곡선이라 한다. 9일차에는 학습 손실만으로 학습률을 진단했다. 검증 곡선을 함께 그리면 일반화 상태까지 보인다.

증상진단처방
학습 손실이 줄지 않거나 요동학습률 과대, 버그학습률 ↓, 기울기 검증
학습 손실이 아주 천천히 줄어듦학습률 과소, 초기화 문제학습률 ↑, 초기화 확인(24일차)
둘 다 높은 곳에서 평평과소적합모델 키우기, 더 오래
학습은 계속 ↓, 검증은 ↑과적합규제, 조기 종료, 데이터(26일차)

코드 실습: 손글씨 숫자 MLP

층과 손실을 정의한다. 18일차 프로젝트의 클래스에 params()를 더했다.

import numpy as np
import matplotlib.pyplot as plt
class Linear:
    def __init__(self, d_in, d_out, rng, scale=None):
        # 기본: He 초기화
        std = scale if scale is not None else np.sqrt(2 / d_in)
        self.W = rng.normal(0, std, (d_in, d_out)); self.b = np.zeros(d_out)
        self.dW = np.zeros_like(self.W); self.db = np.zeros_like(self.b)
    def forward(self, X):
        self.X = X; return X @ self.W + self.b
    def backward(self, G):
        # 제자리에 저장
        self.dW[...] = self.X.T @ G; self.db[...] = G.sum(axis=0)
        return G @ self.W.T
    def params(self): return [(self.W, self.dW), (self.b, self.db)]
class ReLU:
    def forward(self, X):
        self.mask = X > 0; return X * self.mask
    def backward(self, G): return G * self.mask
    def params(self): return []
class SoftmaxCE:
    def forward(self, Z, y):
        Z = Z - Z.max(1, keepdims=True)
        self.P = np.exp(Z) / np.exp(Z).sum(1, keepdims=True)
        self.y = y
        return -np.log(self.P[np.arange(len(y)), y]).mean()
    def backward(self):
        G = self.P.copy(); G[np.arange(len(self.y)), self.y] -= 1
        return G / len(self.y)
def build(sizes, seed=0, scale=None):
    rng = np.random.default_rng(seed); layers = []
    for i, (a, b) in enumerate(zip(sizes[:-1], sizes[1:])):
        layers.append(Linear(a, b, rng, scale))
        if i < len(sizes) - 2: layers.append(ReLU())
    return layers
def forward(layers, X):
    for l in layers: X = l.forward(X)
    return X
def backward(layers, G):
    for l in reversed(layers): G = l.backward(G)
print("준비 완료")

학습 전에 기울기를 검증한다. 작은 신경망(64 → 16 → 10)과 표본 8개로 모든 파라미터를 검사한다.

d = load_data("digits"); X, y = d["X"].astype(float) / 16, d["y"]
def grad_check(layers, crit, Xb, yb, h=1e-5):
    crit.forward(forward(layers, Xb), yb); backward(layers, crit.backward())
    worst = 0.0
    for l in layers:
        for p, g in l.params():
            g_bp = g.copy()
            for idx in np.ndindex(p.shape):
                old = p[idx]
                p[idx] = old + h; Lp = crit.forward(forward(layers, Xb), yb)
                p[idx] = old - h; Lm = crit.forward(forward(layers, Xb), yb)
                p[idx] = old
                num = (Lp - Lm) / (2 * h)
                rel = abs(num - g_bp[idx]) / max(abs(num), abs(g_bp[idx]), 1e-12)
                worst = max(worst, rel)
    return worst
small = build([64, 16, 10], seed=3)
n_params = sum(p.size for l in small for p, _ in l.params())
print(f"파라미터 {n_params}개, 최대 상대 오차 "
      f"{grad_check(small, SoftmaxCE(), X[:8], y[:8]):.2e}")

최대 상대 오차가 $10^{-6}$ 이하이므로 통과다. 0이 아닌 것은 수치 미분 자체의 오차와 ReLU의 꺾인 점 때문이다. 검증을 통과했으니 학습한다. 7일차와 같은 층화 분할(테스트 364개)에서 64 → 64 → 10 신경망을 학습률 0.1, 배치 32로 30에폭 학습한다.

rng = np.random.default_rng(0); tr, te = [], []
for k in range(10):
    idx = rng.permutation(np.where(y == k)[0]); cut = int(0.8 * len(idx))
    tr += list(idx[:cut]); te += list(idx[cut:])
tr, te = np.array(tr), np.array(te)

def train(sizes, Xtr, ytr, Xv, yv, lr=0.1, B=32, epochs=30, seed=0, scale=None):
    layers = build(sizes, seed, scale)
    crit = SoftmaxCE()
    r = np.random.default_rng(seed + 100)
    hist = []
    for ep in range(epochs):
        order = r.permutation(len(Xtr))
        for s in range(0, len(order), B):
            i = order[s:s + B]
            crit.forward(forward(layers, Xtr[i]), ytr[i])
            backward(layers, crit.backward())
            for l in layers:
                for p, g in l.params():
                    # TODO 확인: 제자리 갱신
                    p -= lr * g
        tl = crit.forward(forward(layers, Xtr), ytr)
        ta = (crit.P.argmax(1) == ytr).mean()
        vl = crit.forward(forward(layers, Xv), yv)
        va = (crit.P.argmax(1) == yv).mean()
        hist.append((tl, vl, ta, va))
    return layers, np.array(hist)

net, hist = train([64, 64, 10], X[tr], y[tr], X[te], y[te])
fig, axs = plt.subplots(1, 2, figsize=(9.5, 3.3))

정리

  • 층 인터페이스: forward(저장) / backward(파라미터 기울기 저장, 입력 기울기 반환) / params(쌍 목록).
  • 기울기 검증: float64, 작은 망, 상대 오차 $10^{-7}$ 이하면 정상. 학습 전에 반드시.
  • 학습 루프: 섞기 → 미니배치마다 순전파·역전파·제자리 갱신 → 에폭마다 학습·검증 기록.
  • 학습 곡선: 간격이 벌어지면 과적합, 둘 다 높으면 과소적합, 요동·정체는 학습률.
  • 손글씨 숫자에서 MLP 약 97.5%. 이미지 구조를 쓰지 않는 한계가 있다.

확인 문제

연습 문제

  1. 기울기 검증 함수로, 선형층의 backward에서 db를 G.mean(axis=0)으로 잘못 구현했을 때의 상대 오차를 구하라. 어떤 파라미터에서 오차가 나타나는가?
    풀이

    편향 기울기가 배치 크기(8)로 한 번 더 나뉘어 상대 오차가 약 0.875(= 1 − 1/8)가 된다. 가중치 기울기는 정상이므로, 모든 파라미터 종류를 검사해야 이런 버그를 잡는다.

  2. 학습률 1.0으로 학습했더니 학습 손실이 30에폭 후 0.003까지 떨어졌다. 이것이 좋은 신호인가? 무엇을 함께 봐야 하는가?
    풀이

    학습 손실만으로는 알 수 없다. 검증 손실·정확도를 함께 봐야 한다. 학습 손실이 거의 0이면 학습 데이터를 외웠을 가능성이 높고, 검증 손실이 오르고 있다면 과적합이다.

  3. 배치 크기 8과 128로 같은 30에폭을 학습하면 스텝 수는 각각 몇 번인가(학습 표본 1143개)? 같은 에폭에서 작은 배치가 더 좋은 결과를 낸다면 이유는 무엇인가?
    풀이

    $\lceil1143/8\rceil = 143$, $\lceil1143/128\rceil = 9$이므로 4,290스텝 대 270스텝. 같은 학습률이면 작은 배치가 16배 많이 갱신하므로 같은 에폭에서 더 멀리 간다. 큰 배치는 학습률을 키우거나(23일차) 더 오래 학습해야 비슷해진다.

    layers, h = train(sizes, Xa, ya, Xv, yv, lr=0.1, epochs=20)
    n_p = sum(p.size for l in layers for p, _ in l.params())
    print(f"{str(sizes):22s} 파라미터 {n_p:6,}  학습 정확도 {h[-1, 2]:.3f}  검증 "
          f"정확도 {h[-1, 3]:.3f}")
  4. 배치 크기와 초기화. 배치 8, 32, 128(같은 20에폭)과, 가중치 표준편차 0.001, 0.01, He($\sqrt{2/d}$), 1.0을 비교한다. 초기화는 첫 에폭 뒤의 학습 손실도 본다. 
    import time
for B in [8, 32, 128]:
    t0 = time.perf_counter()
    _, h = train([64, 64, 10], Xa, ya, Xv, yv, lr=0.1, B=B, epochs=20)
    print(f"배치 {B:3d}: 검증 정확도 {h[-1, 3]:.3f}, 시간 "
          f"{time.perf_counter() - t0:.2f}초")
for sc in [0.001, 0.01, None, 1.0]:
    _, h = train([64, 64, 10], Xa, ya, Xv, yv, lr=0.1, epochs=20, scale=sc)
    print(f"초기화 {('He' if sc is None else sc)!s:6s}: 1에폭 뒤 학습 손실 "
          f"{h[0, 0]:.3f}, 검증 정확도 {h[-1, 3]:.3f}")
  5. 최종 모델. 위 결과로 설정을 하나 고르고(예: 64 → 64 → 10, 학습률 0.5, 배치 32, He 초기화), 학습 세트 전체(학습 + 검증)로 다시 학습한 뒤 테스트 세트로 한 번 평가한다. 
    final, h = train([64, 64, 10], X[tr], y[tr], X[te], y[te], lr=0.5, B=32, epochs=20)
print(f"최종 테스트 정확도 {h[-1, 3]:.3f}")
참고 답안과 해설
  • 1단계: 검증 세트는 290개 안팎이라 표본 1개가 약 0.34%다. 정확도 차이 1% 이하(3개 이하)는 잡음일 수 있다. 시드를 바꿔 여러 번 실행하거나 교차검증(12일차)으로 확인해야 확실하다.
  • 2단계: 학습률 0.01은 20에폭으로는 크게 부족하다(학습 손실 약 0.74, 검증 약 89%). 0.1~1.0은 모두 96% 근처이며, 학습률이 클수록 학습 손실이 빨리 0에 가까워진다. 이 데이터에서는 1.0도 발산하지 않지만, 더 큰 모델이나 데이터에서는 안정 범위가 좁아진다.
  • 3단계: 크기와 깊이를 바꿔도 검증 정확도는 95.5~96% 범위에서 거의 같다. 큰 모델은 학습 정확도가 100%에 더 가깝지만 검증은 그만큼 오르지 않는다. 8×8 숫자에는 작은 모델로 충분하다.
  • 4단계: 같은 에폭에서 배치 8이 가장 좋고 가장 느리다(스텝이 많다). 초기화 0.001은 첫 에폭 뒤에도 손실이 ln 10 ≈ 2.30에 머문다. 신호가 층을 지나며 거의 사라져 기울기도 작기 때문이다(24일차). 표준편차 1.0은 첫 출력이 너무 커서 불안정하게 시작한다. He 초기화가 가장 빨리 출발한다.
  • 5단계: 테스트 정확도는 97% 근처다. 최종 숫자보다, 테스트를 마지막에 한 번만 열었다는 절차가 중요하다.
