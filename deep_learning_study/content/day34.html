• 전이학습이 적은 데이터에서 잘 동작하는 이유를 특징의 일반성으로 설명할 수 있다.
  • 특징 추출과 미세조정을 구현하고, 데이터의 양과 유사성에 따라 고를 수 있다.
  • 차등 학습률, 얼린 배치 정규화 등 미세조정의 실무 요령을 적용할 수 있다.
  • 레이블을 지키는 증강을 고르고, Mixup과 CutMix를 구현할 수 있다.
  • 꽃 102종을 클래스당 10장으로 학습하는 실험을 설계하고 방법들을 비교할 수 있다.

왜 전이학습인가

32, 33일차의 CNN은 CIFAR-10 학습 이미지 5만 장으로 처음부터 학습했다. 실제 문제에는 이만한 데이터가 없는 경우가 많다. 오늘의 Flowers102는 꽃 102종을 분류하는데 학습 이미지가 클래스당 10장, 모두 1,020장이다. 파라미터 1,100만 개의 ResNet-18을 1,020장으로 처음부터 학습하면 심하게 과적합한다.

32일차에 본 특징의 계층이 해법을 준다. ImageNet(120만 장, 1000클래스)으로 학습한 CNN의 앞쪽 층은 경계, 색, 질감을, 중간 층은 모양과 부분을 찾는다. 이런 특징은 ImageNet에만 쓸모 있는 것이 아니라 꽃, 의료 영상, 위성 사진에도 쓸모 있다. 큰 데이터로 학습한 모델의 지식을 다른 문제로 옮겨 쓰는 것을 전이학습이라 한다. 현대 딥러닝에서 가장 흔한 작업 방식이다. 7주차의 언어 모델도 같은 원리로 미리 학습한 뒤 고쳐 쓴다.

특징 추출과 미세조정

사전학습 모델을 쓰는 방법은 두 가지다.

  • 특징 추출. 몸통을 얼리고(requires_grad = False) 새 머리만 학습한다. 몸통은 고정된 특징 추출기가 된다. 학습할 파라미터가 적어(ResNet-18이면 $512 \times 102 + 102 = 52{,}326$개) 데이터가 아주 적어도 과적합이 덜하고 빠르다.
  • 미세조정. 사전학습 가중치에서 출발해 몸통까지 함께 학습한다. 특징이 새 문제에 맞게 조금씩 바뀌므로 보통 더 정확하다. 대신 학습률이 크면 사전학습으로 얻은 특징이 빠르게 망가진다. 새 문제에 맞추느라 이전에 배운 것을 잃는 현상을 파국적 망각이라 한다.
새 데이터가 사전학습 데이터와 비슷함많이 다름 (의료 영상 등)
데이터가 적다특징 추출. 미세조정은 조심스럽게앞쪽 몇 단계의 특징만 쓰고 뒤를 새로 학습, 증강을 강하게
데이터가 많다미세조정미세조정(사전학습 가중치가 초기화로서 여전히 도움이 된다)

미세조정의 요령

  1. 차등 학습률. 앞쪽 층의 특징(경계, 질감)은 어느 문제에나 맞으므로 조금만 고치고, 뒤쪽 층과 새 머리는 크게 고친다. 층 그룹마다 학습률을 달리 준다(예: 앞쪽 0.1배 → 머리 1배). PyTorch에서는 옵티마이저에 파라미터 그룹 목록을 넘긴다(29일차).
  2. 워밍업. 새 머리는 무작위로 시작하므로 처음에는 큰 기울기를 몸통으로 보낸다. 학습률을 작게 시작해 서서히 올리면(23일차) 이 충격이 줄어든다.
  3. 배치 정규화. 몸통을 얼릴 때는 배치 정규화 층도 평가 모드로 두어 ImageNet의 이동 평균 통계를 그대로 쓴다. 학습 모드로 두면 가중치는 얼었어도 작은 배치의 통계로 정규화되어 특징이 흔들린다.
  4. 입력 맞추기. 사전학습 때와 같은 전처리를 쓴다. ImageNet 모델은 RGB 순서, 224 × 224 근처의 크기, 채널별 평균 (0.485, 0.456, 0.406)과 표준편차 (0.229, 0.224, 0.225)로 정규화한 입력을 기대한다.
from torchvision.models import resnet18, ResNet18_Weights

model = resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)   # ImageNet 사전학습 가중치
model.fc = nn.Linear(model.fc.in_features, 102)             # 새 머리 (512 → 102)

for name, p in model.named_parameters():                    # 특징 추출: 머리만 학습
    p.requires_grad = name.startswith("fc.")

데이터 증강

데이터가 적을수록 증강(26일차)의 효과가 크다. 영상 분류에서 흔히 쓰는 증강과 그 뜻은 다음과 같다.

증강가르치는 것주의
무작위 크기 조절 자르기물체의 크기와 위치가 달라도 같은 클래스너무 작게 자르면 물체가 빠진다
좌우 뒤집기좌우 방향은 클래스와 무관글자, 숫자, 방향이 중요한 표지판에는 쓰지 않는다
색 변화(밝기, 대비, 채도)조명과 카메라가 달라도 같은 클래스색이 클래스를 가르는 문제(익은 과일 등)에서는 약하게
회전, 기울이기약간 기울어져도 같은 클래스6과 9처럼 회전에 민감한 경우
RandAugment, TrivialAugment여러 변환을 무작위로 골라 적용강도를 하이퍼파라미터 하나로 조절

평가할 때는 무작위성이 없어야 한다. 짧은 변을 256으로 줄이고 가운데 224 × 224를 자르는 것이 표준이다. 학습용과 평가용 변환을 따로 만드는 이유다.

Mixup과 CutMix

보통의 증강은 이미지 한 장을 바꾸고 레이블은 그대로 둔다. Mixup과 CutMix는 두 이미지를 섞고 레이블도 섞는다.

  • Mixup(Zhang et al., 2018): $\tilde x = \lambda x_i + (1-\lambda)x_j$, $\tilde y = \lambda y_i + (1-\lambda)y_j$. $\lambda \sim \mathrm{Beta}(\alpha, \alpha)$이고 $\alpha$는 0.2~1 정도다.
  • CutMix(Yun et al., 2019): $x_i$의 사각형 영역을 $x_j$의 같은 영역으로 바꾸고, 붙인 면적의 비율로 레이블을 섞는다.

섞은 레이블에 대한 교차 엔트로피는 두 레이블에 대한 교차 엔트로피의 가중합과 같다: $\mathrm{CE}(p, \lambda y_i + (1-\lambda)y_j) = \lambda\,\mathrm{CE}(p, y_i) + (1-\lambda)\,\mathrm{CE}(p, y_j)$. 그래서 정수 레이블 두 개와 $\lambda$만 있으면 된다. 두 방법 모두 결정 경계 근처를 매끄럽게 만들고 모델이 과하게 확신하는 것을 줄인다(26일차의 레이블 스무딩과 비슷한 효과). CutMix는 지역적 특징을 유지하면서 물체의 일부만 보고도 판단하도록 가르친다.

def cutmix(x, y, alpha=1.0):
    lam = float(np.random.beta(alpha, alpha))
    perm = torch.randperm(len(x), device=x.device)              # 섞을 짝
    H, W = x.shape[-2:]
    h, w = int(H * math.sqrt(1 - lam)), int(W * math.sqrt(1 - lam))
    cy, cx = np.random.randint(H), np.random.randint(W)
    y0, y1 = max(cy - h // 2, 0), min(cy + h // 2, H)
    x0, x1 = max(cx - w // 2, 0), min(cx + w // 2, W)
    x = x.clone()
    x[:, :, y0:y1, x0:x1] = x[perm, :, y0:y1, x0:x1]
    lam = 1 - (y1 - y0) * (x1 - x0) / (H * W)                   # 실제로 붙인 면적
    return x, y, y[perm], lam

# 손실: lam * CE(out, y) + (1 - lam) * CE(out, y[perm])

실험 설계

오늘의 비교는 다음 원칙을 지킨다(12, 27일차).

  1. 같은 조건. 모든 방법에 같은 증강, 같은 옵티마이저(AdamW, 원사이클), 같은 에폭 수를 쓴다. 바꾸는 것은 비교하려는 한 가지뿐이다.
  2. 검증 세트로 고르기. Flowers102에는 공식 검증 세트(1,020장)가 있다. 방법은 검증 정확도로 고른다.
  3. 테스트는 한 번. 고른 방법 하나만 테스트 세트(6,149장)로 평가한다.
  4. 잡음 감안. 검증 세트가 1,020장이면 정확도 1%p가 10장이다. 1~2%p 차이는 시드에 따라 뒤집힐 수 있다.

정리

  • 전이학습: 큰 데이터로 배운 특징을 작은 데이터 문제로 옮긴다. 머리(마지막 층)만 새로 만든다.
  • 특징 추출(몸통 얼림)은 빠르고 안전하고, 미세조정(전체 학습)은 보통 더 정확하다. 학습률이 크면 파국적 망각.
  • 요령: 차등 학습률, 워밍업, 얼린 부분의 배치 정규화는 평가 모드, 사전학습과 같은 전처리.
  • 증강은 레이블을 지키는 범위에서. Mixup·CutMix는 이미지와 레이블을 함께 섞는다.

확인 문제

연습 문제

  1. Mixup의 $\alpha$를 0.1과 2로 바꾸면 $\lambda$의 분포가 어떻게 달라지는가? 각각 어떤 효과가 예상되는가?
    풀이

    Beta(0.1, 0.1)은 0과 1 근처에 몰린 U자 분포라 대부분 한 이미지가 지배하고 가끔만 섞인다(약한 규제). Beta(2, 2)는 0.5 근처에 모인 분포라 거의 반반 섞인 이미지가 많다(강한 규제, 과소적합 위험).

  2. 노트북의 FrozenBN 감싸개 없이 특징 추출을 하면 어떤 일이 생기는지 예측하고 실행해 확인하라.
    풀이

    학습 중 배치 정규화가 배치 통계를 쓰고 이동 평균을 Flowers102 통계로 바꾼다. 가중치를 얼렸는데도 평가 때 쓰는 통계가 바뀌어 특징이 달라진다. 배치가 작으면(32) 통계가 흔들려 정확도가 떨어지기 쉽다.

  3. 사전학습 데이터와 아주 다른 흑백 X선 사진 300장으로 질병 유무를 분류하려 한다. 입력 처리와 학습 방법을 설계하라.
    풀이

    흑백 한 채널을 세 번 복사해 RGB 형식으로 만들고(또는 첫 합성곱의 가중치를 채널 방향으로 더해 1채널 합성곱으로 바꾼다), ImageNet 정규화를 그대로 쓴다. 데이터가 적고 분포가 다르므로 앞쪽 단계는 아주 작은 학습률로, 뒤쪽 단계와 머리는 크게 미세조정한다. 좌우 뒤집기는 장기 위치(심장은 왼쪽)를 바꾸므로 피하고, 작은 회전·밝기·대비 변화를 쓴다. 의료 영상으로 사전학습한 모델이 있으면 그쪽을 쓴다.

미니 프로젝트: Flowers102 전이학습

ResNet-18로 같은 조건에서 여섯 가지 방법을 학습해 검증 정확도로 비교하고, 가장 좋은 방법으로 테스트 세트를 평가한다.
