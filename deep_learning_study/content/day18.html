• 수치 미분으로 모든 파라미터의 기울기를 구하는 방법이 왜 비현실적인지 설명할 수 있다.
  • 식을 계산 그래프로 그리고, 국소 기울기와 상류 기울기로 역전파를 손으로 수행할 수 있다.
  • 덧셈, 곱셈, max, 분기 노드에서 기울기가 흐르는 규칙을 설명할 수 있다.
  • 선형층, ReLU, 소프트맥스+교차 엔트로피의 행렬 역전파 공식을 유도하고 형상으로 검산할 수 있다.
  • 2층 신경망의 역전파를 구현하고 수치 미분으로 검증할 수 있다.

기울기를 어떻게 구할 것인가

경사하강법에는 모든 파라미터에 대한 손실의 기울기가 필요하다. 5일차의 수치 미분은 파라미터 하나를 $\pm h$만큼 바꿔 순전파를 두 번 하는 방법이다. 파라미터가 $P$개면 순전파를 $2P$번 해야 한다. 17일차의 MNIST MLP(파라미터 23만 개)라면 한 스텝에 순전파 47만 번이다. 학습은 수만 스텝이므로 불가능하다.

역전파는 순전파 한 번과 그 약 두 배 비용의 역방향 계산 한 번으로 모든 파라미터의 기울기를 정확히 구한다. 아이디어는 5일차의 연쇄법칙을 출력 쪽부터 적용하며 중간 결과를 재사용하는 것이다. 이것을 체계적으로 하는 도구가 계산 그래프다.

계산 그래프

복잡한 식을 덧셈, 곱셈, 지수 같은 기본 연산으로 쪼개, 연산을 노드로, 값의 흐름을 화살표로 그린 그림을 계산 그래프라 한다. $f(x, y, z) = (x + y)\,z$를 예로 든다.

국소 기울기와 상류 기울기

역전파는 출력에서 시작한다. $\partial f/\partial f = 1$. 그다음 노드마다 같은 일을 반복한다. 노드 $u = g(a, b)$가 있을 때

  • 상류 기울기 $\dfrac{\partial f}{\partial u}$: 출력에서 이 노드의 출력까지 이미 계산되어 넘어온 기울기.
  • 국소 기울기 $\dfrac{\partial u}{\partial a}$, $\dfrac{\partial u}{\partial b}$: 노드 자기 연산만의 미분. 다른 노드를 몰라도 계산할 수 있다.

연쇄법칙에 따라 입력 쪽으로 보낼 기울기는 둘의 곱이다.

$$\frac{\partial f}{\partial a} = \underbrace{\frac{\partial f}{\partial u}}_{\text{상류}}\cdot\underbrace{\frac{\partial u}{\partial a}}_{\text{국소}}$$
  1. $f = q\cdot z$: 국소 기울기 $\partial f/\partial q = z = -4$, $\partial f/\partial z = q = 3$. 상류가 1이므로 $\partial f/\partial q = -4$, $\partial f/\partial z = 3$.
  2. $q = x + y$: 국소 기울기 $\partial q/\partial x = 1$, $\partial q/\partial y = 1$. 상류 $-4$를 곱해 $\partial f/\partial x = -4$, $\partial f/\partial y = -4$.

검산: $f = (x + y)z$이므로 $\partial f/\partial x = z = -4$, $\partial f/\partial z = x + y = 3$. 맞다. $x$를 0.01 늘리면 $f$는 약 0.04 줄어든다.

각 노드는 "자기 연산의 국소 미분"만 알면 된다. 그래프가 수천 층이어도, 노드 하나의 일은 상류 기울기를 받아 국소 기울기를 곱해 입력들에게 나눠 주는 것뿐이다. 이 지역성 덕분에 역전파는 어떤 구조의 신경망에도 그대로 적용된다.

노드별 패턴

노드순전파역전파 (상류 $g$)기억법
덧셈$u = a + b$$a$에 $g$, $b$에 $g$분배기: 그대로 복사
곱셈$u = a\cdot b$$a$에 $g\cdot b$, $b$에 $g\cdot a$교환기: 상대의 값을 곱함
max$u = \max(a, b)$큰 쪽에 $g$, 작은 쪽에 0라우터: 이긴 쪽으로만
분기(복사)$a$를 두 곳에서 사용두 경로의 기울기를 더함합류: 기울기 합
함수 $\phi$$u = \phi(a)$$a$에 $g\cdot\phi'(a)$$\sigma$면 $g\,u(1 - u)$, ReLU면 $a > 0$일 때만 $g$

분기 규칙이 중요하다. 한 값이 여러 곳에서 쓰이면 그 값을 조금 바꿨을 때 모든 경로로 영향이 퍼지므로, 각 경로의 기울기를 더해야 한다(다변수 연쇄법칙). 신경망에서 한 층의 출력은 다음 층의 모든 뉴런으로 갈라지므로 이 합이 행렬곱 $GW^\top$의 형태로 나타난다. 위 인터랙티브의 "분기" 그래프에서 $x$의 기울기가 $y + 1$이 되는 것을 확인한다.

ReLU는 max 노드($\max(0, z)$)이므로, $z > 0$이면 기울기를 그대로 통과시키고 $z \le 0$이면 막는다. 죽은 ReLU(16일차)가 왜 회복하지 못하는지 이 규칙으로 설명된다.

뉴런 하나의 역전파

로지스틱 회귀 뉴런 $L = -\ln\sigma(w_1x_1 + w_2x_2 + b)$(정답 $y = 1$)를 그래프로 그리면 곱셈 두 개, 덧셈, 시그모이드, $-\ln$ 노드가 이어진다. 위 인터랙티브의 "뉴런" 그래프가 이것이다. $w_1 = 2, x_1 = -1, w_2 = -3, x_2 = -2, b = -3$이면

  1. 순전파: $s = -2 + 6 - 3 = 1$, $p = \sigma(1) = 0.731$, $L = -\ln0.731 = 0.313$.
  2. $-\ln$ 노드: 국소 기울기 $-1/p = -1.368$. 상류 1을 곱해 $\partial L/\partial p = -1.368$.
  3. 시그모이드 노드: 국소 기울기 $p(1 - p) = 0.197$. $\partial L/\partial s = -1.368\times0.197 = -0.269$. 이는 $p - y = 0.731 - 1$과 같다(10일차).
  4. 덧셈 노드: $\partial L/\partial b = -0.269$, 두 곱셈 노드로도 $-0.269$씩 복사.
  5. 곱셈 노드: $\partial L/\partial w_1 = -0.269\times x_1 = 0.269$, $\partial L/\partial x_1 = -0.269\times w_1 = -0.538$. 같은 방식으로 $\partial L/\partial w_2 = 0.538$, $\partial L/\partial x_2 = 0.807$.

입력 $x$에 대한 기울기도 함께 나온다. 학습에는 쓰지 않지만, 이 값이 앞쪽 층으로 넘어가는 상류 기울기가 된다. 신경망은 층마다 이 일을 반복한다.

층 단위 역전파 공식

신경망을 스칼라 노드로 그리면 노드가 수백만 개다. 대신 층 하나를 행렬 연산 노드로 보고 행렬 형태의 공식을 쓴다. 이렇게 계산 그래프를 따라 출력에서 입력 방향으로 기울기를 전달하는 알고리즘이 역전파다(1986년 러멜하트, 힌턴, 윌리엄스가 대중화).

선형층

$Z = XW + \mathbf b$에서 상류 기울기 $G = \partial L/\partial Z$(형상 $(N, h)$)가 주어졌다고 하자. 원소로 쓰면 $Z_{ij} = \sum_k X_{ik}W_{kj} + b_j$이므로

$$\frac{\partial L}{\partial W_{kj}} = \sum_i G_{ij}X_{ik},\qquad \frac{\partial L}{\partial b_j} = \sum_i G_{ij},\qquad \frac{\partial L}{\partial X_{ik}} = \sum_j G_{ij}W_{kj}$$

이를 행렬로 쓰면 세 공식이 된다.

$$\frac{\partial L}{\partial W} = X^\top G,\qquad \frac{\partial L}{\partial\mathbf b} = \sum_{i}G_{i,:}\;(\text{행 방향 합}),\qquad \frac{\partial L}{\partial X} = GW^\top$$

형상 검산: $X^\top G$는 $(d, N)(N, h) = (d, h)$로 $W$와 같다. $GW^\top$는 $(N, h)(h, d) = (N, d)$로 $X$와 같다. 기울기의 형상은 항상 변수의 형상과 같다(5일차).

$\partial L/\partial W$에 배치의 모든 표본 기여가 더해지는 것은 $W$가 모든 표본에서 공유되기 때문이다(분기 규칙). $\partial L/\partial\mathbf b$가 행 방향 합인 것도 같은 이유다(브로드캐스팅의 역연산은 합).

ReLU와 출력층

ReLU: $A = \max(0, Z)$이면 $\partial L/\partial Z = \partial L/\partial A \odot \mathbb 1[Z > 0]$($\odot$은 원소별 곱). 소프트맥스와 교차 엔트로피를 합친 출력층은 11일차의 결과 그대로 $\partial L/\partial Z = (P - Y)/N$이다($Y$는 원-핫, $N$으로 나누는 것은 손실이 평균이기 때문).

2-2-1 신경망을 숫자로 따라가기

입력 2개, 은닉 뉴런 2개(시그모이드), 출력 1개(시그모이드 + BCE)인 신경망에서 표본 하나의 순전파, 역전파, 갱신을 한 단계씩 진행한다. 각 단계의 숫자를 먼저 손으로 계산한 뒤 "다음"을 눌러 확인한다.

은닉층의 기울기 $\delta^{(1)}_j = (W_{2,j}\,\delta^{(2)})\cdot h_j(1 - h_j)$는 세 단계로 읽는다. 출력의 오차 $\delta^{(2)}$가 가중치 $W_{2,j}$를 타고 은닉 뉴런 $j$로 돌아오고(곱셈 노드), 시그모이드의 국소 기울기 $h_j(1 - h_j)$를 곱해 활성화 이전으로 넘어간다. 가중치가 큰 연결일수록 오차를 많이 돌려받는다.

역전파의 비용

선형층의 역전파는 행렬곱 두 개($X^\top G$, $GW^\top$)이므로 순전파 행렬곱 하나의 두 배 FLOPs가 든다. 따라서 학습 한 스텝(순전파 + 역전파)은 순전파의 약 3배다. 메모리는 순전파에서 저장한 중간값이 차지하며, 층이 깊고 배치가 클수록 늘어난다. 큰 모델을 학습할 때 메모리가 부족하면 중간값 일부를 버렸다가 역전파 때 다시 계산하는 기법(그래디언트 체크포인팅)을 쓴다.

코드 실습: 행렬 역전파와 검증

그림의 $(x + y)z$부터 코드로 옮긴다. 순전파 값을 저장하고, 역순으로 국소 기울기를 곱한다.

import numpy as np
x, y, z = -2.0, 5.0, -4.0
q = x + y; f = q * z                      # 순전파
df = 1.0
dq, dz = z * df, q * df                   # 곱셈 노드: 서로 바꿔 곱함
dx, dy = 1.0 * dq, 1.0 * dq               # 덧셈 노드: 그대로 분배
print(f"f = {f},  ∂f/∂x = {dx}, ∂f/∂y = {dy}, ∂f/∂z = {dz}")

다음은 손글씨 숫자 64 → 32 → 10 MLP의 한 배치에 대한 역전파다. 그림의 공식을 그대로 옮긴 뒤, 몇 개의 파라미터를 골라 수치 미분과 비교한다.

d = load_data("digits")
X, yl = d["X"][:64].astype(float) / 16, d["y"][:64]            # 표본 64개
rng = np.random.default_rng(0)
W1, b1 = rng.normal(0, np.sqrt(2 / 64), (64, 32)), np.zeros(32)
W2, b2 = rng.normal(0, np.sqrt(2 / 32), (32, 10)), np.zeros(10)
Y = np.eye(10)[yl]

def forward(W1, b1, W2, b2):
    Z1 = X @ W1 + b1; A1 = np.maximum(0, Z1); Z2 = A1 @ W2 + b2
    Zs = Z2 - Z2.max(1, keepdims=True)
    P = np.exp(Zs) / np.exp(Zs).sum(1, keepdims=True)
    L = -np.log(P[np.arange(len(yl)), yl]).mean()
    return L, (Z1, A1, P)

L, (Z1, A1, P) = forward(W1, b1, W2, b2)
N = len(X)
G2 = (P - Y) / N                                  # (64, 10)
dW2 = A1.T @ G2; db2 = G2.sum(0)                  # (32, 10), (10,)
dA1 = G2 @ W2.T                                   # (64, 32)
G1 = dA1 * (Z1 > 0)                               # ReLU
dW1 = X.T @ G1; db1 = G1.sum(0)                   # (64, 32), (32,)

def numeric(param, idx, h=1e-5):
    old = param[idx]
    param[idx] = old + h; Lp = forward(W1, b1, W2, b2)[0]
    param[idx] = old - h; Lm = forward(W1, b1, W2, b2)[0]
    param[idx] = old
    return (Lp - Lm) / (2 * h)
for name, param, grad, idx in [("W1", W1, dW1, (10, 3)), ("b1", b1, db1, (5,)),
                               ("W2", W2, dW2, (7, 2)), ("b2", b2, db2, (4,))]:
    print(f"{name}{idx}: 역전파 {grad[idx]: .6e}, 수치 미분 "
          f"{numeric(param, idx): .6e}")

모든 쌍이 유효숫자 6자리 이상 일치한다. 역전파 코드는 이렇게 수치 미분과 비교해 검증한다(20일차에 전체 파라미터로 체계화한다).

정리

  • 수치 미분은 파라미터마다 순전파 2번 → 큰 모델에 불가능. 역전파는 순전파 약 2배 비용으로 모든 기울기를 구한다.
  • 계산 그래프에서 각 노드는 상류 기울기 × 국소 기울기를 입력에 전달한다. 출력에서 1로 시작한다.
  • 덧셈은 복사, 곱셈은 교환해 곱함, max는 라우팅, 분기는 기울기 합.
  • 선형층: $dW = X^\top G$, $d\mathbf b = \sum G$, $dX = GW^\top$. ReLU는 마스크, 소프트맥스+CE는 $(P - Y)/N$.
  • 순전파에서 저장한 중간값을 역전파에서 쓴다. 구현은 항상 수치 미분으로 검증.

확인 문제

연습 문제

  1. $f = \max(x, y)\cdot z$에서 $x = 3, y = 1, z = -2$일 때 세 기울기를 계산 그래프로 구하라.
    풀이

    순전파 $m = \max(3, 1) = 3$, $f = -6$. 곱셈 노드: $\partial f/\partial m = z = -2$, $\partial f/\partial z = m = 3$. max 노드는 큰 쪽 $x$로만 보낸다: $\partial f/\partial x = -2$, $\partial f/\partial y = 0$.

  2. $f = \sigma(w x + b)$에서 $w = 0.5, x = 2, b = -1$일 때 $\partial f/\partial w$와 $\partial f/\partial b$를 구하라.
    풀이

    $s = 0$, $f = \sigma(0) = 0.5$. 국소 기울기 $f(1 - f) = 0.25$. $\partial f/\partial b = 0.25$, $\partial f/\partial w = 0.25\cdot x = 0.5$.

  3. MSE 손실 $L = \frac1N\sum_i(\hat y_i - y_i)^2$을 쓰는 회귀 신경망(출력층 활성화 없음)에서 출력층의 상류 기울기 $G = \partial L/\partial\hat{\mathbf y}$는 무엇인가? 8일차의 정규방정식 유도와 연결하라.
    풀이

    $G = \frac2N(\hat{\mathbf y} - \mathbf y)$. 선형회귀(은닉층 없음)라면 $\partial L/\partial W = X^\top G = \frac2N X^\top(X\boldsymbol\theta - \mathbf y)$로 8일차의 그래디언트와 같다. 역전파는 이미 아는 식을 일반화한 것이다.

미니 프로젝트: 2층 신경망 역전파 손계산과 검증

인터랙티브에서 따라간 2-2-1 신경망의 역전파를 NumPy로 재현하고 모든 파라미터의 기울기를 수치 미분과 비교한다. 이어서 17일차의 층 객체에 backward를 추가하고, 소프트맥스 교차 엔트로피 손실과 함께 손글씨 MLP 전체에서 기울기를 검증한다.

  1. 손계산 재현. 인터랙티브의 값으로 순전파와 역전파를 계산해 각 단계의 숫자를 출력한다. 
    import numpy as np
sig = lambda z: 1 / (1 + np.exp(-z))
x = np.array([1.0, 0.5]); y = 1.0
W1 = np.array([[0.5, -0.3], [0.2, 0.4]]); b1 = np.array([0.1, -0.1])
W2 = np.array([0.7, -0.5]); b2 = 0.2
def loss_fn(W1, b1, W2, b2):
    h = sig(x @ W1 + b1); p = sig(h @ W2 + b2)
    return -(y * np.log(p) + (1 - y) * np.log(1 - p)), h, p
L, h, p = loss_fn(W1, b1, W2, b2)
d2 = p - y                                  # ∂L/∂z2
gW2, gb2 = h * d2, d2
dh = W2 * d2
d1 = dh * h * (1 - h)                       # TODO 확인: 시그모이드 통과
gW1, gb1 = np.outer(x, d1), d1              # xᵀδ1
print(f"h = {h.round(4)}, p = {p:.4f}, L = {L:.4f}")
print(f"δ2 = {d2:.4f}, ∂W2 = {gW2.round(4)}, ∂h = {dh.round(4)}, δ1 = {d1.round(4)}")

  3. 프레임워크에 backward 붙이기. 17일차의 층에 backward(G)를 추가한다. 선형층은 dW, db를 저장하고 dX를 반환한다. 손실은 소프트맥스와 교차 엔트로피를 합친 객체로 만든다. 
    class Linear:
    def __init__(self, d_in, d_out, rng):
        self.W = rng.normal(0, np.sqrt(2 / d_in), (d_in, d_out))
        self.b = np.zeros(d_out)
    def forward(self, X):
        self.X = X; return X @ self.W + self.b
    def backward(self, G):
        self.dW = self.X.T @ G                       # TODO 확인
        self.db = G.sum(axis=0)
        return G @ self.W.T
class ReLU:
    def forward(self, X):
        self.mask = X > 0; return X * self.mask
    def backward(self, G): return G * self.mask
class SoftmaxCE:
    def forward(self, Z, y):
        Z = Z - Z.max(1, keepdims=True)
        self.P = np.exp(Z) / np.exp(Z).sum(1, keepdims=True)
        self.y = y
        return -np.log(self.P[np.arange(len(y)), y]).mean()
    def backward(self):
        G = self.P.copy(); G[np.arange(len(self.y)), self.y] -= 1
        return G / len(self.y)                       # (P − Y)/N
class Sequential:
    def __init__(self, *layers): self.layers = list(layers)
    def forward(self, X):
        for l in self.layers: X = l.forward(X)
        return X
    def backward(self, G):
        for l in reversed(self.layers): G = l.backward(G)
        return G
