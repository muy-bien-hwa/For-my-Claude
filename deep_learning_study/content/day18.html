• LeNet → AlexNet → VGG → GoogLeNet → ResNet → 현대 CNN으로 이어지는 설계 아이디어의 흐름을 안다.
  • "깊을수록 학습이 안 되는" 성능 저하 문제와 잔차 연결이 그것을 해결하는 원리를 이해한다.
  • Conv-BN-ReLU 블록과 ResNet BasicBlock을 PyTorch로 구현한다.
  • CIFAR-10에서 작은 ResNet으로 90% 이상 정확도를 목표로 학습한다.
👨‍🏫 아키텍처의 역사는 '아이디어의 역사' CNN 아키텍처를 외울 필요는 없습니다. 하지만 각 모델이 어떤 문제를 풀려고 무엇을 바꿨는지는 꼭 알아야 합니다. 그 아이디어(작은 커널, 1×1 합성곱, 정규화, 잔차 연결)는 CNN을 넘어 Transformer에서도 그대로 쓰이기 때문입니다.

1. 연대기와 핵심 아이디어

모델 (연도)깊이핵심 아이디어

2. VGG: 단순함의 힘

"3×3 Conv 몇 개 → MaxPool"을 블록으로 반복하고, 풀링할 때마다 채널을 2배로 늘립니다(64 → 128 → 256 → 512). 해상도를 줄이는 대신 채널을 늘려 정보량을 유지하는 이 패턴은 지금도 표준입니다.

def conv_bn_relu(c_in, c_out, stride=1):
    return nn.Sequential(
        nn.Conv2d(c_in, c_out, 3, stride=stride, padding=1, bias=False),   # BN이 편향 역할을 하므로 bias=False
        nn.BatchNorm2d(c_out),
        nn.ReLU(inplace=True))

vgg_like = nn.Sequential(
    conv_bn_relu(3, 64),   conv_bn_relu(64, 64),   nn.MaxPool2d(2),     # 32 → 16
    conv_bn_relu(64, 128), conv_bn_relu(128, 128), nn.MaxPool2d(2),     # 16 → 8
    conv_bn_relu(128, 256), conv_bn_relu(256, 256), nn.MaxPool2d(2),   # 8 → 4
    nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(256, 10))

3. 깊이의 역설: 성능 저하 문제

BN과 He 초기화로 기울기 소실을 어느 정도 해결했는데도, 이상한 일이 관찰됐습니다. 20층 망보다 56층 망이 학습 오차조차 더 높았습니다. 과적합이라면 학습 오차는 낮아야 하니, 이건 과적합이 아니라 최적화가 어려워진 것입니다.

이론적으로는 56층 망이 최소한 20층 망만큼은 해야 합니다. 앞 20층을 그대로 복사하고 나머지 36층이 항등함수를 학습하면 되니까요. 그런데 여러 비선형 층이 정확히 항등함수를 학습하는 것은 의외로 어렵습니다.

4. 잔차 연결: 차이만 배워라

He 등(2015)의 해법은 간단했습니다. 층이 원하는 함수 $H(x)$를 직접 배우게 하지 말고, 입력과의 차이(잔차) $F(x) = H(x) - x$를 배우게 합니다.

$$\mathbf y = \mathbf x + F(\mathbf x)$$
🔑 잔차 연결이 강력한 두 가지 이유
  1. 항등함수가 기본값이 된다: 블록이 쓸모없으면 $F(\mathbf x) = 0$, 즉 가중치를 0 근처로 두기만 하면 됩니다. 쉽습니다.
  2. 기울기 고속도로: Day 10의 덧셈 노드를 떠올리세요. 상류 기울기가 그대로 복사되어 지름길로 흐릅니다. $\frac{\partial\mathbf y}{\partial\mathbf x} = I + \frac{\partial F}{\partial\mathbf x}$. 항등 항 $I$ 덕분에 기울기가 아무리 깊어도 사라지지 않습니다.

이 아이디어는 딥러닝 전체로 퍼졌습니다. Transformer의 모든 블록에도 잔차 연결이 있습니다(Day 23).

5. ResNet BasicBlock 구현

class BasicBlock(nn.Module):
    def __init__(self, c_in, c_out, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(c_in, c_out, 3, stride, 1, bias=False); self.bn1 = nn.BatchNorm2d(c_out)
        self.conv2 = nn.Conv2d(c_out, c_out, 3, 1, 1, bias=False);     self.bn2 = nn.BatchNorm2d(c_out)
        self.shortcut = nn.Identity()
        if stride != 1 or c_in != c_out:            # 형상이 바뀌면 지름길도 1x1 conv로 맞춰 준다
            self.shortcut = nn.Sequential(nn.Conv2d(c_in, c_out, 1, stride, bias=False), nn.BatchNorm2d(c_out))
    def forward(self, x):
        out = F.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return F.relu(out + self.shortcut(x))       # ← 잔차 연결

class ResNet(nn.Module):
    """CIFAR용 작은 ResNet (ResNet-18 구조를 32x32에 맞게)"""
    def __init__(self, blocks=(2, 2, 2, 2), widths=(64, 128, 256, 512), n_classes=10):
        super().__init__()
        self.stem = nn.Sequential(nn.Conv2d(3, widths[0], 3, 1, 1, bias=False), nn.BatchNorm2d(widths[0]), nn.ReLU())
        layers, c_in = [], widths[0]
        for i, (n, w) in enumerate(zip(blocks, widths)):
            for j in range(n):
                layers.append(BasicBlock(c_in, w, stride=2 if (j == 0 and i > 0) else 1)); c_in = w
        self.layers = nn.Sequential(*layers)
        self.head = nn.Sequential(nn.AdaptiveAvgPool2d(1), nn.Flatten(), nn.Linear(c_in, n_classes))
    def forward(self, x): return self.head(self.layers(self.stem(x)))

model = ResNet()
x = torch.randn(2, 3, 32, 32); print(model(x).shape)              # torch.Size([2, 10])
print(f"{sum(p.numel() for p in model.parameters())/1e6:.1f}M 파라미터")  # 약 11.2M

ResNet-50 이상은 병목 블록(1×1로 채널 축소 → 3×3 → 1×1로 복원)을 써서 연산량을 줄입니다. GoogLeNet의 1×1 아이디어입니다.

6. 실험으로 확인: 잔차 연결의 효과

노트북에는 같은 깊이(20층)의 "plain" 망과 ResNet을 비교하는 실험이 있습니다. 잔차 연결을 끄는 옵션(use_residual=False)을 넣어 두었으니 학습 곡선을 비교해 보세요. 그리고 첫 층 합성곱 필터를 시각화해서 CNN이 실제로 "선과 색 검출기"를 학습했는지도 확인합니다.

💡 CIFAR-10에서 90%를 넘기는 레시피
  • 모델: 위의 작은 ResNet
  • 증강: RandomCrop(32, padding=4) + RandomHorizontalFlip() + 정규화
  • 옵티마이저: SGD(momentum 0.9, nesterov) lr 0.1, weight_decay 5e-4 또는 AdamW lr 1e-3
  • 스케줄: OneCycle 또는 Cosine, 30~40 에폭

7. 현대 CNN의 기타 아이디어

  • 깊이별 분리 합성곱 (Depthwise separable): 채널별 3×3 합성곱 + 1×1 합성곱. 연산량을 약 8~9배 줄입니다(MobileNet).
  • Squeeze-and-Excitation: 채널별 중요도를 학습해 가중치를 곱하는 "채널 어텐션".
  • 전역 평균 풀링: 거대한 FC 층을 없애 파라미터를 크게 줄이고 입력 크기에 유연해집니다.
